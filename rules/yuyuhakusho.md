# 《幽游白书：魔强统一战》开发规范

适用范围：`games/yuyuhakusho/`。通用、即时游戏、复刻、控制器、加载与音频要求沿用各专题规范。

## 房间与控制

- 开放 2／3／4 人混战和 4 人组队；原版角色槽分别为 `[0,3]`、`[0,1,3]`、`[0,1,2,3]`。平台席位负责鉴权与托管，不能直接作为原版槽号。四人组队为槽 0／1 对槽 2／3；未占用的原版槽不自动生成电脑。
- 来源角色 8 是户愚吕兄，10 是户愚吕弟。11 个人物与八个偶数场地 ID `0/2/4/6/8/a/c/e` 分别维护玩法和素材证据；不得根据画像或旧错误名称交换来源编号。
- 控制器方案 ID／契约布局为 `md-6`，SVG 的 `data-controller-layout="md"` 只是视觉属性。默认 W／S／A／D、F Mode、空格 Start、J B、K A、L C、U X、I Y、O Z；U／I 是普通 X／Y，不使用 FC 连发。按键必须完整保留 12 bit。

## 共享状态与呈现

- `World.Stream` 是录制输入与 Pan 行数据的唯一 owner，`PanRows` 只能作为临时视图。对象、图块槽、HUD 引用和音频各流水阶段只保存不可互推的状态，不持久保留原 RAM、SAT、像素或同字段的 byte／word／long 副本。
- schema 1 的旧像素呈现与 schema 2 的共享引用状态互斥。规则和呈现 metadata 每步完整推进；无需显示的重放帧可以省略像素绘制，但实际绘制必须使用原回调时刻的 Draw 数据，不能用帧末对象反推。
- checkpoint 在 JavaScript 中保持原样字符串。帧号、`Present` 位集等 uint64 不得经过 Number 或 parse→stringify。资源验证使用原样解压字节及 descriptor 的大小／SHA，不能先重排 JSON。
- `Preview` 使用可丢弃分支。非终局可预览 F+1；真实完成帧保持 F，并保留其实际清场画面。不得用复制上一帧图像或额外存档历史掩盖终局判断错误。

## 音频

- 比赛音乐来自八场地选择、角色 override 和结算路径的明确 ID 闭包；平台准备流程不重放原版菜单。原菜单中真实出现的音乐须保留其流程边界，不能因本平台跳过菜单就改称诊断数据。
- 普通 PCM 与音乐 DAC 的描述协议分别解释。音乐只发布前六个字段并单独取声像，不能套用普通描述的第七字节语义；payload 以 encoded SHA 标识，目录借用同一份不可变字节。
- 飞影黑龙合法请求 `F0`，对应单独重映射的 descriptor index 122，不能当成普通 `7A`。`7F` 有真实单字节静音样本及预取生命周期；诊断目录分类不等于 `02/03/04` 控制码，也不等于没有样本。
- 声音请求、priority 写入、暂停确认和消费必须保留原顺序及实际线性化位置，不能把同帧请求全部放到帧尾消费，或把清优先级汇总 bool 统一前置／后置。忙标志、PCM 反馈和总线状态在各自读取阶段查询。
- 音乐分派完成初始化后结束当前 driver 拍，primary 技能音轨分派后继续本拍声部扫描。恢复目标按调用场景验证：all-primary stop 的 PSG3／noise 恢复 secondary slot 17，即使该 slot 不活动；普通 track-end 使用对应音乐 slot。不得只按通道复用恢复目标或多写一次噪声寄存器。
- FM 与 PSG 按各自输入时间域验证单调性，保留实际生产者顺序。总线同步后可能才提交较早的 PCM／YM 事件，不能用已推进的 PSG 总游标拒绝、排序、夹紧或丢弃它，也不能提前推进 PCM 而丢失主机争用成本。只保存不能从现有 owner 推导的时间差，不保留输入历史或第二份寄存器缓存。
- 暂停先取得真实总线，再捕获实际 YM total level；hold 不推进音乐参数、fade 或消费请求，resume 成功后才释放唯一 pending payload。`score.State.Ticks` 统计实际 driver 调用，暂停调用也计数，不能把它当成音乐推进次数。
- delayed request 的 delay 从 1 递减到 0 时不当次提交；busy 重入只增加 backlog，补跑在 driver 后递减当时的 backlog。enqueue 的负 slot 在 TST／CMP 分别读取，不得折成入口队列快照。音频联合状态不复制 World 的 queue、pause 或主时钟。
- 固定参考 profile 的 master cycle、帧末 lookahead 和 FIR 副效单独验证。保持实际调用顺序；Reset 的特定有界过冲不能推广为普通端口写任意回时。单曲、单样本或给定原时刻的 DSP 一致，不等于独立时序及真实混合对局音频已经通过。
