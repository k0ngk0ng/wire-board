# 《幽游白书：魔强统一战》开发规范

适用范围：`games/yuyuhakusho/`。通用、即时游戏、复刻、控制器、加载与音频要求沿用各专题规范。

## 房间与控制

- 开放 2／3／4 人混战和 4 人组队；原版角色槽分别为 `[0,3]`、`[0,1,3]`、`[0,1,2,3]`。平台席位负责鉴权与托管，不能直接作为原版槽号。四人组队为槽 0／1 对槽 2／3；未占用的原版槽不自动生成电脑。
- 来源角色 8 是户愚吕兄，10 是户愚吕弟。11 个人物与八个偶数场地 ID `0/2/4/6/8/a/c/e` 分别维护玩法和素材证据；不得根据画像或旧错误名称交换来源编号。
- 控制器方案 ID／契约布局为 `md-6`，SVG 的 `data-controller-layout="md"` 只是视觉属性。默认 W／S／A／D、F Mode、空格 Start、J B、K A、L C、U X、I Y、O Z；U／I 是普通 X／Y，不使用 FC 连发。按键必须完整保留 12 bit。

## 共享状态与呈现

- `World.Stream` 是录制输入与 Pan 行数据的唯一 owner，`PanRows` 只能作为临时视图。对象、图块槽、HUD 引用和音频各流水阶段只保存不可互推的状态，不持久保留原 RAM、SAT、像素或同字段的 byte／word／long 副本。
- schema 1 的旧像素呈现与 schema 2 的共享引用状态互斥。规则和呈现 metadata 每步完整推进；无需显示的重放帧可以省略像素绘制，但实际绘制必须使用原回调时刻的 Draw 数据，不能用帧末对象反推。
- checkpoint 在 JavaScript 中保持原样字符串。帧号、`Present` 位集等 uint64 不得经过 Number 或 parse→stringify。资源验证使用原样解压字节及 descriptor 的大小／SHA，不能先重排 JSON。
- `Preview` 使用可丢弃分支。非终局可预览 F+1；真实完成帧保持 F，并保留其实际清场画面。不得用复制上一帧图像或额外存档历史掩盖终局判断错误。

## 可玩版本的声音交付

- 当前先交付稳定可玩的媒体音频版本：音乐、台词和动作音效跟随实际对局请求播放，允许与原版有细微差异。精确到原硬件每拍的计时、声部抢占及音乐循环相位研究保留，后续按试玩反馈决定是否继续，不作为本版交付前提。
- 声音请求从实际规则步提取，作为临时呈现结果返回；收集请求不能改变规则、存档、摘要或画面，也不加入常规网络负载。按已呈现帧去重，网络校正、重连、取消静音和后台恢复不得补播旧音效。
- 沿用平台音频、无损压缩、按需加载与真实对局验收要求；分别记录已验证的可玩行为和仍有差异的声音细节。以下精确音频调度条款用于保留的研究与后续精修，不能据单项通过宣称整局逐拍一致。

## 音频

- 比赛音乐来自八场地选择、角色 override 和结算路径的明确 ID 闭包；平台准备流程不重放原版菜单。原菜单中真实出现的音乐须保留其流程边界，不能因本平台跳过菜单就改称诊断数据。
- 普通 PCM 与音乐 DAC 的描述协议分别解释。音乐只发布前六个字段并单独取声像，不能套用普通描述的第七字节语义；payload 以 encoded SHA 标识，目录借用同一份不可变字节。
- 飞影黑龙合法请求 `F0`，对应单独重映射的 descriptor index 122，不能当成普通 `7A`。`7F` 有真实单字节静音样本及预取生命周期；诊断目录分类不等于 `02/03/04` 控制码，也不等于没有样本。
- 声音请求、priority 写入、暂停确认和消费必须保留原顺序及实际线性化位置，不能把同帧请求全部放到帧尾消费，或把清优先级汇总 bool 统一前置／后置。忙标志、PCM 反馈和总线状态在各自读取阶段查询。
- 音乐分派完成初始化后结束当前 driver 拍，primary 技能音轨分派后继续本拍声部扫描。恢复目标按调用场景验证：all-primary stop 的 PSG3／noise 恢复 secondary slot 17，即使该 slot 不活动；普通 track-end 使用对应音乐 slot。不得只按通道复用恢复目标或多写一次噪声寄存器。
- FM 与 PSG 按各自输入时间域验证单调性，保留实际生产者顺序。总线同步后可能才提交较早的 PCM／YM 事件，不能用已推进的 PSG 总游标拒绝、排序、夹紧或丢弃它，也不能提前推进 PCM 而丢失主机争用成本。只保存不能从现有 owner 推导的时间差，不保留输入历史或第二份寄存器缓存。
- 暂停先取得真实总线，再捕获实际 YM total level；hold 不推进音乐参数、fade 或消费请求，resume 成功后才释放唯一 pending payload。`score.State.Ticks` 统计实际 driver 调用，暂停调用也计数，不能把它当成音乐推进次数。
- 世界组件的临时队列视图不能覆盖中途声音消费：声音请求通过显式临时上下文访问 World 的唯一 queue／AudioPause owner；上下文、hook 和操作历史不进入存档。音频与世界须共同分叉，后续对象或帧末处理失败时一起撤销。请求介入点与事务通过，不代表世界耗时及 IRQ 接受时机已通过。
- 没有声音请求的世界计算也须提供实际工作边界；成本取当前分支、循环和数据相关计算，保留工作边界与长操作内部的 refresh 顺序。只给场景回调入口时钟的逐步一致，不等于全世界耗时、VDP 批次或 IRQ 接受已通过；未计价的路径不能按零耗时接入正式调度。
- 普通 IRQ 接受须核对屏蔽条件、当前工作结束后的实际批次边界和 CPU 相位。VDP 信号、异常入口与声音 driver 入口分别推进；RAM IRQ 等待与控制器扫描不可省略。延迟寄存器写入和降屏蔽指令内部接受不能直接套用普通批次入口模型。
- 采样 IRQ 的前置流程与声音调用共用主时钟、refresh 和 CPU 预算。主批次完成后按该批次目标推进同一后台播放器，真实争用须在下一主操作前加回；不能只在 YM 请求时同步，或到声音结束后统一补跑。入口后台须已到当前扫描线起点，避免重算历史争用。中断尾部未完成时不得恢复世界执行。
- 世界传输等待、播放器 Busy 和总线持有分别维护。传输等待只在取得实际总线后写入，由 PCM 各读取阶段采样；读后分支须保留已读值，不能统一停掉全部输出。世界入口的总线读改写按旧读值分支，暂停确认 FF 时保留总线；仅在真实持有总线时允许后台进度落后当前扫描线。世界入口完成仍须等待后续 DMA、世界调用和中断返回，不能提前恢复角色更新。
- 图形 DMA 按每项长度、目标、当前扫描线和垂直消隐阶段推进。参考 VDP 后续批次会重设主机及已经等待总线的后台时刻，不能重复累加原指令尾部或夹紧结果；恰好用完预算与 refresh 越过行尾时须保持原比较和 uint32 运算。传输与世界包装可以跨视频帧，恢复 SR 时可以立即进入垂直中断；单项传输耗时一致不能替代跨帧世界／IRQ 联合验收。
- 中断前置、世界包装、DMA 和垂直中断共用主时钟、refresh、预算与跨帧协调器；前置流程也可能跨帧。连续主时刻用于保存和组合，原参考每帧重置的 IRQ 接受相位须先减去当前 FrameOrigin，不能直接取绝对时刻的相位。
- 固定参考先运行主机批次，再按目标推进后台；后台读取的是当时最新的全局 DMA 状态，不能按后台旧时刻重放主机 DMA 启动历史。显式分段接口保留真实等待锁存和已完成的采样操作；VDP 后续更新重设等待者时刻，传输完成才清除等待。未调度 FramePlan 的拒绝契约继续保留。
- 视频模式 `F512`、已应用视频模式 `F514` 与场景阶段／请求 `F580/F582` 分别映射，不能因回调目标相同而混用。视频配置锁存由图形主状态维护，逻辑场景字段继续使用 World 的唯一 owner。
- 控制器归一化保留设备类型历史及可信调用者的 reserved storage carry；物理按键仍限 12 bit，不能从零按键帧猜 MD3／MD6。读取先锁存、工作 hook 后计至操作完成时，LivePorts getter 须先复用不计当前操作成本的批次／IRQ 前置；后续 Work 只计一次当前操作。
- 给规则前置或角色添加工作介入点时，从实际事务内部借用 Clock、queue、Palette 等字段，跨值返回／克隆边界重新绑定。不得把整份旧 Clock／World 或组件 SoundQueue、Palette.Flags 回写到中途已经变化的 owner；IRQ 可读的滚动等字段须在原写入阶段发布，不能等整个组件结束才合并。
- 中断返回按实际寄存器恢复、屏蔽恢复和挂起 IRQ 顺序推进；RTE 内接受与返回跨批次后的普通接受分别处理。只有确认回到原调用者后才能恢复世界；若下一次世界中断尚未计价，保持待处理并在完整事务入口明确失败，不能把它当成返回成功。
- 采样中断尾部与前置、声音调用继续共用同一预算；寄存器恢复的内部 refresh 跳过、RTE 内屏蔽恢复后的立即接受，以及跨批次后的普通接受分别核对。紧接的 reload IRQ 完成后才能恢复原世界；若又进入未计价世界中断，报告待处理并在完整调用中撤销，不能冒充返回成功。
- delayed request 的 delay 从 1 递减到 0 时不当次提交；busy 重入只增加 backlog，补跑在 driver 后递减当时的 backlog。enqueue 的负 slot 在 TST／CMP 分别读取，不得折成入口队列快照。音频联合状态不复制 World 的 queue、pause 或主时钟。
- 固定参考 profile 的 master cycle、帧末 lookahead 和 FIR 副效单独验证。保持实际调用顺序；Reset 的特定有界过冲不能推广为普通端口写任意回时。单曲、单样本或给定原时刻的 DSP 一致，不等于独立时序及真实混合对局音频已经通过。
