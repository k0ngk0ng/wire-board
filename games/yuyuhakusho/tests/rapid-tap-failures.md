# 快速点按与焦点失败场景

本清单先于回归测试和实现。真机现象为快速反复按下、松开方向和 A 时长停顿，持续按住正常；原始触控、RAF 和规则调用记录保存在 `.local/yuyuhakusho/real-device/`。

- 游戏根节点已经持有焦点，后续触点按下、滑动和多指变化仍重复调用原生 `focus`，触发不必要的 Safari 焦点和视口处理。
- 为避免重复聚焦而省略必要的首次聚焦，导致从外部控件返回后键盘不能控制游戏。
- 同一触点未改变逻辑按钮时，仍发生焦点切换或重复发送输入。
- 快速短按被合并丢失；方向、多攻击键和键盘混合输入互相释放；取消、禁用和配置变化遗留按键。
- 聚焦或触点变化造成页面滚动、控件越界，旋转后继续使用旧几何。
- 只使用静态元素或伪造计时宣称解决真机性能。回归使用实际 MDController、MDInput 和浏览器原生触屏事件，保存焦点调用、输入结果和截图；真实应用另验快速输入、长按、声音与视口边界。

真机记录确认了卡顿，尚未把所有停顿归因于单一调用。浏览器回归验证消除重复原生聚焦及交互正确性，不等同于已完成断开设备后的真机复测。
