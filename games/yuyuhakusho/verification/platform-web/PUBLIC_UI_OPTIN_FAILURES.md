# 公共界面 opt-in 先行失败范围

此修订在任何公共实现变更前冻结失败范围。默认模块保留创建、等待、玩家卡的原 DOM 和行为；仅明确声明能力的模块启用新布局。不运行其他游戏规则矩阵。

- 自有下拉框的 computed 前景／背景或 disabled 合成颜色不足 4.5:1；准备页字段与创建字段串用或保存行为改变。
- `preparationOwnsOptions` 导致创建丢失 Options，或默认模块等待页丢失 Options／Preparation／保存和准备行为。
- compact 卡隐藏姓名、真实资源或必要电脑／托管／离桌／出局状态；队伍分组重复、遗漏席位或增加人物数字角标；无分组模式被错误分队。
- 公开资源卡、战场和下方手柄不能在 320×740 初屏同时使用，或为塞入视口把右侧按钮缩至 24 px 以下。公共聊天浮钮等实际遮挡也须处理，不能隐藏或移动公共区域。
- fit 使用猜测的 header 高度，每个网络包测布局，或自身高度变化与 scroll 形成反馈扩张／抖动；窗口、visualViewport、公开卡片变化后分配过期。
- GameLoading 自动滚到战场而把公示资源滚出初屏；未 opt-in 模块的原自动进入行为被改变。
- fullscreen 被二次缩放，桌面变成难用小图，图片比例损坏；Canvas 重建、epoch 变化、触屏命中或 ESC 恢复失败。

保留真实准备对比度／重复控件 red，默认公共组件 SSR 快照和 opt-in 缺失 red，真实三／四人房间的几何／资源／原生输入，以及零值对照。公共 fit 只在布局／视口事件中合并测量并只写变化的高度。
