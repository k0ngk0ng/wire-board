# 战斗采样中断前置流程：先行失败范围

目标：从真实 RAM IRQ 入口，按实际垂直计数等待、控制器连接方式和原顺序推进到声音调度入口，并在现有音频／世界事务中使用。完整目标保持不变，其他世界工作、延迟 IRQ 和帧存档仍须完成。

先冻结原版证据与测试，再改生产实现。场景包括：

- 双直连 MD6、四人转接器加直连、直连加转接器、双转接器的扫描步数、读取值、结果和时间不同；四人的路径不能沿用双人固定耗时。
- 方向检测短路、首端口子调用和次端口尾调用、清理其余槽、四人设备类型与各 pad 三组数据的顺序错误；A/B/C/Start 与 Mode/X/Y/Z 丢位或混位。
- 刷新跨点、IO 前后时刻、长／短分支和 DBcc 成功／继续／到期的成本错误；以最终总耗时相等代替逐步时刻相等。
- 垂直计数在当前批次未结束时提前更新；跨行后仍使用旧计数；对 HVC 13／15 双重比较、省略的等待或 DBF 采用固定帧偏移。
- 外部资料缺失、预算不足、未支持连接、无效位集、非就绪 controller handshake 未明确失败；后续世界错误泄漏已消费声音、暂停、采样或时钟。
- 拷贝原程序／PC 时间表／原 RAM 为运行时状态，或增加重复时钟、寄存器缓存、持久操作历史。

原始输入、源码成本和原生预期保持独立。捕获期间的芯片／总线行为须记录真实外部反馈。给定入口上下文的前置流程一致不能当成整局独立时序完成。
