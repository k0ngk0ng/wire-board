# 固定参考调度中的 DMA 顺序

原核心先执行主机批次，再按同一批次目标运行后台。后台 ROM 读取查询的是当时最新的全局 DMA end／mode／remaining；即使后台自己的读取时间早于主机刚完成的 DMA 启动，也会看到这份最新状态。因此联合调度须提供当前 DMA 状态，不能按后台的旧时间重放各次主机启动的历史区间。

已有未调度 `FramePlan` 和旧 `RunUntil` 的 remaining 拒绝契约保留。新增显式接口只供真正控制 VDP 分段、后台等待与帧结算的协调者使用。后台等待标志来自真实 ROM 总线读取；后续 VDP 更新只在已等待时重设其时刻，并在传输结束后清除标志，不重新读取样本或重放已完成的操作。

本次原版对照包含 10 条完整输入流、546 帧、两次真实等待置位和五次已有等待时的 VDP 推进。先前六条对照保持原字节；新增四条在普通显示扫描线开始的 DMA。自然世界包装取证仍保持原样。它们分别验证后台与主机流程，不能把外部反馈的主机一致宣称为从新建比赛开始的独立整局计时。
