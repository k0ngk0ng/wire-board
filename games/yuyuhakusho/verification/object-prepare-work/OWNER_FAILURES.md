# 直接借用图形 owner：测试前失败清单

本清单与新增测试先于 `PrepareObjectDrawOnOwner` 实现。既有 320 个原生完整调用、117,120 个工作边界、夹具 SHA 和首次缺失 API 红测保持不变。

- hook 收到局部副本指针，IRQ 通过外层 owner 读不到当前标志或游标。
- 计价完成前发布字段，或将所有字段延迟到整个调用返回后一起发布。
- hook 通过外层 owner 更新字段后，被局部副本或后续整体赋值覆盖。
- 保留数量读取前的更新未参与本次循环，或读取后的更新改写已锁存循环次数。
- 直接 owner API 错误后回滚了已完成的操作，导致外层事务观察不到真实失败位置。
- hook 失败后仍修改当前字段，或继续执行后续操作。
- 值 API 委托公共执行体后，错误时返回部分状态。
- 空 owner、入口无效数量或读取时无效数量未明确拒绝，或入口无效时执行了工作。
- 指针执行体的原生结果、逐步成本、refresh 顺序、native／race／Wasm 结果与原冻结夹具不一致。

直接 owner API 只操作调用者传入的独立事务分支。失败时保留已发生的字段更新，由联合调用者撤销图形、时钟和音频分支；值 API 继续返回入口值。
