# 对象绘图准备：测试前失败清单

本清单先于生产实现与原生夹具生成。目标为原版 `125A` 完整调用；调用者 `3A5A` 的跳转、IRQ 接受与其他对象阶段由联合主时钟验收。

- 原版循环对 `F57A` 执行 `N+1` 次，误写成 `N` 次或把场景默认计数改为零。
- 64 个图层链头遗漏、链头地址递增错误，或把可推导的固定链表作为持久状态保存。
- 保留精灵 link byte 写错偏移，破坏其他七字节，遗漏最后一项，或把末尾 link 提前清零。
- 数量／两个游标／绘图标志未按原写入时点发布；清标志后又过早恢复绘图。
- 每次链头／保留项的工作成本、最后一次 DBF、读取、写入或返回成本遗漏；refresh 边界错误。
- 原版 native/reference 的完整调用或两个固定核心结果／工作边界不相等。
- `ReservedCount` 超出已证实的 H40 80 项域仍被接受，或非法输入触发了部分工作。
- 工作 hook 任一步失败后继续执行、返回部分状态，或把临时 hook／操作历史写进状态。
- hook 借用的活状态在读取之前更新却被入口副本覆盖，或读取之后的更新改变已锁存循环次数。
- 独立调用和重试共享可变包级状态；native／race／Wasm 不一致。

`presentation.FrameState` 的数量、flags、parts、transfers 为当帧窗口；`renderstate.State` 只拥有图块槽与 HUD refs。新主时钟图形 owner 只保存仍独立变化的语义字段，不保存 RAM、SAT、64 链头、PC 或执行记录。原生夹具只用来断言测试，不进入生产调度。
