# 正常 IRQ 接受：先行失败场景

目标是为实际世界工作边界提供固定战斗 profile 中普通 4／6 级 IRQ 的接受判定与异常入口时间。范围限于正常执行批次入口；延迟寄存器写入 IRQ、降屏蔽指令内部接受、RAM IRQ 处理、RTE 和整个世界时间仍需另证。

生产实现前冻结原版结果与测试。失败场景：level 0 误接受；请求级别等于或低于 mask 时仍进入；接受后 mask 不等于请求级别；相位或 master cycle 的非整 CPU 余数被丢弃；把 50..59 个 CPU 周期的入口对齐当成固定 44／50 周期；入口错误改变 refresh 时限；溢出被夹紧；使用未支持的级别或 mask；在无声音请求的 arena 中跨过 VDP 首个 HINT deadline 后找错实际工作边界；介入失败留下局部世界状态。

采样核对真实异常栈中的返回 PC／SR，以及两核心的时间与结果。原 CPU、栈、PC 与输入表仅存在于取证和测试；生产只接收调用方的当前时间、IRQ 级别和屏蔽值。

arena 入口时间与初始 VDP 计数器是声明的外部上下文；对应测试不能声称已经独立生成整局世界的 VDP 信号与 IRQ 时刻。
