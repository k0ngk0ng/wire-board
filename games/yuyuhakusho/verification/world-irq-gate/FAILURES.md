# 世界中断入口与 PCM 传输等待：先行失败范围

先保留原版证据和新测试，再改实现。完整目标继续保持，不能以一个等待标志或一个入口通过代替整局时序验收。

- 把主机写入的传输等待误当 Busy、整个播放器暂停或 DMA remaining；没有取得实际总线就改标志，或写入时暗中推进后台。
- 预装等待、single 等量 refill 等待、single 负 gap 的跳过、dual 等量等待和负 gap 的跳过行为不同；遗漏读与分支间的采样 latch、忙标志、dummy cursor、DAC／pan 输出或末尾恢复。
- 标志为 true 时阻止本来允许的 metadata／buffered 输出，或为 false 时改变原有全部采样时间。clear 后不能从同一正确位置恢复；boot 清零位置错误。
- JSON 恢复／分叉丢失当前标志或已采样值，添加可由其他 owner 推导的状态，或者重置流来掩盖时序错误。
- 世界入口总线 BSET／BCLR 的读改写与分支折成一次动作；暂停确认 FF 时错误释放；HVC206 等待和保存／恢复成本错位；后续未计价阶段被当成世界成功执行。
- 预算、资源／外部反馈错误或后续世界失败泄漏标志、样本、主时钟或声音消费；以原 CPU／PC／RAM／回放时间表充当独立运行时。
