# 默认场景世界耗时：实现前失败清单

目标是让真实世界默认场景回调中没有声音请求的计算也具有可校验的时间推进点。保持全部游戏目标；本阶段不能单独证明世界入口、VDP 信号及 CPU IRQ 接受时机。

先冻结原版完整 arena／camera 调用的步骤与结果及新测试，再修改生产代码。失败范围：

- 暂停与 slow 提前返回、初始化与运行、零／非零摄像机样本、word 求和溢出、无符号除法、左右／上下限分支的耗时或结果错误。
- 把长／短未跳转分支、DBF 继续／终止、固定移位和数据相关除法当成统一成本；丢失除法内部 refresh deadline 推进。
- 滚动行的写入批次、波形组、尾部复制及 Pan 正／负反馈复制的工作数量或顺序错误。
- 仅总耗时相等，内部边界不等；只在回调首尾通知，无法在无声音请求的内部区间运行音频。
- 工作观察器影响纯规则结果或原生核心结果；观察器错误后继续触发外部副作用；世界或帧末失败时泄漏已经推进的真实音频状态。
- 时钟溢出、畸形工作参数、晚期资源错误、非法摄像机样本长度未明确失败。
- 引入原始 PC、opcode、CPU 寄存器、持久步骤历史或回放时间表，或把其他尚未计价的世界工作默认为已经计价。

原始 native fixture 只用于测试。生产成本来自实际规则分支和循环；原生执行步骤作为独立预期。无声音区间音频介入测试使用声明的合成入口时钟，不称为原版 IRQ 接受证明。
