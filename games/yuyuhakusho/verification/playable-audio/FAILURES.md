# 可玩版声音验收

用户已选择先交付稳定可玩版本，音乐和音效跟随动作，允许与原版有细微差异。逐拍音频研究保留，暂不作为交付前提。

实现前固定以下失败场景：

- 世界实际发出了声音请求，但浏览器没有收到；同一帧多个请求丢失或顺序变化。
- 收集声音改变规则、存档、摘要或像素；失败的规则步泄漏声音。
- 本地预测经服务器校正后重复播放；重新连接、取消静音、页面恢复补播旧音效。
- 暂停或后台仍发声，离开房间后声音残留；媒体加载失败阻塞操作。
- 音乐被每次快照重启；结算后仍播放战斗音乐；错误预加载所有场地音乐。
- FLAC 压缩后 PCM、采样率、声道、位深、帧数与源不一致，或实际浏览器无法播放。
- 开启声音后操作、完整对局或可见帧率退化。

先运行新增 Go 对局验证和真实 Board 浏览器验收，保存缺功能失败记录，再实现。验收保存命令、源码摘要、媒体事件、页面截图和结果。媒体声音请求仅为临时呈现结果，不进入权威状态或常规网络消息；不宣称原硬件逐拍混音一致。
