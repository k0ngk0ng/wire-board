# 世界包装与图形 DMA：实现前失败范围

- 把待传输项数折成固定帧耗时，忽略每项长度、VRAM 与 CRAM／VSRAM 的速率差、显示开关、行末截断和恰好结束的边界。
- 原始长度 0 的 65,536 计数、源与目标递增、控制字的半字顺序、传输标志或队列消费位置错误；将原 RAM 命令、重复寄存器或历史输出持久保存为运行时。
- 只在 DMA 开始时一次性暂停主机，漏掉后续扫描线中的 DMA 继续；CPU 尾部周期、refresh、后台目标和 VDP 行边界的先后错位。
- 将观测到的主机或后台时间当成独立运行时输入。参考核心若在 DMA 行边界重设主时钟，须保留原观察，不夹紧时钟以掩盖差异。
- 世界忙分支被当成正常逻辑更新；遗漏 missed 标志、门控清除、暂停 FF 保留总线、transfer-active 清除和实际降屏蔽位置。
- 在 DMA 尚有剩余时错误推进或释放后台总线，漏掉已有后台 ROM 总线等待状态；把门控当成所有后台输出都暂停。
- SR 恢复或降屏蔽内部发生的挂起 IRQ 被当成普通批次入口；未计价的逻辑 World、嵌套 IRQ 或跨帧阶段被按零成本完成。
- 任一项、主机预算、后台反馈或后续 World 失败时泄漏队列消费、门控、图形时间、音频或包装标志。测试与原生证据先于实现，失败记录不覆盖。
