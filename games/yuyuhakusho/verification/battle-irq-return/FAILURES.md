# 采样中断返回：先行失败范围

目标是完成真实声音调用后的临时寄存器恢复、RTE 和紧接的 late-reload IRQ，并允许正确返回原世界。保持完整游戏目标，未计价 World IRQ、跨帧、DMA 与其他世界工作继续待办。

实现前冻结原生结果和测试。失败范围：恢复操作内部112周期、refresh跳过和末尾12周期顺序错误；RTE恢复屏蔽后检查IRQ的位置错误；把RTE末尾20周期提前；主时钟不足一个CPU周期的余数丢失；VDP确认先后顺序或pin错误；同／低级请求误进入；RTE本身触发的接受和跨批次后的普通接受混淆；phase1更新DF及phase2顺序错误；遗漏最后返回前的后台进度；未计价world/vertical路径误当返回成功；预算、观察器或后续World失败泄漏已消费的声音或时钟。

原CPU／栈／PC仅用于取证；生产通过普通Go调用保留局部数据，不建立CPU寄存器文件或返回PC栈。有限调用返回一致仍不等于整局主时钟完成。
