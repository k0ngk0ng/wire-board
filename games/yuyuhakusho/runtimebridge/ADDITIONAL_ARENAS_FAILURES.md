# 七场地呈现与存档接入的失败场景

本清单先于对应测试与实现。规则、素材解码和呈现均使用明确选择的同一场地；旧默认入口及默认存档字节必须保持兼容。

- 场地偏移不是已恢复的八个偶数 ID，或规则、背景、资源列表、初始色盘身份不一致。
- ID a 缺少、错绑或损坏 48 块附加素材；其他场地夹带不使用的附加素材。
- 新建对局、资源就绪和恢复存档使用了另一个场地；篡改 options、match、摘要或附加素材版本后仍接受恢复。
- 资源未就绪、非法输入、后续绘图错误导致世界、HUD、图块缓存或计数器部分提交。
- 滚动源经截断后别名到合法地址；不对源做 16 位掩码，必须验证完整有符号地址与完整的 224 行范围。
- 场地反馈读取了过期 Pan 副本，或 backdrop 在存档投影中丢失；默认零值不能改变历史 JSON 字节。
- 场地 a 的即时精灵顺序、层次、预算、图块来源、透明与优先级错误，或错误地依赖最终对象中最后一次提交的值。
- 2／3／4 人、组队、真人闲置、11 人物、横向滚动和恢复后的画面不连续，或 native／Wasm 状态与像素轨迹不同。
- 浏览器预加载所有场地、切换选择影响正在进行的对局，或资源失败后仍开局；320 px 下选择器、比赛画面和公共 MD 手柄溢出。

证据使用已有七条合法菜单输入及原版采样，不以独立实现产生的状态充当原版参考。逐扫描线精灵溢出的既有限制仍须单列。
