# 资源身份目录先行失败场景

本清单与测试先于共享 decoder。目录是身份元数据，不携带媒体或规则正文；调用者仍须通过可信不可变发布清单认证目录本身。

- schema 不支持；空／null／数组／过大目录；未知、遗漏、重复 JSON 字段或尾随内容。
- 资源数量不是 13、未知／重复／遗漏 ID；逻辑路径与对应已知资源不符，包含任意 URL／文件路径／正文。
- SHA 非 64 位小写十六进制；byte 数为 0、负数、非整数或溢出。
- raw JSON 经 parse／stringify、trim、换行或重排后，错误地当作原身份通过；gzip 与 raw 两个域混用。
- 错 ID、损坏／截断／追加字节的数据通过 Verify；验证失败改变目录；返回的资源副本可改变内部 owner。
- 仅凭目录内自己声明的 hash 就声称目录被认证；server 因共享目录读取客户端像素正文。
