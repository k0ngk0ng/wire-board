# 平台前端接入的先行失败范围

此清单先于对应前端、Wasm 入口与验收实现。正式服务器注册和真实快慢连接验证由 Root 单独收口，模拟宿主不得标为真实平台网络验收。

- 创建／等待页自行重建大厅、重复原菜单，人数、混战／组队、场地或角色选择丢失；来源 8／10 兄弟姓名颠倒。
- 非本人修改真人角色，房主不能选已占电脑席位，空位被当电脑；平台 seat 被误作原 slot／输入 channel。
- 封面使用扫描图、标题替代插画或人物编号；角色／HP 在 320 px 被裁切。
- 资产先 parse／stringify 丢失原 JSON 字节，checksum 只核压缩或只核解压之一；错误／未发布版本静默 fallback；初始预取所有场地。
- checkpoint 经 JS object 重序列化损坏 uint64 Present；frame/seq 被 number／32bit 位运算截断；全存档进入普通帧消息。
- 代码下载、组件挂载或固定时间后提前 ready；frame0 未初始化的背景被当完整首帧；Preview 推进权威、队列或音效；单端重连重置全员门槛。
- 输入先等 ACK／快照才呈现；预测无限延长；确认态与预测态共用可变会话；错误 digest／gap 不恢复或反复无界请求恢复。
- MD 高四 bit 被截断，U／I 当 turbo；短按在下一次 tick 前被 release 覆盖；多来源互相释放。
- 改键后默认键旁路仍生效；文本、配置弹窗、失焦／隐藏／取消／卸载仍持续输入；取消等待普通输入 ACK 导致移动卡住。
- 重放已确认输入或旧 epoch 声音／结果；接管自动化与 replay 不在同一有效 tick；真人闲置／断线／后台自动转 AI。
- full screen 自建按钮、目标包含平台菜单、重新挂载 Canvas、退出丢状态或手机手柄遮住画面。
- 只用假引擎或假媒体宣称完整游戏／网络通过；实际 Go/Wasm 像素、真实原生键鼠／触屏与保存恢复没有证据。
- 页面音效自行创建 Audio／AudioContext；用两个隔离 WAV 叠放宣称原版混音；音频未完成被标为完成。

基础测试采用可控制 Promise 的输入／资源验证，复杂交互使用实际浏览器与真实 Go/Wasm。记录源码、资源和结果 SHA、原始 red、最终日志、桌面与 320 px 截图。物理手柄共享公共实现当前缺失，不能伪造为已实测支持。

物理接入前补充：稀疏 index 的虚拟 standard 设备未驱动实际 Canvas；仅连接识别但服务器未采样；物理松开／断开卡键；断开误释放仍按住的键盘；重连时未回中立即继续输入；合法清除主键被拒；替代键不生效或已清除默认键仍走旁路。以上使用真实 Board/Go/Wasm 和标明虚拟的 Gamepad API 验证，不能据此标注任何硬件型号兼容。

Wasm 适配器负例复核：无效 RGBA target 先推进 session 再报错；Preview 错误或成功修改权威；非 Uint8Array／null 令运行时 panic；无界资源分配；相同 JSON 内容但字节不同被接受；会话超过 16 个或释放后仍占容量。先以实际网络 Wasm 执行负例并记录 red，再修适配层。
