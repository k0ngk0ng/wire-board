# 幻海父子对象与三角色世界：实现前验证范围

本阶段在 `46cc202b` 的酎／户愚吕兄共享驱动上接入来源 0「幻海」。先保留真实菜单、完整原版普通／特殊输入和世界轮次，写失败测试，再组合已独立验证的选择器、持续动作、散射弹与释放光效。

失败场景：仍使用 9／10 的选择器或 AI；`Gravity` 模式与 `Aux48` 弹速出现重复所有者；父体建立子槽时误清保留字段、未来子槽未按原地址同轮执行；源 0 的 `1fbaa` 两个 FX Duration 写入在 Pool 合并时丢失；释放光效错误跟随父体或提交形状；散射弹删除／撞击／暂停顺序错误；新 projectile 动画／短序列未发布或缺库静默回退；语义库混入原 CPU 快照或图形；共享尾段未重新读取阶段掩码；忙碌子槽被当成 API 错误回滚正常副作用；晚期真实错误泄露局部写入；初始化仍固定角色 9；原世界与全新配置混淆；存档遗漏父子时钟、分数能量或图块映射；新增规则数据版本后未分离旧轨迹变化与清单摘要变化；扩展三角色时原有角色轨迹改变；手机选择到幻海但实际规则／输入仍为其他角色。

普通原版输入已取得 3,156 轮、42,212 回调，视频标签 1,800..4,957 到清场，两内核 5,500 视频步完整 RAM／画面一致。该流没有自然运行新 child；另用真实搓招输入采特殊世界，不能把私有 child 调用替代为自然覆盖。
