# 酎共享动作尾段：实现前验证范围

恢复正常入口 `0x15afc` 与命中停顿入口 `0x15b40`，直至完整返回 `0x15b82`。正常路径依原顺序执行战斗结束检查、地面控制、地面／空中特殊招式、地面／空中普通攻击，随后清接触标志；停顿入口绕过这些步骤。两条路径均刷新防御掩码、提交当前动画／形状与声音，再消耗 RNG 更新攻击值。

可能失败的场景：一次读取全部阶段标志，忽略前一调用已改变后续位；把地面与空中、停顿与正常入口混合；漏掉战斗结束条件或把地面高 word 比较改为完整 long；把三攻击键或蓄力门槛当作角色选择器普通请求；二段跳错误分配尘土、使用错误输入通道或先选招式后更新跳跃；误把参数纵速四分之三改为一次乘除而失去分别算术右移；防御掩码在错误时点更新；动画库用预期输出键替代状态查找；遗漏形状／投技／特效／队列副作用；消耗错误数量的 RNG 或使用错误位宽随机化攻击值；下游缺数据时泄漏早期状态写入；将独立音频中断清队列作为尾段自身效果；完整函数夹具冒充完整人物／世界步。

先保存完整原版调用和明确私有输入的原 CPU 隔离组合，再写测试、观察缺实现失败，最后实现组合。自然观察须保持 3,600 帧完整 RAM／画面基线一致；外部声音消费如出现须单独留原始事件，不能把期望改写喂给 Go。隔离关闭中断，完整比较人物、形状、投技、特效、队列、RNG 与相关全局状态。连续流仅代表该函数边界，不代替前置、动作运动和世界调度。

## 已验证结果

4,134 次自然调用中，普通入口 3,974、停顿入口 160。人物、其他人物能量、形状／投技缓冲、特效池、计数、RNG、防御／攻击元数据及待处理声音全部一致；4,118 次完整队列也一致。另 16 次自然调用包含实际 `0x37c56` 队列清理，四槽队列差异作为外部消费保留，不声称由尾段自身预测。原版观察的全部 3,600 帧 RAM／画面仍与基线一致。

816 个原 CPU 隔离完整调用与 5 条单初态流共 30 步，在关闭中断后包含声音队列的完整状态全部一致。矩阵覆盖全部 32 种阶段位组合、普通／停顿入口、战斗结束、三键能量消减、蓄力阈值、二段跳、防御姿态与库查找。二段跳独立变化 `+72` 按下沿与 `+73` 变化位，纵速包含负奇数、正值和有符号边界；分别执行两次算术右移后相加，保留原舍入。初次组合对照暴露了错误使用变化位的问题，现有自然与隔离回归在修正为按下沿后通过。

三键分支按固定的四个人物对象位置检查占用、队伍及生命，扣除其他有效敌人的能量；源人物自身必然因同队过滤。计数／类型／库错误均整体原子失败，不修改调用者的其他人物 map、投技 slice 或只读帧库。完整人物与三个其他对象分别比较全部 256 bytes，特效池 2,048 bytes、形状区 1,024 bytes、投技区 512 bytes 均不屏蔽未知字节。

自然的 16 次外部声音消费发生在比动画提交更宽的函数窗口内，不能直接沿用动画阶段的 8 次计数。独立声音消费者另有完整验收，见[声音队列验证](SOUND_QUEUE_VERIFICATION.md)；具体驱动时基、合成和平台播放仍未实现。
