# 动画时钟与衰减位移：验证范围

本文件先于对应采样脚本、测试和规则实现建立。目标函数仅为原版 `0x19c96..0x19cc2` 的动画时钟，以及 `0x19cc4..0x19cec` 的衰减位移；不将它们作为完整动画系统或角色动作验收。

## 实现前列出的失败场景

- 未从真正的函数入口采样，或在尚未完成的调用上读取输出。
- 观察器改变原版 3,600 帧基线中的 RAM、画面或尺寸。
- 原函数写入未建模的字段或其他角色，却只比较选中的几个字段。
- 动画计数器按无限精度整数递增，丢失 `0xff → 0` 的 byte 回绕。
- 把动画时长与计数的比较当作有符号比较，或把达到时长误作仅超过时长才推进。
- 时长为零、持续计数为 `0xff`、帧索引为 `0xff`、循环标记 bit7、旧完成标记非零时发生错误。
- 未到推进条件却清空原来的完成标记，或在非循环动画推进时错误设置完成标记。
- 衰减量非正时仍移动；正衰减量小于 `0x4800` 时被提前夹到零，丢失原版最后一次反向余量。
- 先位移后衰减，或把朝向 `== 1` 错写成任何非零都朝同一方向。
- 32 位位置加减溢出、负衰减量、边界数值在 Go 中发生符号或精度改变。
- 用自算的边界期望冒充自然原版运行覆盖，或把独立片段通过当作完整对局通过。

## 验证顺序

先从固定 ROM 和本次既有输入时间线被动采集完整函数调用，并与已保存的 3,600 帧基线逐帧比较。再编写 Go 测试，先记录缺少实现时的编译失败，最后实现独立语义。自然记录之外的 byte／word 边界按静态指令语义独立标注；不修改原版 RAM 来伪装自然覆盖。

原生测试由本组件运行；竞态和 Wasm 验收由父任务统一执行。本组件不自行宣布后两项已通过。

## 本轮结果

先生成原版夹具，再编写测试。实现文件尚不存在时，目标测试以 `undefined: AnimationClock / ResidualMotion / StepAnimationClock / StepResidualMotion` 编译失败，记录见 `testdata/animation-oracle-red-phase.json`。之后实现独立 Go 语义，原生目标测试通过。

| 范围 | 实测结果 |
| --- | --- |
| 原版动画时钟完整调用 | 3,974 条，Go 输出全部一致 |
| 原版衰减位移完整调用 | 3,974 条，Go 输出全部一致 |
| 原版全程基线 | 3,600 帧的 RAM、画面及尺寸与无观察器基线全部一致 |
| 写入范围 | 每次完整调用的整个人物 256 bytes 差异均在声明字段内 |
| 未返回调用／采样异常 | 0／0 |
| 独立静态边界 | 动画 9 项、衰减 10 项通过；它们不是额外自然对局 |

自然记录覆盖 127 次计数字节回绕、69 次循环完成、215 次保留既有完成状态；衰减覆盖 60 次正值、223 次负值、3,691 次零值，以及 3 次由正变负的最后一步。自然朝向值只有 0 和 1。零动画时长、动画索引回绕、非标准朝向值以及 32 位坐标溢出使用独立静态边界验证，未冒称原版自然覆盖。

首轮使用「入口到出口期间全部 64 KiB RAM 必须只改人物字段」作检查时，发现 16 次调用有其他区域变化。调整记录粒度后保留了全部调用及全部外部地址／前后值：它们都发生在同一视频帧，因而不能归因于「跨视频帧」。具体中断或其他处理器的交错来源尚未定位；不能把这些全局变化认定为本函数的写入。当前证据由限定范围原指令、完整人物对象写入审计，以及全程基线一致共同组成。没有删去这些样本，也没有改写 ROM 或 RAM。

夹具为 `testdata/animation-oracle.json`，来源、ROM／内核／观察器摘要、覆盖统计与局限见 `testdata/animation-oracle-manifest.json`。实现不执行 ROM 或 CPU 指令；保存状态时必须同时保留完整时钟字段和衰减量，不能把完成字段缩成每帧清零的布尔值。

## 复跑

在本 worktree 根目录执行：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 scripts/yuyuhakusho/capture_animation.py \
  --out .local/md-yuyuhakusho/animation-capture
GOCACHE="$PWD/.local/go-cache" GOMODCACHE="$PWD/.local/go-mod" \
GOTMPDIR="$PWD/.local/go-tmp" \
go test ./games/yuyuhakusho/engine -run 'Test(Animation|Residual)' -count=1 -v
```

采样要求已存在本项目固定的带钩子参考内核及 `hook_filter.dylib`，脚本不自行下载或重编译它们。Go 临时目录需预先存在。两段仍需由完整动作管线按原顺序调用；本轮没有恢复所有动画表、命令缓冲、碰撞、特效构造器或角色连续对局。
