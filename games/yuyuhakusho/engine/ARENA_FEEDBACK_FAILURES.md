# 场地反馈公共视图失败场景

以下清单与先行测试在公共反馈实现之前保存。

- Pan 为零时错误读取不使用的地址，或改写旧行数据。
- 不按各场真实 SourceA/B 读取，错误复用默认 Y 公式。
- 先截低 word 使实际 ROM 地址伪装成已拥有 RAM 行 bank。
- HUD／RowsA／RowsB 的跨 bank 224-word 复制越界、未保留有符号 word 回绕。
- A 已复制后 B 失败仍返回部分修改，或修改调用者输入。

该 helper 只消费已证明的三组当前行 view，地址空间不扩大为 RAM VM。各场原 CPU 完整 callback 与单初态流另行验证这些行与指针公式。
