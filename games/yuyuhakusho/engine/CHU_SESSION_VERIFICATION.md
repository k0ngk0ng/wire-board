# 全新酎对局：实现前验证范围

在已验证的对象轮次之外，提供平台准备阶段的新世界构造、一次性资源就绪交付和完整逻辑 tick。世界从空对象／零统计与明确配置创建，不读取原 CPU 状态或预录对局快照。准备阶段建立 manager 的资源请求但不推进游戏时钟；资源未就绪不得开始逻辑 tick。

当前构造范围明确为默认场地、源角色 9 的两至四个人物，允许显式电脑与原双人／四人位置，四人组队使用原 1／1／4／4 队伍码。平台席位、昵称和积分仍由外层映射；没有空闲或断线自动接管。其他角色数据或 AI 存在不代表完整动作已可玩。

可能失败的场景：从参考快照伪装全新初态；配置非法却部分创建；重复槽／人类通道或不支持角色／场地静默回退；未就绪推进时钟；迟到资源 ACK 覆盖已运行色盘；先裁切／批量执行对象或重置每人物 RNG；模拟器视频标签当逻辑 tick；低字节控制输入被客户端自报按下沿替代；错误使用队伍判胜或自行写生命／结果；中途恢复丢失缓冲／计数／种子；错误后泄露前置或对象写入；结果后重复结算或继续跑原菜单。

测试先于实现。完整对局验证仅使用新构造状态、显式逻辑按钮和真实已恢复 AI，持续到实际生命周期清场，保存可复跑结果；恢复验证从一次中途存档独立继续，不逐帧注入参考状态。此阶段不冒充平台房间／浏览器、全角色、全部场地或完整音频 E2E。
