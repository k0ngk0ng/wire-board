# 开战／结果覆盖层：实现前验证范围

目标是原版开战对象 `0x101f2` 及其 `0x10330` 子字块、实际结果对象 `0x10436/0x104ac/0x10522/0x10616/0x106e8`，以及影子登记消费者 `0x14882` 的规则和生命周期。追加实际出生的暂停／模式／回合标签和训练对象 `0xfe78/0xfeb2/0xff74/0x10088/0x10116/0x10172`。绘制可以返回具名请求，但不得把省略的精灵提交、文字图块或硬件队列伪称为已经完成。

可能失败的场景：猜测固定显示时长；初始化后误执行下一阶段或漏掉原 fallthrough；暂停／慢动作改变错误计数；有符号 byte／word 与回绕错误；错误人物／队伍／角色查表；遗漏声音、全局门槛或绘制前状态；结果对象清理长度错误；影子位置和登记消费时序推断错误、漏清计数或改变顺序；对齐／坐标低位被误清；只比较选中字段却遗漏父对象或全局写入；原 CPU 私有栈与统计别名；重复注入原中间态后声称完整生命周期；观察器改变原版基线；忽略默认出生的辅助标签；模式对象强制慢动作或训练控制器跨通道 OR 被遗漏。

严格顺序为：核对有限静态控制流，采集原 CPU 完整规则返回与明确隔离边界，编写 Go 测试并保留真实缺实现失败，最后实现。自然采样保持完整 RAM／视频基线一致；连续流只改变声明的外部输入，不能回灌期望结果。交付须列出真实覆盖、返回绘制／静默／清理的差异，以及仍待世界层和呈现层组合的部分。

## 规则边界与调用顺序

`StepMatchOverlay` 处理 12 个开战／结果／标签回调；`StepMatchShadow` 处理影子；`StepMatchTraining` 处理暂停训练调血，共 14 个实际入口。绘制路径停在进入 `0x1580` 之前，静默路径停在真实外层 RTS，删除路径完成 `0x3556` 的对应前缀清理后返回。本模块不运行硬件精灵编码、资源上传或完整世界循环。

| 入口 | 已确认的规则 |
| --- | --- |
| `101f2` | 7 阶段开战管理器：72 计时，两次建立 `10330` 的两个子槽，分别等待首子槽清零，最后清理自身 |
| `10330` | 7 阶段字块：初始化后同调用缩放至 32，放大至 256，80 计时，再缩小或直接清理；暂停／慢动作不推进但仍请求绘制 |
| `10436 / 104ac` | 和局／胜利标题：初始化、放大和稳定停留，等待外部清场；首个初始化调用同样推进缩放 |
| `10522 / 10616 / 106e8` | 角色／队伍／搭档结果文字：96 计时、同调用初始化与缩放、角色或搭档延迟声音、稳定停留 |
| `fe78` | 初始化后只在暂停 bit7 置位时请求绘制，不按慢动作跳过初始化；未凭图形参数猜测文字内容 |
| `feb2` | 8 阶段模式过渡；按有符号 ModeFlag 比较推进，显示时每次强制 `F55A=1`，最后写 `A096=3` |
| `ff74` | 仅暂停时 OR 四通道的普通／扩展 Held；按方向选择四人物，把生命改为 223 或 0，置 0 时保留已经负生命的目标 |
| `10088` | 按模式、视频计数低 byte 的 bit5／6 和逻辑回合索引选择参数或静默返回 |
| `10116 / 10172` | 初始化时以 `+18.w` 作为偶数字节偏移 0～14 选择八项位置／属性／图形，后续保持绘制 |
| `14882` | 实际位于 `FF9C00`，在人物与 FX 后按 cursor 轮转取一个登记 owner，复制其完整 X、地面 long 及深度，再投影并清 `A034` |

自然观察纠正了早期的影子位置假设：`FF8200` 实际是 `fe78`，不是影子。取证窗口现包含真实 `9c00` 的全部 128 bytes；不能根据早期假设把影子描述为消费上一帧列表。它消费的是实际运行时已经登记的列表，在原对象顺序中处于本轮人物之后。

`10330` 的删除发生在 wrapper 的 BSR 内部，清理后仍返回 wrapper 并请求 `1580`。因此 `Draw` 与 `ClearedBytes` 可以同时非零；零坐标随后由呈现层裁切，世界层不能将所有删除硬编码为 `Draw=false`。结果标题自身不删除，稳定阶段须等待对局管理器清场。

## 已验证范围

固定输入至第 3,600 帧后松开，全部 5,500 帧 RAM／视频仍与既有未观察原内核基线一致。自然取得 14,460 次完整规则调用：影子、模式、暂停标签、回合标签各 3,223，开战管理器 264、子字块 376、胜利标题和角色结果各 464。自然没有出现的和局／组队／训练／淘汰标签由明确私有输入验证，不把它们称为菜单或完整模式已验收。

28,094 个隔离原 CPU 输出中，28,073 个有界语义调用完整比较。另 21 个 `10088` 私有 Round 11 输出指向图形参数 `D6`，其图形表项为零；保留原输出作为 `reference-only`，Go 在确实需要该表项时原子拒绝，不把未证明的零帧或邻接表内容当正常素材。原父场景的有效回合推进范围仍需世界层确认；负 ModeFlag 固定参数、模式闪烁静默等不读该索引的路径照原行为处理。

14 条单初态流共 2,372 次调用连续推进。开战流实际调用原父对象和两个子对象并走到真实清理，不外部注入子 header 的完成状态；结果标题只验证至稳定停留／延迟声音，不伪造删除。影子流仅外部补入声明的登记数量；模式流仅外部修改声明的 ModeFlag；训练流仅更新声明的暂停与四通道输入。其余计时、缩放、队列、header 和生命由规则自行演进。

每次比较 `8100..83ff` 的 768 bytes 对象窗口、`9c00..9c7f` 的 128 bytes 影子、四个人物各 256 bytes、128-byte 登记区、全部相关全局参数和四槽声音队列。没有字段掩码或独立音频例外，训练输入以外的人物字节保持不变。隔离覆盖所有 14 入口、合法阶段、有符号计时／缩放回绕、部分前缀清除、所有角色／队伍查表、四通道之间分属的训练输入 OR、以及角色 9／11 的两种延迟声音。

## 集成接口与资源

`MatchOverlayState` 单独持有共享 `ModeFlag / SlowFlag / SoundQueue`；每个回调输出须写回世界，再由后续对象读取。它们不是每个覆盖层私有的独立世界副本。`Environment` 只读暂停、blink、回合、人物和队伍名选择。训练 API 输出四个 `{Behavior, Health}` 目标，调用者写回四个真实人物；不在规则内直接改平台积分或判胜。

影子的登记数据与人物 `RegisterFighter` 使用同一 `FighterRegistrationState`，不能把其 `Used` 按对象重置。输入／其他人物 map 和登记 slice 不被原地改写；未知角色名、不可表示清理前缀或缺失 owner 均整体原子失败。`ClearedBytes` 请求还须清理世界层持有的未纳入当前类型的字段。

结果／标签使用 `GraphicsSet=DA1DA, TilesBase=24B9E0, SkipGraphics=0`；开战字块使用 `DAA4A / 25D260 / 0`。影子使用 `27F618 / SkipGraphics=1 / Parameter=26`，其 `TilesBase` 字段不由规则初始化，须使用真实预载图块，不能从 ROM 地址 0 读取。文字内容、全部资源呈现和像素合成由独立呈现层验收。

## 复跑

```sh
mkdir -p .local/md-yuyuhakusho/tmp
PYTHONDONTWRITEBYTECODE=1 python3 scripts/yuyuhakusho/capture_match_overlays.py \
  --out .local/md-yuyuhakusho/match-overlays-replay
GOCACHE="$PWD/.local/go-cache" GOMODCACHE="$PWD/.local/go-mod" \
GOTMPDIR="$PWD/.local/md-yuyuhakusho/tmp" \
go test -race -count=1 -run '^TestMatchOverlays' ./games/yuyuhakusho/engine
```

Wasm 使用研究工具说明中的 Node 执行器。各组件并发红阶段时，本任务使用报告列出的明确源码文件聚焦构建，最终仍由父阶段运行整个游戏包。真实初次缺类型失败和追加标签缺字段／训练接口失败先于相应实现；来源、夹具及最终日志见[验证记录](testdata/match-overlays-validation.json)。
