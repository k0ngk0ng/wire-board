本轮在 `605efb55` 基线上恢复来源 4「飞影」。规则为独立 Go／Wasm 实现，运行时不读取 ROM、执行模拟器或灌入原版中间状态。最终摘要与全部检查绑定见 [hiei-session.json](../verification/hiei-session.json)。

每个场景均比较逐轮独立调用和单初态持续推进。比较覆盖完整 typed world、对象顺序、进入时 header 与保存 stride、原始拥有字段、共享 RNG、形状／HUD／色盘与队列边界。Draw 在实际 callback 提交时保存值，按原顺序比较；硬件后续写入的精灵 cache 单列排除，不能排除位置、图形偏移、参数、属性和图层。视频标签不等于逻辑 tick。

双真人练习菜单的早期阶段不在本次 Go 运行边界内。首次过早捕获因 main 尚未进入已证明的等待阶段而失败；改用独立 producer，从实际 `a01e/stage32` 的 2500 开始，仍早于本场首次受击，完整保留弱生命条件的生成、放龙、操龙、吞龙及恢复。未把 header 归一化为其他模式。

## 状态与数据所有权

- 新增 canonical 仅为对象 `DragonBank`（`+FE`）、共享 `DragonBankCursor`（`A038`）及四组、每组 32 个 typed 轨迹样本。样本只保存原版实际使用的 X／Y、角度、深度、图层／跳过图形、状态，不保存历史区域空洞或整 RAM。
- 完整 `Aux48` 保存方向；VX 保存有效角度；Gravity／VY／Energy 的高 word 提供波相、年龄、声音时钟视图。身体段和强化父体同样只临时借用既有 owner，清除后再合回各视图，保留未被原版清除的低 word。
- `MovementSource` 在 world、actor、action 间完整往返；不可变表在动作入口和 MAIN 后重新按当前来源选择，保证吞龙同次调用的后续规则使用正确参数。
- schema3 新增九条公共 AN、一份 1,344 项 signed-word 曲线和强化参数来源。曲线保留经原 CPU 实际读地址验证的 `-32..1311` 范围，不使用现有 signed-byte 波表或角度取模替代。schema1/2 继续可读。
- 未使用的三个新 owner 不进入旧角色存档 JSON，旧角色状态摘要保持原样。非零状态和完整强化恢复另有实际保存恢复证明。

规则包导出前已保存缺字段、unsupported source4、缺少 schema3 与旧 bundle 不一致的失败记录。新增 selector、MAIN、三个龙回调、完整组合均先冻结失败场景和测试，再保存真实 red，最后实现。全量检查另发现来源 0 历史测试仅接受 schema2 的元数据断言；它现接受 schema2/3，原非法序列与 schema1 校验保持不变，独立原生／Wasm 复跑留证。

现有精灵目录无需增加媒体。资产审计确认 13 个精确键及 292 个图块，包含身体直接参数 86／88／90 和强化图形；最终自然数据中的十二个有效图形参数均实际出现。暂停脏初态保留的 54 个请求单列，不作为素材覆盖。浏览器验证飞影实际 tag4、前向攻击 `03/83`、原生键盘移动、三指触屏／取消、后台释放及桌面／320px 截图。

来源 4 原版自然世界在本轮由真人控制；原版 AI4 采用既有完整隔离／组合证据，显式电脑另由全新独立完整对局验收，不把真人自然样本写成电脑样本。平台房间、网络预测、其他两个人物、七个其他场地及音频播放仍未验收；本轮未上传、发布或部署。
