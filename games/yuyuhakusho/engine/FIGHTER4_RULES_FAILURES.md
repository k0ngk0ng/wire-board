# 飞影规则包与轨迹存档失败场景

本清单及规则包测试先于 schema3 解码与导出实现。

- schema1/2 历史规则包无法读取，或默认移动参数来源没有建立索引。
- schema3 丢失强化移动参数、将强化来源覆盖默认来源，或接受重复／未知来源。
- 把 signed-word 曲线截成 byte、角度取模、漏掉前缀／尾部数据，或接受长度与起始索引错误的曲线。
- schema3 漏读既有 source0 释放序列，或丢失任何既有规则数据。
- 四组 32 个轨迹样本或全局 bank 游标在 JSON 存档时丢失；子对象 FE 被另一个别名代替。
- 解码失败返回部分规则库，或执行时改写共享规则数据。

规则包测试直接使用已绑定原 ROM 的九条公共 AN、1,344 个 signed-word 和两组移动参数资源。它验证语义数据编解码；原版回调、世界与呈现结果由独立原 CPU／E2E 证据验证。
