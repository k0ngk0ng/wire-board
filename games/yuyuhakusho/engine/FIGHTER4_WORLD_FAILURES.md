# 飞影完整世界失败场景

以下清单与完整原版逐轮／单初态测试先于 world source4 开放。

- source4 在活动回调中被拒绝，或被替换成其他角色。
- 飞影普通招式、对方子对象、FX 与 HUD 回调顺序改变。
- 每轮重新灌入原状态才通过，单初态持续推进发生漂移。
- 首轮 driver entry 数量猜错，多推进一次时钟。
- 固定物理输入下原版清场，独立规则无法到达同一结局。
- typed `+FE`、`A038` 及龙轨迹存档丢失，恢复后产生不同结果。
- 同轮多次绘制按最后对象值重建，导致已经提交的 draw 被复用槽覆盖。

普通原版对战范围为 frame1800..4832，3,032 轮与 39,782 回调；首轮实际没有 driver entry。黑龙、强化、恢复与素材的额外验收独立记录，不能用普通世界测试代表已完成。
