# 树完整世界验收

本轮在 `4b1a5c15` 基线上恢复最后的人物来源 7「树」。原版工具仅用于开发对照，最终对局由独立 Go／Wasm 运行，没有 ROM、模拟器、CPU VM 或中间参考状态加载。最终检查、来源和剩余工作由 [itsuki-session.json](../verification/itsuki-session.json)绑定。

两条原世界都经过逐轮输入和单初态持续推进。比较完整 typed world、原始拥有字段、对象先后／header／保存 stride、RNG、形状、HUD、色盘、滚动和明确边界。特殊 Draw 是各 callback 当时的值快照，按原顺序逐项核对；硬件随后写入的精灵 cache 和物理音频消费者有各自独立边界。普通对战与原版在相同位置清场，特殊保留区间不声称比赛已结束。

另以 11,323 个原 CPU 子回调边界直接经过 world 分派，比较父体生命、sibling 目标、FX 和全局晃动；三种 callback 各八个实际状态保存恢复。特殊完整世界在 1901、1935、4053、4308 四个真实状态保存恢复，并比较下一轮完整状态和事件。

## 原版动作与跨对象效果

共享人物驱动已接入树的四 selector、专属 `39/3a/3b/3c/3d` 及 `0f/11/13/14/45` 公共上下文。`3d` 即使第三子槽占用也按 Team 遍历另外三个固定父体，将 HitStopTicks.byte 写 `ff`，不按 Size／Health 过滤。临时 peer 视图沿既有 `OtherFighters` 携带字节，自身仍只用原 Action.HitStopTicks；退出或晚期错误不会泄漏 map 修改。

`136e6` 会在地面修正前把方向、完整位置写入 `1391e` 所在 sibling 的 Aux48／VX／VY，作为其追踪目标。`1391e` 用有符号 long 差值和算术右移平滑跟随；回血按四个父体的实际位置、Size 和 Health 判断，不做队伍过滤。八个 type24 FX 分别有自己的 VY 与 Delay，均映射已有 owner，没有复制计数或另存整 RAM。

`15094` 不绘制。它把自身 VY 高 word 作为计数，每次减 `10`，写全局 `F570.word`（Clock.PanAmplitude），最后清除。自然记录在 4053..4308 共 256 次，末值为零。前两个 callback 的命中停顿分支确由主入口条件到达，与仙水未找到实际 caller 的相邻孤立入口不同。

## 自然输入与证据边界

固定输入共 5,502 控制步，实际入口截至 5500、两步排空；P1 为树，P2 为原电脑酎。14 个玩家可达特殊根分别在 1893..4038 成功扣费，包含地面／空中变体；R4 没有玩家命令绑定，仅有声明私有／AI 边界，未声称自然输入到达。

两次 `13b1a` 回血分支在 1935、2112 实际执行，并创建原版八个 FX。但四个父体 Health 在这两次自然样本中没有增量，不能写成自然生命增加。真实生命变化、上限、有符号边界及队伍不筛选由原 CPU 私有样本和 world 回调验证。

特殊 MAIN 另保存 507 次原 CPU 阶段；旧 MAIN 冻结样本、选择器样本与后续补证分别绑定。测试初态修正保留 v1：实现前发现退后动作的自造 Y／Ground 与 ground 期望矛盾，仅把初态 Y 设为 Ground 后重新冻结并取得真实 red，未改变 CPU 夹具或期待业务结果。

## 两个实际集成问题

完整场景在 3142 揭示音频中断可先清空声音槽、同一动作再向该槽排入新请求。原组合适配器只能表示清零，不能表示清后重入队。v2 仅增加原 CPU 实际请求、写槽、drop 与外部 clear 的总有序流：物理四槽重放严格等原版 After，剔除外部消费者后同步投影严格等 Go 四槽；所有其他 state／raw／clock／AN／actor／child 字段与 v1 完全相同。v1 代码、全部原始夹具和真实失败保留，没有整队列遮蔽或业务代码迁就。

晃动首次在 4054 揭示旧状态把输入录制流和滚动线保存了两份，实际原版 `6000..63ff` 被两者共用。修复后 Stream 是唯一持久字节 owner，PanRows 只是大端临时 view，场景回写保留两处 64B 间隙；输入录制／播放和滚动相互可见。存档的 PanA／PanB 只是序列化时派生的旧格式投影，恢复只使用 Stream。六份旧完整 JSON 字节和旧对局摘要兼容，原 CPU 比较没有去掉 Stream 或滚动字段。

## 数据、呈现与后续范围

schema3 追加 94 条子对象 AN／shape，合计 4,907 条，未覆盖冲突数据。资源审计确认现有 21 个精确键、361 个图块可复用；四个预载 FX 图块另从默认场地压缩源和原 VRAM 交叉验证。1,296 个脏保留请求和 224 个脏 palette 预载上下文单列，不作为正常素材覆盖。

完整矩阵为 25 组规则对局、14 组完整呈现，覆盖 11 人物正反对战、三人／四人、组队、真人静止与恢复。原生／Wasm 比较完整状态、事件和像素轨迹；旧十角色 140 配置共 280 份报告要求原有世界、事件和生命周期一致。浏览器核对 tag7、前向 `03/83`、原生键盘／三指触屏／取消、后台释放及桌面／320px。

本轮只开放默认场地。其他七个场地、音频播放、平台房间与权威同步／本地预测仍未完成；未上传、发布或部署。原版自然树由真人控制，AI 的隔离／完整输入与新电脑对局分别记录，不称为原电脑树自然世界。
