# 起跳、落地和空中阶段：实现前失败场景

本清单先于本批采样、测试和独立规则。目标为 `0x18580` 完整起跳、`0x18564` 完整落地，以及 `0x19dc6` 到共享尾段 `0x15afc` 之前的空中动作组合。

- 只恢复位置积分，遗漏起跳／落地的两次独立尘土分配、游标变化和全局池写入。
- 方向来自旧纵速高 byte，却从当前按键或已替换后的纵速推导。
- 先清掉横速，再处理方向，改变原版非 1／5／9 方向保留旧横速的行为。
- 横速符号、相对朝向动画 6／7／8 的条件，以及非 0／1 朝向不一致。
- 动作重置遗漏时钟、辅助字段、队伍恢复，或额外清空命令、请求、动画标志和速度。
- 起跳参数、32 位取负／积分溢出不一致，或把各角色参数硬编码为酎。
- 落地按完整小数比较，或者向上运动时提前落地；未保留原整数高 word 的有符号比较。
- 落地时未先恢复完整地面坐标再建立特效，导致特效 Y 与人物不同。
- 清除二段跳标志时机错误，或无落地时错误清除。
- 构造器内的通用 reset 被误配成外层 return；嵌套落地／空中边界或未返回调用被丢弃。
- 共享 `0x15afc` 之后的输入、动画／判定和随机数尚未执行，却把当前阶段声称为完整角色更新。
- 满池、单空槽和游标回绕被简化成总是分配两侧。
- 在错误状态下返回部分已修改的独立状态，而未报告非法池游标。

先从原版自然输入采样并证明 3,600 帧 RAM／视频不变，再用每次恢复同一原检查点的隔离原 CPU 用例覆盖边界。夹具与测试先于实现；对完整 256-byte 人物对象及完整 0x800-byte 池比较。隔离输入不是自然完整对局。

## 已验证结果

先生成两组原版夹具并编写测试；`jump.go` 不存在时，目标测试实际以 `undefined: FighterBodyState / JumpParameters / BeginJump / BeginLanding / StepAirAction` 编译失败。之后实现独立规则，原生 `TestJump*` 全部通过。竞态与 Wasm 尚由父任务统一执行，本组件不提前宣称它们已通过。

| 原调用范围 | 自然调用 | 隔离原 CPU 用例 |
| --- | --- | --- |
| 完整起跳构造 | 3 | 90 |
| 完整落地构造 | 3 | 6 |
| 空中动作到共享尾段之前 | 156 | 21 |

自然落地记录嵌套在空中阶段内，不能把调用数相加称为独立帧或对局。观察器没有改变原 3,600 帧 RAM／视频／尺寸基线；无未完成调用或观察错误。279 个记录均比较了完整 256-byte 角色与 0x800-byte 特效池，共 642,816 bytes，同时核对池游标、左右分配索引和原控制流是否进入落地。

隔离用例覆盖方向 `0/1/5/9/255`、朝向 `0/1/128`、空／满／单空槽池、两组起跳参数（含 32 位取负边界）、整数位置溢出、同整数格而小数不同的落地、上升不落地，以及地面高 word 的有符号比较。每次用例恢复同一检查点，设置的参数和池状态均保存在记录中；这些不是额外自然对局。

## 组合语义

- `FighterBodyState` 嵌入 `GroundActionState`，纵速只保留 `VerticalVelocity` 一份，避免预备方向 byte 与实际纵速状态脱节。
- `BeginJump` 先调用两侧独立尘土分配，再执行通用动作重置；读取旧纵速高 byte 为方向后，才覆盖纵速与重力。方向 9／5／1 分别为正横速／负横速／零横速，其他方向保留旧横速。
- `BeginLanding` 保留速度和二段跳标志，完成尘土、落地动作与通用重置。Y 贴地与清二段跳标志属于调用它的空中动作，不能提前塞进构造器。
- `StepAirAction` 按原顺序积分；达到原落地条件时，先把完整 Y 设置成地面基线，再调用落地构造器，最后清二段跳标志。因此尘土的位置使用落地后的 Y。
- 满池或单侧分配失败不阻止角色状态切换。结构不满足槽对齐条件时，独立接口返回错误和原输入状态，不返回半更新状态。

这些阶段之后仍需执行 `0x15afc` 起的共享尾段；当前不执行其输入、动画／判定提交或随机更新，也不代表完整角色或世界更新。

## 复跑

```sh
PYTHONDONTWRITEBYTECODE=1 python3 scripts/yuyuhakusho/capture_jump.py --out .local/md-yuyuhakusho/jump-capture
mkdir -p .local/md-yuyuhakusho/jump-tmp
GOCACHE="$PWD/.local/go-cache" GOMODCACHE="$PWD/.local/go-mod" \
GOTMPDIR="$PWD/.local/md-yuyuhakusho/jump-tmp" \
go test ./games/yuyuhakusho/engine -run '^TestJump' -count=1 -v
```

夹具为 `testdata/jump-oracle.json.gz` 与 `jump-boundaries.json.gz`，身份、采样器摘要及解压前后 SHA-256 保存在对应 manifest。完整对象未知字段由测试适配器保持前态，仅覆盖独立规则中的命名字段后逐字节比较，未用屏蔽差异或清空旧对象获得通过。
