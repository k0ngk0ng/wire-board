# 仙水完整世界与规则数据失败场景

本清单、原 CPU 完整轮次和以下 E2E 先于 source5 world 接线及规则数据合并。

- 普通／特殊世界拒绝 source5，或把角色替换成其他来源。
- 三 callback 未分派，反射无 Draw 分支被错误绘制，或父体停顿／输入保留的修改丢失。
- 146ba 错用 FE 作为父地址；它实际跟随自身 ID 减 0x200。
- 子对象 Gravity 最高 byte、完整速度／小数、FE owner、Trail clock 与父体状态合并遗漏。
- 每轮灌入原状态才通过，单初态推进发生漂移；同轮 Draw 被后续复用槽覆盖。
- 缺少子对象实际读取的 typed AN，或把源码数据的十六进制 pose 与十进制 pose 混淆。
- 新 AN 数据与既有记录冲突；旧角色或 schema1/2/3 数据读取改变。
- 存档恢复丢失 parent owner、variant／方向或子对象生命周期。

普通场景为 3116 轮／41188 回调，到视频标签4916清场；特殊场景为1801轮／24007回调／12058个有序Draw，范围1800..3600，原control3602步。特殊场景不声称比赛结束。
