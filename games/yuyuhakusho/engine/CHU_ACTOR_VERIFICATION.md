# 酎活跃人物回调：实现前验证范围

组合 `0x12682` 的完整规则部分，边界为 `0x126ba` 执行精灵提交 `0x1580` 之前。顺序为人物登记，暂停／慢动作门槛，完整输入（含原版 AI 与录制恢复），完整动作，屏幕投影，生命不等于 −1024 时的边界／坐标样本，HUD，最后发出绘制请求。初始化 `0x126c8`、实际精灵提交、子对象回调与整个世界循环不在该边界内。

可能失败的场景：组合顺序与原版不同；暂停或慢动作错误跳过登记、边界、HUD或绘制请求；把慢动作按bit而非整个byte判断；把生命过滤扩大为负生命全部跳过；提前裁切世界X再投影；复制人物状态时丢失AI计时、输入保留、能量小数、子对象或图形字段；从旧人物副本构造后续阶段；共享RNG、样本、登记、HUD游标、形状计数或录制标志按人物重置；给AI回灌预期输出；控制器视图或其他人物的可见数据过期；晚期错误泄漏早期登记或录制；把“规则到draw前”称为完整渲染／世界；掩盖独立声音消费、只用分组件通过代替完整CPU组合。

先采集完整规则边界的自然、隔离和单初态原CPU结果，编写测试并保留真实缺实现失败，最后实现组合。生产模型使用统一人物字段、共享世界状态和只读视图，不保留整幅RAM作为游戏状态。测试逐字节核对人物／子槽、其他人物、流、队列、样本、HUD及已知全局字段；明确声音中断例外，绝不把预期中间状态送入Go。

## 已验证结果

两套各 3,600 帧的原版输入基线全部逐帧一致；固定输入使用既有基线，特殊动作输入另外使用未挂钩原内核生成同输入对照。共 8,268 次自然完整规则段、1,654 个原 CPU 隔离规则段，以及 6 条单初态流共 144 步，与独立组合规则一致，原生竞态与 Node/Wasm 的 3 项聚焦测试均通过。

自然记录中 113 行实际出现独立声音消费者清槽，这 113 行的四槽声音队列被明确排除断言，其余字段仍完整比较。其中 112 行的队列确有差异，1 行最终值恰好相同；另外 8,155 行包含队列的完整状态通过比较。全部隔离和连续流关闭中断，包含四槽声音队列的完整结果一致。队列事件原样保存在夹具，没有把它们回灌给 Go。

每次比较当前人物 256 bytes、三个子槽 768 bytes，以及完整四族 4,096 bytes（含其他人物及未写子槽）。另外比较特效池 2,048 bytes、四组形状 1,024 bytes、投技区 512 bytes、录制流 1,024 bytes、HUD 单元 1,024 bytes、完整传输队列 3,072 bytes、位置样本 128 bytes、登记列表 128 bytes 和计数／共享标志／RNG。新 HUD 传输用语义描述符解释原始命令字节，不在生产状态存入 RAM 图像。

隔离矩阵覆盖四个来源人物槽、23 个动作、六种输入路线（人类、AI、播放、人类录制、AI 录制和禁用）、动画边界及暂停／慢动作／生命门槛。另有八个人类通道的录制终止／已停止状态、回放终止及 AI 录制不误读人类 Start 的组合。暂停位只看 bit7，慢动作看整个 byte 是否非零；暂停时仍登记、裁切／采样（生命不等于 −1024）、更新 HUD 并请求绘制。

完整规则的随机调用按实际路线变化，原版自然记录可为每次 0～8 次；暂停时为零，其他路线由真实 AI 和动作尾段共同推进。组合没有按人物重置或复制独立种子。投影先于世界 X 裁切，裁切后的坐标进入样本，而屏幕位置保留之前计算的结果。

## 状态与共享顺序

`ChuActorState.Fighter` 统一持有人物本体、完整能量值、输入／AI 计时、子槽与显示资源；`World` 持有共享 RNG、形状／特效、停止标志／marker／流、登记、样本和 HUD。`World.OtherEnergy` 只保存其他人物可被本回调改写的能量，队伍／生命／占用等其他可见事实由只读 `ChuActorView` 提供，避免两份人物状态。AI 的自身几何与子槽从当前 `Fighter` 重建，不使用旧的自身视图。

调用者按原对象顺序将输出 `World` 交给下一个回调，并把其他能量变化应用回真实人物；不得每人物重置 RNG、样本、登记、HUD 游标或录制标记。这里只返回 `DrawRequested/ObjectID` 与新增 `HUDTransfers`；实际 `0x1580` 精灵提交没有执行。

晚期 HUD 存储失败测试先完整执行录制 AI、动作和投影／采样，再验证所有人物、共享 map／slice、登记、流与 RNG 整体回滚，不泄漏绘制请求。只读动画库未修改。真实缺 `ChuActorState/ChuActorView/StepChuActor` 编译失败先于实现；来源与日志见[验证记录](testdata/chu-actor-validation.json)。

连续流仅更新声明的物理控制帧与暂停／慢动作标志；从同一初态推进输入、AI、动作时钟、动作、投影、边界、HUD和共享计数，不注入期望中间态。包含录制 Start 终止后的保持行为，但没有碰撞管理器、其他人物、子对象、相机／音频驱动或真实世界帧刷新，不能作为完整世界或对局证据。

## 复跑

```sh
PYTHONDONTWRITEBYTECODE=1 python3 scripts/yuyuhakusho/capture_chu_actor.py \
  --out .local/md-yuyuhakusho/chu-actor-replay
```

规则执行 `go test -race -count=1 -run '^TestChuActor' ./games/yuyuhakusho/engine`；Wasm 使用研究工具说明中的 Node 执行器，所有缓存与临时目录位于 worktree 内。大型夹具按记录流式解码并验证完整摘要，避免把整批原始 RAM 文本同时保存在 Wasm 内存。父阶段仍需执行整个游戏包集成回归。
