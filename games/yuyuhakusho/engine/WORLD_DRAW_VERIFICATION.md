# 世界绘制请求：实现前验证范围

绘制请求须保存对象回调结束时的必要呈现字段，不能只保存槽 ID 并在整个轮次之后重新读取。未来回调可能复用、清除或修改同一槽。绘制数据是值拷贝，不保存整个规则世界、RAM 或硬件队列；规则包不依赖呈现包。

失败场景：图形偏移错误读取投影临时偏移；有符号屏幕坐标转型丢失 word 回绕；图层／属性／图形缓存遗漏；未请求绘制的对象被补画；已清除但仍有 Draw 的分支被吞掉；后续对象写入使先前请求变化；出错后泄露半轮事件。

先写字段与真实覆盖层回调的测试、保存缺实现失败，再添加可选绘制载荷。既有原 CPU 整轮规则对照继续校验调用顺序与状态；这里不把请求字段完整性当作全场景像素验收。

两项测试已随原生竞态和 Wasm 全包回归通过，完整规则／呈现对局也实际消费该载荷。前置失败与当前源码／日志由[独立对局验收](../verification/independent-session.json)绑定。
