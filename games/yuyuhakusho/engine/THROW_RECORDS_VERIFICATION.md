# 投技形状生产：实现前验证范围

先从原版实际写入定位 `FFA600` 投技区及 `FFA00C` 计数的生产入口，再恢复完整生产函数。已恢复的接触消费者不能证明生产者容量、帧门槛或数据来源。

失败场景：把启动清零和碰撞管理器计数清零误认成生产；漏掉实际生产变体；观察器改变原版帧或丢失日志；把最近 PC／栈候选当成完整调用栈；误判形状 X/Y 相邻 word 的布局；混淆 byte 偏移与记录数；容量边界、末槽复用或无保护写入被自创裁切；朝向、坐标字加／回绕或元数据来源错误；覆盖原函数保留的记录字节；漏掉帧门槛、人物改写、池或全局副作用；把隔离写入当作自然输入可达性；Go 直接读取 ROM 或回灌期望输出；缺失数据时部分修改调用者状态。

顺序为：失败范围文档、被动运行与完整原 CPU 夹具、先写测试并保留缺实现失败、再编写独立 Go 规则。自然采样须与固定输入的 3,600 帧完整 RAM／视频基线一致。隔离输入明确声明，比较完整人物对象、投技区、计数和原函数写入范围；原始 ROM 和模拟器仅用于开发对照。

## 已确认生产分支

对第 1,800～3,600 帧的实际 M68K 写观察得到 17 个 PC、没有日志截断，全部 3,600 帧 RAM／画面与原版基线一致。16 个 PC 位于酎地面输入的 `0x17ecc..0x17f2e`；另一个 `0x1edda` 只是碰撞管理器清计数。原执行上下文回溯到已确认分派分支 `0x17eb0`。本片段只有酎的生产分支，不能据此排除其他人物的生产者。

本实现覆盖选择后的 `0x17ec2`，以及尾跳 `0x18854 → 0x19c00 → 0x19c1c` 的完整动作构造与重置。按钮、方向和优先级门槛由外层选择器处理，不在提交函数中重新猜测。指令见 [记录写入](../../../docs/research/md-yuyuhakusho/static/throw-records-chu.txt) 与[构造尾段](../../../docs/research/md-yuyuhakusho/static/throw-records-tail.txt)。

记录 X／Y 是相邻的 signed word，Y 等于人物高 word 减 40；宽／高为 24／40。接触后的来源姿态为 `B8`、目标姿态为 `40`、双方动作为 3、偏移 X／Y 为 24／0、目标朝向为 1。提交者本身进入动作 3、姿态 `83`、阶段标志 0，再按保留输入修正朝向并执行共用重置；保留输入右优先于左，未按左右则保留旧朝向。

原分支直接使用 `A00C` byte 偏移写入，然后 word 加 32，**没有容量检查或末槽复用**。自然片段每次入口偏移都是 0；隔离明确使用 1,024-byte 私有存储，覆盖偏移 0／32／96／480／512／992，证明 512 不是此分支的裁切界限。独立 API 使用调用方提供的 `ThrowContactBuffer.Records`，缺少目标槽时原子失败。这个数据结构边界不代表原版分配容量；异常计数产生的任意 CPU 地址别名不在本阶段声称的覆盖内。

## 验证结果与复跑

9 次自然完整提交与 1,536 个原 CPU 隔离调用逐个比较完整人物 256 bytes、声明记录区 1,024 bytes 和计数，无字段掩码。隔离覆盖四种含回绕的坐标、朝向 0／1／2／255、全部 16 种方向组合、队伍重置、旧槽未写字节和上述偏移。所有调用无额外 RAM 写入，原生竞态与 Node/Wasm 聚焦验证通过；记录 slice 未改变及缺失存储／未对齐计数的原子失败通过。测试和实际缺少类型／函数的红阶段先于实现。

原版复跑：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 scripts/yuyuhakusho/trace_throw_records.py \
  --out .local/md-yuyuhakusho/throw-records-trace
PYTHONDONTWRITEBYTECODE=1 python3 scripts/yuyuhakusho/capture_throw_records.py \
  --out .local/md-yuyuhakusho/throw-records
```

保留夹具运行：`go test -race -count=1 -run '^TestChuThrowSubmission' ./games/yuyuhakusho/engine`；Wasm 使用[研究工具说明](../../../scripts/yuyuhakusho/README.md)中的执行器和 worktree 内缓存目录。来源、夹具和真实测试输出见[验证记录](testdata/throw-records-validation.json)。聚焦测试显式列出依赖源码，避免其他并行组件的红阶段打断本组件比较；整体包级回归由集成阶段执行。

本阶段没有恢复全部人物生产者、生产者选择器、后续抓取／投掷运动／伤害或完整世界时序。9 次提交和 1,536 个隔离调用不能作为对局完成数。
