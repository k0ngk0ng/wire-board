# 场地 2／6／8：实现前失败清单

范围为 `A060.word` 的十六进制偏移 `2`、`6`、`8`，对应主回调 `20ae0`、`20e28`、`20fb4`。本清单先于本批生产实现和测试冻结。资源清单 `2175c`、`217cc`、`21800` 只证明初始化绑定，不证明持续规则或场地完成。

## 静态来源与限制

来源为 [场景完整静态](../../../docs/research/md-yuyuhakusho/static/arena-assets-scenes.txt)，其中保存三个完整主回调及公共相机 `21556`、反馈 `21690`。raw 68000 不在当前 REA 原生输入支持范围；该记录来自直接 Ghidra，不能标为 REA 反编译或原 CPU 执行结果。

主回调先检查 `F550.bit7`，再检查 `F55A.byte`。任意门控命中都直接返回，跳过初始化、相机消费、滚动和反馈。非零阶段均直接执行正常更新，不能把阶段约束为 `2`。阶段 0 写 `F6E7.byte=3`、`F6DF.byte=0`，在完成本场初始化后以 word 加 2 推进阶段。

## 可能失败的场景

| 类别 | 必须覆盖的失败场景 |
| --- | --- |
| 来源与范围 | 把资源绑定、默认场地夹具或修改 `A060` 的私有样本称为合法菜单路径；观察器改变任一自然帧；跳过本场唯一原版对照；把静态推断写成实际执行 |
| 门控和阶段 | 暂停标志不是只检查 bit 7；慢动作只检查低 bit；门控期间初始化、反馈或样本被消费；错误拒绝非零 dirty 阶段；`F6DF` 的初始化写丢失 |
| 对象存储 | 混淆 word 写和 long 写；word 写覆盖对应低 word；把同一对象 long 的高 word、低 word 作为互相独立的持久字段；误清未写的 dirty 字节 |
| 场地 2 | 漏清第三组漂移或波相；将三组加数合并；波相按普通整数增长；把 `+08/+14/+1c` 的高 word 当作 low word；错误重算原曲线首 word 的半值公式；行数、起点或未写空隙变化 |
| 场地 6 | `MULS #7000`、`SWAP` 后取 word 错误；算术右移变为无符号或普通除法；五个持久 word 的任一低 word 被覆盖；平面 B 半速源按默认场地计算 |
| 场地 8 | 忽略 `+0c.long` 实际曲线指针写；`+1c.word` 在反馈非零时仍推进；把 56 行波幅和步进套成场地 2；`NEG/ADD/SUB` 中间 word 回绕被数学合并改变 |
| 查表 | 将 `34000+(phase&7fe)` 的 signed byte 误作 signed word；用数学正弦替代原表；根据地址间隔猜曲线；错误使用默认 56 行尾表；缺表或短表静默填零 |
| 相机和垂直源 | 未按 word 回绕求和、无符号除法；无样本时重写相机；`dy*2` 在 word 回绕后才扩展的顺序被改变；平面 B 的移位、偶地址取整或偏移顺序错误 |
| 反馈复制 | 复制长度不是 224 word；忽略 HUD 前缀；反馈加法未按 word 回绕；B 源误作 A 源加 256 word；错误拒绝合法负选择；读出已知视图外时静默遮罩或零填充 |
| 原子性 | 相机消费或阶段初始化之后发现曲线／波表缺失，仅部分回滚；反馈在末段失败后保留已写行；错误路径改动调用者输入 slice／map |
| 连续状态 | 每步把前置状态重新从原版注入；外部相机样本与本场持久字段混在一起；暂停、慢动作、反馈后的恢复出现相位跳变；长时间 word／long 回绕后漂移错误 |
| 完整 delta 和归属 | 只比较字段快照，漏掉完整 64 KiB 中的未知写；把 IRQ、音频消费者、stack 或别的对象写混作场地主回调；通过扩大允许地址集或 mask 消除差异 |
| 独立运行 | 测试或运行时依赖 ROM、原内核、68000 CPU／VM；只在原生 Go 通过而未在 Node/Wasm 复跑；没有固定来源摘要、缺实现失败记录和可重复执行产物 |

## 已核对的对象与行写入

对象偏移均相对于 `A5=FF8180`。区间使用闭开表示。

| 场地 | 初始化对象写 | 正常对象写 | 持续滚动行写入 |
| --- | --- | --- | --- |
| `2` | `+08.long=0`、`+14.long=0`、`+1c.long=0`，`+20/+22/+24.word=0` | 无反馈时三个 long 分别加 `4000/6000/8000`，三个相位 word 加 `8/10/10`；曲线结果写 `+18.word`，半值结果写 `+0c.word` | 初始化 `RowsB[0:120]=01a0`；每帧 `RowsA[80:104]` 波形、`[104:160]` 常量、`[160:248]` 曲线；`RowsB[120:152]` 波形、`[152:192]` 常量、`[192:240]` 波形 |
| `6` | 无 scratch 清零 | `+08/+0c/+10/+14/+18.word` | 初始化 `RowsA[16:112]=01a0`；每帧 `RowsA[112:176]` 常量、`[176:248]` 曲线；`RowsB[16:136]`、`[136:152]`、`[152:168]`、`[168:208]` 常量 |
| `8` | `+1c.word=0` | 无反馈时 `+1c.word += 20`；曲线首 word 写 `+08/+14.word`，实际曲线地址写 `+0c.long`，其余结果写 `+10/+18.word` | 初始化 `RowsB[16:144]=01a0`；每帧 `RowsA[80:144]` 常量、`[144:248]` 曲线；`RowsB[16:144]` 常量、`[144:200]` 波形、`[200:240]` 常量 |

`RowsA/B` 是 `E800..E9ff`、`EA00..EBff` 的 word 视图。未写区域必须保留当前值。场地 2 的曲线是 `24000+(x-2e0)*256+20` 起的 88 word；场地 6 是同基址 `+40` 起的 72 word；场地 8 是同基址起的 104 word。所有数值和地址均为十六进制，区间索引与行数为十进制。

## 计划保留的证据

1. 使用根任务提供的合法固定输入及本场唯一 `original3602control`，记录完整自然帧 RAM／视频摘要并核对观察等价；本 collector 不重新生成原版基线。
2. 从合法状态保存 checkpoint，恢复时显式使用 `restore_refresh_cycles=True`。私有 dirty 矩阵记录实际入口、实际 RTS 后状态、完整 64 KiB delta 与 stack／规则写的归属；任何未知写必须失败。
3. 单初态连续序列只补外部输入，不回灌本场状态，覆盖暂停、慢动作、反馈、相机样本、signed byte、word／long 回绕与恢复。
4. 在冻结的原 CPU 夹具上先编写测试并保存针对本批真实生产符号的缺实现失败，再实现 `StepArena2/6/8`；保留原生 Go 竞态与 Node/Wasm 的可复跑日志及来源摘要。

尚未得到合法自然对照、公共状态接口冻结或真实缺实现失败前，不把本批状态标为已恢复。本清单不证明资源解码、背景像素、平台场地选择或完整对局通过。
