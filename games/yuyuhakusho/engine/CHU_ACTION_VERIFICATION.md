# 酎完整动作调用：实现前验证范围

目标为 `0x15a18` 进入至 `0x15b82` 完整返回：角色命令准备、共用输入准备、命中停顿／正常前置、实际动作分派及共享尾段按原顺序组合。它属于完整动作调用，不包含外层输入采样、其他对象调度、碰撞管理器、画面提交或完整世界步。

可能失败的场景：在停顿时错误冻结命令准备；把世界 RNG 按角色重置；命令请求／输入准备顺序错误；动作使用前置更新前的动画计时；动作转移后又执行第二个动作；错误映射十进制和十六进制动作编号；能量高 word 与低 word 在阶段转换时丢失；重复推进时钟、清理标志或 RNG；遗漏三个子槽、特效附加字段、其他人物能量或全局反馈；把下一角色或同角色子对象的更新混入函数边界；用单阶段成功替代完整调用对照；非法库／类型／存储失败后部分写入；回灌原中间状态形成表面连续；独立声音消费者被误认为该函数内生写入。

先取得完整原 CPU 调用与明确私有输入的隔离样本，再写组合测试并保存缺实现失败，最后编写组合。比较人物及三个子槽、其他人物、全部形状与投技、特效池、相关全局状态及 RNG；自然记录中的独立声音消费单独保留，不向 Go 注入期望队列。连续流只改变声明的外部输入，动画时钟与动作中间状态由独立规则连续推进。所有可复跑证据、实际覆盖和剩余调度边界必须保留。

## 已验证结果

两套各 3,600 帧原版输入的完整 RAM／视频基线保持一致，取得 8,108 次完整自然返回。人物、三个子槽、其他人物能量、特效池、形状／投技、计数、反馈与 RNG 一致。99 行有实际声音消费者清槽，测试仅在这 99 行排除四槽队列，其中 98 行预测队列不同；其余 8,009 行包含完整队列的比较通过。没有将外部消费的期望队列写入 Go 输入。

3,312 个隔离完整调用覆盖 23 个已确认酎动作；8 条单初态流共 790 次完整调用连续推进，期间只更新声明的低字节控制输入。动作时钟、命令缓冲、动作转移、能量小数、子槽建立与共享 RNG 由规则自行演进，不恢复原中间态。每个原版调用都实际消耗一次 RNG，Go 顺序一致。

原生竞态和 Node/Wasm 集成回归通过；错误路径保留整体原子失败，帧库与命令库不变。实际缺实现失败先于生产函数，日志与来源摘要见[世界基础阶段验收](../verification/world-foundations.json)。独立只读复核未发现已覆盖有效状态的顺序或字段错误。
