# 场地 A：实现前失败清单

范围为原场地偶数偏移 `0a`、主回调 `21126` 和创建于 `9e00`、大小 `40` 的 `21258` 子对象。静态证据来自直接 Ghidra；REA 当前不支持 raw 68000。生产实现必须由已冻结的原 CPU 参考驱动。

- 门控：主回调在暂停位 7 或非零慢标志时无操作；子回调在这些门控期间仍执行其末尾六次 `14d0` 提交，不能提前返回。
- 初始化：仅阶段零初始化，所有非零阶段保持合法；主对象创建子对象时只写回调、大小、阶段及 `+1a` 父 word，不能清空 dirty 字段或合并成父的呈现副本。
- 子对象：`+18`、`+1a` 共用完整 `Aux18`；`+1c` 是 `GraphicsSet` 高 word。不得新建重叠持久字段。父引用必须读取真正对象；暂停时保留上次缓存值。
- 描述符：子对象的 `+20..+29` 在每次提交前被重写；保留原 `+20` long 两个 word、`+24` word、`+26` word、`+28` word 的别名，不能套普通人物 DrawRequest 或只读取最后一次状态。
- 描述符有效域：正常初始化设置 `+22=0ffc` 和 `+28=ffff`；非零阶段保留任意 `+22`，不得强制重设 size/link。若非初始化路径的 `+28` 被人为破坏，原 `14d0` 会继续读额外内存，窄接口应原子报缺少有界描述符，不得伪称仍只有六条。合法自然状态不触发此错误。
- 提交链：必须解析 `14d0` 全部可达逻辑、逐次即时捕获六次输入、追踪消费者和完整 RAM 差异。不能因相邻天空对象而推断用途，也不能把硬件输出缓冲区说成世界规则。
- 算术：所有 word 运算依原 16 位溢出、符号移位和符号扩展；`F59C` 先双倍、算术右移、清低 bit，不能直接用未经 wrap 的 dy。
- 行缓冲：主回调写 A 的索引 `80..247`、B 的 `16..239`，保持其他 dirty 行、HUD 前缀及存储间隙；A 尾部从真实表拷贝 64 word。
- 查表：父 `+0c` 保存真正 ROM 行地址；按相机 X 从 `24000+(X-2e0)*100+50` 读取，不猜填充，不把默认 56-word 尾表冒充本场 64-word 尾表。
- 反馈：必须复用共享 Stream 所有权语义，覆盖偏移、负源行、pan word wrap 及保持间隙；不能持久保存第二份 PanA/B。
- 全局与外部：记录 `F6DF/F6E7` 初始化，IRQ、音频消费者及回调结束点；全 64 KiB actual delta 有归属，不能用宽 allowed 范围掩盖未知写入。
- 连续性：自然合法选场、dirty 边界、父创建与同一轮子执行、重复更新、暂停/恢复和保存恢复均用原 CPU，挂钩完整帧与唯一原版基线一致。
- TDD：先冻结夹具和调用真实新增符号的测试、保存缺实现 red，再实现；禁止补断言或缩减覆盖让实现变绿。原生与 Wasm 使用同一夹具且不依赖 ROM、MD core 或 VM。
