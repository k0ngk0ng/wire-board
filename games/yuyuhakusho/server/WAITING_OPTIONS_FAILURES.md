# 等待房间配置与原版角色映射的失败场景

本清单先于配置／准备代码和对应测试。此阶段只验证平台配置边界，不表示完整实时模块、网络或发布已完成。

- 人数不在 2／3／4；组队用于非四人；场地不是已恢复的八个偶数 ID。
- 角色不是来源 0～10，角色数量与房间容量不符；把平台 seat 直接当原版 slot。
- 空请求与显式 null 混淆，未知字段、重复字段、尾随 JSON 或类型错误被接受；把输入 raw／角色 slice 原地改写。
- 非占座者或越界 Actor 进行准备；占座元数据与容量冲突；将未占座当电脑。
- 非房主改场地或队伍模式；用户改其他真人角色；房主不能改显式电脑角色。
- 准备中改变了其他席位选择；默认角色覆盖已选角色；取消托管、后台或断线触发电脑替代。
- 映射丢失三人 0／1／3 或两人 0／3 布局；真人通道不按平台 seat 鉴权，电脑标记从客户端数据伪造。

角色默认按平台 seat 保存，原版 slot 映射只在开局配置投影中派生。原版规则、AI 和对局仍由独立引擎实现，准备不执行原菜单。
