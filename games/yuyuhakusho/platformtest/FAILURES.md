# 真实平台接入的先行失败场景

本清单先于 composition-root 注册和对应实际主机验收。测试使用真实 HTTP、身份会话、SQLite 与平台时钟；测试账号只在临时工作区数据库。

- 游戏未注册、默认下架、创建／加入／准备／开始不走公共入口；普通玩家能改管理状态。
- 模块加载门槛与公共 ready 混淆；未加载席位导致规则提前推进，或重连重新暂停全员。
- spectator／别人的 seat 可写入；错误 epoch、重放序号、超 12-bit 按键和多余字段被接受。
- 短按丢边沿、失联保持按键、闲置／后台误交电脑；主动托管或取消托管重置生命、动作或其他席位状态。
- /sync 发送 parse 后会损精度的 checkpoint object，或 uint64 Present 高位丢失；持久化重启重置局面／clock。
- 普通 View 携带 World、HUD 像素、完整 save 或无界事件；慢 HTTP／WebSocket 接收阻塞另一玩家或权威时钟。
- 房间席位与原版 0／3、0／1／3、0／1／2／3 映射混用；winner／draw／显式电脑积分标记错误。
- 编译／模块级模拟 host 被误写成真实浏览器、物理手柄、低延迟或所有网络条件完成。

本目录的首个注册 red 是真实缺失 composition-root；规则模块的先行 E2E 由 server 自有测试独立保存。最终 UI／原生输入到像素延迟还需浏览器实测，不能以 ACK 耗时替代。
