# NFS4 极品飞车专项改造失败场景清单

本清单在编写实现与测试前列出 7 项改造的全部关键失败场景，对应测试优先于实现编写。

## 1. PC 端仪表盘下挡位背景过长
- 全屏模式下 `[data-room-fullscreen] .racing-gauges[data-mode="analog"] .racing-gauges-gear` 使用 `padding-bottom: 16px` 撑大深色背景，导致数字下方出现 16px 留黑。
- 修复背景高度时直接移除底部留白，导致全屏右下角聊天按钮与仪表盘重叠。
- 非全屏桌面端或紧凑模式（窄竖屏 `data-mode="compact"`）挡位文字被裁切、背景偏移或错位。
- 倒挡 `R` 或多位数/默认挡位文字与背景不居中。

## 2. 车辆差距时间（参考原版 `nfshsd.exe` `0x4cad50` 与 `0x4c9640`）
- 发车倒计时阶段或零位移时出现 `NaN`、`Infinity` 或无意义大数值。
- 头车（第 1 名）相对头车显示非零时间差，或自己相对自己显示非零时间差。
- 两车均已冲线时未使用精确 `finishAt` 差值，导致完赛成绩与实时间距不一致。
- 刹车/弯道/停车/复位瞬间仅按瞬时速度估算导致差距剧烈跳变或除以零。
- 被套圈车辆（落后整圈 `>= 1` 圈）未按标准赛车规则显示 `+N 圈` / `-N 圈`，反而显示混乱秒数。
- 相对参照方向相反（领先自己的前车未显示负号 `-`，落后自己的后车未显示正号 `+`；或总榜相对头车符号错误）。
- 读取无 `gateTimes` 字段的旧存档失败，或 6 车 `View` 报文超过 8 KiB 预算。
- HUD 差距列表在窄屏/横屏/平板上与小地图、仪表盘、后视镜或触屏按钮重叠。

## 3. iPhone / Surface Duo / iPad 触屏按钮布局与观感
- `Board.tsx` 踏板内联不透明 `background: linear-gradient(...)` 覆盖半透明玻璃质感样式。
- Surface Duo（单屏 540×720、展开 1114×720）与 iPad（768×1024、1024×768、820×1180、1180×820）未命中抬高与放大规则，按钮仍紧贴屏幕底部难以拇指按压。
- 圆形按钮尺寸小于 44×44px，或放大后与底部视角/喇叭/复位键、全屏聊天键、顶部小地图/仪表盘重叠。
- 左右圆形转向键之间拖动切向（`RacingTouchContacts`）失效或长按触发原生选择/菜单。
- 半透明按钮在白天明亮路面或夜间暗背景上文字/图标对比度低于 4.5:1。

## 4. 赛道小地图放大与车辆圆点可见度
- 小地图仍按含额外留白的 `track.width / track.height` 缩放，导致实际赛道线条缩成一小团。
- Canvas 固定 160×112 未按 DPR 缩放导致放大后发虚。
- 车辆圆点过小、缺少高对比度描边/光晕，或在多车靠近时自己圆点被对手圆点遮盖。
- 赛道地图弹窗（`RaceMap`）在超大 v3 经典赛道上缩小时车辆几乎不可见。
- 放大后的小地图在 320px 竖屏或横屏下与顶部仪表盘、后视镜或触控按钮重叠。

## 5. 等待房间每个玩家旁的车辆小图标与悬停型号提示
- 已入座的人类玩家或电脑玩家（AI）旁边未显示对应车型缩略图。
- 空座位误显示车辆图标。
- 玩家未手动切换车型时，前端默认车型与服务器 `configure()` 默认分配顺序不一致。
- 鼠标悬停或键盘聚焦车辆图片时未显示具体车型型号文字（缺少 `title` 与即时浮层提示），或浮层被 `.waiting-seat` 裁切。
- 图标与房主皇冠、AI 徽章、移除电脑 `×` 按钮重叠，或在 320px 窄屏溢出容器。

## 6. 德国乡间公路 & 金迪亚克公园树碰撞体积与公园火车转弯问题
- Billboard 物体（`type == 2`）继续继承无关 `object_attributes[0]` 的碰撞属性，在路边或路面形成空气墙。
- 静态 3D 树（`type == 4, collision_type & 3 == 1`）继续使用完整树冠 2D 凸包而非原版 `nfshsd.exe` `0x438d30` 的树干圆柱半径 `(u1 >> 1) / 256` 米，导致德国和金迪亚克公园多棵树碰撞体突入沥青路面 1.5m–2.4m。
- 修改路线碰撞体后破坏历史旧存档（`stale-v3-laps/*.json`）的不可变 `geometryHash` / 道具目录 / 地形目录兼容性。
- 可撞毁道具（`collision_type == 2`）数量、索引或 `ruleEdges` 校验失败。
- 金迪亚克公园两列火车（`object_556..565`）沿用错误的四元数共轭 `(-qx, qy, qz, qw)` 而非 `(qx, -qy, -qz, qw)`，转弯时车厢反向旋转高达 90° 侧滑重叠。
- 火车循环重置时的 548m / 614m 瞬间跳变仍被 glTF `LINEAR` 插值，导致火车横穿公路森林。

## 7. 原版撞击音效与远距离静音截断
- 超过原版 `nfshsd.exe` `0x42c3a0` 截断距离（`2 * d^2 >= 5625`，即 `d >= 53.033m` / `530.33` 分米）的他车撞击仍然触发音频播放或占用声道。
- 近距离他车撞击缺少原版二次衰减 `(5625 - 2*d^2) / 5625` 或左右声道空间定位。
- 自己车辆撞击被误衰减或误截断。
- 可撞毁道具事件仍把坐标清零 `(0, 0)`，导致道具撞击声无法计算与听者的真实距离。
- 未从原版 `gen.bnk` 提取无损 FLAC 碰撞音效及校验 SHA-256，或运行时发出清单外网络请求。
- 连续撞击未遵守原版 `0x42c123` 防同样本重复切换，或静音/切后台/失焦时仍播放撞击声。
