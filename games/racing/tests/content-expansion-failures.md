# 原版车辆、赛道与选择缩略图

本轮增加宝马 M5（BMW5）、捷豹 XKR（JXKR）、奔驰 CLK GTR（MCLK）和德国乡间赛道（GERMANY）。保留现有五车、四赛道及历史几何引用，不重新生成或覆盖旧资源。

实现前的失败场景：

- 新车型或赛道只出现在选择框，正式 Configure、Prepare、Start 或电脑输入不接受；请求可伪造其他席位的车型。
- 原模型、驾驶舱、四轮节点、轮位、尺寸、基准 CARP、调色板或发动机声音缺失，实际使用旧车型的外观或性能。
- 原赛道的道路点、高程、路宽、地面材质、固定墙、可撞倒物件、昼夜场景或天空不完整；电脑不能完成路线。
- 新资源改变旧模型、旧道路文件、旧几何摘要或旧存档引用；新地图仍使用旧地图的碰撞或材质。
- 远端 ISO 资源范围、长度、ETag 或路径不一致；输入不完整时产生半份公开清单；工具写出工作区或覆盖已有素材。
- 缩略图与实际选择内容不同、无法加载、切换后仍显示旧图；把整套 3D 模型或其他地图作为房间缩略图预加载。
- 320px 选择区域裁切、错位或挤压公共房间布局；键盘、实体手柄与触屏不能继续使用原选择操作。
- 新增车或新地图在单电脑、混合车型、完整比赛、托管、取消托管和恢复时失效；服务端包包含客户端图像、模型或音频。

原始数据只读取已有 ISO 索引中选定的资源范围，不获取或执行程序文件。记录实际下载范围、字节数与 SHA-256；原始来源和生成产物分别留存。缩略图使用原版对应菜单图或实际模型／场景渲染，不能用换色旧车或改名旧赛道代替新增内容。

验收保留正式 Module 完整驾驶记录、资源摘要与原数据对照、PC／320px 原生选择和图片加载截图，以及本地 CDN 回读和服务器包边界结果。
