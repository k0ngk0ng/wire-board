# 原驾驶舱动态：实现前失败清单

- 方向盘、RPM／MPH 原针只显示静态网格；以转向按钮代替实际前轮转角，回正后仍保留旧姿态。
- 仅看部件名字猜绕 Z 或 UV 滚动；针的实际三角根部、盘面法线与原 part 原点不同，旋转后飞离表心。
- 原 steering 薄平面与轴心未由几何核对，转动时摆动、缩放或绕车体旋转。
- 动态修改共享原顶点、UV、原材质、昼夜可见性、驾驶舱相机或车身位姿，影响其他车辆。
- 转速与速度串用，同样速度下转速／挡位变化不能反映；非法读数产生 NaN 或超出冻结范围。
- MCF1 没有原 MPH 针仍新增悬浮假表，或用覆盖原盘的通用圆表掩盖缺失。
- 切换追车／驾驶舱、B 后视、F5 或观战导致动作重播／归零／错跟车辆；卸载不还原动态包装。
- 浏览器把手刹左右转、撞护栏后的近零速度末样本当作“加速中”，错误声称 MPH 针未响应。先在仍有真实前进速度的直行区间读取速度针，再保留同样左右转向、原像素、五车与 320px 断言；不得降低针角变化门槛。

该场景已在 `.local/racing-nfs-browser/final-cockpit-01/` 留下红报告和原生输入证据：P911 的 loaded／left／right 原针角为约 0.534／0.613／0.678 rad，末 moving 样本已撞护栏停至约 0.21 km/h。场景修正保持原 `>0.01 rad` 速度变化门槛，不能把这份旧红计为产品针不动或最终通过。

证据核查：五车原 GLB 的 `extras.originalPart`、3 顶点 RPM／MPH 三角针、原 UV 与 dash00.tga 原像素；方向盘为独立原网格。短边根部通过原 DASH 面 UV 反投影落在原表心；不能直接用 part 原点。原像素对照保存在 `.local/racing-cockpit-dynamics/`，属于素材静态证据，不冒充 Windows 实机运动测量。

先编写几何不漂移、原像素／材质不变、五车实际节点绑定及独立读数测试，再实现。实际驾驶舱像素变化由正式浏览器 E2E 验证。
