# 原物件呈现：实现前失败清单

- 原碰撞 CAN clip 在开局被作为环境循环播放，未碰撞的物件自行倒下。
- 可破坏 wrapper 被静态合批，导致权威 broken 状态无法独立移除原几何；旧隐藏几何继续参与镜头射线。
- 只收到事件而未收到确认 broken 位时提前播放；低速／高速动作选错或按碰撞方向改写原动画。
- 按本地帧时钟从零播放迟到事件，重复快照／事件使动作重播或时间倒退。
- 恢复时仅有 broken 状态、没有近期事件，仍复活或补播旧动作。
- 短动作／长动作分别丢失原 0.46875／1.5 秒时长，结束后回正或循环。
- 减少动态效果仍播放倒下过程，或切换减少动态效果让已倒物件重新出现。
- 事件先于其可见权威时刻触发；动作进行中事件退出有界事件环后被重置。
- 目录与 GLB／规则 geometry／catalogHash 不一致，或索引、节点、motion 节点及 clip 身份错误时静默使用错误素材。
- 镜头仍被 broken 物件对应的碰撞边阻挡，或后视镜另一次剔除让主场景中的状态重置。
- 独立物件每帧重建几何或材质、减少原三角面以掩盖性能问题；动画卸载未释放 mixer。

先写 `classic-prop-animation.test.mjs`，再实现纯权威动作状态及场景绑定辅助。正式房间撞击、恢复、重复事件与帧率验收由 `check-nfs.py` 接入，不用隔离验证替代页面 E2E。
