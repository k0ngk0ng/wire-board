# 指针仪表与轮胎印：实现前失败清单

- 速度／转速仍以大数字主导；指针与 km/h、rpm、倒挡或车型红区不一致，异常值导致 SVG 非有限坐标。
- 320px 仪表溢出或压住油门／刹车／转向／手刹／聊天，F5 不能隐藏，缺少可读取的速度和挡位语义。
- 只因方向键或普通转弯留下胎印；低速停车、保护／复位或已知松散地面仍连续画黑线。
- 急刹、真实横向滑移或手刹没有轮迹；手刹错误让前轮锁死；观众只看得到自己的车印。
- 轮距根据通用车宽猜测，未使用原模型轮心；轨迹浮空、穿坡、桥上车印落到桥下，条带宽度不随路面法线投影。
- 重新接管、旧快照、复位或瞬移跨越赛道连出长线，松开刹车后下一次印迹连接旧痕。
- 缓存无界、每段创建 Mesh／材质，胎印不渐隐或减少动态效果后继续生成；卸载没有清理。
- 用降低车辆／赛道精度或放宽既有帧率预算换取轮迹性能。
- 把 VROAD 宽度外的真实柏油当作草地而不画胶印，或仍以最近 VROAD 平面代替实际地形高度／法线；没有地形命中时生成悬浮印迹。
- 将未知材质猜成草；已知草 3、碎石 2、落叶 4／11、尘土 5／13、雪 9／15 仍画黑胶印；地面缺口后连接旧轮迹。
- PC 仪表仍占用 330px、向左空出 96px，或缩小后与小地图底边不齐；公共聊天压住圆盘实际像素。
- 320／390／430 竖屏仍用近 200px 双圆盘压住前方道路；紧凑读数和约 70×50 小地图侵入中间视线或触屏按钮。
- 挡位仍带 D、放在盘内或独立大框中；在圆盘外的 footer 字号过大。
- portrait／landscape 切换后只更新旧隐藏节点，实际可见 speed／rpm／gear 停留在零值；F5 或 aria 丢失。
- 320×480 竖屏误命中仅按 pointer／max-height 判定的“短横屏”规则，镜开后 HUD／紧凑数字／地图错位。
- 844×520 横屏高于旧 500px 上限，镜开时仪表落到 206px 并压到踏板；短横屏规则须覆盖到 600px 且限定 landscape。
- 844×390 的圆盘虽不碰踏板，小号 gear footer 实际文字仍低于油门顶部 0.8125px；需给短横屏 analog 留明确垂直净空，不能放宽相交门槛或改变 compact 108px。

先编写指针映射、触发边界、坡面条带、有界轨迹与重置测试，再实现。真实 PC／320px 页面、指针像素变化、地面轨迹截图与现有性能预算由浏览器验收补齐。
