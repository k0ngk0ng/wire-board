# 原版参考运动核心：实现前失败清单

2026-11-11，先于 `classic_motion.go` 与 `classic-motion.ts` 编写。范围是 SI 单位的独立运动核心；生产房间、碰撞、检查点与网络验收由接入层承担。

- 原版 CARP 只是参数证据，尚未证明原版程序的全部使用语义。不能把本轮轨迹当作原版实测。
- Go 与 TypeScript 对相同输入序列产生不同位置、速度、偏航、转向、挡位或转速，导致权威校正持续拉回。
- 输入转向直接跳满、释放后不回正，或反向时跨过零点发生不连续。
- 全刹采用速度指数骤降，20 ms 内从高速突然限速；低速车会穿过零速变成无意倒车。
- 在路肩边界直接裁切速度，导致路肩进入时骤停。
- 车型仅换外观，真实质量、轴距、制动、极速、传动、输入斜率被丢弃。
- 前后轴抓地没有差别；手刹只给车头加速，没有失抓、侧滑或恢复。
- 低速轮胎数值不稳定、方向抖动、零速自行旋转；高速满转向产生瞬时掉头或无限偏航。
- 换挡重复跳挡、转速不掉、起步被红线限制、无油门倒退或挡位反复振荡。
- 低速按住制动无法进入倒挡；断线保护的全刹却错误进入倒挡。
- 上坡不减速、下坡不影响运动，低抓地路面对转弯没有影响。
- 非有限数、非法输入、非法 dt、零质量等边界将 NaN/Infinity 传播到服务端和浏览器。

验证先于实现：共享输入夹具，Go 执行全部轨迹后由 Node 读取同一夹具独立执行 TS，逐步核对每个运动状态字段。另有与实现独立的物理边界：100 km/h 全刹停车距离 35～90 m、停车不反向、单个 20 ms 制动减速小于 0.35 m/s；路肩切换速度差小于 0.5 m/s；低速转向可控、高速偏航有界；手刹产生额外侧滑并在释放后恢复；两车有独立极速/传动与响应；上坡、下坡和抓地改变产生正确方向的影响。上述是本项目冻结的设计验收范围，尚不是原版误差承诺。

原版参数来源：试玩 `Data/Cars/P911/car.viv` 与 `Data/Cars/FM50/car.viv` 内基础 `carp.txt`，原始字段、偏移与摘要保存在 `.local/racing-nfs-reference/physics-reference/carp-observed.json`。采用公开标准双轴车辆运动、轮胎力限幅和独立设计的低速稳定化；不复制 GPL 操控实现。所选轮胎刚度、重心高度、侧滑恢复和阻力拟合必须明确标注为设计选择。

可重复执行：`. scripts/env.sh && go test ./games/racing/server -run TestClassicMotionContract -count=1`。产物在 `.local/racing-nfs-motion/`：完整 Go 轨迹、跨语言误差报告和场景指标。生产接入后仍须执行房间 E2E 与原生事件到像素延迟验收，不能用该核心验证替代整款游戏验收。
