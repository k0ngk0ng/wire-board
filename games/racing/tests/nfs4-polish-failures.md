# 极品飞车（NFS4 复刻）六项打磨失败场景清单

1. **iPad 触控按钮尺寸与布局**
   - iPad 竖屏（768×1024、820×1180）与横屏（1024×768、1180×820）及双屏展开视口下，左右转向按钮小于 100px，或右侧油门/刹车未相对放大一圈。
   - 放大后的触控按钮与底部视角工具栏、手刹按钮、右上仪表或左上小地图发生重叠或超出视口。
   - 手机窄屏（320px/390px）与横屏手机（844×390）受到平板样式污染导致按钮溢出或遮挡视线。
   - 全屏模式下 `[data-room-fullscreen]` 覆盖了平板按钮间距或导致手刹按钮错位。

2. **全赛道中英文名称一致性**
   - 房间选图显示「金迪亚克公园」，进入赛局左上角 HUD 却显示「奇迪亚克森林」；或「法国乡间公路」变成「法国乡间」、「海豚湾」变成「滨海公路」。
   - 直接修改不可变规则 JSON 导致 `RuleSHA256` 校验失败或破坏历史对局快照兼容。
   - Go 服务端 `Tracks()` / `Start` / `View` 与前端 `classicTrackFromRoute()` / `classicTrackNames` 任一处赛道名称不一致导致镜像一致性测试失败。

3. **房间→车漆→小地图→差距列表统一玩家配色**
   - 8 席玩家/电脑配色不足 8 种、重复或彼此区分度不足。
   - 房间等待席位头像与车辆徽章、3D 车身喷漆、小地图圆点（含自身）、大地图圆点及差距时间列表的玩家名称颜色不一致。
   - 颜色在深色 HUD 背景（`#08131f`）上对比度不足（低于 WCAG AA 4.5:1），或浅色头像背景导致文字难以辨认。
   - 小地图上将自身圆点改为席位颜色后，无法与对手圆点一眼区分（缺少白色外圈与方向指示）。

4. **房间人数标签格式与 8 人竞速支持**
   - 房间左侧及创建弹窗仍显示冗长的 `2 / 3 / 4 / 5 / 6 人`（或 `2 / 3 / 4 / 5 / 6 / 7 / 8 人`），而不是 `2～8 人`。
   - 非连续人数游戏（如 `2 / 4 / 6 / 8`）被错误折叠成 `2～8`。
   - 8 人对局在服务端 `Configure` / `Prepare` / `Start` / `decode` 被旧的 6 人上限拒绝，或 8 辆车发车格排布异常、动态 `View` JSON 超出预算、8 人完整完赛排序/差距异常。

5. **比赛圈数上下数字组件**
   - 房间选项仍使用 `<select>` 下拉框，未改为上下数字组件（`−` / 数字输入 / `＋`）。
   - 服务端仍仅允许 `1 / 3 / 5` 圈，拒绝 `2 / 4 / 6 / 7 / 8 / 9 / 10` 圈；或未拒绝 `0 / -1 / 11` 等越界与非整数值。
   - 非房主或提交中状态下未禁用按钮，或在边界值（1 圈 / 10 圈）未禁用对应减/加按钮。

6. **车辆引擎声恢复、原版刹车胎响与近处撞击声**
   - 进入赛局加载阶段因 `props.sound` 为 `false`，`loadClassicScene` 跳过发动机音频下载；进入对局后 Service Worker 封存清单拒绝新请求（504），导致引擎声完全消失。
   - 失焦/静音切换时 `useClassicEngine` 反复重建并丢失已解码音频，或旧版 `racing-engine`/`racing-tires` 40ms 定时器干扰新版连续音频。
   - 刹车/手刹/甩尾时缺少原版 `gen.bnk` 刹车胎响循环（补丁 41/42/45/46/47），或在停车、腾空、完赛、复位、静音或切后台时继续发声。
   - 空间撞击声（`audio.spatial`）因 4096 字符长度截断或对 `data:` URL 调用 `fetch()` 触发 CSP 拦截而静默失败。
   - 移动端触屏按下控制按钮触发 `preventDefault()` 后未解锁平台音频。
