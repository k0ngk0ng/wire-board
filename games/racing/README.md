# 极品飞车

2～6 人的车后追逐视角竞速，支持真人、电脑和混合对战。游戏 ID 为 `racing`，沿用平台的大厅、两步创建、等待房间、玩家栏、托管和结算浮层。

## 赛道与车型

首批 5 条长赛道：霓虹城区、工业港湾、滨海公路、林间山道、赤岩峡谷。每条都有独立路线与环境；可选 1、3、5 圈。新对局最长 20 分钟，首车冲线后其他车辆有 30 秒完赛。排名按实际过线时间，未完赛按有效检查点进度；没有有效进度时使用平台和局结果。

可选保时捷 911 Turbo、兰博基尼 Countach、法拉利 F40、日产 GT-R R34、丰田 Supra A80、宝马 M3 E46。六款车使用各自的风格化车身轮廓、车顶、灯组和尾翼；模型由项目代码生成。车型性能和碰撞尺寸一致，外观选择不改变坐标、输入序号、圈数或比赛期限。

道路极速约 324 km/h；电脑在直道提高巡航速度，提前观察弯道并减速。

## 操作

- W／↑：油门；S／↓：制动；A／D 或 ←／→：转向。
- 空格：手刹，降低侧向抓地并减速。
- 按住 B：向后看，松开恢复追车视角；回看不改变转向或服务器状态。
- R：低速重置到最近已通过的检查点，等待 2 秒重新起步，冷却 5 秒；不增加进度。
- 高速时可用转向幅度减小，弯道需要提前减速；键盘、鼠标、手柄与本地预测使用同一转向规则。
- 全部自动挡，不提供手动换挡。挡位显示按速度派生。
- 手机使用方向盘、油门、刹车、手刹及后视按钮，可同时多指操作；踏板从左到右为手刹、刹车、油门。油门按住加速、松开滑行，制动优先于油门，不提供自动加速。

赛道图通过统一弹窗打开，支持鼠标拖动、滚轮锚点缩放、触屏拖动／双指缩放及小地图连续定位。关闭地图回到驾驶键盘焦点。新对局由平台滚动到实时游戏区域一次，快照不会抢回用户的滚动位置。

失焦、隐藏、失去控制权和重连会清除旧按键；键盘自动重复不能在重连后重新踩油门。真人空闲不自动托管，手动托管和取消托管继续使用平台入口。

## 画面与联机

主画面为 WebGL 三维追车场景，渲染器只在赛车创建／等待或对局时加载。无法使用 WebGL 或图形上下文丢失时，使用同方向的透视兼容画面，驾驶规则保持一致。车身、路面与环境是独立绘制资源，不依赖外站图片才能驾驶。

道路中心线、路宽和路边实体位置由服务器提供。三维场景采用平面街机驾驶物理；路边实体使用地面碰撞近似。自身使用有界短预测，驾驶视角中的其他车辆短推算，观众使用插值；客户端不决定圈数、名次或碰撞结果。旧存档保留已保存的赛道几何、进度和期限。

普通移动和物理帧仍在内存中推进，每秒保存检查点，关键阶段立即保存。音效继续通过平台音频接口播放和静音，不创建游戏私有播放器。许可及旧版素材见 [assets/README.md](assets/README.md)。

## 验收

失败清单先于实现写入 [重制计划](../../docs/research/racing-remake/PLAN.md)。本轮覆盖 5 赛道 × 2～6 人 × 1／3／5 圈，共 75 组自然完整对局；另有 HTTP、恢复、托管、输入边界、短预测及浏览器验收。

```sh
. scripts/env.sh
npm --prefix web run build
npm --prefix web test -- racing
go test ./games/racing/... -count=1 -timeout=25m
python3 -B scripts/racing/check-remake.py --out .local/racing-remake/new-browser --skip-maps --players 6 --extended
python3 -B scripts/racing/check-remake.py --out .local/racing-remake/new-compatible --skip-maps --tracks metro --fallback
```

浏览器记录区分桌面和 320px 触屏仿真，不将 Chrome 仿真声称为实体手机性能测试。main 按改动范围检查，tag 只复用同一提交的已验证构建。
