# 极品飞车

2～6 人的车后追逐视角竞速，支持真人、电脑和混合对战。游戏 ID 为 `racing`，沿用平台的大厅、两步创建、等待房间、玩家栏、托管和结算浮层。

## 赛道与车型

新版提供四条独立的《极品飞车 4》PC 参考路线：法国乡间公路、海豚湾、凯尔特遗迹、金迪亚克公园，分别保留原路线、高程、路宽、建筑与环境，支持白天／夜间。可选 1、3、5 圈。新对局最长 20 分钟，首车冲线后其他车辆有 30 秒完赛。排名按实际过线时间，未完赛按有效检查点进度；没有有效进度时使用平台和局结果。

在统一等待房间选择保时捷 911 Turbo、法拉利 550 Maranello、兰博基尼 Diablo SV、迈凯伦 F1 GTR 或雪佛兰 Corvette。五车使用原始车型几何、贴图与性能参数，质量、轴距、抓地、驱动分配、制动、传动和碰撞尺寸各自不同。车型在开赛时固定，比赛中不能切换动力性能。

驾驶核心独立实现双轴轮胎力、转向建立与回正、制动、侧滑、坡度和自动挡，采用固定 20ms 规则步；输入与滤波后的驾驶状态分别保存。当前模型是基于原版参数的街机驾驶重建，未声称完整复现原版物理。电脑通过普通驾驶输入完成路线，提前制动并对真实障碍选择可通行侧，卡住时按正常操作倒车恢复。

## 操作

- W／↑：油门；S／↓：制动，停稳后继续按住约 0.3 秒进入倒车；A／D 或 ←／→：转向。倒车停稳后按油门恢复前进。
- 空格：手刹，降低侧向抓地并减速。
- C：循环近追车、远追车、引擎盖、原车驾驶舱。按住 B 向后看，松开恢复所选视角；H 按住鸣笛。
- F3 切换最大绘距，F5 显示或隐藏仪表，F7 开关真实后视镜，F11／F12 缩小／放大游戏视区，M 打开赛道地图。
- R：低速重置到最近已通过的检查点，等待 2 秒重新起步，冷却 5 秒；不增加进度。
- 转向逐渐建立并自动回正，高速弯道需要提前减速；路肩连续降低抓地并增加阻力。键盘、鼠标、手柄与本地预测使用同一驾驶含义。
- 全部自动挡，不提供手动换挡。速度表显示实际挡位与发动机转速；Corvette 为 4 个前进挡，Diablo 为 5 挡，其余车型为 6 挡。
- 手机使用左右转向箭头、油门、刹车、手刹及后视按钮，可同时多指操作；左侧两箭头转向，右侧为刹车和油门，手刹作为小按钮放在右下边缘。油门按住加速、松开滑行，制动优先于油门，不提供自动加速。

赛道图通过统一弹窗打开，支持鼠标拖动、滚轮锚点缩放、触屏拖动／双指缩放及小地图连续定位。关闭地图回到驾驶键盘焦点。新对局由平台滚动到实时游戏区域一次，快照不会抢回用户的滚动位置。

失焦、隐藏、失去控制权和重连会清除旧按键；键盘自动重复不能在重连后重新踩油门。真人空闲不自动托管，手动托管和取消托管继续使用平台入口。

触屏按原生触点编号分别维护转向和踏板，每次触摸事件都核对当前仍在屏幕上的手指；丢失 pointer 松开通知时，也会释放已离开的触点。转向可在左右箭头间滑动，滑出后归零；松开一根手指保留其他手指、键盘和手柄的输入。比赛区域禁止文字选择、长按菜单和 iOS 触摸呼出，平台聊天等编辑控件保留正常选择。

## 画面与联机

主画面为 Three.js／WebGL 2 真三维追车场景，包含起伏道路、车身路面姿态、独立车轮、原生环境动画和转向惯性镜头。渲染器随赛车模块按需加载。三维画面初始化或贴图解码失败时保留重试，不会在白模场景上确认就绪；开局后的图形故障释放本地输入。旧存档仍使用其原有的透视兼容路径。

道路与碰撞规则使用和场景相同的原始变换，并按精确几何摘要冻结；常规网络更新只发送几何引用与动态车况。自身使用有界短预测，驾驶视角中的其他车辆短推算，观众按同一时间轴插值高度、姿态与转向；客户端不决定圈数、名次或碰撞结果。旧版 `physics=0` 存档保留已保存的赛道几何、运动、进度和期限；旧五个路线 ID 只作为兼容入口，不计入新版四条赛道。

四条路线包含 265 件经原始属性核实的可撞毁物件，包括部分路牌和护栏。首次有效接触由服务端确认，播放原 TR02／TR03 一次性动作，之后车辆可通过；固定墙仍保留碰撞。破坏状态按比赛保存并同步，刷新或迟到观战不会重播旧动作。物件识别边界和数值验收见 [可撞毁物件说明](../../docs/research/racing-nfs/PROPS.md)。

普通移动和物理帧在内存中推进，每秒保存检查点，关键阶段立即保存。模型、贴图、声音按所选路线、时段与当前车型加载，显示真实读取大小，完成解码和首帧绘制后才确认就绪。正式资源绑定当前构建的不可变 CDN 目录；GLB 通过无损 gzip 传输。

原车发动机使用 27 个有原始循环标记的无损 FLAC 片段，由平台原生音频通道按转速与负载调整音量和音调。静音、失焦与离场由平台统一控制，不建立游戏私有播放器。资源来源、离线验证和限制见 [NFS4 资源记录](assets/source/nfs4/README.md)；许可及旧版素材见 [assets/README.md](assets/README.md)。

## 验收

失败清单、完成依据与性能预算先于本轮实现写入 [新版计划](../../docs/research/racing-nfs/IMPLEMENTATION-PLAN.md)。新版验收覆盖四条原路线、五款车型、2～6 席与 1／3／5 圈，另有原始资源转换、跨语言运动与生产输入轨迹、HTTP／恢复／托管、真实浏览器加载及输入响应。各项是否通过以对应产物为准，不以离线转换或单车型完整比赛代替全范围验收。旧版计划见 [重制计划](../../docs/research/racing-remake/PLAN.md)。

```sh
. scripts/env.sh
npm --prefix web run build
npm --prefix web test -- racing
go test ./games/racing/... -count=1 -timeout=45m
python3 -B scripts/racing/check-nfs.py --out .local/racing-nfs-browser/new-full --phase full
python3 -B scripts/racing/check-nfs.py --out .local/racing-nfs-browser/new-latency --phase latency
```

浏览器记录区分桌面和 320px 触屏仿真，不将 Chrome 仿真声称为实体手机性能测试。main 按改动范围检查，tag 只复用同一提交的已验证构建。

本轮触屏卡键与防选中验证见 [手机输入验收](../../docs/research/racing-nfs/MOBILE-SAFETY.md) 和 [机器记录](../../docs/research/racing-nfs/mobile-safety-validation.json)；可撞毁物件的规则验证另见 [物件验收记录](../../docs/research/racing-nfs/props-validation.json)，实际网页、观战、恢复和性能见 [物件网页验收](../../docs/research/racing-nfs/PROPS-BROWSER.md)。

路肩计圈与复位位置回归见 [计圈验收](../../docs/research/racing-nfs/LAPS.md)：检查点范围包含两侧 3 m 路肩，复位不增加已完成圈数，实际三圈驾驶由正式页面与服务端共同核对。

## 画面与操作

新版桌面场景取消底部方向盘、踏板和车辆设置，仪表叠加在赛道画面内；手机使用画面内的左侧双箭头、右侧双踏板与独立手刹。操作说明集中在平台「玩法速查」，不再重复占用画面下方空间。

- W／↑ 油门；S／↓ 制动，停稳后继续按住倒车；A／D、←／→ 转向；空格手刹；R 重置。
- C 依次切换近追车、远追车、引擎盖、原车驾驶舱。B 按住后视，松开回到当前视角。H 按住鸣笛。
- F3 轮换最大绘距（1200／1800／2400 米，仍受原赛道雾距限制）；F5 显示或隐藏仪表；F7 开关真实后视镜。
- F11／F12 调整游戏视区尺寸；平台全屏沿用公共入口。M 打开地图，Backspace 关闭。
- 标准映射 Gamepad：左摇杆／十字键转向、右／左扳机油门／制动，下方面键手刹、上方面键后视、左方面键重置，L1 视角、R1 喇叭、Start 地图。使用平台控制器设置保存按用户、游戏和设备隔离的键盘／按钮／轴映射。

视角与显示操作可在托管、观战期间使用；驾驶、重置和鸣笛仍按手动席位权限处理。原车发动机音频沿用平台媒体通道，喇叭使用项目自制双音循环，不能视为已确认的原版 H 音效。
