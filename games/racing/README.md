# 逐风赛车

2D 俯视卡通漂移竞速，使用跟车镜头，支持 2～6 人真人与电脑混合比赛。游戏 ID 为 `racing`，分类为「体育」，默认上架；管理员可随时下架。创建与等待房间、公共玩家栏、托管和结算沿用平台框架。

## 玩法

- 林间环道、海岸曲线、赤岩回廊分别提供宽弯、连续弯和发卡弯；选择 1、3 或 5 圈，默认 3 圈。
- 3 秒发车倒计时后同时起步。按有序检查点计圈，逆行穿终点、跳过检查点和抄近路不能增加圈数。
- 首车完赛后保留 30 秒完赛时间，比赛最长 8 分钟。按实际过线时刻排名；未完赛按有效赛道进度排名，完整平局使用平台显式和局结果。
- 六种席位颜色、五种车身只改变外观，速度、加速、抓地力和碰撞轮廓统一。每辆车有清楚车号，公共玩家栏显示对应车号、颜色、名次和圈数。
- 支持漂移、车身胶囊碰撞、路外减速。救援须先减速，回到最近有效检查点，等待 2 秒重新起步，冷却 5 秒，不增加比赛进度。
- 电脑使用与真人相同的驾驶输入，能提前制动、避让和回驶补过检查点；不写入位置、圈数或胜负。

## 操作

PC 使用 WASD／方向键控制加速、制动、左右转向，空格漂移，R 救援。手机默认自动加速，滑动方向盘转向，可用另一根手指同时按住漂移或刹车。

赛道地图操作沿用统一规范：拖动查看赛道，滚轮／双指以锚点缩放，小地图连续拖动定位，「跟车」恢复驾驶镜头。地图拖动与方向盘输入分开，不误触驾驶。

切后台、失焦或重连会释放控制，恢复后需真实手势重新操作；不能因刷新快照自动踩油门。超过 750 毫秒没有新的输入，服务端自动制动；15 秒无输入由平台托管，可从公共入口取消。接管只清除自己的旧控制，不重置赛程或其他席位的操作期限。

## 模块与联机边界

`server/` 独立拥有赛道、车辆物理、检查点、排名和电脑策略，`web/` 负责控制、插值／预测、画面及事件音效。字段和失败场景见 [CONTRACT.md](CONTRACT.md)。

服务端每约 100 毫秒处理一帧，内部使用 20 毫秒物理子步。平台的 `Module.Realtime` 显式启用快速调度，每帧对受控席位调用普通 `BotAction → Apply` 后执行 `OnTimer`，以单笔事务提交。帧中任一操作或数据库写入失败则整帧回滚。普通游戏保留原有节奏。

真人只提交方向、油门、刹车、漂移和递增输入序号；服务器不接受客户端位置或圈数。序号按席位和比赛 epoch 验证，限制相对跳跃与整数范围，旧比赛、旧序号和观众操作会被拒绝。本地即时响应并有界校准，客户端不决定胜负；观战车辆、火花和音效使用同一展示时间轴。

持续输入只保留最新未发送状态；松手优先发送。平台实时操作不持有全局界面 busy 锁，快照请求采用单个在途请求和合并刷新，避免慢网时所有响应都被新通知作废。进行中的驾驶与系统帧只通知同桌玩家和观众，生命周期与结束结果仍通知大厅。

## 图片与声音

车辆、场景及粒子采用已核验的 Kenney CC0 素材，封面为项目原创 SVG；引擎为 domasx2 CC0 循环，漂移录音为 Tom Haigh／qubodup 的 CC BY 3.0 素材并保留署名，提示音离线原创合成。生成方式、许可、SHA-256、图集和 CDN 记录见 [素材说明](assets/README.md)。

图片和声音使用 OSS 的 `racing/v1/` 不可变目录，配同版本本地回退。音效通过平台 `BoardProps.audio`：引擎和轮胎使用独立循环通道，短音效不打断循环；统一静音、隐藏和离桌停止全部声音。游戏不创建播放器或 `AudioContext`。

## 验证

测试先列失败场景并编写，再实现模块；浏览器使用生产注册、真实身份、SQLite 和原生键盘／触摸操作。不同层次的结果不能互相替代。

```sh
source scripts/env.sh
npm --prefix web run build
npm --prefix web test -- racing
go test -count=1 -timeout=10m ./games/racing/...
python3 -B scripts/racing/verify-assets.py --dist --oss
python3 -B scripts/racing/check-browser.py
```

Go 完整比赛覆盖 3 赛道 × 2～6 人 × 1／3／5 圈的 45 组组合，要求每辆车自然完成规定圈数，不能仅凭超时出现结算就通过。HTTP 覆盖默认可创建、配置、并发／大序号拒绝、真人与电脑混合、托管／接管、丢包和 SQLite 恢复。物理验证包括车身胶囊接触、漂移、路面、逆向门线和同一物理步内的真实过线顺序。证据在 `.local/racing/module/`、`.local/racing/http/` 和 `server-verification.json`。

浏览器验证覆盖 1280／390／320px 创建、等待与六席公开资源，真实连续转向、多指漂移、慢网快照、断网／隐藏恢复、观战只读、地图交互、换肤、原生循环音效及统一静音。报告和截图保存在 `.local/racing/browser/`；以最终 `result.json` 的通过项为准。

main 自动运行公共检查和本游戏受影响检查，其他游戏不因赛车改动启动完整对局；tag 复用全部必需检查通过后的二进制。

当前验收记录（2026-10-15）：45 组自然完整比赛、45 项真实浏览器检查、3 项 CDN 故障后的实际本地回退检查均通过，18 张截图已复核。83 项公共与赛车前端测试、公共平台竞态套件、嵌入式应用启动及全部 13 项素材服务校验通过；汇总在 `.local/racing/verification/completion-audit.json`。浏览器使用 Chrome 原生键盘／触摸输入模拟，未将它宣称为实体 iPhone 硬件验收。
