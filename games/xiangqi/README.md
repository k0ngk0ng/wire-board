# 中国象棋

独立两人模块，沿用平台创建、等待、玩家栏、托管、计时、历史和结算。新增默认下架，只有管理员上架后开放创建。

## 行棋与裁定

九路十行，随机红黑、红先。服务端生成合法着法，检查九宫、河界、马腿、象眼、炮架、兵卒方向、将帅照面和送将；将杀与困毙均判无法继续的一方负。

循环裁定依据《2018 世界象棋规则》第 3、19、20 条，采用明确的线上提示流程：第三次出现相同局面时提示有责方变着，第四次仍重复时判定。长将责任高于长捉；双方同责或均无犯例则和棋。子力保留实体 ID，按连续被追逐的目标判断，不把不同棋子的同类字面当成同一目标。

长捉检查包含将帅／兵卒及未过河被捉兵卒例外、真根与假根、同类互吃、马炮捉有根车、交替兼兑和不同目标。真根需在假设吃子后仍有合法回吃，受牵制的保护子不能算真根。测试覆盖官方双方长将图例及有根、假根、兼兑等专门局面；这是可复核的实现范围，不是对全部竞赛裁判案例的认证。

连续 50 回合、双方共 100 着没有吃子，服务器确认后自动和棋；动兵不清零。将杀、困毙及重复犯例裁定先于自然限着。双方均无进攻子力时判和。可随走子提议和棋，对方同意才结束；拒绝或继续走子不会重置时限。真人和棋双方 0 积分、不计胜场，保留记录；含电脑的对局不计分。

采用休闲每步时限：30～300 秒，默认 120 秒。超时由电脑接管，可通过平台取消托管；不是比赛总时钟，也没有实体桌面的摸子、按钟与现场犯规申诉机制。生产房间不接受任意棋盘或 FEN 创建选项。

## 电脑与保存

基础电脑不依赖外部模型、付费 API 或额外服务。合法快速回退优先直接获胜，包括困毙；后台采用迭代加深 Alpha-Beta、子力与位置估值及重复历史。入门预算 30ms／800 节点／深度 2，标准 160ms／8,000 节点／深度 4；外层平台预算 600ms。预算不是 Elo 标定。

搜索输入独立序列化，在平台锁外执行，取消后丢弃旧任务；结果仍经过正常 `Apply` 和事务。候选行动还会检查是否立即因循环犯例判负，有其他合法延续时避开。不得用引擎评分直接决定胜负。

存档保留棋盘、实体 ID、手番、动作序列、循环历史、未吃子计数、提议及期限。手动接管不延长对方时限；重启不会重置局面。

## 显示与素材

己方在下方，只旋转显示坐标，不改变服务端席位或阵营；观战默认红方在下。PC 保持 9:10 的棋盘比例并限制宽度，手机棋子可见直径至少 24px。鼠标、方向键／回车和触屏均需选棋子、选目标、再确认。

走子以服务端事件为准，到达前保留被吃棋子、吃子数量和未结算状态。连续事件排队，刷新／重连／跳号不重播旧动作，支持减少动态效果。音效只通过 `BoardProps.audio`，使用平台静音和设备媒体音量。

21 个素材：红黑各 7 种中文圆棋子、棋盘、独立的楚河与帅将封面，共 16 张 WebP；走子、吃子、将军、胜利与和棋 5 个 WAV。

- 图片为本游戏原创 SVG。中文使用固定 Google Fonts 提交的 Noto Serif SC，保留 OFL 许可、源 URL 和 SHA-256，以 fontTools 4.60.1 将可变字体固定为 700 字重后渲染，避免小棋子字面过细。
- 走子／吃子为 Kenney Boardgame Pack 的 `chipsCollide2.ogg`、`chipsCollide3.ogg`（CC0），其余为平台原创音效生成器。来源和许可见 `assets/sources.json`、`assets/licenses/`。
- 正式地址为 `ASSETS_BASE_URL/xiangqi/v1/`，本地回退为 `/xiangqi/v1/`；两处图片均失败时以圆棋子及中文文字继续显示。已发布目录不可变，改素材时提升目录版本。

复现生成：

```sh
. scripts/env.sh
PIP_CACHE_DIR="$PWD/.local/pip" PYTHONDONTWRITEBYTECODE=1 \
  python3 -B -m pip install --target .local/xiangqi/font-tools --no-compile fonttools==4.60.1
node --experimental-strip-types scripts/xiangqi/prepare-assets.mjs
python3 -B scripts/xiangqi/verify-assets.py --dist --decode
```

另需工作区 `.local/chess-family/assets-tools` 中的 `@resvg/resvg-js@2.6.2`、`cwebp`、`ffmpeg` 和固定摘要的 Kenney 压缩包。生成器校验原字体及原音频包摘要，再生成成品摘要；字体只用于渲染，不把整个字体包加入网页。

## 验收

```sh
. scripts/env.sh
python3 -B scripts/ci/scope.py run --game xiangqi --backend
WIRE_BOARD_XIANGQI_ASSETS=https://cdn.ichenj.com/bga/v20261002-1 \
  python3 -B games/xiangqi/tests/accept_ui.py
```

规则 HTTP、电脑与动画测试先于相应实现。测试夹具和自然对局明确区分；临近 100 着、长将长捉等中局不冒充自然完整局。两档策略各经真人 HTTP 会话完成 1 局；原生电脑席位＋托管真人另各完成 1 局，保留生产调度和预算、中途重启，竞态检查再次覆盖原生调度与三个房间同时搜索。

浏览器使用正常初始棋盘，仅固定红黑抽签以重放坐标；覆盖封面与创建、原生鼠标／键盘／触屏、桌面／390px／320px、黑方朝向、吃子动画、静音、减少动态效果、刷新、公共结算和 CDN 故障后的图片／音频回退。检查最终样式对比度与截图，不只检查 DOM 文本。

当前证据在 `.local/xiangqi/http/`、`.local/xiangqi/browser/result-natural.json`、`.local/xiangqi/assets/` 和 `.local/ci/xiangqi/result-0.json`。官方来源和额外裁定记录见 [裁定实施记录](../../docs/research/chess-family/xiangqi-adjudication.md)。游戏专项与公共平台分开验证，不运行未修改游戏的完整对局。
