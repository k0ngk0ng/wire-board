# 经典地图选择与预览：实现前失败场景

- 地图遗漏、重复、资源名称或原始编号错配；九个主题分组错误。
- 2002 留存版地图被标成现行国服地图，小区10误用 Village09 缩略图。
- 地图切换后仍显示上一图、窄屏预览裁切、标题溢出。
- 预览一次请求全部 112 图；只应加载当前选中图。
- CDN 故障没有同源回退；同源也失败后无限重试、空白或旧图冒充新图。
- 旧四图和随机入口消失；随机预览声称已选定实际场地。
- 创建与等待房间地图不同步；禁用或非房主仍能更改地图。
- 随机生成旧场地缩略图被冒充为精确的本局箱子分布。
