# 泡泡堂图集与渲染失败场景

先列场景、编写针对性检查，再实现；地图、移动和游戏规则另由 E2E 验证。

- 下载源或复制文件变化而清单未变：校验每份 PNG／WAV 的 SHA-256 和字节数，并绑定上游提交。
- 图集帧裁切越界、方向颠倒或错误缩放：检查角色、水泡、水柱、困泡帧尺寸及网格整除关系；帧号钳制。
- CDN 图片失败：顺序尝试同源资源；两者都失败时保留可辨认的矢量地形、角色、水泡和道具。
- 图片尚未解码就绘制：只绘制 complete 且 naturalWidth 有效的图像，加载状态不阻塞操作。
- 多次绘制发起重复网络请求、旧来源迟到覆盖新来源：按 base 缓存独立图集，使用当前来源。
- 水柱呈孤立小圆点或连接越过未受影响格：只按服务端 active blasts 的上下左右邻接连接，过期水柱不绘制。
- 无减弱动态效果支持：reduced 时固定步态与水泡帧，保留状态变化和剩余时间。
- 重连重播死亡：仅显示时间窗口内服务端事件；不按浏览器首次见到死亡开始动画。
- 手机角色过小、边缘角色上半身被裁切：角色绘制宽度至少 32 逻辑像素，边缘仅裁切定位框而不移动全棋盘；320px 宽度下浏览器检查实际角色可辨认。
- 装饰遮住水柱、生命状态、座位标识：地面、障碍和角色按图层绘制，困泡计时和席位在最上层。
