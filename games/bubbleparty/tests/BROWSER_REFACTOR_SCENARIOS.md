# 泡泡堂浏览器重构验收：实现之前的失败场景

这些场景在浏览器验收代码修改前列出。验收只运行泡泡堂，通过生产 HTTP、SQLite、真实主时钟和原生键盘／触控驱动；不注入前端游戏状态。

1. 创建选择仍叫泡泡大作战，人数或地图设置无法创建；名称应统一为泡泡堂。
2. 地图 cells 不是数字数组，或者数组正确但 Canvas 未画出墙和木箱。需分别读取公开状态与实际画布像素，保留桌面和 320px 截图人工检查。
3. 键盘输入 seq 增长但角色没移动；短按丢失；按住第二方向后释放无法恢复第一方向；全部释放后继续移动。
4. 放泡短按只改变 seq，未生成水泡；离开后可重新进入未爆水泡格。
5. 触控按钮可见但低于 44px、被遮挡或触控事件不能使实际坐标变化。
6. 桌面／320px 关键战场被裁切，画面扁平，关键资源或操作按钮不可见；文字计算对比度不足。
7. 停止输入超过 3 秒自动托管或位置自行变化；显式开启／取消托管失败，取消后电脑仍操作。
8. 刷新重置 epoch、停止角色位置或困泡期限；困泡显示缺失、被命中立即死亡、困泡期间仍可移动／放泡。
9. 结算超时仍标绿；关闭浮层后普通快照自动重开；重新查看失效。
10. 服务进程失败、浏览器错误、测试超时或截图未生成没有让验收失败。
11. 临时 DB、profile、socket 或缓存写出仓库，覆盖旧验收记录，或完成后遗留本次临时目录。

输出必须包含 result.json、公开状态快照／坐标证据、像素证据和桌面／320px 截图；超时一律失败。困泡场景由玩家真实放泡并等待爆炸产生，结算等待真实规则完成。

12. 原生触控拖到另一方向键仍沿旧方向移动，或 touchCancel 后继续移动；需以公开坐标及 applied 状态确认。
13. 输入响应被宽泛超时掩盖；每个事件保存发出至首次观察到公开位置变化的毫秒数，以及取样轮数。
14. 减少动态效果模式刷新改变角色位置或旧 epoch；原生媒体仍在统一静音后播放，或试听按钮自行解除静音。
15. 图片请求失败造成地图或角色不可见；阻断 sprite 请求后保留实际回退截图及 Canvas 像素证据。

16. 320×844 开始八人新局时战场和触控操作落在首屏之外；开始前即设为窄屏，开始后不主动滚动，验证整张战场及方向／放泡键同时完整可见。普通快照不得反复抢滚动；随后主动回页顶，公共八席仍须存在且可见。
17. 存活切换困泡让公共玩家摘要换行，推动棋盘；比较同宽度下棋盘文档坐标，允许误差不超过 1px。

18. 同一手机视口下，困泡到期结算与关闭结果浮层使公共按钮／摘要换行，挤动最终棋盘；比较间不滚动、不改视口，保留三个状态的 Canvas 文档坐标和截图，位移须不超过 1px。

19. PC 方向按钮能被命中但原生鼠标按下／松开不移动或松开后不停；通过真实 CDP mousePressed/mouseReleased，观察安全走廊内实际坐标变化与释放后的持续停止，记录观察响应时间。

20. 普通动画模式中，已结束对局的死亡动作因冻结时钟反复播放或刷新后重播；在死亡至少 2 秒后记录局部 Canvas 像素哈希，刷新后立即和下一普通快照分别比较同一局部像素，不允许重播旧死亡帧。减少动态效果验证后切回普通模式并刷新，使此场景确实覆盖动画路径。
