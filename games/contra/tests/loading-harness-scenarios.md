# 资源分派隔离检查的环境适配

现有 `web/loading.test.mjs` 在新公共加载器引入 worker URL 后，esbuild 直接打包 `?worker&url` 报缺少默认导出，尚未执行任何业务断言。此次只适配既有检查环境，不修改生产加载器、资源驻留策略或分派规则。

修改前冻结失败场景：测试执行真实 worker 脚本并污染 Node 全局；没有提供页面来源或加载租约，导致与资源分派无关的环境异常；隔离注册表没有加载真实魂斗罗模块；把公共驻留层替身错误应用到游戏的独立运行时；遗漏原有「只请求清单与程序、不预取板载音频和 Wasm」断言；临时目录越出 `.local/contra/` 或测试夹具写入真实业务域名。

保留原来的模块身份、请求列表、下载总量与初始化进度断言。真实服务工作线程、缓存与游戏内输入继续由浏览器和真实房间验收覆盖。
