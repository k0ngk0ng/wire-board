# 魂斗罗复刻实施记录

目标：日版原版第一轮八关，单人／双人合作，独立规则引擎，PC／手机操作，电脑与主动托管，统一加载／全屏／音效，以及全队通关加分、最终失败扣分。首关或局部对照通过不能作为完整交付。

## 实现前失败场景

- ROM／bank／CPU 地址身份混用，尤其把美版地址当日版地址。
- 原版录制未真正进入游戏，或者输入脚本结束后模拟器仍推进，产生不可重复初态。
- 手柄采样与显示帧错位，短按、双人同时按键、方向组合与连发边沿丢失。
- 定点移动、重力、跳跃、落地或镜头推动与原版不同；角色坐标和画面坐标混淆。
- 只实现横版首关，基地纵深／瀑布纵向／Boss／最终演出不完整。
- 单人死亡提前判负，借命或续关重复消费，通关漏算已阵亡队友。
- 机器人只能局部活动，不能完成全部开放关卡；取消托管遗留输入。
- 预测提前确认受伤、死亡、过关；重连重播事件或恢复改变随机状态。
- 放弃或自动清理逃分、恢复重复加减分、旧局被补算、电脑与练习误计分。
- 手机多指互相覆盖、全屏丢操作、关键资源零值隐藏、素材未就绪就开始计时。

完整验收矩阵见 [实施方案](../../docs/research/nes-contra/README.md)。复杂行为先录制原版基准并建立 E2E，再写独立规则。需要隔离的算术／状态转换先写验证用例。

## 当前阶段

2026-10-25：独立输入与垂直物理已按先测后写落地；真实 FCEUX 运行产生 1,440 条输入采样、11 次起跳、714 次重力更新和 714 次垂直位移观测，全部通过 Go 差分。另一份独立运行目录从开机重建初态，8 个场景的 RAM 和调用轨迹逐字节一致。地图碰撞窗口采样随后通过 3,234 次原版查询，来源索引、槽位、原字节、结果与标志均一致。完整游戏尚未实现或注册。

公共合作计分已完成模块显式启用、开局冻结、全员 `+20/−10`、关闭／闲置失败与恢复幂等；相关 HTTP E2E 与公共回归通过。它仍未在魂斗罗或既有合作游戏启用，不把平台夹具验证当作游戏通关验收。

第一关的 13 个不同屏幕及前瞻引用已接入独立地图解压／展开。纯 TypeScript 背景与精灵合成通过 13 个完整原版帧、798,720 像素的零差异对照；其中状态来自原版捕获，不是独立游戏对局。八关原版初始化也已采集，使用明确记录的单次关号设置，仅供后续分支验证，不能当作自然八关通关。

后续接入已推进到完整角色／子弹帧阶段：第一关自然场景 1,220 次，基地、基地 Boss 与瀑布 3,719 次，均逐项匹配。八关资源现由 `LevelResources` 加载，146 次原版地图加载全部通过；按关拆分的资源包不携带其他关地图。动态图案更新也通过 2,048 次原版调用及 28 次边界调用，仍保持下一次显示边界才提交。

用户已明确允许独立联机版的随机序列与 FC 不同，要求保留原版随机运算和敌人决策条件，并保证服务器存档／回放确定性。`AdaptedRandom` 将确定性熵注入明确标为平台适配；原版累加器和敌人同 tick 对共享工作值的修改分别保留。恢复、重连和取消托管不得重建种子。

首关普通战斗现已接成 `ActiveWorld`：从一个初态连续运行 600 帧，角色／弹丸、敌人／生成、地图／碰撞、街机分数、CHR／OAM、图形队列及声音请求顺序全部匹配原版。另有 180 帧暂停／恢复轨迹，其中 100 帧暂停、两次暂停恢复，独立重录一致。原版帧前熵是测试的明确输入，不回填原版 after 状态。正常包路径检查及[验收范围与摘要](../../docs/research/nes-contra/evidence/active-world-verification.json)由 `scripts/contra/world_verify.py` 保存。`ActiveWorld` 提供基础战斗阶段，完整战役调度由下述 `World` 负责；真实音频状态和平台联机仍未完成。

后续 `World` 已把战役调度接到真实角色、敌人和场景状态。四个连续场景合计 7,625 帧通过正常包 `-race` 验收，并在每一帧比较 JSON 保存恢复、重复 tick 和倒退 tick。新增场景包括 373 帧实际全灭／96 帧等待，以及 6,472 帧实际击杀首关 Boss 到出口演出结束。全灭场景只在起点设剩余命数为 0；Boss 场景只在起点设为 30，之后均以按键和原版规则产生死亡／胜负，不注入 Boss 生命值或结局。这不是标准三命通关。两条新原版轨迹分别独立重录一致，最终验证期间源码与资源无变化。

该长轨迹修复了三个集成遗漏：S 弹速度表指针留下的生成状态、Boss 击败时炮台的批量销毁标记、出口独有渐隐计数与调色板计时混同。Intro 的文字图形与战斗矩形图形现在共用一个带显式模式的队列，保留各自原始字节预算和调色板提交门槛。各关初始化、Intro、进场和 Interlude 的独立阶段已落地；新局接线见下，完整跨关循环仍待验收。

新局初始化、完整 Intro、地图铺设和进入战斗已接入 `World`，新增 1,077 帧连续原版对照，包含实际背景／调色板 PPU 的逐帧比较。背景复制会跨嵌套 NMI，录制器现用 C001 的入口栈深匹配真正完成点；修正前后的原版 RAM 完全一致，错误短帧记录已排除。该启动场景与此前四个场景合计 8,702 帧，新增菜单验证见下。

`NewSession` 已提供不依赖 ROM／研究存档的新局入口：单人／双人、标准剩余命数 2、3 次续关、已批准的确定性熵适配和真实音频控制。原版随机工作值只保留在 World，熵适配器不另存副本。`StepPads` 在权威帧生成按下边沿并保存输入状态，重复帧不会消耗输入或重新播放声音。另有 1,460 帧独立标准新局／逻辑按键对局验证，覆盖完整或跳过 Intro、进入战斗、双人移动／射击、暂停及保存恢复；并已通过正常包 race 检查。这不代替 PC／手机真实输入、浏览器画面、联机或标准生命八关通关验收。

全灭后的菜单流程已接通：898 帧原版续关并重返战斗、386 帧选择结束均连续匹配实际 PPU，并分别独立重录一致。只在起点减少剩余命数以触发研究场景，死亡与选择由原版实际执行产生。`FlushTerminal` 在发布结果前提交剩余图形、延迟调色板、显示忙碌状态和音频；不推进物理、输入或随机数，重复调用和恢复均不重放。原版连续对照累计 9,986 帧。

跨关接线另补齐了具名 `TerrainWork` 运算契约，以及 Guardian 清墙越过碰撞表时对图形队列前 5 字节的有限清位效果：保留原始队列预算，首命令被清为 0 时停止绘图。2,677 个原版阶段前缀／24,310 次操作及 50 个 Guardian 消费场景通过，但上游方法尚未全部接到生产 World，不能算八关连续对局完成。第六关另有 800 个真实玩家／弹丸阶段，修复了平台下方实心格应阻挡子弹的调用遗漏。上述范围及本轮共享调用方回归均通过 race 检查。

真实生产调用已连接到同一 `TerrainWork`：2,677 个原版 Combat／Scroll 阶段匹配，320 个第八关 Guardian 世界调用从单初态连续通过。首关实际 Boss 击杀后的过场、清理、第二关 Intro／进场及前 120 个战斗调用也已连续通过（共 7,997 调用，和旧首关轨迹存在重叠，不能简单相加），独立 race 记录见 `world-interlude-verification.json`。完整八关、电脑与联机尚未验收。

控制器接入明确复用平台 `classic-2` 配置、`KeyboardController`、公共 Turbo 采样及 `FCController` 手柄。魂斗罗的 `web/controller.ts` 只转换逻辑按钮位，不保存键位或提供另一套设置；自定义键位、更换配置、释放和公共 Turbo 转换的 3 项契约测试通过，浏览器真实输入仍待接线验收。

八关各 800 个完整原版 World 调用现已全部通过；第 4 关滚轮继承值改为来自同帧真实碰撞框高度，旧归一化豁免已撤。该范围覆盖各关片段，不等于自然连续打通八关。原版最终关清理边界也已受控验证，允许真实 ending 场景呈现且只发出一次通关决定。

浏览器开发入口已有首轮真实首关游玩证据：原生 Go 与 Go/Wasm 接受相同输入、核对摘要，PC 键鼠与 320 px 触屏使用公共 FCController 和 classic-2 配置。完整隐藏／恢复及新版协议验收仍在进行，不把早期通过当最终浏览器交付。电脑策略已用标准命数独立打通首关，剩余关卡和双人配合尚未完成。

正式服务端接入正在开发。新增 `PresentPaused`／`RequestResume`，将纯呈现帧与规则／熵帧分开，并保存统一 Revision；正常 Session、暂停恢复和终局相关 race 检查通过。`BuiltinLevelBundle` 提供稳定八关 manifest 身份及逐关内容校验，服务端可预先加载可信嵌入数据，浏览器仍按当前关下载。代码构建身份与资源身份分开绑定。

目录元数据和原创 SVG 封面已准备，使用公共「动作」分类；桌面、320 px 及 160 px 缩略图已视觉核验，无横向溢出，TypeScript 检查通过。封面不含角色编号或外链图片，来源与源码摘要见 `assets/cover-source.json`，验收见 `evidence/cover-verification.json`。仍未向生产目录注册未完成游戏。

正式 server 模块已具备 HTTP／WS／SQLite、revision 重放、跨关资源门槛、主动托管与共同终局接口。首轮真实合作账本验证已覆盖 1／2 人成功各 +20、失败各 −10、重启不重复；真人主动托管保留开局资格，显式电脑席位不计分。浏览器正式 Board 适配与跨关在途输入复查继续推进，不能把模块边界夹具当八关完整对局。

正式平台浏览器宿主已准备（`server/browser_fixture_test.go`，仅显式 ENV 开启），使用真实登录／房间／加载屏障、私有 SQLite 和规则构建目录，不修改生产注册；普通包只做编译跳过，实际平台浏览器验收仍待 Board 完成后启动。

可见性审查发现旧 Bot 观察读取了未提交的逻辑状态，且把 blank sprite 1 当成可见敌人。因此旧策略前两关进展只保留为开发记录，不能作为最终公平性或电脑能力验收；正在改为已呈现画面／公开 HUD 的纯观察与视觉追踪。另有 20 条原版平台接触案例确认 Player Y 更新后逻辑显示未同步，已修正最终绘制投影，相关原版与八关片段回归通过。
