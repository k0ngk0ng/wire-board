# 正式房间前端验收边界

实现前列出失败场景。使用仅注册魂斗罗的真实平台测试服务器、正式前端、原生服务端与 Wasm，不使用浏览器注入的游戏初态。

- 初始加载尚未完成就推进规则；清单地址逃出不可变目录；开局预载其他关卡；规则或资源身份不一致仍继续。
- 观战、托管、加载屏障仍发送按键；切换期间旧按键残留；输入、释放和关卡确认序号冲突；重连使用旧序号或倒退检查点。
- 常规快照、全屏切换、控制器配置更新重建棋盘；更换账户串用控制器配置；输入框及设置弹窗触发游戏。
- 原生鼠标、键盘或 320px 多指触摸不能移动、开火及跳跃；暂停继续改变规则帧；恢复破坏 epoch 或回放摘要。
- 等待房间错误显示全屏入口；全屏包含公共菜单和玩家栏；手柄与画面重叠；必要状态、错误提示和退出操作不可见。
- 结算或离开后继续发送输入；当前生命为零被隐藏；移动端关键资源裁切。

记录 PC 与 320px 截图、真实请求、服务器检查点、客户端已校验的 revision／digest 与原生输入结果。首关浏览器测试不替代八关自然战役、电脑完整对局、网络延迟或实际音频听感验收。
