# 历史多人测试

用户已确认当前范围为「单人 98 原版＋个人长期存档」。本目录保存此前只适用于多人席位的测试原文，扩展名为 `.go.txt`，不进入当前 Go 测试发现。`manifest.json` 记录原路径、摘要和调整原因。

当前游戏只接受 1 人。历史测试不代表仍开放多人模式，也不是跳过当前单人验收的入口。

| 历史场景 | 当前处理 |
| --- | --- |
| 多位队员控制者分别批准／取消合击 | 由 `TestSoloOriginalCooperativeMagicAndBacktrackingSave` 验证原版合击、未提交选招、续档和本人修改上一名队员指令，不等待他人同意 |
| 未分配角色的其他真人参与合击批准 | 当前只有本人席位，不适用；单人元数据及非法席位拒绝有独立验收 |
| 空闲队友取消托管但不能打断领队 | 当前没有其他真人席位；保留本人托管、取消托管、旧输入释放和续档检查 |
| 多人共同保存和到齐确认 | 由 `TestPALOriginalSoloPrivateSaveRestartHTTP` 验证个人保存、事务回滚、私有续档、切换游戏及重启恢复 |
| 三位原玩家在救援施法时保存 | 由 `TestPALOriginalSoloRescueMagicSaveHTTP` 验证同一账号拥有两名原版角色、施法中保存、重启、本人继续和接管 |

普通输入时序、菜单、暂停、存档、视图隔离、原版战斗和托管场景仍在活动测试中，人数矩阵已调整为 1。其他人数仅保留为非法输入的负向测试。
