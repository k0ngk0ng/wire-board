# 画面直接操作

按用户最新要求，PC 和手机都不显示虚拟方向、确认、返回或「读完」按钮。画布继续按 320×200 原比例占满可用空间，控制不分配额外高度。平台保存、退出和全屏入口继续沿用公共界面。

## 操作

| 位置或状态 | 操作 |
| --- | --- |
| 对白 | 点击或轻触游戏画面继续当前一页；保留键盘确认 |
| 人物周围 | 按原版等距地图的四个方向点按移动；按住持续移动，松手停止 |
| 人物处 | 点按搜索／交互；长按打开原版菜单 |
| 手机双指轻触 | 打开菜单或返回；缩放和拖动不执行此操作 |
| 原版菜单文字、战斗图标 | 点选另一项；再次点击当前项确认 |
| 物品／法术列表 | 直接点选原版条目，或滑动切换选择 |
| 选敌／选队员 | 点击原版敌人或队员体力面板选择，再次点击确认 |
| 菜单中长按 | 返回上一层 |

PC 键盘和实体控制器继续使用平台已有方案。鼠标点击对白同样继续；场景中单击画面仍可聚焦键盘，右键可打开菜单。

## 输入边界

装备与场景中用物的自绘人物列表同样支持直接点击。按公开的原版名字字形与高亮识别当前项，选中另一队员后停下，再次点击才确认；灰色角色可查看，但能否装备仍由原版判断。长按逐层返回原版菜单，不直接跳回场景。

触控位置换算到原版画布坐标，人物中心取当前公开位置和镜头；菜单依据公开条目或当前原版绘制的文字、游标和高亮命中。原版战斗杂项及道具子菜单由自绘文字呈现，须识别其实际高亮，不能假定它们一定出现在 `menu.items` 中。

操作继续通过 `PalInput` 发送正常方向／确认／返回，不旁路写规则状态。方向按住沿用原有预测、权威校正和释放机制。菜单导航等候原版光标或高亮实际更新后再继续，抵达所选项后停下，等待下一次确认；不能只根据输入 ACK 或已接受的序号继续发送方向。切换页面、角色、菜单或操作代次时取消旧手势和未完成导航，键盘输入亦终止旧的触屏导航。

对白只在同一次有效按下／松开中继续当前页；浏览器兼容鼠标点击不重复发送。拖动取消、缩放、失焦、离开、保存和加载不得保留按住方向或延迟执行确认。保存及全屏操作独立于画布手势。

## 验证记录

当前源码再次通过实际桥道存档的 PC／手机回归，7 项检查覆盖四向点按、按住移动、松手／取消释放、原版菜单、私人续档和最大比例画布。手机画布为 320×200，PC 为 1280×800，均无虚拟操作按钮；截图经人工核对。结果、源码和 SHA-256 清单保存在 `.local/pal/verification/surface-touch-current.json` 及同名归档中。本次功能核验不增加剧情完成数。

第 17 段同次完整重跑另验证 72 次群妖与书中仙触屏阅读，以及桌面／手机的塔毁、三段切换演出和第 151 场景中的私人保存续玩。画布尺寸和无虚拟按钮要求保持不变。手机演出保存使用 `phone-cinematic-frozen.json` 与 `phone-cinematic-restored.json` 比较完整公开边界；普通 `frozen-view.json`、`restored-boundary-view.json` 分别记录各自最近一次操作，不一定属于同一次保存。淡入画面须留取内容清晰的截图，不能只保留第一张近黑帧；采样像素摘要用于证明实际动画变化，不代表原版绘制帧数或帧率。

第 18 段同次完整重跑的阿奴约定入口亦通过真实 PC／手机：RGM 29、桌面画面点按、2 次手机阅读、取消和缩放不误读、原版阿奴／逍遥领队顺序、键盘／触屏移动及个人续档均正常。画布仍为 320×200／1280×800，无虚拟操作按钮；阿奴加入后仍由唯一玩家手动操作全队。

第 19 段同次完整重跑的麒麟变人入口另通过 RGM 28、桌面画面点击、40 次手机阅读、取消／缩放不误推进、原版阿奴／逍遥归队、键鼠／触屏移动与私人续档。画布保持 320×200／1280×800，无虚拟操作按钮；浏览器产物为 `solo-kirin-human-browser/result.json`。

第 20 段同次完整重跑的取杖和托付入口通过两组 PC／手机浏览器，共 17 项检查、11 次手机画面阅读。原版 RGM 73、取消／缩放、角色切换、私人续档、键鼠／触屏及最大比例画布保持正常；手机另在单独巫后的最后对白中保存，完整冻结／恢复公开边界相同。凤凰由原版自动靠近触发运送，未额外提交接近输入。产物分别为 `solo-past-queen-browser/result.json` 和 `solo-past-sacrifice-browser/result.json`。

七星剑真实装备存档另覆盖自绘人物列表：修复前点击灰色月如没有响应；修复后原生触屏能够切换人物，月如按原版限制无法装备，逍遥实际由铁剑换为七星剑，五项净变化为 110、50、4、32、33。已装备时个人保存续玩保留结果。场景止血草另在选中月如时保存，续玩后实际恢复 50 体力，逍遥不变；原版菜单逐层返回、键盘和最大比例画布通过。报告为 `solo-tower-equipment-browser/result.json`，验收摘要为 `.local/pal/verification/tower-equipment-stage.json`。该功能不增加剧情段数。

原版 `scene.c` 将人物层级加入排序位置后，在实际绘制时减去同一层级；人物精灵底边最终为 `worldY - cameraY + 4`。桥道的层级 48 影响遮挡计算和排序，不能直接加到触控中心。首次扩展测试误将该层级作为位移，点击到人物下方而失败；核对原版绘制公式后只校正测试坐标，原有触控实现保持不变。

扩展回归现已通过：实际桥道入口、原版层级 48 下的人物长按、原版菜单、四向碰撞／朝向、双指操作、缩放不操作、按住移动及松手／取消释放，以及个人续档和 PC 键盘均正常。`solo-tower-bridges-browser/result.json` 保留 7 项结果；其存档来自真实开发分支。第 16 段同次整段重跑另有 `solo-tower-sage-browser/result.json`，验证原版书中仙头像、两页触屏阅读及个人保存续玩。两例均保持 320×200／1280×800 最大比例画布，不显示虚拟操作按钮。
