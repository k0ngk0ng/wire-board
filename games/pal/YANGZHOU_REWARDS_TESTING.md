# 扬州奖励验收

原版位置、脚本与数量按当前 Windows 简体资源核对，文字出处为[扬州擒贼攻略](https://gamegene.cn/wiki/361)，缓存为 `yangzhou-text-guide.md`。本批不观看视频。

## 实现前失败场景

1. 剧情布包在初始事件表中未启用，却从错误时点取得；或者从已经捡过的档重复领取。须使用女飞贼逃走、布包仍在地面的真实存档，保留其消失、提示及库存变化。
2. 宝库领取碰到紫金葫芦或追捕触发器，误推进审判、离队或胜负。根档须匹配真实剧情时点，并避开本批不需要的原版转场。
3. 宝库空奖励箱显示「获得紫青玉蓉膏」，却因物品编号 0 被工具补成正常药品，或将它计入有实际奖励的 732 条候选。须核对原始提示、零物品指令、库存保持、开启帧及保存后的重复搜索，单独审计而不新增候选计数。
4. 同箱 5 枚袖里剑被当成 5 个事件，5000 文与战利金混合，或珠宝开启状态未保存。按事件计数，分别核对每项数量、钱包和原版帧。
5. 多间民房共用场景号，误把废宅、南城民居或厨房当成连续区域。按原版街道门口进入，不能改场景、坐标或碰撞。
6. 原版可重复的搜索奖励被强制改成一次性，或原版一次性奖励在恢复时自动重发。先检查脚本续行和实际次数；合法的新搜索与恢复中错误重发分开验证，原始行为保持。
7. 普通战斗消耗正在核对的物品，或强制把月如领队、单独逍遥变为固定队伍。沿用真实根档，保留角色顺序、本人控制、正常伤害及成长，战利金逐场核对。
8. 新结果覆盖旧归档、版本选择漏掉旧证据，或把无奖励审计算成真实领取。使用独立 v9 前缀，逐项比较旧进度内容及旧产物摘要，明确各类记录的计数范围。
9. 只读复核误把内存中的 SSS 文件副本当成实际事件表，混淆物件状态与加载器缓存，或缺少真实核心／完整内存摘要校验。须唯一定位运行事件表，分别核对布包激活与消失、空奖励箱开启与续行、大蒜关闭状态，资源缓存字段单列。

## 正常路线与领取

各分支来自同次完整扬州主线中的真实存档，根档及完整非诊断报告摘要登记于 `campaign-roots.json`。保留各自的原版角色顺序、本人控制和正常数值变化：东郊、布包及民居使用逍遥／月如，宝库使用原流程第 47 步的单独逍遥。此处分支没有重开主线或更改角色、背包、场景、坐标及碰撞。

布包初始原始状态为 0，原剧情 PC13628 将事件 1631 设为状态 2。真实第 22 步档中仍可见；普通搜索执行 PC14041～14046，先隐藏布包、刷新一帧、显示「拾起布包」，再发放物品 271。取得前、提示中、取得后与重复搜索后的全新运行器均保持原进度，布包只增加 1 件。

厨房经城南事件 1552、坐标 `880,584` 的门口进入。民房经城北事件 1576、坐标 `368,360` 的门口进入；当前 98 简体资源中的大蒜位于 `1264,920`，实际搜索可取得，PC38272 随后关闭原事件。文字攻略对 95 版的描述不能代替当前资源核对，本批未据此移动物品或改资源。

宝库十个普通奖励分别保留原珠宝开启脚本与帧，5000 文实际只增加一次，袖里剑同箱取得 5 枚并只计一个事件点。重复搜索保持原站位与朝向，库存和钱包不再增加。进入宝库的剧情转场按原版避开，本批没有重触审判、改变队伍或重发紫金葫芦。

## 原版空奖励箱

事件 1704 位于场景 93、地图 85、坐标 `784,1624`，使用原版珠宝精灵 389。原始 PC37479 调用开箱，PC37481 显示「获得紫青玉蓉膏」，PC37482 为 `0x001f,0,0,0`，PC37483 将续行入口替换为原版空箱脚本 36509。当前原始版本没有将该物品编号改为药品编号。

实测提示出现时箱子已从帧 0 变为帧 1；取得后和重复搜索后都保持帧 1，触发脚本为 36509。已检查库存前后一致，紫菁玉蓉膏没有增加，钱包保持；各阶段均通过新运行器恢复及原站位 3 次搜索。原文「紫青」与库存物品名「紫菁」分别按原资源保留。

报告将它放在 `emptyChestAudits`，明确 `originalZeroItemChest: true`、`countedCandidate: false`、`grants: []`；没有加入实际领取列表。它不在当前 732 条有实际奖励的候选中，不增加进度或分母。文字出处也注明该箱只有提示、实际无物品，并说明部分 98 版本修正过；本批按已登记的当前版本原样保留。

## 原生只读核对

`yangzhou-original-review.py` 验证完整原生内存摘要与真实核心，区分原始 SSS 副本和实际运行事件表。布包按原版从状态 0 激活为 2，搜索后保持 0；空奖励箱保持状态 2，当前帧从 0 变为 1，续行至 36509；大蒜从状态 1 变为 0，其余原始位置、外观、朝向及语义字段保持。加载器资源索引和自动帧数字段单列，不当成剧情变化。

结果为 `.local/pal/verification/yangzhou-original-rewards-review.json`，对应四个阶段的原始状态与摘要均保留。布包和大蒜属于本批 16 处实际领取，不能因重复对照再增加计数；空奖励箱始终不算取得药品。
