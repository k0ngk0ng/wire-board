# 对战经济与平衡复测

本表属于平台攻防对战规则，不是 PC 初代冒险模式的取证参数。规则版本 3 用于新对局；版本 0／2 的存档保留原有开局资金、补给、生产间隔和换边默认牌组。

## 经济参数

| 场景 | 植物队初始阳光 | 每次基础补给 | 补给间隔 |
| --- | ---: | ---: | ---: |
| 白天草坪 | 500 | 25 | 4 秒 |
| 夜晚草坪 | 300 | 25 | 8 秒 |
| 泳池 | 600 | 25 | 4 秒 |
| 浓雾 | 400 | 25 | 8 秒 |
| 屋顶 | 700 | 25 | 3 秒 |
| 夜间屋顶 | 700 | 25 | 3 秒 |

2v2 共享草坪，初始阳光和基础补给按团队均分，余数轮流分配；每人仍有独立钱包。生产植物的收益归种植者，队友收取也不会改变归属。

向日葵、双子向日葵和阳光菇在种下／升级后 3～6 秒首次生产，此后间隔 18～20 秒。每次产量保持 25／50／幼体 15、成熟 25，阳光菇保留 120 秒成长时间。金币花的生产节奏保持原值。植物价格、伤害和生命未因本次经济调整而改变。

僵尸队开局总脑力仍为 250，开战后每 2 秒获得团队补给，首分钟每次 25，之后每分钟增加 5，最高 45。每队两次付费部署至少间隔 3 秒；原有更长的单位冷却继续生效。特殊单位仍在 45／60／90／120 秒分批开放，气球、矿工与蹦极在 90 秒后开放。

屋顶预算补偿花盆成本；夜晚草坪与浓雾有免费／廉价蘑菇，补给低于白天。屋顶默认牌组补充樱桃炸弹和火爆辣椒，默认僵尸牌组补充远程单位；夜晚牌组提供车辆和爆炸类应对喷菇阵。卡册仍包含全部 49 张植物卡和 33 种僵尸，默认牌组不限制可选内容。

## 测量方法与结果

使用真实 Go 规则核、`ProjectState`、`BotAction`、`Apply` 和 50 毫秒规则步，以 200 毫秒间隔做决策。防守包括生产策略与优先经济／逐路补火力两种策略；进攻包括生产策略、普通单位压迫、存钱购买强化单位、预留资金在 120 秒购买巨人四种策略。每次行动均通过普通规则验证，使用自然钱包、冷却与生产，不注入资金、单位位置或胜负。

以下「守住率」是这些固定策略的回合结果，不代表真人胜率。两回合分别统计，避免比赛和局掩盖双方都被迅速突破。

| 对照 | 完整比赛 | 攻防回合 | 植物守住回合 |
| --- | ---: | ---: | ---: |
| 原经济，3 分钟，固定种子 0～2 | 288 | 576 | 121（21.0%） |
| 新经济，同场景、人数、种子和策略 | 288 | 576 | 354（61.5%） |
| 新经济，额外种子 3～9 | 672 | 1344 | 867（64.5%） |
| 新经济，6 分钟，种子 0 | 96 | 192 | 55（28.6%） |
| 新经济，10 分钟，种子 0 | 96 | 192 | 48（25.0%） |

默认 6 分钟模式中，僵尸仍有后期压力。3 分钟夜间 2v2 在所测策略下偏向植物；6／10 分钟夜间 2v2 的植物守住回合为 9／16。短局更容易守住、长局的递增脑力更有利于僵尸，不能把总平均值当作所有场景都均衡。后续真人反馈应继续按场景、人数、回合时限和使用牌组复测。

原经济的 288 场完整行动记录还会在新引擎中回放，要求最终摘要完全相同，验证旧规则冻结。新经济记录再通过原生与 Wasm 两端对照，并用真实认证房间、鼠标种植、可见钱包、实际产出计时及桌面／320px 视区核对呈现。

## 复跑

从仓库根目录执行，临时目录与缓存放在工作区：

```sh
. scripts/env.sh
PVZ_BALANCE_ASSESS=1 PVZ_BALANCE_LABEL=verify \
  go test ./games/pvz/tests -run '^TestPVZEconomyBalanceAssessmentE2E$' -count=1 -json
python3 -B games/pvz/tests/balance-summary.py .local/pvz/balance/verify \
  --output .local/pvz/balance/verify-summary.json
go test ./games/pvz/tests -run '^TestPVZEconomy(NewMatch|Producer|Legacy|Starter)' -count=1
```

额外种子使用 `PVZ_BALANCE_SEED_FROM=3 PVZ_BALANCE_SEEDS=7`；长局使用 `PVZ_BALANCE_SECONDS=360` 或 `600`。完整初始状态、普通行动、最终摘要与每 15～30 秒经济采样保存在输出目录，`TestPVZEconomyRecordedReplayE2E` 可通过 `PVZ_BALANCE_REPLAY=<记录目录>` 逐场复播。

浏览器先启动 README 中的生产模块夹具，再执行 `PVZ_BROWSER_URL=<夹具地址> python3 -B games/pvz/tests/balance-browser.py`。原生／Wasm 对照可执行 `PVZ_RUNTIME_BALANCE_REPLAY=<新经济单场记录> npm --prefix web test -- pvz`。本次结果、源码摘要与截图保存在 `.local/pvz/balance/`。
