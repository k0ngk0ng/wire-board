# 对战经济平衡先行场景

本清单与基线测量先于参数调整。

- 基础阳光明显低于脑力收入；夜间或生产植物被消灭后，植物钱包长期停滞。
- 开局资金只能覆盖少数路线，投资向日葵后无法补齐防线；泳池基座和屋顶花盆增加成本，却沿用草坪预算。
- 向日葵／阳光菇的产出与回本时间不适合实时玩家连续出兵，首两分钟形成持续资源缺口。
- 2v2 按席位重复发放团队补给，或分配余数长期偏向同一人；生产收入转入队友钱包。
- 仅用电脑能完成对局代替平衡验收；两回合结果和局掩盖双方进攻都能轻松突破。
- 只测单一场景、种子或策略；通过给夹具加钱、清冷却、移动敌人或改写结果制造胜率。
- 调参导致植物全面碾压，僵尸无法形成压力；削弱植物原版伤害或偷偷提高僵尸生命来掩盖经济问题。
- 新经济污染旧存档；换边、恢复存档、Wasm 重演或布阵时钟产生不同收入。

测量覆盖六场景、1v1／2v2、多种固定种子和普通行动。分别记录进攻回合突破率、时间、清扫车消耗、路线覆盖、收入与支出；电脑结果只反映所用策略，不代表真人胜率。真实浏览器再核对种植与可见钱包变化。
