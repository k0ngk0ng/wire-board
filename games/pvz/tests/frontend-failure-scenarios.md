# 前端先行失败场景

以下场景在生产界面实现前定义。验收使用真实服务器、生产 Board、认证房间、原生鼠标或 Chromium 触摸输入；浏览器视区模拟不等于手机真机验收。

1. 大厅缺少新游戏，或创建选项允许 3 人、2v2 未满员开始。
2. 原图、动画、运行时或首次 Canvas 绘制尚未完成就提交加载确认；资源失败被空白画面掩盖。
3. 植物和僵尸玩家拿到相同卡槽，观众能提交动作，植物在错误格子种植，僵尸进攻行命中偏移。
4. 本人点击要等待网络确认才显示响应；连续操作丢失，拒绝操作后残留预测单位或错误钱包。
5. 钱包合并、卡牌冷却互串、队友植物可铲除；公共玩家栏的钱包在 320px 被裁切。
6. 卡片选择或点击草坪被页面滚动截获；铲子／Escape／数字键无效，后台恢复补交旧操作。
7. 攻守换边后保留旧选择、旧输入序号、旧僵尸卡槽或旧回合动画。
8. 图片按错误锚点绘制、僵尸与子弹停止运动、命中前提前扣血、刷新重播旧音效。
9. 全屏隐藏卡槽或资源；切换全屏重新挂载 Canvas；退出后无法继续操作。
10. 手机卡片不可点、行入口不可达、页面横向溢出、倒计时文字超出边界或颜色对比不足。
11. 设置更改后 1v1／2v2 模式与分队不匹配，准备画面重复提供平台已有开始／托管入口。
12. 浏览器脚本只检查 DOM 文本，未验证可见性、实际输入和服务器结果，或未保存截图、轨迹与复跑命令。
13. 草坪格子几何与实际绘制不一致；方向导航看不见焦点，确认键无法种植；控制器设置改键后旧的数字键／S 处理器仍绕过平台映射。
14. 公共导航取消不能清除卡牌或铲子，失焦后仍有旧选择；全屏后可导航格子的坐标停留在原大小。

## 全目录与经典场景扩展

以下失败场景在全目录界面实现前补充，验收入口 `frontend-full-browser.py`。

15. 49 种植物或完整僵尸目录缺失，卡槽直接平铺全部单位，卡册无法打开／关闭或关闭后被快照强制重开。
16. 首局卡槽为空、超过 10 槽、重复选卡、保存卡组消耗资源／重置冷却，或一位玩家改卡导致队友卡槽改变。
17. 植物与僵尸卡册切换混用个人卡组；观众、托管席位或不允许的阶段能改卡；选卡期限结束后仍提交旧草稿。
18. 模仿者未选择目标就能保存，目标非法／重复，模仿卡显示真实目标和费用不清；升级植物未说明前置植物，进入同格时错误挡住合法升级。
19. 水生卡、墓碑吞噬者、花盆等地形限制没有可读原因；卡册仅靠颜色表达禁用；种在错误地形后残留预测单位。
20. 泳池／浓雾只有 5 行，6 行命中区与视觉行错位；屋顶没有坡度或落点不随坡度；切换场景沿用上一张背景与格子数。
21. 睡莲／花盆、本体、南瓜同格时后画的单位遮住管理入口；铲除错误层或队友层，咖啡豆不能种在合法休眠植物上。
22. 浓雾仅用半透明滤镜处理，隐藏僵尸、投射物、死亡特效或详情仍出现在 DOM／调试图层／预测结果；应使用权威投影和规则可见区。
23. 一次加载全部场景和所有单位动画导致开局停顿；加载未用单位失败却阻止进入当前地图；新单位真正出现后没有完整原画或偷偷降低精度。
24. 卡册在全屏目标外、手机内容溢出、保存按钮不可达；弹窗导航／取消漏到下层草坪。
25. 射手攻击时只有头部，茎叶或身体丢失；需对原图 idle 与 attack 的完整身体近图做视觉对照，并保存桌面和手机真实战场截图。
26. 金币／阳光拾取物不可点击或不能用控制器确认，命中区挡住草坪；队友代收改变收益归属，3 秒自动入账后仍能重复领取。
27. 原图层动画 gzip 无法解码、变换矩阵或透明度未按原值应用、场景坐标僵王被当作普通行单位定位；合成姿态缓存裁切极值帧、丢失附属身体层或改变锚点。
28. 雪橇小队把每位乘客重复绘成完整车辆，下车后乘客又全部消失；须按权威 leader／slot／sled 状态表达整车与独立单位。
29. 晚于出生数秒触发的撑杆跳跃、巨人投掷、窝瓜跳跃直接显示非循环片段末帧；动画必须从权威 phaseAt 开始，冻结期间保持相位。
30. 线上非空旧版 ASSETS_BASE_URL 把 PvZ 新素材或运行时导向旧 CDN；必须使用本次构建 BASE_URL，真实服务器以不可用旧地址验收并检查没有访问该地址。
31. 六场景原版 BGM 缺失，或一次下载所有主题；必要主轨数据未就绪即开局。普通快照／换边重新播放前奏，静音／后台后补播旧音效或重连音乐从零开始；验证平台原生媒体轨的实际位置、播放身份与静音状态。
32. 蹦极偷取后植物凭空消失，或错误挂随手腕旋转；携带原植物须按原版固定脚锚偏移绘制，刷新也能凭公开原型 ID 还原。大型单位死亡不得统一截成 3 秒。
33. 玉米炮右半格只能选到基座，不能管理炮身或进入瞄准；两格须命中同一炮 ID，基座仍按各自格子区分。
34. 全局 button:disabled 的低透明度使卡槽、卡册已锁定卡组和装填按钮不可读；须检查实际计算样式与文本对比度，保留禁用语义。
35. 模仿者尚未完成变身就显示目标植物；显示原型须始终由权威 Kind 决定，只有变身完成后的目标才使用灰色变体。
36. 一个本地非法操作或服务端拒绝清空其他有效在途预测；未发送的非法输入耗尽 seq 窗口。必须只撤销失败输入，并保留其余输入及具体规则错误。
37. 同帧多种音效通过单声道相互 stop，仅剩最后一种；使用固定 8 个平台原生一次性音轨槽，并按 epoch/eventID 去重。静音／后台立即清理，恢复不补播旧事件，BGM 轨保持独立。
38. 初始静音的可选鼓／钹层仍被立即拉取；预测僵尸或雾后总数触发混音。只按权威、已过滤的可见压力达到 10 后启动可选层，加载完成后按当前音乐时间定位；夜晚变奏若无可靠对齐则保留主轨，不叠两份旋律。

复跑入口：`PVZ_BROWSER_URL=<测试服务器地址> python3 -B games/pvz/tests/frontend-browser.py`。服务器需开放仅用于本地验收的注册邀请码 `pvz-browser`；脚本创建正常房间，不使用生产规则中的资源作弊或隐藏场景。
