# 前端先行失败场景

以下场景在生产界面实现前定义。验收使用真实服务器、生产 Board、认证房间、原生鼠标或 Chromium 触摸输入；浏览器视区模拟不等于手机真机验收。

1. 大厅缺少新游戏，或创建选项允许 3 人、2v2 未满员开始。
2. 原图、动画、运行时或首次 Canvas 绘制尚未完成就提交加载确认；资源失败被空白画面掩盖。
3. 植物和僵尸玩家拿到相同卡槽，观众能提交动作，植物在错误格子种植，僵尸进攻行命中偏移。
4. 本人点击要等待网络确认才显示响应；连续操作丢失，拒绝操作后残留预测单位或错误钱包。
5. 钱包合并、卡牌冷却互串、队友植物可铲除；公共玩家栏的钱包在 320px 被裁切。
6. 卡片选择或点击草坪被页面滚动截获；铲子／Escape／数字键无效，后台恢复补交旧操作。
7. 攻守换边后保留旧选择、旧输入序号、旧僵尸卡槽或旧回合动画。
8. 图片按错误锚点绘制、僵尸与子弹停止运动、命中前提前扣血、刷新重播旧音效。
9. 全屏隐藏卡槽或资源；切换全屏重新挂载 Canvas；退出后无法继续操作。
10. 手机卡片不可点、行入口不可达、页面横向溢出、倒计时文字超出边界或颜色对比不足。
11. 设置更改后 1v1／2v2 模式与分队不匹配，准备画面重复提供平台已有开始／托管入口。
12. 浏览器脚本只检查 DOM 文本，未验证可见性、实际输入和服务器结果，或未保存截图、轨迹与复跑命令。
13. 草坪格子几何与实际绘制不一致；方向导航看不见焦点，确认键无法种植；控制器设置改键后旧的数字键／S 处理器仍绕过平台映射。
14. 公共导航取消不能清除卡牌或铲子，失焦后仍有旧选择；全屏后可导航格子的坐标停留在原大小。

复跑入口：`PVZ_BROWSER_URL=<测试服务器地址> python3 -B games/pvz/tests/frontend-browser.py`。服务器需开放仅用于本地验收的注册邀请码 `pvz-browser`；脚本创建正常房间，不使用生产规则中的资源作弊或隐藏场景。
