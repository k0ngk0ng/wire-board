# 全植物与弹丸先行失败场景

以下清单与动作/推进 E2E 先于 `engine/plants.go`、`projectiles.go` 实现。测试使用明确标记的完整世界战斗夹具，便于使所有经典单位进入其特殊状态；它们不冒充正常经济整局。生产配置、卡组、放置/升级/同格支架/咖啡/模仿者/浓雾信息过滤由 root 的全世界与 HTTP E2E 覆盖。

- 生产：向日葵/双子/阳光菇没有对应产量，睡眠仍产出，阳光菇永不长大；金盏花没有金币拾取物或收益归错钱包；金磁偷取队友钱或把金币改成阳光。
- 蘑菇：白天睡眠仍攻击；小喷/海蘑菇无限射程；大喷不能穿过门盾/同一行多个目标；胆小菇附近有僵尸仍攻击；忧郁只打一个目标/没有四轮范围；寒冰菇只减速却不冻结；毁灭没有坑或误伤范围外；墓碑吞噬者不清除墓碑。
- 发射：双发/机枪少发或无界连发；三线在边界越行或只打一行；裂荚不攻击后方；杨桃没有五方向、只按row判碰撞；仙人掌打不到气球；香蒲不跨行追踪、不优先气球或追踪已死目标永久泄漏。
- 吞噬与触发：大嘴花吞掉巨人、消化时继续吞、吞噬阶段没有延时；未成熟地雷引爆；窝瓜未锁目标/不跳杀；水草不杀潜水目标或无限重复使用；魅惑睡着也触发、抢改单位所有者；大蒜不能转行/转入非法水路。
- 范围与地面：樱桃/辣椒/毁灭/玉米炮伤害或范围错误；辣椒不清冰、不克制冰球；寒冰菇不抵消火球；地刺少打或打到气球，地刺王没有双次伤害/车辆损耗；火炬重复点燃同弹、冰豆一步变火豆；后方射击错误拦盾。
- 磁力与防护：吸塑料路障/报纸却不吸铁桶、门、梯、矿镐、跳杆、玩偶匣；磁力无冷却或无限移除；伞保护范围错误，篮球仍伤到伞范围内植物。
- 投手：卷心菜/玉米不跨屋顶坡度，黄油无1/4概率或没有4秒固定；西瓜没有范围与总溅射上限，冰瓜漏减速；投射物在视觉到达前扣血；空目标残留永远不释放。
- 玉米炮：未装填、非本人、睡眠、回合非battle或非法目标也可发射；无飞行延时/无重装冷却；一发重复命中。
- 确定性与上限：Flags/Hits浅拷贝；分段/一次推进不同；最多256弹丸被突破；被魅惑的僵尸弹因Owner仍是僵尸而错打植物；boss冰火弹免疫对应反制。

产物：`.local/pvz/full-plants/*.json`，记录夹具语义、初始/最终世界摘要、回放和场景结果。复跑 `go test -json -count=1 ./games/pvz/tests -run '^TestPVZFullPlants'`。

- 仙人掌高位针不能被前方地面僵尸当作普通低位弹丸拦截；三叶草只吹走气球飞行状态，不能误杀蹦极下降状态。
- 辣椒全行燃烧必须同时清除该行已放置的梯子；对应冰球的反制不能误清其他行。

## 审阅补充：发射源行与跨行运动

- 香蒲瞄准另一行时，针刺必须先在香蒲所在行出现，再逐步追踪；不能在目标行直接出生。
- 三线射手上下行弹丸必须由本体位置发射，以逐渐衰减的竖直速度过渡到相邻行；首帧不能移动整整一行。

## 复审：目标类别、金属盾与原版参数

- 卷心菜/玉米/西瓜/冰西瓜必须锁定并命中潜水僵尸（原版mask 0xD），香蒲必须继续排除潜水；西瓜潜水溅射同样按该mask。
- 土豆雷mask 0x4D包含地下，必须由同格潜地矿工自然触发；窝瓜mask 0xD可以主动锁定潜水目标。
- 梯子被磁吸时必须连同500HP盾移除，正面豌豆随后应直接扣身体；已挂梯不再作为同一只僵尸的随身工具。
- 活跃跳跳杆状态不得被大嘴花锁定/吞下；夺杆或被冻住后可以。除巨人/红眼/僵王外不能凭额外类型列表把可吞车辆改成40HP咬伤。
- 所有植物索敌须复用统一伤害可用性过滤，不能锁定载具雪橇的免伤后排和仍在下降/离开的蹦极。
- 玉米炮合法发射必须更新tick单位的flags.attackAt，不能只将state改为charging；非法发射不能更新。
- 西瓜密集溅射预算为7*主伤80=560，不能误用7*secondary26=182；火豆预算仍为主伤40。
- boss冰火球每秒位移分别按原_ground周期均速，保留整数余量，不用临时的125逻辑单位/tick。

- 香蒲全图目标按实际二维距离比较，不能只按横向距离；磁力目标按欧氏距离加行惩罚，地上梯子按原版最近Chebyshev排序，不能取数组首项。
- 小喷/海蘑菇短程孢子寿命75个10ms更新，不得因同tick出生后立刻推进而提前一个50ms显示步消失。

- 火豆主目标是冰车/投石车或仍有门/梯盾时，原版改走40单体，不产生对周围人的溅射，也不解除该抗火目标寒冷；普通主目标产生溅射时同样排除这些抗火次目标。不能把参考源码漏掉`==FIREBALL`的条件误套到西瓜。
