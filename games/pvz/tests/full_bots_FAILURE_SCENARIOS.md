# 完整对战电脑的先行失败场景

本清单和对应 E2E 在修改电脑策略前编写。

- 泳池第六行越界，或电脑把陆地单位直接放进水中、屋顶缺少花盆；非法提案令整帧回滚。
- 电脑提出本人卡组之外的动作、越过费用／冷却／入口间隔，或直接修改世界与钱包。
- 蘑菇白天长期睡眠、不用咖啡豆；升级卡没有自己的基础植物；玉米炮不瞄准与发射。
- 蹦极没有格子目标、雪橇缺冰道、僵王在错误场景或重复购买；只有特殊兵种时策略永久空闲。
- 只会使用最初8植物／6僵尸，自定义49／33卡组中有可合法使用的牌却始终不选。
- 地刺在屋顶／水路永远不能种植，策略却把基座当作其前置而持续购买无用花盆／睡莲。
- 浓雾电脑根据投影中不存在的敌军位置作决定；夹具隐藏单位改变其可观察行为。
- 1v1／2v2任一场景无法自然完成两回合；换边仍用上回合阵营、卡组、余额或序号。
- 主动取消托管改变逻辑时间／资源，真人空闲时被策略自动接管，或恢复存档补算离线战斗。
- 同一输入状态的电脑提案不确定，或者选择动作本身改变RNG、冷却、序号和对象列表。

验收覆盖六场景 × 两种人数的生产模块自然整局。单卡策略场景明确使用充足资源、定向敌军位置和合法基础植物作为受控夹具，仅验证策略覆盖，不冒充自然经济对局。所有提案通过普通 `Apply` 执行；结果保留命令、源摘要、回放、摘要和胜负。
