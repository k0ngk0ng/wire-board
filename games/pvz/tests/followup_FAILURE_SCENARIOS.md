# 加载、清扫车、出兵节奏与结算先行回归

本清单与相应验证在修复前编写。

- 开局资源由游戏自行下载但公共加载页没有 loaded/total，音乐、Wasm、动画或图片请求未计入；按文件个数冒充字节百分比。
- CDN 地址错误、走源站回退或资源不缓存；首屏强制下载完整 10.5 MB 音乐，静音也等；预取后播放器重复下载音乐；无限并发细碎请求挤占关键资源。
- 普通地面敌人、撑杆／海豚／小鬼临时腾空越过左界时，有车却提前判输；矿工出土后向右走被判为向左突破；真正飞行绕过车的规则与临时跳跃混淆。
- 清扫车已驶过后不是整行无敌；已耗尽、未耗尽、移动中、空中、潜地与魅惑单位均须分别验证；同一条边界不能重复结算。
- 保留植物队初始总阳光 300（2v2 每人 150），进攻方通过切换卡牌／队友同时点不同入口绕过出兵节奏。部署失败、重复 nonce 不消耗钱或其他冷却；固有召唤不被玩家部署间隔破坏。
- 换边后双方各赢一回合，结算没有清楚说明最终比较；双方均攻破但用时差小于1秒，界面四舍五入成相同时间；进攻失败被误标为该进攻队「守住」。
- 结算原因、两回合结果与服务器胜者一致，并在公共结果浮层、全屏和320px可见；不得因此加载其他游戏模块。
- 气球、矿工、蹦极等特殊僵尸开局即可部署，防守牌组没有对空手段；提前清空卡牌冷却可绕过解锁时间；布阵时间计入解锁或换边未重置；旧存档在恢复时被静默改为新解锁规则。
