# 平台接入与运行时的先行失败场景

本清单与相应 E2E 在实现、注册和浏览器运行时之前编写。

- 注册缺失、重复、默认下架，2／4 人元数据与实际开局校验不一致；3 人或未满员 2v2 被启动。
- 客户端伪造席位、队伍、余额、冷却和测试场景；观众提交种植，僵尸在布阵期出兵。
- 同一格并发种植重复扣款，nonce 重试再次扣款，失败操作改变本人或队友钱包。
- 队友铲除他人植物，旧回合 epoch、超大序号、越界格子和未知字段绕过校验。
- 电脑和主动托管无法完成 1v1／2v2 的两个阵营；取消托管延长比赛或重置余额。
- 真人未完成资源加载就开始计时，观众阻塞加载；重连重新暂停全员。
- SQLite 保存与重启丢失植物、个人钱包、冷却、回合、操作序号和比赛期限。
- 两回合换边没有重置场地／钱包；和局伪装成共同获胜；团队结算遗漏队友。
- WebSocket 小更新重复完整存档，断流不能恢复，慢连接阻塞其他玩家。
- 正式页面在正常与单端 320 毫秒 RTT 下，原生输入到种植像素首帧 p95 超过 100 毫秒；显示帧间隔 p95 超过 35 毫秒。先冻结此目标，再执行测量；真实触屏用浏览器原生触摸派发验证，手机视区模拟不声称为真机。
- Go 与 Wasm 的初始状态、同序操作、固定步推进和最终摘要不同；本地预测决定权威结果。
- 浏览器运行时缓存与源码摘要不匹配，运行时或原始研究安装包进入正式服务器镜像。

验收保留运行命令、源码版本、HTTP 轨迹、原生／Wasm 重放摘要、结果 JSON 和浏览器截图。真实时间与测试时钟场景分别标记，不以夹具表现替代正式页面的输入响应。
