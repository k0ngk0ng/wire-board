# 植物大战僵尸

以 PC 初代英文版 `1.0.0.1051` 的单位、场景、动画和音乐为基准实现完整攻防对战。支持 1v1／2v2、共享战场、个人卡组和独立钱包。每场比赛包含两个回合，第二回合交换植物／僵尸阵营。

## 内容与玩法

- 全部 49 张常规植物卡，包含模仿者、八种升级植物、玉米加农炮主动瞄准与分层建造。
- 全部 33 种僵尸原型，包含水路、飞行、地下、车辆、召唤、偷取、扶梯、植物僵尸、红眼巨人与僵王。僵王仅在夜间屋顶开放；雪橇小队需要冰道。
- 六种场景：白天草坪、夜晚草坪、泳池、浓雾、屋顶、夜间屋顶。泳池／浓雾使用六行，其他场景五行。水路基座、屋顶花盆、蘑菇睡眠、墓碑、弹坑、冰道、梯子和浓雾揭示均参与规则。
- 每人至多 10 张卡，布阵时可改卡组，换卡保留冷却。模仿者先选普通植物目标，完成原计数与变身动画后才获得目标能力。
- 植物使用阳光，僵尸使用脑力。2v2 将团队初始资源与基础收入按人数分配；向日葵和拾取物归生产者。队友可提前协助收取，款项仍记入原所属钱包。
- 植物队开局阳光与基础补给按场景配置：白天草坪 500、泳池 600、屋顶／夜间屋顶 700、夜晚草坪 300、浓雾 400；2v2 将团队开局资金和基础补给均分到独立钱包。向日葵、双子向日葵和阳光菇在种下／升级后 3～6 秒首次产出，此后每 18～20 秒产出；金币花保留原节奏。具体参数、对照与限制见[对战经济平衡](BALANCE.md)。
- 僵尸队两次付费部署至少间隔 3 秒，不能通过切换卡牌或队友同时出兵绕过；各单位更长的冷却仍生效，召唤出的随从不占付费部署间隔。屋顶默认植物牌组提供樱桃炸弹与火爆辣椒解围，默认僵尸牌组加入远程单位；全部单位仍可从卡册选择。
- 新对局按开战时间分批解锁特殊僵尸，布阵不计入解锁时间，每次换边重新计时。45 秒开放橄榄球、舞王及豌豆／坚果僵尸；60 秒开放潜水、海豚、小丑、跳跳、扶梯及窝瓜／高坚果僵尸；90 秒开放气球、矿工、蹦极、冰车、雪橇、投石车、雪人及辣椒／机枪僵尸；120 秒开放巨人、红眼与僵王。原有场景、冰道及费用条件继续生效。六个场景的默认植物牌组均含对空手段，草坪／屋顶默认带三叶草。
- 花盆／睡莲、本体、南瓜分别保留归属和生命。只能铲除自己的层；升级要求本人的基础植物，玉米炮要求相邻两株本人玉米投手及一致支撑。
- 每行保留对应清扫车。消耗后僵尸突破房屋边界即结束该攻防回合，气球另有飞行突破规则；守到时限则防守成功。仅一队攻破则该队获胜；两队都攻破比较用时；两队守住或用时相同为显式和局。
- 结算显示两回合的进攻队、防守队、是否攻破及精确到百分之一秒的用时，并说明最终获胜或和局原因。临时跳跃不能绕过可用清扫车；真正飞行中的气球仍须用对空植物处理，向右行进的矿工不算突破房屋。
- 回合时限 3／6／10 分钟，布阵时间 10／20／30 秒。双方换边时重置场地、资源与冷却，并使用相同初始随机条件。

PC 支持鼠标和平台键盘／手柄导航、确认、取消与改键；手机支持卡槽、卡册、分层管理、主动技能与真实触摸操作。全屏复用平台框架。所有开放人数、场景和阵营都支持电脑及主动托管，真人断线保持手动。

完整范围与分工边界见 [FULL_CONTRACT.md](FULL_CONTRACT.md)。原表另外 4 个单机专用植物模板保留资源与证据，不冒充常规选种；本模块不含原单机冒险剧情、迷你游戏关卡、生存或禅境花园。

## 原版依据与表现

样本身份、SHA-256、函数地址及 180 条 REA 证据见[取证说明](../../docs/research/pvz/README.md)。完整图层、附属动画、受损姿态、矩阵与脚底锚点由原资源解码，射手的独立头部和茎叶循环分别合成；大型单位使用共享原图和压缩变换，保留完整帧。素材方法与来源见[资源说明](assets/README.md)。

166 段原音效与 19 条无损 FLAC 保留原主题、前奏、循环及分轨。音乐、静音、后台恢复和有界多音效槽都通过平台音频端口管理。可选节奏层按已公开单位压力适配，浓雾不使用隐藏兵力触发音乐。夜晚高潮轨保留，但没有可靠原 bar 切换时钟时不叠加第二条旋律。音频测量与恢复边界见[音乐说明](../../docs/research/pvz/MUSIC.md)。

原 Windows 程序未执行，本实现未宣称逐帧动态等价。僵尸 `_ground` 周期内步态采用已验证周期均速适配；随机数使用独立、可存档的确定性实现，保持已恢复的取值范围。50 毫秒逻辑时钟、僵尸购买与收入、多人经济、比赛期限和部分动画完成阶段属于平台适配；原版动态混音未逐采样运行对照。

## 模块与同步

`engine/` 保存 Go 独立规则，`server/` 对接认证、时钟、电脑、存档与结算，浏览器 Wasm 使用同一引擎。常规同步传有界新增操作与摘要，接入、换边和缺口恢复才传完整检查点。

浓雾按认证席位过滤敌方单位、目标坐标、事件与恢复快照，电脑也只读取该席可见投影。此模式只做本人显式操作预测和公开运动外推，伤害、实体生命周期、资源与地形以权威投影确认。客户端可见帧使用实际公开位移做亚帧呈现；不靠提前推进下一逻辑步显示命中或消失。

所有客户端程序与资源从本次构建的不可变 CDN 根地址加载，不复用平台旧素材前缀。Wasm、原图、压缩动画、音效和音乐由统一发布清单上传校验并从正式服务器包剥离。原始 EXE／PAK／MO3 与解码工具仅保存在工作区研究目录，不参与发布。

公共加载页显示当前下载阶段的已下载／总大小。开局只下载本局必要场景、可用单位和运行时；尚未解锁的单位在临近开放或实际出现时加载。音乐由平台原生媒体通道从 CDN 流式读取，不作为首帧就绪条件。特殊僵尸解锁与经济属于对战平衡参数，不是原版冒险规则；更新前已保存的对局保留原规则版本，新经济仅用于新对局。

## 验证与复跑

先行失败场景和 E2E 位于 `tests/`；实现前先写测试，审阅发现的缺陷保留独立回归。自然整局、受控机制夹具、真实浏览器和音频解码结果分别记录。

```sh
. scripts/env.sh
go test -json -count=1 -timeout=10m ./games/pvz/tests
npm --prefix web test -- pvz
npm --prefix web run build
python3 -B scripts/check_game_boundaries.py
```

素材校验使用资源说明中的工作区 Pillow 解释器与已有 FFmpeg：

```sh
mkdir -p .local/pvz/assets
.local/pvz-research/venv/bin/python -B -m unittest discover -s games/pvz/build -p 'test_*.py'
.local/pvz-research/venv/bin/python -B games/pvz/build/verify_native.py --output .local/pvz/assets/native.json
.local/pvz-research/venv/bin/python -B games/pvz/build/verify_music.py --output .local/pvz/assets/music.json
```

真实浏览器使用生产构建、认证房间和仅在测试二进制开放的服务。非空旧素材前缀用于验证正式环境兼容性：

```sh
WIRE_BOARD_PVZ_BROWSER=1 PVZ_BROWSER_LEGACY_ASSETS=https://legacy-assets.invalid/unavailable \
  go test ./games/pvz/tests -run '^TestPvZBrowserFixture$' -count=1 -timeout=90m
```

服务地址写入 `.local/pvz/browser/url`。另一终端将该地址设为 `PVZ_BROWSER_URL`，运行 `frontend-full-browser.py`、`frontend-animation-browser.py` 和 `integration-interaction.py`。独立呈现回归运行 `python3 -B games/pvz/tests/full_presentation_browser.py`。完成后创建 `.local/pvz/browser/stop` 停止测试服务。

加载回归运行 `PVZ_BROWSER_URL=<地址> python3 -B games/pvz/tests/followup-loading-browser.py`。对空与结算回归还需用 `PVZ_RESULT_BROWSER=1 go test ./games/pvz/tests -run '^TestPVZFollowupResultBrowserFixture$' -count=1 -timeout=16m` 启动受控结果夹具，再将 `.local/pvz/followup-result/url` 写入的地址设为 `PVZ_RESULT_URL`，运行 `followup-ui-browser.py`。该脚本在正常房间等待真实 90 秒解锁并执行气球／三叶草操作；另一房间只控制初始局面，最终结果由规则核结算。记录保存在 `.local/pvz/followup-loading/` 和 `.local/pvz/followup-ui/`。

结果集中于 `.local/pvz/`：`full-world/`、`full-plants/`、`full-zombies/`、`full-bots/`、`full-presentation/`、`frontend-full/`、`interaction/` 以及完整套件 JSONL。所有记录包含命令、场景、源码／资源摘要和适用范围；手机视区与原生触摸派发属于 Chromium 仿真，不冒充手机或手柄真机验证。
