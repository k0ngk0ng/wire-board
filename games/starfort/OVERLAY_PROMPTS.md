# 星垒波前提示与战场浮层修复

来源：许愿 `11da7aef34092d3532c6f21a1dac6b63`，正文修订 0，以及用户要求恢复战场内状态／按钮浮层。只改客户端呈现，存档版本和规则保持原值。

## 实现前失败场景

- 首领提示漏掉路线；用波数或当前已出兵数量推算错误；包括未启用路线；刷新重播已关闭提示；结算商店误报上一波首领。
- 首领提示与任务询问重叠；关闭首领后始终不询问任务；已有矿场奖励或商店使后续任务一直被抑制；同波普通快照反复打开；同一房间再开一局或同 ID 下一波漏问；观战不能收到玩家承接操作。
- HUD／按钮仍为独立占位，出现空白条；提示出现、消失或过期改变战场尺寸、缩放或焦点；手机和全屏按钮超出地图或互相遮挡。
- 灾害尚未生成就出现文字，全部效果结束仍显示；台风只有计划但尚未激活仍提示；洪水过期不关闭；暂停错误消耗仿真提示时间。
- 事件提示遮住 HUD、道路或小地图；拖动、缩放后定位失配；提示层截获原生点击和触屏；色彩不可读。

## 验收

先写独立提示策略与位置计算的针对性测试及真实浏览器验收，再修改实现。复用现有公开 HTTP／SQLite 场景，不新增服务端规则、规则测试或夹具。首领、任务、灾害的队列和生命周期按权威快照呈现；保留桌面、320px、全屏、原生鼠标／触屏和逐帧几何记录。无提示时不创建占位区域，地图尺寸不因提示变化而改变。
