# 薄雾倒退与弹坑卡局失败场景

实现前记录。线上第 25 波存档在 tick 6031 合法，但下一次公开模块计时返回「敌人引用无效弹坑」，平台拒绝提交并不断重试，因此整盘停止推进。

- 薄雾倒退中的敌人同时被冰封／睡眠，速度变为零；不能再次进入弹坑或参与填坑。
- 冰封结束或恢复速度从零变为正值后，敌人开始倒退，不能保留原弹坑引用、在旧坑位置工作或留下无效存档。
- 没有倒退效果的冰封／睡眠敌人仍留在坑里，停止工作；恢复后按原规则继续填坑。
- 倒退结束后正常前进，继续遵守既有逐塔弹坑保护，不重置保护、状态期限、等级、金币、波次或随机数。
- 规则版本 9、10 均须保持计时、序列化、重启可用。现场存档须通过真实 HTTP／SQLite 恢复继续推进；不得删除敌人、塔、任务或清空当前波来绕过校验。

复现存档只包含公开游戏模块数据；平台账号、房间密码、聊天和对局日志未进入夹具。原始现场与摘要留在 Git 忽略的 `.local/starfort-stall/`。
