# 扩展战场界面验收场景

实现前记录。复杂交互使用真实房间 E2E 验证并保留 JSON 结果与桌面／320px 截图；仅靠 DOM 文本存在不能证明可见性。

1. 第 6／11／16 波只在准备阶段出现扩展选择；预览能比较真实候选道路、入口、地图面积、建造点和高地，旧塔保留。
2. 每席投票准确显示，观众只能查看；选择投票携带当前 epoch。未决路线或成长选择期间不能准备，也不能误显示即将出波。
3. 全员投票后的多数、平票及超时结果与服务端一致；界面提示规则，确定后显示新的完整整备时间。
4. 波次事件显示实际效果及后两波预告；无尽模式入口轮换显示当前入口，不对已有敌人改路。
5. 第 5 波后的成长选择显示具体加成、真实投票和当前累计加成。刷新、暂停、恢复不会提交旧投票。
6. 矿场、瞭望塔、补给队显示花费、完成条件、当前进度、风险及奖励；金币不足、暂停、战斗、观众不能承接。据点／补给队独立生命实时可见；矿场与瞭望塔守一波，补给队沿真实路线移动并显示护送进度，不能把基地受伤误写成目标失败，不能把固定波数误写成送达条件。
7. 自己的塔可选择最接近星核、最强敌人或支援敌人优先；队友和观众只能查看。伤害、射程、攻击间隔显示服务端提供的实际数值及建造点地形。
8. 新敌人与首领阶段能看懂；已有建造、升级、出售、金币支援、准备、暂停操作及原有验收选择器保持可用。
9. 320px 无横向溢出，选择卡片不挤窄，前景／背景对比可读；暂停与结算不出现可提交的假按钮。全部新增请求均携带 epoch。
10. 旧快照缺少世界数据仍可浏览；玩家金币和星核生命不被新面板遮挡。地图操作由 Canvas 独立验收拖动、缩放、入口定位和返回基地。
