# 图标操作与紧凑状态验收

实现前记录，覆盖用户截图中的医疗包／商店新增后右上按钮重叠。

- 准备、取消准备、暂停、恢复、战区选择、建造、医疗包、商店、任务、情报改为图标按钮；保留准确的无障碍名称、悬停提示、按下状态及医疗包数量。
- 所有按钮处于同一布局流；医疗包、商店、长金币、多人与准备投票、320px、iPad 横竖屏和桌面均不能重叠、越界或遮挡左上状态与全屏退出。
- 左上压缩为生命、波次、金币、时间／剩余敌人数和必要的天气图标；金币保留可获取的精确数值。无特殊天气时不显示相关文案或空天气栏，情报与预告也不显示「无特殊天气」。
- 移除左下缩放、回到星核、全图、入口与外置预览按钮；保留滚轮锚点缩放、双指缩放、拖动平移、小地图定位和选择弹窗内的路线预览。
- 无任务的合法存档可能返回空列表或 `null`，打开任务时都应显示空状态，不能使游戏组件崩溃。
- 真实鼠标／触摸仍能准备、取消、使用医疗包、打开与关闭建造／商店／任务／情报；布局更新不重置对局。

浏览器脚本使用真实 HTTP／SQLite 夹具和生产组件，保存结构化结果、几何坐标及截图。手机／iPad 尺寸为 Chromium 触屏仿真，不能冒充实体设备验收。
