# 冰墙与箭塔分支

新开局启用新技能规则；旧存档保留原技能和专精。玩法参数见 [当前新局规则](README.md)。箭雨和穿心在升到 4 级时二选一，沿用平台升级操作；电脑通过同一接口选择合法分支。

随机判定由服务端完成，随机状态随存档保存，不传给客户端。冰墙仅在尚未永久减速的敌人实际跨越对应路线位置时判定一次；停留、修补弹坑或刷新页面不会重复判定。永久减速保存在敌人身上，冰墙消失或原塔出售不清除；治疗不清除，死亡后新生成的单位不继承。临时减速与永久减速取较强效果，不连乘堆叠。

一箭穿心的秒杀同时要求普通类型和等级符合门槛；护盾与护甲不阻止符合条件的秒杀。精英、首领及超过门槛的普通敌人按三倍攻击伤害结算，正常应用护甲和护盾，低血量时仍可被正常伤害击败。箭雨主目标使用正常伤害，半径 75 内其他存活敌人承受 70% 攻击伤害。

存档使用 schema 4 记录新技能规则、敌人等级、永久减速和冰墙；继续支持 schema 1～3。网络投影不传随机状态，继续使用近期事件窗口；冰墙只传绘制所需的 ID、位置、朝向和时间，永久减速事件只带目标与冰墙标识及特效坐标，不重复整份敌人状态。冰墙最多同时存在 32 堵，造型按朝向缓存，单个 Canvas 最多保留 32 张冰墙纹理；动画仅改变本地呈现，不决定随机结果或伤害。

## 验证

实现前失败场景记录在 `server/ice_arrow_test.go` 和 `tests/accept_ice_arrow_ui.py`。规则检查覆盖触发／不触发、等级边界、精英与首领免秒杀、减速持久化、墙体过期、数量上限、分支鉴权、旧存档和随机状态恢复；完整对局继续覆盖 1～4 人、电脑、托管、闯关与无尽模式。

```sh
. scripts/env.sh
go test -count=1 -timeout=20m ./games/starfort/server ./games/starfort/tests
npm --prefix web test -- starfort
npm --prefix web run build
python3 -B games/starfort/tests/accept_ice_arrow_ui.py
```

浏览器验证使用真实 HTTP 房间、生产 Canvas、PC 原生鼠标和 320px 触屏仿真，保留分支选择、说明可见性、冰墙绘制、刷新后的永久减速及静态纹理复用记录；不代表手机真机测试。结果位于 `.local/ice-arrow/browser/`。在路径较长的 macOS 工作区，可将 `STARFORT_FOLLOWUP_SOCKET_DIR` 指向仓库内较短的临时目录。
