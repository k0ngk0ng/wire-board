# 世界扩展素材验收

实现前列出以下失败场景，验证脚本先于绘图及声音生成脚本编写：

- 六种地形缺失、尺寸错误、图片不能解码、背景接缝或图案边缘裁切。
- 透明物件失去透明通道、有效图像空白或触碰画布边缘；图集裁片和独立图片不一致。
- 新敌人的三个姿态完全相同，或关键特征无法区分。
- SVG 引用外部图像、字体、脚本或其他未包含的资源。
- 音效格式错误、静音、削波、过长或边缘产生点击声。
- 清单遗漏文件、校验和与成品不符，或重新生成后内容变化。

独立验证使用 Pillow 解码和逐像素比较，不依赖生成脚本中的素材列表。生成后人工检查联系表，确认卡通风格和角色轮廓。整体验收仍由真实对局浏览器测试确认画面集成与动画。
