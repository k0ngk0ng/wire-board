# 密室逃脱美术规格

原创的俯视微缩场景，细密像素笔触与克制的绘画纹理，青灰阴影、黄铜暖光、明确的人物轮廓。空间保持统一的斜俯视投影；不复制参考游戏的角色、图案或构图。

- 封锁站：深青色搪瓷、锈蚀黄铜、暖白安全灯、玻璃控制室、老式仪表与潮湿石砖。冷暖分区，通路保持可辨。
- 沉没档案馆：墨绿木作、赭金书架、铜制天文仪、浅水倒影和青色月光。房间主体、材质、装置与撤离目标独立于封锁站。
- 背景画幅 1536 × 1024，运行时映射到 1000 × 666.667。主要行走面为 x=150～850、y=265～560；中心空出，固定装置在可交互层独立绘制。四向出口由游戏按实际连接叠加。
- 人物采用四套服装和轮廓：琥珀色机修员、青色潜水侦察员、珊瑚色急救员、乳白色档案研究员。没有数字角标。
- 所有角色和道具用同一光向、比例与像素密度。状态用造型、动画与光色共同表达，不能只依赖颜色。
- 主界面保留平台公共框架。游戏内采用深墨绿面板、暖白正文、黄铜分隔，线索和地图按需打开。
- 灯光、雾、浮尘、积水、设备运转和人物动画在真实规则时间上呈现；减少动态效果时保留信息。

生成模型为用户指定的 `gpt-image-2.5`，通过当前配置的 API 使用 imagegen 技能 CLI。精确提示词保存在 `prompts.jsonl`。运行产物进入本游戏公开素材目录，经公共资源发布流程分发。
