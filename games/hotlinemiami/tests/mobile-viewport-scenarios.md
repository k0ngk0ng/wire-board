# 手机视区与人物可见性失败场景

- 实际 Canvas 比例改变后仍把固定 576×360 视区分别横向、纵向缩放，导致人物变形或缩成数个像素。
- 将透明精灵帧宽度当成人物大小，而原图非透明主体在 320 px 手机上不足 24 CSS px。须按对应图集和实际非透明边界测量，并保留截图。
- 全屏仍被标题、分数、外置 122 px 控制器和底部说明挤占，或者固定 8:5 的战场在竖屏裁切。
- 只放大人物图片，镜头、触点转世界坐标及预测后瞄准仍使用旧缩放；移动、边缘跟随和改变宽高后发生偏移。
- 当前玩家出生、移动到地图边缘、转动屏幕后被摇杆、按钮、文字或全屏工具遮住；镜头安全偏置与输入换算不一致。
- 单指松开清除另一指，滑出控制区后卡住，取消、失焦、隐藏、尺寸或输入方式变化后未释放旧触点。
- 普通、原生全屏、网页全屏之间切换重建 Canvas、重置生命代次或重开对局。
- 手机、Duo 与 Pad 的控件远离底边、右侧按钮过多，或窄 PC 窗口错误显示触屏控制。

端到端入口：`node games/hotlinemiami/tests/mobile-viewport-browser.mjs`。使用当前源码的实际平台与 Board，连接既有本地 HTTP／SQLite／WebSocket 浏览器夹具；不修改规则，不运行后端完整对局。结果、原始输入、人物主体边界、视野和截图位于 `.local/hotlinemiami/verification/mobile-viewport/`。
