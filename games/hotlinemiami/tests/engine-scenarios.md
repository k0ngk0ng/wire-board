# 战斗引擎失败场景

先登记场景并编写测试，测试缺少实现时执行一次，再开始实现。测试不把夹具地图冒称原版关卡。

- 非法人数、地图、武器、造型、时间或超范围坐标导致运行时崩溃。
- 对角移动加速、按键未释放、碰撞越墙或高速移动穿墙、Go 和 WASM 运动结果不一致。
- 重复、乱序、过大序号与旧生命输入改变当前状态，短暂射击被随后的松开覆盖。
- 空弹药仍开火，射速冷却被多次输入绕过；同一弹丸重复击杀；同帧攻击无法互杀。
- 高速弹丸穿薄墙，玻璃和门状态不参与碰撞，门关闭把人物推进墙内。
- 投掷后原武器仍可用，投掷重复生成物品，拾取补满旧枪弹药，两人同时捡到同一把枪。
- 击倒状态仍能开枪，处决不受距离或遮挡限制，处决者被赋予无敌。
- 复活前输入被用于新生命，复活保护挡弹，主动攻击没有解除保护，出生位置落在碰撞体内。
- 电脑越过墙射击、知道隔墙或画外敌人的位置、无法走出拐角、不能完成各人数与地图的完整比赛。
- 事件、尸体、掉落武器或历史记录无限增长，种子相同的比赛产生不同结果。
- 计时结束后还能操作，和局被报告为多人共同获胜。
- 弹丸补偿接受任意过去或未来的帧；使用上一条生命的射手位置；补偿段遗漏当时关闭的门或目标保护状态。
- 补偿命中过去的目标后伤害其复活新生命；补偿后再次推进已命中的弹丸；同一射击重复扣弹药或结算击杀。
- 弹丸回放把静态墙、门和玩家直接改成历史状态；近战、投掷与处决错误使用枪械回溯。
- 扩充内容后仅界面出现新名称，服务器不能创建新增造型／武器；新增枪械未遵循冷却、弹药、真实弹丸和历史补偿。
- 规则源扩充到六张地图后只注册旧三图，生成器静默跳过新增地图，新增关卡电脑无法完成自然比赛。

复跑入口为 `go test ./games/hotlinemiami/engine -count=1`，详细报告使用 `-json` 写入 `.local/hotlinemiami/verification/engine.jsonl`。首次失败记录和完成后结果均由父任务保存。

规则使用每像素 256 单位的整数坐标、60 Hz 固定推进和 0 至 1023 的方向。速度、弹药、射速、复活时间与出生保护属于多人改编参数，不声称是原版逐帧恢复值。六张地图的静态墙、家具、门和初始出生点来自恢复的数据，额外武器点是多人新增规则。

电脑使用与所有设备相同的 384 × 240 原像素视野，以本席位置为中心并限制在地图边界内，再通过墙和门的视线检查选取敌人与掉落武器。已知地图出生点可用于巡逻，不能通过完整状态获取画外对手位置。

`go run ./games/hotlinemiami/cmd/maps` 从 `data/maps.json` 生成定点规则；加 `--check` 不写文件，只检查生成结果一致。Go 数据只存规则几何，不含地图图片、图集或音频。`Maps()` 和 `MapByID()` 返回进程初始化完成的只读规则，调用者不得修改其切片内容；动态门与破碎玻璃存放在各自对局状态。

浏览器共享运动入口由 `GOOS=js GOARCH=wasm go build ./games/hotlinemiami/cmd/motion` 生成。`hotlineMotion.init()` 缓存当前静态地图；`move()` 接收定点坐标、整数方向、连续输入、最多 9 帧预测及动态门／玻璃状态。`weapons()` 返回同一份武器规则供开火呈现使用，前端不另维护射速表。

弹丸补偿由 `viewFrame` 提示最近看见的权威帧。未来帧拒绝，超过 6 帧的旧画面自动使用当前判定。服务器仅回放新射击最多 100 ms 的历史弹道，使用每段当时的门、玻璃和玩家位置；当前弹药、冷却、生命与门状态不回滚。命中携带历史生命代次，同一生命只结算一次；已命中的弹丸不会再次进入当前推进。近战、投掷和处决按当前时刻处理。历史环最多保留 8 帧，由服务器存储，不能出现在公开网络投影中。

补充验证入口为 `node --test games/hotlinemiami/cmd/maps/contract.test.mjs` 和 `node --test games/hotlinemiami/cmd/motion/contract.test.mjs`。原版地图的 6 图 × 2／3／4 人电脑比赛覆盖自然 10,800 规则帧，另外执行 `-race`；Go 日志与 WASM 运动结果写入 `.local/hotlinemiami/verification/`。它们验证共享引擎与产物契约，不替代正式认证房间和真实浏览器的操作响应验收。

扩充后的八个造型均通过相同创建入口验证，十二类武器逐一验证有效攻击、弹药消耗、投掷释放和拾取不补弹。新增马格南以较慢射速换取精度与射程，MP5 在 Uzi 与 M16 之间提供中距离连射，双管霰弹以两发弹药换取近距离宽覆盖，斧头范围更长但动作更慢，砍刀位于小刀与武士刀的范围与节奏之间。旧七类武器参数保持不变，所有武器继续使用同一服务器权威战斗与弹丸补偿入口。
