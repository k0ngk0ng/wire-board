# 原版大地图交付的失败场景

此清单与 `runtime-catalog.test.mjs` 先于九图门槛实现。测试只处理本地元数据，不编译 Go、WASM 或应用。

- 少于或多于 9 张地图、8 个造型、12 类武器须拒绝；旧 6／8／12 清单不能伪装成当前交付。
- 新增原版场景固定为 highball／65、exposed／148、hot-heavy／59；重复旧图、重复原版 room、改标签或替换来源 ID 都须拒绝。
- 地图图像、规则坐标与同源原版场景的原始尺寸必须一致；只加黑边、只放大图片、缩放旧碰撞或拼接其他 floor 不能冒充原版大场景。
- 场景的有效原版地面和实际可达指标须与原版恢复证据一致，不能以外框面积代替有效面积；不预设面积倍率。
- 新地图的必要参考图缺失、静态图像载荷摘要变化未登记或规则来源不匹配时停止交付。
- 新 runtime 仍须通过原有 Go 源码、工具链和构建脚本绑定，不接受旧运行时恢复为九图。
- 资源登记按实际 SHA、MIME 和编码判断增量；旧 map／preview 的必要去残影修复允许新内容地址，未变字节必须复用原 key。历史记录只追加替换前的精确条目，不改其他游戏。

完整编译与正式资源登记在地图、引擎及媒体冻结后，由根任务统一执行。
