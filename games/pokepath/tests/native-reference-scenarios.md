# 原创实现的事实目录验收

本轮只抽取公开的数值、名称、描述、路径、图集尺寸、地图坐标和波次名单。提取器静态读取研究目录中的数据字面量，不运行、嵌入或翻译原游戏程序。原创规则由独立 Go 引擎实现。

先于提取器实现登记失败场景：

| 场景 | 预期 |
| --- | --- |
| 数据文件含函数调用、方法、动态代码或浏览器操作 | 拒绝求值，不执行源码 |
| 相对数据引用循环、越过研究数据目录或引用不存在 | 明确失败，不写不完整目录 |
| 表对象在波次或角色中重复展开 | 用稳定 ID 引用，波次只保留敌人 ID 或空位 |
| 任一表数量、编号集合或波次数量少于固定版本 | 完整性检查失败 |
| 宝可梦进化、技能、弹道、敌人被动或地图天气引用悬空 | 完整性检查失败 |
| 把敌人原始每帧速度当作每秒速度 | 按公开单位换算为像素／秒，保留原始数值事实 |
| 图集维度不能被帧数／方向行数整除 | 拒绝静默猜测，记录明确例外或失败 |
| 地图坐标被取整、裁切，或大型地图布局按普通图解释 | 保留浮点坐标；按原网格列数和 24 px 单元归一 |
| 字段为 NaN、Infinity、函数或存在循环 | 不允许进入 JSON 或 Go 规则数据 |
| 原始数值表没有升级费用、费用分类未知或等级价格缺项 | 使用明确注明出处的独立静态价格事实表；不得回退成自拟曲线或运行原费用函数 |
| 价格事实变化而规则摘要不变 | 来源摘要同时绑定研究数据文件和独立价格事实文件的字节、路径与摘要 |
| 按音乐编号加一猜测音源、曲序缺项或地图曲目悬空 | 保留 41 曲的稳定音源 key、名称和播放顺序；地图使用明确曲目引用 |
| 音乐元数据触发全曲下载或把原版歌曲转换程序带入产品 | 只发布事实与按需媒体路径，不执行原版映射、排序或播放程序 |
| 棋盘房混合格子被丢弃、棋子坐标错位或物种映射错误 | 保留原格子事实，并归一 16 个稳定棋子、物种及 24 px 坐标；只随当前单图下载 |
| 上游重复文件名含空格或括号，阻断公共 CDN 路径校验 | 发布路径使用规范字符，保留原来源 URL 和字节摘要；重复构建不得恢复非法路径 |
| 客户端目录包含原程序、整批预载素材或缺少真实摘要 | 只发布事实目录、单图 JSON 和资源元数据清单 |
| 浏览器 Wasm 静态引用完整地图规则 | JS 平台只安装 core 与当前单图，未引用的原生完整常量由 Go linker 剥离 |
| 损坏 core、陌生版本、未知敌人或未知单图安装失败 | 保留完整旧目录，安装必须原子合并 |

固定范围：47 地图、4007 波、517 形态、257 收集编号、347 敌人、254 能力、85 敌人被动、197 物品、39 成就、11 天气、62 弹道。源版本为 v1.7.3。每次导出保留研究数据文件摘要和独立规范化目录摘要。

命令：`node --test games/pokepath/tests/native-reference.test.mjs`。重建命令：`node games/pokepath/build/extract-reference.mjs`。证据写入 `.local/pokepath/verification/native-reference/`。
