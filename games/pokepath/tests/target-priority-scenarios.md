# 战斗选敌顺序验收

- 「最前」「最后」、生命和护甲数值选项按对应数值排序。同分时保留敌人队列顺序，即使敌人标识的大小顺序不同。
- 「无护甲」把无护甲的敌人移到前面。仍有护甲的敌人按队列顺序处理，护甲更低不构成额外优先条件。
- 已中毒、未中毒、已灼伤、未灼伤、已眩晕、未眩晕、已减速、未减速和噩梦各自分组。同组敌人按队列顺序处理，不因行进距离不同改变顺序。
- 「诅咒」选项在原版保留队列顺序。「可诅咒」先按队列顺序选未诅咒的敌人，再反向处理已诅咒的敌人。原版比较器区分 `curse` 和 `cursed`，实际施加的状态是 `curse`。
- 隐形优先仍要在各组内按行进距离排序。一次随机多目标攻击不能只随机第一发。

对照原版 v1.7.3 的选敌方法与独立规则的实际多目标开火。随机场景按原版先确定主目标、再排列其余目标的流程注入同一组随机数。独立规则通过公开的部署、装备、目标模式和波次操作进入战斗；测试只预置确定的敌人状态。报告保留输入敌人、期望顺序、实际发射顺序、源码摘要和规则版本。
