# 自写 Go 浏览器运行器失败场景

实现前建立真实 Wasm 和浏览器端到端验收。只编译本项目新写的 `games/pokepath/engine` Go 规则，禁止导入原版 JavaScript、Goja、iframe 或旧 Main。

- 原生 Go 与浏览器 Wasm 从相同选项、人数、随机种子和逻辑时刻创建世界；执行相同操作和推进后，完整快照及公开投影必须一致。
- `create`、`apply`、`advance`、`project`、`clone` 均通过同步桥执行；调用方传入快照不被修改，克隆可独立推进。
- 多人 actor 和人数须传给同一份 Go 规则，不可由浏览器省略鉴权上下文。
- 资源清单记录规则源码、工具链、Wasm、标准 Go 支持脚本的 SHA-256 与实际字节。缺文件、HTTP 失败、摘要或大小不符必须拒绝，不运行损坏资源。
- 加载进度只统计实际读取或已验证缓存的字节。Go 主程序注册桥并能执行规则后才算运行器就绪，不能只以下载完成报告成功。
- 失败后可重试；并发／重复加载去重，单个调用取消不能把已就绪实例标记为失败。
- 规则请求不接受可执行代码，未知操作、非法快照、非有限时长和不安全整数须明确报错。
- 标准 `wasm_exec.js` 来自实际 Go 工具链；发布目录另保留 Go 的版权与许可证文本。构建和测试缓存都保存在仓库内。

验证命令：`node --test games/pokepath/tests/native-runtime-e2e.test.mjs`。验收记录位于 `.local/pokepath/verification/native-runtime/`。

## 已建立的交叉运行验收

基础轨迹比较同步 JSON 接口。扩展轨迹使用正式初始 50 金币和 1 级伙伴，通过合法招募、部署、升级和三席轮换完成五波；覆盖三座塔、三次付费升级、灼烧与减速，以及在途弹道。炮弹飞行检查点导入另一个独立 Go/Wasm 实例后继续推进；11 个检查点逐字段比较原生 Go 的完整快照和公开投影。

预测快路径使用 Go 内保留的只读状态编号，不逐 RAF 往返完整存档。每次推进或操作返回独立副本，静态地图与重复精灵信息通过紧凑投影和缓存重建，结果须与完整 Go 投影严格相等。每个运行器最多保留 128 份状态，调用方显式释放替换值并在退出时销毁会话；真实生命周期验收由 `prediction-session-e2e.test.mjs` 覆盖。密集合成复制场景用于测量开销，不作为自然通关或正式页面帧率证据。

仓库详情按稳定 UID 查询单只真实战斗属性，不逐帧计算整个仓库；查询不得修改状态、随机数或保留状态数量，返回对象不能反向修改规则状态；未知 UID、已释放状态和其他会话的句柄须拒绝。

资源验收同时覆盖原始字节复用、按逻辑路径去重计数、SDK 与 Wasm 分别引用不同历史目录、同 SPA 更换资源读取器后继续加载地图，以及两个实际 Go 冷构建并发发布同一内容寻址缓存。构建器不会删除已通过校验的不可变缓存；冲突时回读校验并复用。

## 固定 Unicode 依赖

名称规范化使用项目已有的 `golang.org/x/text v0.34.0`。浏览器构建只允许其当前实际依赖的 `transform` 和 `unicode/norm` 包，核对模块元数据、版本、`go.sum` 中的模块／go.mod 摘要以及固定 BSD 许可证摘要。替换模块、其他版本、其他模块、越过仓库的缓存路径、研究 JavaScript 与其他游戏代码仍须拒绝。实际参与编译的每个 Go 源文件、模块文件和许可证记录独立摘要，标准化路径使用 `go-module/golang.org/x/text@v0.34.0/`，公开清单不写机器绝对路径。
