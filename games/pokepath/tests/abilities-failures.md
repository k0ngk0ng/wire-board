# 独立能力引擎失败场景

本模块使用公开规则描述与数据事实独立实现 Go 计算，不导入、执行或翻译原版 Tower、Enemy、Projectile JavaScript。先写下列失败边界与规则链路测试，再实现计算代码。

1. 未知或尚未实现的能力、物品和天气必须显式报错，并列入覆盖清单；禁止未知分支静默退化成无能力普通攻击。
2. 燃烧、毒、噩梦、眩晕、减速和诅咒的持续时间、堆叠和抗性须保存在状态内；分段推进与一次推进相同，保存恢复不重置计时。
3. 普通燃烧持续 10 秒、每秒损失最大生命的 0.5%；毒永久每层每秒 0.1%；慢速为 50%；眩晕期间不能移动。来源为原版公开教程状态说明，具体攻击描述有差异时须单列差异，不能暗改数值。
4. 概率使用宿主传入的随机结果，不能自行读取时间或全局随机数；不满足概率或抗性的目标不能被施加状态。
5. 护甲吸收、穿透与真实／持续伤害要分开；不能产生负护甲、负生命、NaN、重复击杀或超出实际生命损失的伤害统计。
6. 反隐、破甲、多目标、范围、反弹、多段、轨道和贯穿都须输出可执行攻击计划，不以能力名称占位。
7. 天气和地形加成、光环与装备修正必须组合后计算；基础资源和原输入不可原地修改。
8. 负面装备反转／增幅、专属装备限制、治疗与每波次数、特殊成长和累计攻击须按明确上下文计算，缺少世界级钩子的能力列为待接入，不能声称完整。
9. 敌人被动抵消状态、回复、直伤减免、护盾、复活或分裂等行为必须实际接入世界钩子；覆盖清单区分数值规则和世界事件。
10. 公开描述未给出的细节须保留为待对照事实，不能从实现源码直接翻译算法，也不能为了通过测试虚构原版数值。
11. 投射物发射后，普通光环、装备和来源属性冻结；命中重算目标状态、护甲、被动与飞行时长时不能丢失发射属性或重复叠加光环。技术高手在暴击及目标加成后判断最终伤害阈值。
12. 路径方向在生成时冻结；晃晃斑、超级晃晃斑与唱反调路径须正确选择；风和泥地只修正移动，不能污染按速度计算的伤害。眩晕应用序号仅在真正新增眩晕时递增。
13. 敌人临时加速的刷新、残留叠层和计时须经过保存恢复；再生抑制、棋子倍率、尾风、空草地回复不能只保留配置字段。全场吸伤、暴击标记压制、同伴伤害、挪移尸体、护甲破裂锁定与装备移除须产生可消费的事件，并保持来源归属与幂等。
14. 咒链不得反复命中同一目标或递归爆炸；伤害须穿过各接收者的护甲和被动并归属原攻击者。磷火只在已有咒链传播燃烧。同步传染以主目标为中心，不可由飞溅目标继续扩散；噩梦布只额外传播一层噩梦。
15. 幸运拳射程加成在 6000 ms 到期；饱腹之香仅按本波已完成的整秒累计 2.5，再向下取整。淘金潮持护符金币时每位累计金币的加成为 15%，不能沿用普通 7.5%；暗影爪的主目标圆形范围与最终取整由实际攻击模式结算。
16. 柔软沙子是可取得的范围攻击装备，不能报未知物品；同次范围攻击须冻结有效目标总数，先按 400% 逐目标数减半且下限 1% 计算加成，再向下取整后暴击。装备限制须拒绝波动攻击。197 项道具目录逐项审计，并构造每个可装备、未删除定义在全部合规接收者及等级边界上的攻击计划；目录条目数不能代替实际构造。
17. 饱腹之香在塔的有效战斗时间中累计整秒，再由独立的 100 ms 属性刷新读取；同一步先刷新属性、后累计道具，不能在开火或只读投影时提前读取新一秒的加成。保存须保留未完成的道具时钟、属性刷新余量和当前已发布加成；恢复、暂停、分段推进及新波次不得跳过边界。进化辉石的冷却为原值的 80%，不能除以 80%。
18. 真实 60 Hz 战斗的持续伤害周期须累计实际规则步长，不能先取整为 16／17 ms 再决定命中先后。燃烧和灼伤以完成的伤害周期消耗持续次数；首个浮点周期延后一帧时，最后一次伤害仍须执行。保留小数余量，保存恢复和分段推进不能移动伤害帧、改变来源或漏掉最后一跳。
19. 进化辉石、后攻之尾、先制之爪和放大镜的命中加成／惩罚不能提前写入基础弹道威力。先按实际伤害来源取整，再结算暴击；后续弹射衰减读取未混入该装备加成的原始弹道威力。原版普通投射物的进化辉石按原威力的五分之一向上取整；塔的直接伤害按当次伤害的 20% 向下取整。减半惩罚向上取整后扣除，不能用最终向上取整的半威力替代。区域、光束与普通投射物分别经过真实发射和命中链验证。
20. 每座塔的投射物从队尾向队首更新。新产生的弹射追加到末尾，不能继承已终止父弹丸的位置，也不能在出生的同一步提前推进；下一步应按完整逆序处理。同帧到达的投射物须保持原版先后顺序，不能因为最终总伤害相同就忽略顺序。不同塔的排序和交错另行对照，不能用全局反转替代每塔逆序。

测试入口：`. scripts/env.sh && go test -count=1 -v games/pokepath/tests/abilities_e2e_test.go`。端到端规则链覆盖构造攻击计划、命中、状态推进、移动速度与 JSON 中途恢复；平台鉴权和共享世界由主游戏 E2E 另验。
