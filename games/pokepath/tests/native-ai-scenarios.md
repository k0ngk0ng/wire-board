# 原创电脑策略验收

本策略在 Go 中独立实现，只读取本席位的资源、阵容与公共战场，并返回普通行动。规则、随机结果、费用、伤害和胜负始终由同一套权威 Go 引擎处理；不执行研究脚本，不写入资源或结果。

实现前登记失败场景：

| 场景 | 预期 |
| --- | --- |
| 重复提案、取消托管或多人依次操作 | 提案不改状态或随机源；每席从本人的最新钱包、阵容与公共战场决策 |
| 部署地形不匹配、塔位冲突或已占用 | 只返回当前合法部署点；不会重复部署到原塔位 |
| 金币不足、等级上限、挑战等级限制 | 不产生透支或无效升级 |
| 隐身、高护甲、高速密集群、再生首领 | 按公开波次预览选择配队、目标和部署位置 |
| 自然回复首领、噩梦成员被灵活地形成员挡住 | 优先保证噩梦成员持续攻击；通过合法移动腾出部署点，不收回队友、不打断在途攻击，也不原地反复搬动 |
| 波中移动存在在途弹道、特殊锁定或不可搬动伙伴 | 保留现有攻击，不反复重置塔或提交非法移动 |
| 重金属或压迫感已经锁定本波操作 | 不提议部署、换队或装备；能力触发的针对性验证使用明确的低等级能力夹具，不作为自然成长通关证据 |
| 普通失败 | 使用合法检查点或重开保留成长；晚期考虑生命预算 |
| 永久死亡挑战失败、暂停或自定义关卡完成 | 停止行动，不擅自取消挑战或解除手动暂停 |
| 轮抽阶段 | 选择有效报价并携带当前轮抽令牌 |
| 每席三只初始伙伴和全部开放人数 | 都能真实买蛋、部署、升级并推进前 10 波 |
| 完整路线 | 从 50 金币、等级 1 的正常初始条件自然打完第一条 100 波，不使用高等级或胜负夹具 |

命令：`go test ./games/pokepath/engine -run '^TestAI' -count=1 -v -timeout=25m`。过程与结果保存在 `.local/pokepath/verification/native-ai/`，包括固定初始种子、行动序列、阶段和最终资源。再生首领的受控阵容验收使用 `TestAICleansingBossKeepsItsCounterAttackingE2E`，不代替正式开局的百波验收。
