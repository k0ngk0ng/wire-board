# 挑战计时和放弃挑战验收

- 开启挑战和轮抽时显示零；首次真正开波时才开始计时。原版固定按百分之一秒显示，快进不倍乘时间，后续波间继续计时。
- 手动暂停、普通战败、路线胜利、保存确认和等待续玩期间计时不动。普通重试留在挑战并恢复原时间；永久死亡结束挑战。后台纠正与恢复采用权威时间，不能把各席位页面的打开时间当计时起点。
- 放弃挑战保留当前波次、敌人坐标／生命／路线、已累计金币和生命、本波条件及自动下一波。收回伙伴和塔的专属弹道，卸下物品和超级形态；下一波不再应用挑战配置。
- 暂停和战败期间不能通过放弃跳过当时的局面。过期输入及观察者无权结束挑战。
- 在实际四人浏览器房间核对计时显示、暂停的时间一致性、手机底栏不重叠、放弃后仍在同一波。独立对照验证原版标签、位置、格式和像素。
