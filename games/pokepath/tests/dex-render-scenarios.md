# 图鉴显示、搜索和排序对照

先运行只绘制图鉴的原版对照器，固定资料与战斗统计，不执行上游规则。验证原版教程、塔、敌人三页签及展开面板。使用相同资源和字体，保留每个输入后的 DOM、截图、动作收据与像素对照。

失败场景：

- 教程页标题与内容不完整、图像与文字顺序反转、换行／高亮不同；秘密图像触发错误动作。
- 13 种塔排序和 18 种敌人排序少项、方向错误或切换时相互覆盖。
- 塔搜索漏掉当前语言的名称、能力或自定义别名；敌人搜索漏掉名称或稳定编号。
- 锁定敌人、已击败敌人和刻意不在图鉴收录的敌人显示错误；不同路线的统计覆盖或重置。
- 历史收录和排序数据用真实规则计算，不能由客户端编造或把布尔条目当击败次数。
- 未知图腾仅在原版字体条件或已经拥有时出现，问答打开后搜索输入不能改变名单。
- 展开时没有滚动到条目、切页后仍显示前页选择、键盘或手机无法进入内容。
- 预加载整个资产库或为匹配参考截图隐藏正常素材；资源完成之前不得比较像素。

涉及新统计时，先用 Go 对局测试覆盖击败、逃脱、分配伤害、恢复存档与各席位一致，再增加投影字段。观察或训练数据的适用范围要与原版一致。

伙伴终身统计另覆盖：重新部署计数、移动及收回期间时钟、物理速度换算、最后一击与命中最高值、波末及百波首领计数、进化和保存后沿用同一伙伴 ID、Nox 图鉴解锁前后及每项前三名。原版定义了挑战统计字段但观察到的游戏代码没有写入路径；显示现有值，不从缎带数推算。
