# 轮抽规则与界面验收

- 首轮保底已满足地图标签时，仍从除它以外的候选中寻找该地图保底。无匹配时只能用其余合法成员补位，不能重复同一持有记录。
- 同一原版候选池在每次展示前原地洗牌。下一次重抽、选择或读取存档应继续使用该顺序与随机源。按原版路线、轮次及地图能力顺序比较候选。
- 轮内重抽消耗机会；新候选带有原版三种特殊伙伴之一时返还机会。普通选择开启下一轮，重启使用已选成员和仓库重新建池。旧代次的选择、重抽及重启不得改变任何状态。
- 准备中和战斗中的挑战开始行为符合原版；暂停时不触发重开。成功开启挑战回到第一波，清空原波战场和展示统计，保留持有记录及金币。旧战场的波次操作不能穿过重开。
- 弹窗按原版位置显示标题、轮次、最多三位候选、三处详情入口、重抽和重新开始。比较不同字体、主题、已耗掉重抽机会和不足三位的状态。
- 详情只读，轮抽期间服务器不接受升级等战场或管理操作。多人重抽或重启后不能保留过期候选详情。观众可阅读；玩家通过真实鼠标、键盘或手机触控操作。四人房验证重复请求被拒绝及共享结果。
