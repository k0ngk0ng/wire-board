# 地图视区失败场景

先建立真实浏览器验收，再实现 `web/map-viewport.js`。命令为 `node --test games/pokepath/tests/map-e2e.test.mjs`，结果与截图保存在 `.local/pokepath/verification/map/`。

- 滚轮在地图内缩放，以鼠标所在逻辑点为锚；地图外滚轮保留页面滚动，不改变地图倍率。
- 鼠标左键拖动越过阈值后平移，松手和离开边界不产生建造或塔身点击；未越过阈值的点击仍产生一次真实点击。
- 缩放和平移后，实际绘制的塔身仍映射到同一逻辑坐标，不直接改变游戏规则坐标。
- 手机单指拖动和平移、双指缩放均使用真实触摸输入；双指松开不追加点击。
- 指针取消、窗口失焦、尺寸变化和地图原生尺寸变化清除旧手势，并约束视区边界。
- 放大、缩小、适应全图和复位按钮都有效；手机默认保持 1:1，适应全图为显式操作。
- 具有缩放祖先的桌面布局仍正确计算滚轮锚点和逻辑坐标。
- 不新增或重排 Canvas 父 DOM，确保服务端 UI 结构路径保持稳定；销毁 helper 后清理观察器、捕获和本地样式。
