# 战场同帧对照

- 用原版 `Enemy.draw`、`Sprite.draw` 和塔身绘制片段，在相同路线上对照完整 720×624 画面。敌人走向取当前拐点，覆盖横向、纵向、斜向、镜像、分叉及走到可见边缘前的第一帧。
- 对照多敌人重叠、塔身像素、固定朝向、道具翻转、灵幽马的上层绘制，以及悬停和全体范围层。完整画面不遮掩塔身和边缘。
- 根据关卡和界面语言绘制生命、护甲、隐藏数值、诅咒徽记及铁壁百分比。验证最后一波显示所有敌人的数值，而普通波次不显示首领数值。
- 击倒敌人继续绘制服务器保留的淡出帧，重生期间显示原有的伸缩。切换显示设置、暂停、已逃逸和已移除的状态不能提前改写规则或改变原始状态对象。
- 火焰之躯、雪隐、静电、扎根和顺风对照固定时刻的光环、风线及粒子。粒子关闭后基础光环仍可见；敌人身体在画面外，但光环进入画面时，保留应当可见的部分。
- 保留同一输入、原版片段摘要、未遮罩截图及像素差。地图、敌人和塔身基础绘制通过不能替代所有特殊技能、粒子或网络行为的验收。
