# 原版设置与自动波次

实现前逐项固定 `MenuScene.settingData`、七组 `effectOpacityDefaults`、五组 `mute` 和 `Area`／`DefeatScene` 的行为。

- 默认值与原版一致；12 项选项、七组透明度、五组静音完整保存，未知键、越界、非整数和非步长值原子拒绝。
- 全局平台静音始终覆盖游戏设置。游戏的五组静音只过滤对应事件，不创建独立播放器；透明度、指示器、健康条和粒子选项必须被真实呈现消费。
- 自动波次遇隐藏敌人名单时可停止；首领停止适用于所有路线第 100 波及地图 ID ≥12 的第 50 波，不误停其他波次。
- 自动重开为 0／1／2：关闭／从首波重开／从检查点重试；第 25 波前走首波，第 100 波检查点仅 1 心。保留速度和原自动波次意图，尊重首领停止；永久死亡挑战不自动重开。
- 保存离线期间不执行自动重开，不推进时钟、不重复累计重试记录；Go 和 Wasm 用相同规则决定自动行为。

自动波次和重开边界使用正式地图、波次与真实 Apply／Advance；已完成波次／濒死敌人属于明确的隔离夹具，用于验证阶段转换，不能当作自然通关证据。
