# 路线结算场景

- 第 100 波或秘密地图胜利时冻结当前战场，保留首领、出战队伍和结果；在确认前不能换图、跳过或重新买卖。
- 普通胜利确认回到同一路线第 1 波、满生命，保留实际塔位、收藏、金币和记录，停止自动下一波。挑战胜利先结算奖带和出战者的挑战次数，确认后卸装并把队伍送回仓库。
- 秘密路线伙伴按原版在确认时授予。多席位重复确认、旧代次和续玩都不能重复发放奖励或重复增加结算记录。
- 战败可从第一波重开；第 25 波起允许从上一个检查点重试；第 100 波只给 1 条生命。普通挑战重试保持规则与计时，永久死亡退出挑战。原版的重开保留仍合法的部署并清理旧波次的锁定。
- 自定义练习使用原版成功／失败图与提示；重开不能修改正式路线进度，且保存仍记住原路线。
- 画面对照涵盖首领、名人堂、挑战规则行、普通战败、检查点提示、永久死亡、万圣主题和自定义练习。独立组件与隔离的原版 DOM 片段比较。
- 两个真人和一个观众通过正式网页共享确认，含 320 px 真触控检查点重试。电脑应能确认纯托管对局，混合房须让在控真人决定。
