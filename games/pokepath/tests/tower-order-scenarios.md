# 多塔更新顺序

原版 `Game.js:531` 在每个规则子步复制塔列表，按纵向位置稳定排序，并把物种为 `spectrier` 的塔放到最后。`Tower.js:6023` 在当前塔发射后逆序更新当前塔的普通投射物，再处理其光束；这些结果会影响下一座塔的选敌。

修改前固定以下失败边界：

- 部署顺序与纵向位置相反时，错误沿用部署顺序。
- 相同纵向位置的塔被按物种、横向位置或 ID 重新排序。
- 灵幽马的位置较高，但仍须在其他塔之后更新。
- 只调整发射顺序，仍把全队投射物推迟到所有塔发射后才命中。
- 前一座塔的同帧击杀未影响后一座塔的选敌，或者提前清空敌人列表导致来源和奖励错乱。
- 排序原地改变部署列表，影响相同高度的后续顺序、选中对象或存档。
- 新弹射在另一座塔更新期间被再次推进，或者未部署来源的残留弹丸被重复推进。
- 保存恢复、不同毫秒分段与相同规则帧数产生不同结果。
- 本机与 Wasm 对斜向距离计算相差一个浮点末位，导致完整状态或规则摘要不一致。公共距离计算须固定运算舍入，覆盖零、负零、正负坐标、普通斜线、极大／极小有限值、无穷大与 NaN；不能通过放宽状态比较忽略差异。
- 世界级半血特性在本塔更新时读取前一座塔的命中结果；不能提前为全队判断，也不能让先更新的塔读取后更新塔的未来伤害。
- 移动前确定本子步的塔顺序，不能先移动全队再排序。盘旋的原点、精灵左上角位置与当前碰撞中心分别保留，不能将精灵宽高当作固定 24 px。
- 加速帧的中间子步不绘制精灵，最后子步才应用原版绘制造成的中心更新；0.4、0.8、1、1.7 和 5 倍速分别验证，不能只验证单子步。
- 正负电荷连接由部署列表中的第一座塔在普通弹丸和光束之后更新，整帧结束后再按完整帧时长推进一次。正常塔更新路径使用 1000 ms 冷却、12 px 宽度；伙伴仍普通射击。每次先结算负电方，再结算正电方，击杀归属必须正确。覆盖预热计时、普通攻击前后、致死首击、宽度边缘及连续 120 帧的小数周期。`Area.rebuildPlusMinusLinks` 的 900 ms／10 px 备用方法未被正常调用，不能据其参数推断实际玩法。

`tower-order-reference.test.mjs` 在本地运行原版 `Main`、`Game`、`Tower`、`Enemy` 与 `Projectile`，使用真实部署后固定的两端位置、属性和敌人。原版程序只用于测试，不进入产品。Go 夹具通过公开操作部署、开波和 `Advance` 推进，输出完整事件；浏览器记录同帧发射／命中的交错、实际伤害和最终生命，并保留截图与来源摘要。这些受控多塔场景不代表自然成长、所有移动塔或所有特殊能力均已完成对照。

```sh
. scripts/env.sh
node --test games/pokepath/tests/tower-order-reference.test.mjs
node --test games/pokepath/tests/tower-order-wasm-e2e.test.mjs
go test ./games/pokepath/engine -run '^TestCoreEuclideanLengthHasPortableRoundingAndScale$' -count=1
```

每次原版对照使用独立运行目录，`tower-order/latest.json` 指向本次结果。当前共 24 组：多数推进三个实际规则帧，另有连接场景推进 120 帧。比较事件顺序、目标、实际扣血、结算后未截断伤害及塔身位置；位置沿用 1e-6 的既有量化边界。超级大嘴娃由真实装备超级石进入对应形态。连接致死归属场景通过固定冷却暂停普通射击，其余连接场景保留普通攻击。

Wasm 对照独立生成同一批原生轨迹，依次导入保留句柄、推进、导出完整状态并读取瞬时投影，共比较 402 项；`tower-order/latest-wasm.json` 指向对应结果。两类产物分别保留原生输入、规则版本、运行时摘要和逐帧状态。普通弹丸与光束组合仅观测前三帧，光束的完整持续命中与更广组合仍须另验。

## 伤害阶段取整

修改前固定以下失败边界，以实际原版 `Game.animate`、塔更新和投射物命中链路验证：

- 半血增伤在暴击之前合并倍率，导致奇数威力、必定暴击的伤害与原版不同。覆盖威力 6、7、15，暴击率 0／100，以及 490／500／510 血、1000 最大生命。半血边界严格小于，不含正好一半。
- 超级大嘴娃的额外攻击须先计算暴击，再将伤害乘 0.5 向上取整，进入敌人受伤阶段后才计算半血增伤；普通射击与额外攻击分别隔离。
- 不能只比较实际扣血，须同时比较宝可梦伤害统计的增量，保留过量伤害差异。
- 自然之怒领域应先向上取整，再检查技术高手的 1000 伤害门槛；覆盖威力 5、831、833、834、836，以及增伤后跨过 1000 的边界。辅助塔保持真实部署和能力，仅抑制射击。
- 原版对照测试扩展为 71 组；同一初始快照在本机及 Wasm 逐帧比较完整状态与瞬时投影，共 731 项。额外攻击倍率须保存在弹道状态中，存档恢复和规则分段不能改变结果。

- 新增弹道末阶段倍率的快照解码边界：省略／零值与 0.5／1／2 可恢复；负值、文本值与超出浮点范围的数值必须拒绝。验证从真实部署射击获得的弹道，不通过构造空状态绕过其他检查。
