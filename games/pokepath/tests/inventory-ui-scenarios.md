# 背包界面与操作对照

测试先行。参考器只提取原版背包 DOM、排序、搜索与拖动输入方法，装备调用记录为测试收据，不运行原版规则。产品使用实际 React 组件与已校验资源。规则层的装备条件仍由 Go 权威状态提供。

可能失败的场景：

- 7 种排序缺失、方向相反或循环越界；按非当前语言名称排序。
- 默认顺序、获得顺序与稀有度混为一谈；未知稀有度顺序不一致。
- 搜索使用包含匹配代替原版前缀匹配，或 `mega` 没有筛选全部超级石。
- 实用分类错误包含没有标签的道具；类别与搜索组合后丢失筛选。
- 打开背包误用场上选中伙伴作为道具筛选，或无法再次点击取消伙伴筛选。
- 使用队伍下标或复制客户端条件代替稳定 ID 和服务器投影的可携带列表。
- 5 档图标大小缺失或边框计入方式不同，滚动和换行偏离原版。
- 道具首选项、空背包名称与说明、主题、字体、背景、投影、颜色标签及图像缩放不同。
- 鼠标拖动的 6px 阈值错误，短按、取消、拖到空位或不合法目标时误发装备操作。
- 同一拖动多次发装备，拖动结束后又触发点击，或席位只读时仍可装备。
- 面板关闭后仍保留拖动图像、监听器或失效资源回调。

保留固定输入、源摘要、每步实际 DOM、可信鼠标输入、装备收据、原版与产品截图及逐像素差异。测试浏览器静音；所有临时构建和 profile 只在仓库内创建，并在结束后清理。
