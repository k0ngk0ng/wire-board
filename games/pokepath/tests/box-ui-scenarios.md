# 仓库对照与联机换位

- 进仓库能同时看到队伍和库存。选择伙伴后显示本地选择，排序、搜索及尺寸变化不改变其持有编号。对照原版的图鉴统计、昵称／等级、收藏、异色和所持道具徽记。
- 比较默认排序、昵称和能力搜索、等级及攻击属性排序、地形标签调暗和四档卡片尺寸。没有命中时保留详情与数据按钮状态，不应替别人选择伙伴。
- 队伍与库存移动使用持有编号。拖放至已占用的队伍槽位，只替换当时看到的伙伴；部署中的旧伙伴退场，原道具保留。目标变化、无效槽、选择队伍成员作拖动源、已暂停及旧代次不得改状态。相同请求重传不得再次换位。
- 重命名支持原版的输入与恢复默认名称。空白确认不覆盖昵称。观众可查看和排序，所有写操作禁用。
- 320 px 宽度能触摸选择、移入队伍和移出队伍，桌面能从仓库拖动到队伍。记录原版及重写的几何、画面、操作回执和真实双人房间状态。
