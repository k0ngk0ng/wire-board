# 多人独立训练家验收

先登记失败场景，再建立 E2E，最后修改实现。

| 场景 | 断言 |
| --- | --- |
| 1～4 人开局 | 每人各有 50 金币和小火龙、木守宫、呱呱泡蛙；标识全局唯一 |
| 独立操作 | 升级、购买、装备、编队、仓库整理只修改本人资源与成员 |
| 越权 | 拒绝升级、收回、移动、改名、换目标、装备或瞄准队友成员；失败保留完整原状态 |
| 商店 | 买蛋价格、蛋池、货架、背包分别保存；购买不消耗队友金币、不把伙伴加入队友界面 |
| 独立界面 | 队伍、仓库、商店、详情、金币及个人设置使用当前席位；选择、面板开关互不影响 |
| 公共战场 | 可见所有人的塔、敌人和弹道；队友的塔不能作为本人可操作成员 |
| 奖励 | 正常击杀与波次收入分别记入每个人钱包，不能由先操作的人占用公共余额 |
| 并发 | 各人购买和升级可各自成功；抢同一部署位置最多一人成功；重复输入不再次扣款 |
| 电脑 | 每个电脑经营自己的资源与队伍；混合席位不能阻止其他电脑行动 |
| 保存与恢复 | 钱包、归属、库存、商店、设置完整保存；恢复不再次发放御三家或初始金币 |
| 预测 | 相同快照与动作经宿主机和 Wasm 重演一致；个人投影不能让两个浏览器显示同一份队伍 |
| 旧档 | 已知旧版显式迁移并保留进度；未知规则仍拒绝，不能静默重开 |

执行命令与结果位于 `.local/pokepath/independent-trainers/`。

真实认证双端界面验收使用 `node games/pokepath/tests/native-trainers-browser.mjs`。原版战斗与成长对照继续使用单只伙伴的固定规则夹具，入口为 `reference_fixture_test.go`；该夹具不作为新版开局或多人隔离的通过证据。新版开局、钱包、权限、商店与保存恢复由 `native_trainers_e2e_test.go` 和 `engine/trainers_e2e_test.go` 验证。
