# 手机战场与结算操作

改动前覆盖以下失败场景，使用正式平台框架、独立 Go/Wasm 和真实鼠标／触屏输入，保存尺寸、命中、操作回执和截图：

- 390×640、320×740 手机非全屏：房间标题和公共玩家栏占用首屏时，战场不得被剩余高度压成窄条；战场自身至少 300 CSS px 高，页面可以正常滚动查看。
- 竖屏和横屏全屏：战场占据主要区域，操作和队伍可访问；横竖屏切换不重新挂载画布、不改变对局或丢失地图中心。
- 放大／缩小、全图、原寸、双指缩放和拖动：最小倍率能完整显示地图，不得继续缩成难以辨认的小角落；画布小于视区时居中，放大以指针或双指中心为锚点。
- 手势结束、取消和切换方向不能误部署或误选塔；缩放后点击实际塔身仍命中同一单位。
- 未选择伙伴时点空地图须提示先选伙伴；点伙伴名称或卡片空白后可在合法地形部署，非法位置须解释。平台玩法速查须能在手机打开、阅读和关闭，并说明部署步骤、下一波及重新开始／重试的区别。
- 第 3 波战败：重新开始回到同一路线第 1 波、14 生命，保留队伍、等级、金币、道具和合法部署；检查点重试未解锁，按钮视觉与禁用状态一致。
- 第 28 波战败：检查点重试回到第 25 波、7 生命。手机真实点击后共享队友和观众同步关闭结算；失败原因在结算层可见。
