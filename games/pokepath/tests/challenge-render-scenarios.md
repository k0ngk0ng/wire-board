# 挑战界面对照场景

- 默认打开时显示当前路线、累计奖带、七条规则和四个奖励。未选规则不能开始。
- 行按原版的关、轻度、重度顺序循环。鼠标经过和键盘聚焦显示对应说明；等级限制、禁用道具显示警告，轮抽显示首领削弱。
- 奖励从一条奖带到五条奖带排列，发送时仍使用原版逻辑编号 3、0、1、2。门槛、持有状态以及可重新领取的道具和伙伴按服务器规则呈现。
- 进行中的挑战显示权威规则；点击规则不能修改当前挑战，结束按钮发送独立行动。
- 观众可看说明及奖带，但不能开始、结束或领奖。320 px 下无需横向滚动，可以触控选项或关闭。
- 用同一语言、配色、字体、路线、奖带及奖励状态比较独立 UI 与研究界面的画面。参考夹具只使用 DOM 渲染、规则行循环和说明切换，领奖和决策只记录操作，不运行原存档与战斗。
