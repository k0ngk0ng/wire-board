# 攻击几何的独立像素重建

先固定原版 `Tower.draw` 中的可见参数，再写真实 Canvas E2E。参考绘图分支仅提取到 `.local` 研究夹具，产品不包含原类、事件或程序运行器。

| 攻击 | 实现前的失败边界 |
| --- | --- |
| 精神利刃 | 18 段外缘／内缘、正弦厚度、四层辉光与核心线；颜色中的零通道遵循原回退；8 个可关闭粒子；旋转、前进与透明度不改变规则输入 |
| 热沙风暴 | 145 px 余迹、38 px 波峰、固定控制点、三层渐变、6 道流动纹路与粒子；显示时钟与物理前进距离独立；不能用平涂矩形替代 |
| 声波 | 6 px 碰撞环对应三层叠色线条，2.2／0.7／0.2 倍线宽，内环缩 0.25 倍宽；透明度跟随实际半径比例，延迟与出生帧不提前显示 |

使用固定角度、位置、颜色、显示时钟、粒子与透明度，逐字节比较参考和独立 Canvas RGBA，并保留 PNG 与摘要。测试验证绘图本身，完整多人画面和性能另验。

命令：`node --test games/pokepath/tests/attack-effects-e2e.test.mjs`。
