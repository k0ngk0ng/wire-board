# 训练家资料失败场景

实现前固定原版 `ProfileScene.js`、`Player.js`、`Enemy.js`、`Area.js` 和默认 `data.js` 的事实。全部资料属于共享训练家，操作仍通过认证席位的 Go Apply。

| 场景 | 失败边界 |
| --- | --- |
| 初态与投影 | 头像 0、已有伙伴 1、等级 1、累计金币 50；21 统计有真实来源；读取不改变状态、随机数和历史 |
| 名字和头像 | 名字最多 11 个字符；头像为整数 0～79；观众、旧代次、非法值不改变状态；真实席位共享资料 |
| 原版设置 | 默认 PressStart2P；仅原版五字体、四主题；拒绝虚构选项，完整保存恢复 |
| 自然战斗 | 正式 50 金币开局部署、升级并推进首波；真实伤害、击杀、物种、完成波数、金币纪录更新 |
| 状态计数隔离 | 新眩晕／减速／灼伤／诅咒各记一次；重复非叠层不重复计数；中毒每次成功施加计数；抗性、免疫、失败概率不计 |
| 波次与纪录 | 奖励结算后记录单波金币与每秒金币，路线标签准确；失败也记录已赚金币；清空单条纪录不改变其他项 |
| 保存恢复 | 在途战斗与已累计资料完整保存；恢复后同样操作得到同样统计；读取或重连不重复累计 |
| 挑战换场 | 进入／退出挑战、重新轮抽清理原世界、攻击链和特效；不残留原来的目标和场地状态 |

路线标签的轻量隔离边界：原版仅隐藏 ID 20／30／31／33／35 的标签；32 和 46 即使属于秘密地图也沿用其数值标签，不能用 `isSecret` 统一替代。

自然战斗使用真实初态；状态计数使用公开的同一命中处理入口和正式敌人结构，属于明确标注的隔离边界，不作为自然解锁或完整通关证据。播放时长遵循平台在线规则时钟，存档离线时钟冻结。

执行：`. scripts/env.sh` 后 `go test games/pokepath/tests/native_profile_e2e_test.go -count=1 -v`。
