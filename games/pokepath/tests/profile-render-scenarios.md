# 训练家面板固定状态对照

先建立原版只绘制界面的对照器，再修改产品代码。对照器只提取 `ProfileScene` 的 DOM 绘制、文字更新与头像选择标记，以及原版的 DOM 工具与数字格式方法；不加载 Main、战斗、存档、音频或网络程序，不进入产品载荷。

失败场景：

- 字体与成就资源尚未加载，错误地把空白参考图当成目标。
- 训练家输入框的默认高度、描边、投影或主题颜色不同。
- 成就区域使用边框代替外轮廓、网格代替换行，导致一像素错位。
- 统计行的边框、间隔、文字基线或最后一行位置不同。
- 英语、日语与韩语使用逗号，法语使用空格，其余语言使用点的分组格式不一致。
- 小数、负数、大数与最高纪录被浏览器本地化或取整改变。
- 隐藏敌人计入引擎总量后，显示分母偏离原版的 345 上限。
- 原版四主题、PressStart2P、NGC、Lexend 与 Unown 字体覆盖不完整。
- 原版与产品用了不同状态，掩盖实际显示差异。

保留提取源摘要、固定输入、原版与产品截图、逐像素差异、文字与几何结果。对照图像不遮罩；屏幕其余区域不在本面板验收范围。浏览器静音，临时目录与 profile 均在仓库内并在结束后清理。
