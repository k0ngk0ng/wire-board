# 设置菜单固定状态对照

使用静音浏览器渲染原版菜单和独立设置组件，加载同一字体、主题、语言与规则配置。记录置顶画面、音频、快捷键及鸣谢，对照行内容、选项和链接。研究夹具只渲染，不连接外站或运行原版存档、兑换或音频程序。

可能失败的场景：官方链接、设置、音频、快捷键、数据和鸣谢的卡片位置或顺序改变；效果滑块脱离设置卡；音量百分比与原版 0～20 显示混用；五个静音组标签或按钮与真正的动作字段不对应；语言、主题、字体或图形选项读错事实文案；用原版固定键名覆盖平台改键；移动端需要横向滚动或挡住关闭；共享房间在只读状态仍提交设置。

设置夹具使用真实鼠标、键盘和 320 px 触控验证滑块、地图效果、分类静音、语言切换和关闭。平台夹具以两名玩家比对十种语言和音乐音量的同步，确认第三个观战会话只能读设置。数据流程单独验收：平台保留统一存档、恢复、身份和设置权限。任意原版本机存档文件不能作为多人权威快照直接载入；原版兑换仍待核对与平台身份的映射。
