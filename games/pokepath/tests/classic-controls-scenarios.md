# 战斗控制按钮

原版 `ui.css:1302–1391` 中，自动波次的关闭和开启背景分别为 `autoWave1`、`autoWave2`，悬停只提高亮度到 1.15，过渡仅包含 50 ms 的位移。按下时增加 3 px 顶部内边距，不移动按钮，也不把背景改成半透明灰色。

修改前固定以下失败场景：

- 平台通用按钮悬停覆盖自动波次的蓝色背景。
- 自动波次继承平台 160 ms 的背景、阴影过渡，关闭时延迟显示结果。
- 平台通用按下位移和 0.94 亮度覆盖原版按下反馈。
- 开启状态正确而关闭状态错误，或只修复鼠标移出后的颜色。
- 修改主题后仍使用普通蓝色／绿色按钮变量，忽略原版专用控制变量。
- 验收切换自动波次后未恢复原值，或只修改 DOM 而未通过平台操作。

`node games/pokepath/tests/classic-controls-browser.mjs <label>` 只复用 `native-browser/latest.json` 明确登记的静音测试房。分别检查开启和关闭状态的真实鼠标悬停、按下与松开，保留计算样式、原生截图及 SHA256，最后通过真实点击恢复初始状态。完整输入像素与快慢双席预算仍由 `presentation-network.mjs` 独立验收。
