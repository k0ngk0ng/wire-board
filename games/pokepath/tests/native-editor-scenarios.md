# 自写编辑器失败场景

实现前登记。编辑器只整理规则事实并使用本项目 Go 引擎，不加载原版程序。

| 场景 | 预期 |
| --- | --- |
| 非法席位、旧代次、战斗中、暂停或挑战中切入自定义波次 | 拒绝且原局面不变 |
| 非法地图、未解锁地图、未知敌人、空敌人波次 | 拒绝且不污染规则目录 |
| 生命越界、强化不是 5 的倍数、负数／非整数／过大数量、未知字段或多余 JSON | 拒绝，不分配无界数组 |
| 256 组以上或展开超过 4096 个出兵位置 | 拒绝，保留旧草稿与正式进度 |
| 两个房间设置不同自定义波次 | 各自独立，完整 Catalog 不被修改 |
| 实际运行自定义波次至胜利或失败 | 不新增金币、星数、路线纪录或永久奖励 |
| 实践中保存、重启并继续 | 敌人、延迟出兵、护甲强化和现场完整一致 |
| 返回原路线／重试自定义波次 | 恢复原波次与生命，保留正常成长且不重发资源 |
| 分享码编码／导入与损坏码 | 合法字段稳定往返，损坏或超限码明确拒绝 |
