# 原生界面验收边界

本界面自行实现 React 布局、Canvas 绘制与输入，不加载、嵌入或执行参考游戏的 HTML、CSS 和 JavaScript。参考网站仅用于玩法对照，已登记的图像和音频作为静态资源使用。

实现前登记以下失败场景：

1. 游戏目录、房间和游戏区没有沿用平台外壳，或仍存在 iframe、原版运行器、跨帧通信。
2. 共享金币、生命为零时不显示；多人界面把共享资源误当作各席独立资源。
3. 两席选中不同伙伴，因数组下标或共享菜单状态导致升级、部署和装备错误对象。
4. 观众、托管席位或已结束对局仍能改变世界；客户端把金币、伤害或胜负当成行动提交。
5. 点击实际绘制的塔身无法选中；缩放、平移后命中偏移；拖动地图被误当作部署或升级。
6. 手机把整个桌面缩小导致按钮、角色不可辨认，或关键操作被横向裁切。
7. 首屏加载其他路线和全部历史角色；资源失败提前确认就绪；百分比与字节数不对应。
8. 只按网络更新绘制画面；预测重复执行行动、音效或扣费，校正后遗留旧输入。
9. 仓库、背包、商店、路线、挑战和图鉴缺少可操作入口；成长后仍显示过期属性。
10. 切换全屏重新创建规则状态、改变选中对象，或弹窗落在游戏区外。

轻量界面契约检查：`node --test games/pokepath/tests/frontend-native.test.mjs`。完整链路由原生平台浏览器验收覆盖真实键鼠、320 px 触摸、两席合作、托管、观战及保存继续，并保留命令、断言和截图。静态渲染检查不能代替真实交互验收。

音频事实补验：普通发射、范围、光线、瞬移、异色分别消费静音组 0／3／4／1／2；同塔同逻辑时刻的范围多目标发射去重。声音先经 SHA／实际字节校验及 WAV→FLAC 别名解析，再交平台音频接口；全局静音和晚到任务不得恢复旧声音。
