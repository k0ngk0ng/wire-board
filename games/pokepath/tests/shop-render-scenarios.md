# 商店与孵化验收

- 商店固定为一个蛋位和十个货架，保留各货架池配色、贴图、价格及售罄牌。比较原版动画在多个固定时刻、不同主题和关闭地图效果的画面。
- 金币不足时保留道具说明，不能扣款；空货架不发购买请求。普通道具成功后补货，不打开获得窗口。蛋只在服务端确认后显示该操作实际孵化的伙伴。
- 房间共享货架、钱和蛋池。买道具需确认同一货架的道具；买蛋需确认当前库存数，价格封顶时旧库存也不能再次提交。两个玩家看到同一旧报价时最多结算一笔；重复输入、缺失报价、旧报价、观众和旧操作代次均无副作用。
- 孵化窗口使用实际伙伴的名字、配色及图像，只有购买者打开。普通道具和失败购买均不打开；金色硬币对应的伙伴获得显示沿用原版。
- 保存或刷新重建视图时不重播历史窗口。桌面鼠标、键盘焦点说明、手机触控和平台静音保留。截图及购买回执可重复验证。
