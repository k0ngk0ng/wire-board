# 前端操作失败场景

- 数字快捷键不得把队伍下标作为规则标识；Ctrl 数字保存编队不得同时部署。
- 输入框、下拉框与可编辑区域中不得触发游戏快捷键；重复按键不得重复执行。
- 法语 QWERTY/AZERTY 面板映射应遵循原版；F11 留给平台全屏，Escape 不阻止平台退出。
- 跟随鼠标仅限可操作、未暂停、已部署且移动模式为 followPointer 的当前伙伴；切换伙伴、代次、房间、拖动、缩放、取消与卸载清理待发输入。
- 触摸点击立即更新绝对目标，触摸拖动与双指缩放不发送目标；连续鼠标移动不播放点击声、不逐次更新 HUD。
- 伤害图表固定按队伍顺序显示十行，读取独立全局分母；历史伙伴贡献不可从当前队伍求和恢复。
- 切换实际伤害／未截断伤害只改变本地显示，不重置或修改规则状态；零分母不产生无效百分比。
- 支援与受苦标签依据图鉴编号，而非房间中的稳定伙伴标识；中央窗口与右侧图表独立。
