# 自写规则本地预测验收

先列失败场景，再编写测试和辅助器。运行规则来自独立 Go 引擎及其 Go/Wasm 构建；客户端不加载原站 JavaScript、原版 Main 或 iframe。

| 场景 | 验收边界 |
| --- | --- |
| 真人操作立即响应 | 本地 Clone 状态先按同一套 Go Apply 规则执行并呈现，再发送输入；权威 State JSON 保持不变 |
| 已确认动作重复消费 | 用认证 actor 和 clientInputID 对应本人输入；确认后先移除 pending，再重放，不能重复扣金币或升级 |
| 两席同时提交相同行动 | 另一席的同名 ID 不确认本人的 pending；两次合法行动各自按服务器顺序执行 |
| 服务器先 ACK 后广播 | 成功 ACK 只记录收件状态，直到权威操作或完整快照收据确认；拒绝 ACK 回滚该输入 |
| 普通消息到达 | 保留本地显示相位，校正到权威基线后重放未确认输入；不盲目重新 New 世界 |
| 本地输入与已显示帧排序 | pending 保存本地实际目标时刻，重演不得回填进此前已显示的时间 |
| 慢连接与输入窗口 | 本地领先最多 200 ms、最多 8 个 pending；不会持续增加缓冲或拖住其他客户端 |
| 低延迟切换到单向 120 ms | 每 100 ms 接收权威更新，分别用 57、60、144 Hz 独立显示时钟；达到 200 ms 上限后不得反复停帧和突进，稳定期逐帧继续运动，领先上限不变 |
| 预测上限后的恢复 | 无消息时停止在既定上限，不累积无法显示的时间；有效权威快照追上后，下一显示帧恢复正常推进，不补播停顿或增加领先上限 |
| 绝对值连续输入 | 同 key 的中间值可合并；独立确认行动仍保留，不能将 input 改成 change |
| 非法权威更新 | 拒绝时保留最后有效基线，并明确请求恢复，不提交一半的规则状态 |
| 暂停、隐藏与恢复 | 暂停不补跑离线时间；隐藏清旧输入，恢复先取得有效快照；旧 epoch 输入不得重放 |
| 显示暂停期间权威继续 | 单端加载或显示暂停后，若有效权威时钟已经超过本地时间锚点，校正后下一帧继续本地推进；不能永久退化为只按网络消息刷新；常规确认保留原显示相位 |
| 绘图与成本计时 | RAF 使用原生时间；规则 clock 与成本测量时钟分开；20 ms 规则步的显示插值不改规则状态 |
| 性能预算 | 预先固定普通状态 Clone p95 不超过 8 ms，密集状态不超过 25 ms；未实测的范围不称作达标 |

针对性验证：`node --test games/pokepath/tests/prediction.test.mjs`。独立 Go/Wasm 场景：`node --test games/pokepath/tests/prediction-native-e2e.test.mjs`。记录保存在 `.local/pokepath/verification/prediction-*.log` 与 `prediction-native-result.json`。

真实认证房间还需独立记录原生 RAF、Canvas 像素变化数量、原生事件到首次可见响应、输入 ACK 和 WebSocket Ping/Pong RTT；不能用 ACK 或回调次数替代可见帧与操作响应。模拟快慢时钟及 Node/Wasm 场景证明规则与预测边界，不代替正式浏览器的桌面、手机和快慢双席验收。

## 密集复制隔离场景

密集复制预算单独使用从正式开局波次导出的合法敌人结构构建 200 个不同 ID 的状态，只测完整 Go/Wasm Clone 与深独立性。场景明确标记为合成负载，不修改正式模式，也不将合成状态当作通关或正式房间流畅度证据。失败边界包括 ID 冲突、共享条件对象导致原状态被修改、复制 p95 超过预先固定 25 ms，以及把逻辑时钟当作成本计时。
