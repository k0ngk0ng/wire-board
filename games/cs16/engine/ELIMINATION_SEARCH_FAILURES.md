# 歼灭图固定种子搜索失败场景

本清单先于本轮测试与修复。Linux CI `44930507469` 的冰雪世界十席自然对局在原有 270 秒模拟预算内未完成；当时随机种子与私有检查点未上传，不能用随机重跑代替定位。

- 明确记录多个固定种子，使用 `New → BotPurchase/Buy → BotInput/QueueInput → Advance`，每三帧采样；所有失败保存原种子、完整规则检查点、事件计数和稀疏角色轨迹。
- 保持两回合、270 秒预算与原版歼灭胜负，不增加超时结算、不强制死亡、不直接改位置、库存、时钟或队伍得分。
- 有备弹但装填边沿失效、空主枪未换有弹副枪、所有弹药耗尽后持刀而未接近敌人，分别核对真实输入与规则事件。
- 路径目标位于不可达 NAV 分量、最近节点隔墙、终点已抵达却反复选择同一点，以及真实 hull 被墙／动态人物阻挡时，须保留路径与位置证据。
- 一对一残局双方只在互不相交的出生点或重复路线间循环、缺少公开可达区域搜索、交错通过而长期未形成可见交战，须用固定种子重现。
- 搜索策略只能使用公开地图、自己状态与可见敌人；改变隐藏敌人位置不能改变未见敌时的搜索目标。
- 新策略的私有状态须可保存与恢复，不得破坏原四图目标、六图规则身份、定点确定性或原生／WASM 一致性。

产物保存于 `.local/cs16/verification/elimination-search/`，原始失败检查点与修复后结果分别保留。
