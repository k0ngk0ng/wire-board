# 空仓自动装填失败场景

先列场景并编写规则 E2E，再修改实现。使用 `QueueInput` 和 `Advance` 驱动，初始库存与碰撞场地属于隔离夹具。

- 全部 24 枪空仓且有备弹，松开左右攻击、冷却严格结束后必须开始装填；相等及前一帧不能提前开始。
- 普通枪持续按住左键只空击，松开后自动装填；右键仍按住时不得自动装填。
- M3、XM1014 的原始空仓攻击分支直接调用装填：按住左键仍开始逐颗装填，有子弹后可中断并继续射击。
- 散弹枪完全浸水时，持续开火走水下禁射分支，不能触发空仓攻击装填；松开双键仍允许普通自动装填。
- 尚有膛内子弹、无备弹、小刀、C4 或投掷物不能错误启动自动装填；不能重复发装填事件、凭空补弹或出现负库存。
- 未发完的三连发不能被自动装填打断；续发结束后按正常空仓条件判断。
- 切枪取消旧装填；新武器须等待部署冷却；死亡不能开始或完成装填。
- 准备期允许空仓自动装填，但不能因按住左键执行散弹空仓攻击。
- 保存并恢复中的自动装填须在相同权威帧结束，保持弹药和事件一致。

固定原样本静态证据与参考重实现分别登记于 `docs/research/cs16/auto-reload.md`。本测试不声称浏览器或原版运行验收。
