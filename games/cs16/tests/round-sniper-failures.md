# 回合收尾与栓动狙击枪失败场景

- 回合结果出现后活人运动被锁定，客户端停止预测，或服务器校正把人拉回原地。
- 回合收尾仍应保留原有碰撞、跳跃、蹲下和输入释放；死亡、开局冻结及比赛结束不能被解锁。
- 移动导致重复结算、改写既定比分或延长下一回合的截止时间。
- AWP／Scout 射击后没有退镜，拉栓动画仍被镜面遮住，或冷却结束前恢复瞄准／再次开火。
- 一倍、二倍镜恢复到错误档位；未开镜射击后自动开镜。
- 切枪、丢枪、装填、死亡、换回合或恢复存档时遗留待恢复镜头。
- 本地开火反馈与权威退镜不同步，或者其它自动狙击枪被错误套用栓动退镜。

参考固定 ReGameDLL 提交 `1f16a7f25c14225931f8df1abc51f68d18ded839` 的 `wpn_awp.cpp`、`wpn_scout.cpp` 和 `weapons.cpp:999`：AWP 1.45 秒、Scout 1.25 秒冷却；射击后退出镜头，冷却后恢复原档位。该来源为公开参考实现，不冒充原版运行采样。
