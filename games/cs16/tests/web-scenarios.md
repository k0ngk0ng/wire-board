# 首版网页失败场景

以下清单先于实现建立。正式认证房间的浏览器 E2E 是完整可玩性依据；纯函数验证用于输入队列、事件游标和资源身份等独立边界。

- 目录人数上限不足 10；四张地图遗漏；24 枪的选择、队伍限制、价格和名称漂移。
- 按下立即松开在等待 ACK 时被合并；离散换枪、装弹、使用和副攻击丢失；队列无限增长；暂停后重播旧射击。
- 重连或生命代次改变后继续提交旧输入；序号回退；解除 Pointer Lock、失焦、隐藏、弹窗、托管时仍按住开火。
- 原生鼠标位移在本地没有立即反映；普通确认重建预测时钟；未确认输入没有按已应用序号重放；死亡仍能预测移动。
- 预测超出固定窗口；显示目标帧早于已显示输入；新输入被回填到过去帧；纯转头被位置确认覆盖。
- 重连重播枪声；重复事件触发重复反馈；旧生命命中影响新生命；事件游标缺口没有恢复。
- 资源大小、SHA、地图 ID、运行时身份不符仍确认就绪；未完成解码或首帧绘制就就绪；失败后无法重试。
- 为一张地图下载其余三张；选图预览下载全地图；选择角色与实际模型不一致；场景仍使用方块示意图。
- 地图贴图与烘焙光照方向错误；角色坐标轴与命中位置不一致；开镜和第一人称枪械视图不同步。
- 320 px下关键资源裁切；触屏滑动触发文字选区；两指移动转头互相覆盖；松开一指取消另一指；手柄断开覆盖键盘输入。
- 购买界面打开后仍开火；错误信息被全屏遮挡；死亡观战无法切换目标；比赛结果无法在平台结算中查看。
- 电脑、真人、观众和托管席位权限混淆；普通快照抢走购枪和准备界面焦点。

浏览器验收保存原生输入到画面指标、帧间隔、RTT、ACK、规则应用、网络配置、截图和 trace 到 `.local/cs16/verification/`。正常网络键鼠 P95 ≤33 ms、触屏 P95 ≤50 ms；目标 60 FPS。模拟触屏不代表实体手机实测。

## 原生纹理与手机交互补充

- CSP 禁止 blob URL 时内嵌 GLB PNG 仍须通过 bufferView 直接解码；纹理失败必须阻止就绪，不能白模通过。
- 视模使用原始骨骼、默认右手反射与独立固定水平视野；不能靠整体缩小或隐藏错误几何通过截图。
- 双拇指同时左摇杆移动、右侧开火按钮拖瞄；主开火区域至少 64 px，其余至少 44 px。右指滑出开火按钮仍保持捕获，分别松一指保留另一指。
- 触屏蹲下可切换，PC Ctrl 保持按住；失焦、取消、死亡或打开菜单清除触屏锁定状态。
- 手机竖屏与横屏的摇杆、按钮、库存、生命、弹药和公共聊天浮钮互不遮挡。安全区与全屏工具栏均避让。
- 购枪面板使用原生触摸滚动，能滑到副武器弹药；分类切换不滚动页面，菜单打开时暂停战斗输入。
- PC Q 切回上把武器，滚轮轮换，逗号/句号购买主/副弹药；既有键位与鼠标锁定继续有效。
- brush 增量字段省略时沿用最近完整列表，显式空列表清空；换地图、epoch 或恢复不得携带旧门状态。
- 卸载房间先终止输入代次且不再发 release；旧 promise 回调不能向下一房间报告错误或继续发排队操作。
- 小误差权威校正只影响显示：同生命与姿态、8 原单位以内、同源碰撞 trace 可通过时，在最多 80 ms 内衰减；运动与伤害仍用权威／预测规则坐标。
- 连续普通 ACK 不延长已有 80 ms 校正窗口、不重建运动显示时间锚；重复／旧帧不累计校正。新输入仍立即显示。
- 死亡、重生、姿态改变、大误差、恢复和墙／动态门阻挡立即切回有效规则位置；平滑期间门关闭须在下一显示帧停止平滑。

## 鼠标锁到触屏交接的预先失败清单

- 鼠标已锁定时首次触摸执行 `setPointerCapture` 抛 `InvalidStateError`，导致已经记录原生事件却未接收触摸。
- 退出鼠标锁的事件晚于触摸按下，旧鼠标清理误清刚接收的触摸；第二指触摸再次清除第一指。
- 解锁尚未完成且尚无显式捕获时，手指拖离控件后移动、松开或取消丢失；不能依赖隐式捕获必然有效。
- 松开任一指、正常释放后重复 `lostpointercapture`，错误清除另一指；意外失去已建立的捕获反而没有取消对应指针。
- 失焦、页面隐藏、禁用、死亡或卸载后保留触摸、蹲姿、捕获或待补捕获；解锁后恢复已释放的旧指针。
- 非预期捕获／释放异常被吞掉，留下悬挂输入；捕获失败或取消开火没有先取消对应动作，再发布仍有效的另一指。

先验证真实 `TouchInput`、指针所有权、延迟解锁及实际 EventTarget 上的窗口接续，再由正式 FY／血战回廊原生浏览器路径验证鼠标已锁定到触屏的切换。测试驱动不得预先退出鼠标锁。

## 全屏聊天容器变化的预先失败清单

- 全屏尺寸已经稳定，聊天按钮稍后插入嵌套 portal，根容器的直接 childList 监听没有收到变化，弹药 HUD 在第 3 帧仍被遮挡。
- 聊天按钮被替换或移除后仍使用旧节点的尺寸，避让值没有更新或清零。
- 为捕获嵌套插入而监听所有后代 style，触屏摇杆自身样式导致持续无效测量；只增加后代 childList 通知。
- 卸载后仍有子树监听或待执行动画帧，写入旧棋盘；新增监听必须和原监听共同断开。

先保留正式 `release-sixmaps-3dab99ae` 的 Dust2 原生全屏 RED：第 0、1、3 帧避让均为 0，聊天与弹药稳定重叠。定向验收沿用原全屏入口、固定三帧、无重叠和画布身份断言。

## 触屏卸载的预先失败清单

- 父棋盘先销毁输入通道，触屏子组件的卸载清理仍发布 changed 或 interrupted，访问已经销毁的通道并导致整个玩家页面空白。
- 静默卸载只跳过通知，却遗漏清空所有触点、蹲姿、捕获或待捕获状态；后续解锁事件使旧指针重新生效。
- 运行中的失焦、禁用和取消错误沿用静默清理，导致仍有效的父输入通道没有收到释放；静默模式只用于绑定卸载。

真实关闭房间 RED 与两个玩家的 TypeError 堆栈保留于 `.local/cs16/browser/reports/close-unmount-error-proof/`。先验证卸载不再通知已销毁的所有者，再用真实关闭、离开房间和可见大厅验证。
