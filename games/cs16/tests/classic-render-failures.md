# 经典呈现反馈的先行失败场景

- 权威 zoom 为实际视场角 40、15、10、55，渲染却把任何大于 1 的值都当成同一档；切换倍率或退出开镜后画面没有相应变化。
- 刀左挥选中只有两帧的占位 slash1／slash2，未使用原模型 midslash1／midslash2；右键空挥错误选择 stab 命中姿势。
- Glock 的 shoot 和双持手枪的 shoot_left／shoot_right 未匹配射击动画；枪械反馈只发声音／火光，没有即时可见的枪身后坐，连续射击后不恢复。
- 爆头、胸部、腹部、左右手和蹲姿死亡没有选择对应原始动画；新出现的尸体从头重播旧死亡，复活后旧尸体或死亡镜头仍残留。
- 尸体呈现错误放开活人隐私、穿墙滑动，或每次死亡无限增加对象；丢失视线时仍显示未获授权的坐标。
- 原版 200–300 HL/s 的击退被过紧位移上限或过快指数阻尼截掉，飞出不可辨识；重力、地面摩擦和地图碰撞须保留可核验的来源与有界极值。
- C4 原始上抛约 836 HL/s，2 秒后仍在上方却被提前冻结；碰到天花板后贴顶不落下。有限运动窗口须覆盖原爆炸上限，并在顶部接触后由重力继续落地。
- 死亡立刻跳到队友镜头，缺少短暂倒地视角；重连已经阵亡的玩家又补播过去的倒地过程；没有可观战活队友时镜头又站回原高度。
- 手电只增加 Three.js 灯光，但地图为不响应灯光的 MeshBasicMaterial，实际像素没有改变；开启时全图一起提亮，关闭后无法恢复原像素，首次开灯临时编译 GPU 程序。
- 落地只有扣血，没有原版兼容移动代码的冲击反馈；低于冲击速度仍抖动，冲击累积不归零，或重复权威事件重播。
- 为修复可见性而无依据改变全图 gamma／曝光／环境光；用户最新反馈亮度可接受，本轮保留既有线性 BSP 光照与颜色纹理处理。

原模型静态来源为既有第三方归档样本；兼容代码仅作语义参考，不冒充原版运行轨迹。定向验证保留纯模块边界结果与独立真实 WebGL 呈现夹具的像素／截图，不代替正式联机或实体设备验收。
