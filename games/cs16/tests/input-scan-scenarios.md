# 输入存档单次扫描的预先失败清单

- 每次旧版本准入与 Apply 都先完整 json.Valid，再扫描 root、world、players，重复访问不相关玩家、事件和压缩历史。
- 自定义单次扫描遗漏逗号、冒号、尾随值、无效转义、控制字符、数字格式或 10000 层深度边界，接受标准 JSON 解析拒绝的数据。
- root／world 的重复键或转义字段名改变原有回退语义；嵌套扩展中的 world／players 被错误当作真实字段。
- 玩家 span 偏移把别人的存档覆盖；未知扩展、历史压缩正文、非当前玩家或旧 Match.Data 被改写。
- 旧版本准入为了减少反序列化而忽略生命代次、alive、receivedSeq、队列／传输年龄或瞄准参考帧边界。
- 用全局可变缓存、未经验证的持久化 offset 或放宽 200 ms／100 ms 预算掩盖扫描成本。

先比较标准 json.Valid 的语法与深度矩阵、逐字节截断及 root／world／玩家 span；继续执行既有四图、友伤模式和逐动作／后续规则等价回归。仅私有输入扫描与准入解码改变，存档格式、规则、坐标精度、时钟与公共代码保持不变。普通性能和 race 正确性分别运行，保留失败、profile、源码身份及最终结果。
