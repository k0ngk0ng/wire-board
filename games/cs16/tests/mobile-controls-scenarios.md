# CS 手机操作验收失败场景

手机布局是平台适配，CS 原版不提供触屏布局，不把本轮方案标为原版手机操作。

- 购买仍藏在「更多」，或在不满足 `buyZone` 与 `buyAllowed` 时仍出现；独立购买按钮与其他按钮重叠。
- 手电仍藏在「更多」，触摸无法独立开关，或误触发射击。
- 弹药的原精灵被裁剪、过度缩小、超出视区，或被按钮、聊天、全屏工具、库存覆盖；只检查外框而遗漏数字本身。
- 仍出现独立开火按钮或开火方式切换；默认瞄准区触摸不射击，拖动时停止射击或不能瞄准。
- 左指移动与右指射击互相覆盖；松开／取消一个触点错误释放另一触点，或火力保持不松开。
- 控件、购买菜单、聊天、库存、战绩和网页全屏工具被当作射击区域；在这些区域开始拖动后进入瞄准区误射。
- 旋转、调整视区、隐藏、失焦、禁用、触屏切回鼠标或触点丢失后恢复旧射击输入。
- PC 鼠标左右键、键盘和改键被触屏默认开火方式影响。
- 320 px、Duo 内外屏与 Pad 横竖屏的普通页面／全屏存在遮挡、横向溢出或小于 44 px 的按钮；按压区域与显示区域不一致。
- 没有可信浏览器触摸事件、实际发布过的 HUD 图集、本地操作提交记录、截图及可复跑结果；把隔离 UI 夹具声称为完整对局或实体设备验收。
