# 原版交互修复失败场景

先保留失败测试，再修改实现。原始素材静态解析、参考重实现和浏览器实际观测分别记录。

- T、CT 菜单编号不同，不能混用其他 CS 版本的编号；B 后连续数字不能丢键、切枪或开火。0、Escape、B 关闭菜单后立即恢复原先的鼠标锁，触屏关闭不申请鼠标锁。
- 购买成功才播放原版购买音；余额不足、弹药已满、离开购买区时静默。逗号和句号与数字菜单走相同购买确认。
- C4 携带图标、爆破区闪烁与购买区图标处于原版左侧状态图标区，不能把购买时限当作地理区域。埋设和拆弹进度由权威帧计算，取消、死亡、回合变化立即清除。
- C4 按模型事件播放安装按键声；埋下后按权威倒计时播放本地滴声，重复投影不重播，恢复连接不补播旧声，距离外听不到。
- 命中部位和爆头使用权威事件；不得由本地射线判断命中。击杀栏显示爆头标记。
- 敌人尸体只有可见时才能投影，死亡动画不被活人可见性规则过滤；隐藏活人、背墙尸体、库存和全局击杀坐标不能泄露。
- 手电按键边沿、松开、取消和网络排队保留顺序；只传操作及必要的权威字段。
- 320px、Duo、Pad 和桌面等待房间：长名称、房主徽标、电脑徽标、准备状态、空席和满员高度稳定；连续添加 9 个电脑时按钮中心和页面 scrollY 不移动。满员后按钮保留位置并禁用。
- CS 队伍区域为最大五人预留紧凑空间，添加电脑不增加页面高度；公共准备卡片使用固定紧凑行高，不能靠 scrollIntoView 掩盖自动滚动。
- 普通房间聊天按钮不能覆盖 FC/MD 触控动作，退出全屏、旋转和展开控制器后仍可操作。

亮度按用户后续更正保留现状，仅修复有证据的光照错误。
