# CI 自然对局失败诊断的预先失败清单

- 自然对局达到上限后失败，只上传 `.local/ci/cs16` 日志，遗漏游戏目录中的初始状态和最终私有 checkpoint。
- 命令失败后收集逻辑没有执行，或归档把真实退出码／失败清单改成通过。
- 只归档成功结果、不保留嵌套 JSON checkpoint，或把缓存、profile 和素材正文一并复制。
- 在非 CS16 lane 也收集 CS16 产物，改变其他游戏执行命令或 workflow 步骤，破坏已完成的部分复用。
- 64 位 seed 经过浮点数或仅记录最终值，导致失败无法从初始状态重现。
- 失败日志缺少 map、初始／最终 seed、frame、phase、round、存活席位和回合结算原因。
- 为使随机失败变绿，加入产品 seed 注入、固定成功随机局、改自然对局上限或获胜规则。

先用真实轻量子进程模拟 CS16 命令成功／失败，验证 scope 输出在失败时仍收集 JSON、保留原退出码，并确认缺少产物及非 CS16 lane 行为。诊断解析用纯 JSON 夹具验证完整 uint64 seed 和存活席位；不运行自然对局、性能或 race。现有 workflow 的 always 上传步骤和游戏命令保持不变。
