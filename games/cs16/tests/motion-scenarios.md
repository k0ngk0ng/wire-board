# 共享运动核心失败场景

在编写 WASM 入口和原生对照命令前建立此清单与 `motion-runtime.test.mjs`。

- 地图 ID、碰撞平面、hull、节点根缺失，初始化失败。
- 非字符串、畸形 JSON、超大 JSON、越界帧数、非整数坐标或输入，不进入规则。
- 同一原图、人物初态和输入轨迹在原生 Go 与真实浏览器 WASM 中产生不同结果。
- 斜向移动、跳跃、蹲下、台阶与墙面滑动在 WASM32 上因整数宽度溢出失配。
- 连续预测污染上一个权威人物对象，导致回放不可重复。
- 切换地图后保留上一张地图的 hull 指针。
- 版本、倍率、频率或枪械表与服务端源码不一致。

原生对照命令只接受已登记地图和有界步骤，作为轨迹 oracle。生产测试编译同一运动核心，读取真实地图规则，以相同操作逐步比较全部人物字段。报告保存在 `.local/cs16/verification/motion-runtime.json`，不是原版游戏等价性证明。
