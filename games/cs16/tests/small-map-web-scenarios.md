# 两张经典小图前端的预先失败清单

- 地图目录或资源清单仍只接受原有四图，导致冰雪世界或血战回廊无法创建、等待或加载。
- 按 `cs_` 前缀把血战回廊标成人质营救，或把冰雪世界标成爆破；地图选择、购买装备和触屏使用键采用不一致的模式。
- 歼灭图仍显示无效的每回合时长选项，切图时丢弃已选时长，返回原图后无法恢复原设置。
- 歼灭图 live 阶段显示 `0:00` 或虚构倒计时；冻结和回合结束阶段反而丢失实际倒计时。
- 原有爆破、人质和 C4 倒计时在引入歼灭状态后变化，分钟边界再次出现跳秒。
- 歼灭图购买菜单出现拆弹器，或误加载人质模型；原有爆破图和人质图的专用装备、模型选择被改变。
- 冰雪世界地面武器的原始朝向丢失，拾枪后旧模型残留，或下一回合刷新时复用错误位置、朝向及实体。
- 玩法速查遗漏两图的歼灭目标、死亡后等待下一回合、冰雪世界地面拾枪及购买区域，或把回合模式说成持续自动复活。

先用真实 React 静态渲染检查六图、三种模式、创建与等待界面、时长控件及装备可见性，并保留可重复执行的 HTML／JSON 结果。纯函数边界覆盖 HUD 阶段和倒计时；正式浏览器六图加载、十席自然对局、桌面和手机验收由统一浏览器入口完成。
