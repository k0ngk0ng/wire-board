# 军棋

独立维护两人陆战棋和四国对家模式，支持真人、电脑及平台托管。仅开放 2、4 人；房间人数与规则模式在创建时绑定，四人房间不能提前作为两人局启动。新增默认下架，管理员上架后才对玩家开放。

## 规则

两人使用南北棋盘，四国使用四向阵地与中央九个铁路点。四国红黄对家、蓝绿对家，显示旋转不改变服务端席位或队伍。规则规格及来源见 [实施规格](../../docs/research/chess-family/junqi-implementation.md)。

每方 25 枚，六排五列、五个空行营。军旗放在一个后排大本营，地雷仅在最后两排，炸弹不在前排。开始后先进入私有布阵阶段，可以交换或随机布阵，全部确认后红方先行。每席独立计时和修改序号，其他玩家调整不会使本人仍有效的布阵请求失效。

普通道路走相邻一步，行营有相邻斜线。铁路可以沿连续直道走多个空点，不能越子；四国四角弧线按连续边线处理。普通子不能在交叉点改换线路，工兵可以转弯；实际需要转弯时公开工兵。优先采用不转弯路线，避免无必要的身份公开。行营内敌子不可攻击，进入任何大本营后不能移动，军旗和地雷始终不动。

军阶从大到小为司令、军长、师长、旅长、团长、营长、连长、排长、工兵。大吃小，同级同归；工兵排雷后存活，其他普通子碰雷阵亡；炸弹与任何棋子同归。炸弹撞军旗也算夺旗。司令阵亡后公开军旗。

军旗被夺、认输或轮到时无合法移动，均使该方出局并清除棋子。四国队友可以继续，胜方包含已出局的对家。正常胜负优先；连续 200 着无战损或同一实际局面及手番出现四次时和棋，真人与电脑一致适用。也可由存活玩家一致同意和棋，提议不暂停或重置时限，走子或拒绝会取消提议。真人和棋 0 积分、不计胜场，含电脑的对局不计分。

## 隐藏信息与电脑

`State` 保存私有棋子，`View` 独立定义，不嵌入私有状态。自己只能看到己方及已公开身份，队友、观众不能看其他暗子；结束后公开仍存活的棋子。棋子使用独立随机 ID，视图按公开位置排列，清场事件中的 ID 也按随机 ID 排序，避免私有军阶顺序从事件泄漏。

电脑先投影为该席位的 `View`，策略只接收这个视图。替换不可见敌子军阶不会改变电脑提案。入门策略以出动和接近大本营为主；标准策略增加护旗判断，未知敌子按普通可移动子作保守推测，不查询其真实军阶。近期公共走子用于减少往返，所有提案仍走相同行动接口和交战规则。策略不依赖模型、付费 API 或额外服务，也不承诺 Elo。

默认随机阵型将另一大本营留给地雷，避免无意锁住可移动棋子；真人仍可按合法规则调整。超时走平台托管，取消托管只恢复自己的过期期限，不改变其他布阵者的期限。存档保存阵型、身份公开、当前手番、布阵修改序号、时限和和棋提议。

## 界面与素材

沿用公共创建、等待、玩家栏、计时、历史与结果。棋子按红、蓝、黄、绿区分归属，棋面及封面棋子均无数字角标。对局保留公开的剩余棋子数与对家提示。

手机默认适屏显示完整棋盘；四国全图使用简洁色块观察位置，两人全图保留棋面。全图点选只放大区域，不选子或走子。放大后的操作棋子至少 24px，支持鼠标、键盘方向键／回车、触屏拖动和双指缩放；「全图」可恢复全貌。概览拖动只定位，不提交行动。

走子和交换以服务端路径为准，连续事件排队，战损、军旗公开、清场与结果在到达后更新。刷新、重连和跳号恢复当前局面，不重播旧动画。音效仅通过平台音频接口，遵循统一静音；爆炸效果只根据本席位已知的炸弹判断，不能用声音泄露未知炸弹。

63 个素材：四方 48 个军阶字面、4 个暗面、2 个棋盘底纹和坦克封面，共 55 张 WebP；走子、交战、爆炸、亮旗、夺旗、就绪、胜利及和棋 8 个 WAV。封面不画人物，采用坦克与军棋棋子构图。图片为原创 SVG，字形使用固定版本的 Noto Serif SC（OFL）；碰撞声来自 Kenney CC0，其他为原创合成。许可、来源和 SHA-256 见 `assets/sources.json`。

正式路径为 `ASSETS_BASE_URL/junqi/v1/`，本地回退为 `/junqi/v1/`；图片均失败时仍显示颜色与中文棋面。当前素材已上传并回读校验，修改已发布内容须提高目录版本。

生成工具只需通用渲染依赖，不要求先运行另一款游戏的素材任务：

```sh
. scripts/env.sh
npm install --prefix .local/chess-family/assets-tools --no-save --ignore-scripts @resvg/resvg-js@2.6.2
PIP_CACHE_DIR="$PWD/.local/pip" PYTHONDONTWRITEBYTECODE=1 \
  python3 -B -m pip install --target .local/chess-family/font-tools --no-compile fonttools==4.60.1
node --experimental-strip-types scripts/junqi/prepare-assets.mjs
python3 -B scripts/junqi/verify-assets.py --dist --decode
```

另需 `cwebp`、`ffmpeg`。生成器按固定 URL 和摘要获取原字体／音频包，允许复用已校验缓存。字体固定为 700 字重后渲染，整包字体不加入网页。

## 验收

```sh
. scripts/env.sh
python3 -B scripts/ci/scope.py run --game junqi --backend
WIRE_BOARD_JUNQI_PLAYERS=2 WIRE_BOARD_JUNQI_ASSETS=https://cdn.ichenj.com/bga/v20261002-1 \
  python3 -B games/junqi/tests/accept_ui.py
WIRE_BOARD_JUNQI_PLAYERS=4 WIRE_BOARD_JUNQI_ASSETS=https://cdn.ichenj.com/bga/v20261002-1 \
  python3 -B games/junqi/tests/accept_ui.py
```

HTTP 用例先于规则实现，覆盖人数绑定、默认下架、布阵限制、同版本并发确认、暗子／观战／队友隔离、铁路直行／转弯／弧线、行营、大本营、交战、夺旗、出局队友胜负、和棋表决、恢复与时限。缩减中局夹具单独标记，不计为自然完整局。

两种人数×两档策略经真人 HTTP 会话完成自然对局。另用生产调度的电脑席位＋托管真人完成两种人数各一局，包含真实布阵与中途重启；竞态检查覆盖原生完整局、并发布阵、超时和接管。不存在强制指定胜者或为电脑单独缩短和棋阈值的验收模式。

浏览器验证真实鼠标／键盘／触屏、完整手机棋盘与放大、蓝方在下、暗面、交换、快速连续走子的实际移动帧、静音、双指缩放、刷新、四人一致和棋及 CDN 故障回退。当前结果分别在 `.local/junqi/browser/result-2.json`、`result-4.json`；规则与完整轨迹在 `.local/junqi/http/`，专项结果在 `.local/ci/junqi/result-0.json`。只运行军棋与必要的公共平台检查，不重复未修改棋类的完整对局。
