# 升级

上海预设，四人对家搭档；默认两副牌（八十分），可选一副牌（四十分）。分别实现发牌与亮主、庄家取底扣底、跟牌、结构比较、无效甩牌直接拒绝（不扣牌、不罚分）、抠底、单双副计分、换庄及打到过 A。

单副没有同花同点实体对子，支持上海资料中的四同领出与无分牌明示重发。双副的拖拉机按主牌顺序计算，跟牌优先保留完整、部分拖拉机及对子。默认所有其他玩家（含搭档）均可破甩；每收回一张罚 10 分，可关闭罚分但仍须强制领出。单副底分 ×2；双副默认按末墩领出张数 ×2，也提供明确公式的最大结构指数选项。

线上在发齐手牌后集中亮主，允许更强反主，不允许自反、自保或同强度反主。级牌始终属于主牌；不启用常主 2 或勾 J。A 必须坐庄守过，不能跳过。各地约定并非完全相同，具体规则在创建、等待和玩法说明中展示并随对局保存，详见 [实施约定](../../docs/poker-implementation.md)。

```sh
. scripts/env.sh
go test -count=1 -timeout=5m ./games/shengji/...
python3 -B scripts/accept_poker.py
```

自然整场记录在 `.local/poker/shengji/natural-*.json`；单双副真实 HTTP 房间、隐私、取底扣底、自然结算及 SQLite 恢复记录在 `.local/poker/shengji/http/`。牌型边界和错误路径先于实现编写。

默认下架，由管理员上架。规则不导入另外两款扑克游戏；仅共享牌面、手势与相对座位呈现。素材见 [素材清单](../../assets/poker/README.md)。
