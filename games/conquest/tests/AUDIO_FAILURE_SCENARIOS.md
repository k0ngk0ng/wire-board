# 音效先行验证

本文件和 `audio_contract_test.py` 先于生成器及音效成品建立。

- 漏掉行军、占领或新回合音效，或额外写入未声明的媒体。
- 文件不是可解码的 PCM WAV；采样率、声道或位深不符合约定。
- 音效为空、全静音、持续时间超过 0.8 秒，或峰值削波。
- 起止处突变，或整体音量过低／过高。
- 同一源码重复生成产生不同字节，清单 SHA-256 或字节数不匹配。
- 清单缺少原创来源、生成方法、生成器源码摘要及单文件摘要。
- 复验中间文件残留，或写到工作树之外。

验证只检查离线合成成品。静音、加载失败、离桌及不重播旧事件由前端真实浏览器验收覆盖。
