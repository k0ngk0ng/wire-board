# 地图操作与触控改版：先行验收

本清单和 `accept_map_ux.py` 在界面改版前编写。旧版基线必须保留真实截图、输入与性能记录；不能把先前仅检查缩放数值的通过结果当作实际手机体验。

按用户最新要求保留平面分区地图，已取消山脉、森林和立体城堡方向；不再将立体层或城堡缩放作为交付要求。

## 操作与视觉失败场景

- 仍以固定大表单、数值输入框、目标下拉完成征兵／进攻；地图不能成为主要操作区域。
- 每块领土都有常驻矩形按钮或编号装饰，遮住小区域；兵力数字与地图失去关系。
- 未选中地区就铺满行动按钮；选中己方地区后没有少量可辨认的征兵／进攻／筑堡图标。
- 操作图标没有无障碍名称、键盘不可达、触摸命中区重叠；小地区点不到或总点到相邻地区。
- 进入进攻模式后无法取消；拖动、双指结束、取消手势后误下指令。
- 快捷征兵／出兵超过金币、人口、行动点或可移动兵力；没有反馈而反复失败。
- 一条成功派兵被撤销后，再点同目标被旧回执锁住；首条请求明确拒绝后等待不存在的订单，后续操作永久失效。
- 长按征兵退化成短按、长按与松手各执行一次、额外消耗行动点；城镇长按或 Shift+Enter 在资金不足时错误退回短按筑堡。
- 游戏仍按服务端规划／提交／结算规则运行；不能通过前端交互改动结果、重置时限或泄露对手计划。
- 表单移除后遗失托管、暂停恢复、计划撤销、结算关闭／重开和观战权限。
- 重新添加常驻数字按钮、复杂地形或昂贵的逐省滤镜，影响平面地图的识别与移动性能。

## 触控与镜头失败场景

- 在陆地、兵力文字或城堡图标上开始双指，只有海面可缩放。
- 子元素捕获与 `lostpointercapture` 冒泡删除其他手指；两指缩放中一指移出边界便失效。
- 放大与缩小只能单向；双指改成单指时镜头跳变；取消、失焦或页面隐藏后仍残留手势。
- 浏览器页面缩放取代地图缩放；手势把整个页面拖动；地图外正常滚动被阻止。
- 滚轮缩放不能保持鼠标锚点；左键拖动误触区域操作；小地图只支持点击。
- PC 从实际领地路径或兵力文字上开始拖动失效；仅在空白海面拖动通过。越界松开后仍保持拖动，或者后续点击被永久阻止。
- 连续移动每个 pointermove 都重渲染完整地图；一帧重复绘制，出现长任务与明显掉帧。
- 世界手机入口只预绘制视窗内军队，拖动到远方时必须松手才补出已知军队。远方标记预绘制的 DOM 检查只证明可供连续变换使用，不冒充实际可见性。

## 可重复记录

- 两张地图分别覆盖 1440px 桌面和 320／390px 移动视口，保留进入、选地、行动图标和战斗截图。
- 使用 agent-browser 独立浏览器；CDP 只用于向它拥有的页发送原生鼠标／触摸输入，不直接调用游戏回调或写游戏状态。
- 手势持续 0.8～1.2 秒并按帧节奏发送；记录实际 rAF 时间、长任务、镜头绘制及地图渲染计数、区域 DOM 属性变化。基线没有渲染计数时明确标记，不冒充 React 性能记录。
- 正式性能检查要求稳定手势期 p95 帧间隔不超过 50ms、无大于 120ms 的帧停顿，地图主体不能随每次移动重渲染；记录原始样本而不是只写通过。
- 每次输入前后读取真实服务端计划；纯镜头操作不得改变计划。点击图标后的计划必须通过服务端合法接口建立，实际结算才改变兵力或归属。
- `--baseline` 只保存旧版测量，并记录新界面不变量的实际失败；正式运行必须全部通过。手机宽度模拟不声称手机真机或 WebKit 验证。

运行：`python3 -B games/conquest/tests/accept_map_ux.py --baseline` 或 `python3 -B games/conquest/tests/accept_map_ux.py`。所有临时状态、profile、数据库和结果仅保存在本工作树 `.local/conquest-map-ux/`，结束后清理临时浏览器和编译产物。

回执、长按和预绘制可先分别复跑，不能把小范围通过当作完整验收：

```sh
python3 -B games/conquest/tests/accept_map_ux.py --skip-build --queue-case all
python3 -B games/conquest/tests/accept_map_ux.py --skip-build --marker-case
python3 -B games/conquest/tests/accept_map_ux.py --skip-build --hold-actions
```

拒绝回归只在独立本地浏览器中用 CDP Fetch 对第一条实际 `move` 请求返回一次明确的 HTTP 400，随后立即移除拦截；不改服务端状态。再次点选必须在原进攻模式内正常排单，不能靠刷新、切换模式或测试代码清理应用状态。长按回归使用原生 750ms 按住／松开，记录真正提交的请求，并检查不足资金的城镇操作不会退回短按筑堡。
