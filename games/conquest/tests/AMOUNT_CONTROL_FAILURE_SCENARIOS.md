# 征兵、派兵人数与皇冠：先行验收场景

本清单与测试在实现前编写。规则接口不变，使用真实房间和原生输入验证前端。

- 征兵仍固定 1,000 或自动征满；默认值不是当前合法上限的一半。奇数向上取整，只有一人时为 1，上限为零时不可提交。
- 滑块只有外观，鼠标、触屏或方向键不能改变实际订单；直接输入的精确人数被忽略。
- 打开、调整或取消人数选择就消耗金币或发送行动；长按征兵绕过所选人数直接征满。
- 滑块与数字框不同步；空值、负数、小数、越界值或行动点不足导致非法订单。
- 征兵上限遗漏金币、人口、总兵力容量或行动点约束；派兵超过剩余可动兵力。
- 默认连续进攻未逐笔使用服务端剩余兵力；手动数量未随点击入队，后来改滑块影响已经排队的请求。
- 海运费用不足时静默减少人数；手动调低后仍不能正常派兵。请求拒绝、撤销后重试卡住。
- 普通快照清掉手动人数；换领地、换操作、换轮、托管或重开后残留旧人数／操作面板。
- 拖动滑块误移动地图或点选领地；拖动地图后滑块不可用；320px、手机键盘或全屏时数字框／确认按钮被遮挡。
- 两种操作面板相互覆盖；地图按钮、财政和计划弹窗、取消进攻及默认半兵操作退化。
- 皇冠仍是两个三角；金色底座、冠齿和宝石缩小后不可辨认，遮挡兵力、要塞或失去选地命中。
- 皇冠的 SVG 渐变 ID 冲突；地图缩放后皇冠随地形缩成小点或放得过大；桌面、320px 和全屏截图需核查。

- 计划下面没有已用／总行动点；把免费税率计划计成一步、把 0.5 点筑堡计成一步，或撤销／下一轮后数字不更新；小数浮点误差、零值、观战及全屏显示需验证。

## 连续征兵限制补充

- 选中领地没有公开剩余人口，或征兵后的数字仍是原始人口，没有反映已加入计划的征募。
- 可征人数为零时按钮完全无法查看原因；误把金币／行动点不足一律归因于人口。
- 多个资源同时不足时只显示不相关原因；上限为零仍可以点击确认。
- 人口和限制说明在 320px、全屏或长地名下溢出、被遮挡；正常领地也一直显示错误文案。

## 征服时代全屏尺寸补充

- 外层进入全屏，但棋盘仍受 1,120／1,160px 最大宽度与 640／660px 固定高度限制，大屏留出大片空白。
- 只扩大宽度、地图高度不变，或为了铺满而拉伸地理形状；超宽屏失去合理宽高比。
- 全屏扩展后底部计划、人数滑块、地图按钮或退出按钮不可见；320px 发生横向溢出。
- 进入／退出全屏重挂棋盘、重置选择或人数；全屏地图无法用原生鼠标／触屏平移。
- 结束对局后回到固定小地图；退出后普通页面宽度或高度没有恢复。保留四图 PC、320px、超宽屏测量与截图。
