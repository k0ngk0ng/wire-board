# 地图先行验收场景

地图生成之前先固定以下失败场景；几何与连接检查属于地图资料的针对性验证，完整对局与浏览器交互另由游戏 E2E 覆盖。

- 世界／欧洲地图缺失，地图 ID、版本、摘要不一致，生成不确定或依赖未记录的在线数据。
- 区域 ID 重复、名称为空、标签落在海洋、几何为空／越界／非有限值、反经线导致横跨全世界的巨大多边形。
- 欧洲地图没有欧洲轮廓，世界地图缺少美洲／非洲／亚洲／大洋洲，或将地图替换为规则方格。
- 陆地边界遗漏，未相接地区被误连，边只存在于一个方向，自连接，指向不存在的区域。
- 島屿与大陆隔绝，海路未经显式记录，海路引用无效，海路与陆路重复。
- 2～8 个势力的开局区域不存在、重复、相邻堆积，或地图上存在永远不可到达的地区。
- 新地图覆盖旧文件但不更新版本／摘要；前后端消费不同区域 ID 或几何。
- 中文地名遗漏、源码地理数据来源与许可不清、下载改变而摘要没有提示。

复现：`python3 -B games/conquest/tests/map_contract_test.py`。
结果保存到 `.local/conquest-maps/validation.json`，包括地图 SHA-256、区域数、陆路与海路数、所有人数的开局检查与连通性。
