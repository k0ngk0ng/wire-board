# 先行规则失败场景

在规则实现前列出并以模块公开契约执行 E2E 验证，真实 HTTP 集成由平台验收覆盖。

- 非2～8人数、不存在地图、非支持难度/期限、未知选项、null、超大JSON与非法schema。
- 初始地区重复、地图摘要不同、初始君主丢失、单一地图复制冒充多地图。
- 他人或中立省招募、负数/零/超额兵力、未邻接/不合法跨海行军、未知地区/建筑。
- 同轮计划双花金币/行动点/兵力；删除前置招募使后续行军保留越界；提交后继续规划。
- 计划或随机源泄露给敌人/观众；电脑读取未来敌方指令。
- 网络提交先后错误决定战斗优先级、重试改变次序、结算重复执行、半次战斗刷新先显示扣兵。
- 相等攻防、城镇/工事/君主加成；君主随军/死亡；同省多路攻击；途中来源已失陷。
- 经济维护/收入/人口/士气边界，负余额、超大兵力、无限招募；新兵错误重复移动。
- 暂停投票越权、电脑投票阻止暂停、暂停仍倒数/电脑行动、恢复重置其他席剩余时间。
- 托管接管已超时席位与取消托管，已提交者机器人无意义循环。
- 地图与规则版本不匹配的恢复被静默接受；恢复丢计划/回合/随机源/事件。
- 淘汰者再次行动，仍有其他存活势力就提前获胜，最后存活势力被剩余中立地区阻止结束，纯真人/电脑结果误计分。
- 两张地图2～8全部人数电脑完整局停滞、无法跨海击败岛上敌军、军队往返、用认输或资源作弊伪造完成。

复跑：`. scripts/env.sh && go test -count=1 ./games/conquest/server`。结果写入 `.local/conquest/rules`，包含初始快照、动作、系统时间与最终快照，可验证重放。

恢复审阅补充（均先写回归再修复）：预计到达部队同轮二次行军、君主连续随军；结算阶段重复投影已执行计划；损坏待执行队列越界；已提交席暂停后撤回提交丢期限；指令编辑计数越界生成不可读存档；恢复时接受超额计划；城镇中王冠公开与未知非城镇君主隐藏。
