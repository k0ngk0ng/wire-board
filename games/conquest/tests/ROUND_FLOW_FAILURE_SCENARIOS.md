# 原计算、整数行军显示、随机出生与逐步播放：先行场景

最终要求：内部恢复原消耗和结转公式，界面将计划条数与可执行的完整行军次数分开。出生点每局随机，双方可见行动逐步、清楚地播放。此前统一每条计划扣一次的方向已撤回，不作为实现要求。本轮改动涉及服务端，须运行征服时代完整规则、电脑和 HTTP 对局矩阵。

- 界面把 3.2 行动点误标成 3.2 次行军；计划条数、剩余行动点和可行军次数混为一谈。
- 为显示整数而改变内部 3.2 起始点数、原始费用、免费税率或半数结转；显示取整反过来影响服务端合法性。
- 旧存档恢复丢失已提交计划、改变出生点、重置计时、修改点数或额外获得行动。规划／暂停／执行途中分别验证；已经开始的动画不能重放或提前完成。
- 随机出生只是打乱固定名单；部分地图或人数仍固定；玩家重叠、直接相邻（含海路）、初始资源不同，或候选选择死循环。
- 同一初始上下文不能重放；不同开局无变化；刷新、恢复或托管重新随机；私有种子泄漏给对手或观战者。
- 只有行军有时间线，征兵、建设和解散瞬间一起结算；敌我行动混在一起、来不及识别；结束结果盖住最后一步。
- 显示到达或完成之前就扣资源、换领地或改变兵力；同一步重复执行；提前触发计时器提前结算；掉线恢复跳步或重播。
- 行动完成后没有阅读停留时间，下一步立即覆盖结果；取消／失效计划仍画出成功行动。
- 视野外的敌方行动不可见；路线、来源、目标、人数、行动者与结果缺失；镜头移动影响规则或误发命令。
- 迷雾下泄露不可见行动、兵力或总计划数；关闭动画偏好后连必要的文字反馈也消失。
- PC、320px、全屏下行动提示、路线或结果被遮挡；刷新、重连、连续事件及最后一步结束不符合真实时间线。
- 电脑只适应固定出生点；随机岛屿、多人数或新行动额度下停滞，无法自然完成对局。

## 慢动作下的 HTTP 长对局时钟

原速完整矩阵曾因等待动画超过旧的 12 分钟上限，失败时仍在正常推进回合。长对局测试仅推进模块测试时钟，不改资源、出生点、动作或结果：真实 HTTP、SQLite 与平台计时回调仍执行。记录生产模块收到的原始上下文和原始快照摘要，逐步重放验证；浏览器、竞态及独立托管整局保留真实速度。

- 测试时钟倒退、影响另一房间或变更生产配置；普通／浏览器验收误用加速时钟。
- 仅缩短信封截止时间，却没有让规则收到对应时刻；重放使用变换后的信封导致摘要不一致。
- 每步加速意外缩短玩家规划时间；重复回调、重启或取消托管改变时钟映射。

## 随机开局下的电脑僵持

美国 6 人／简单／迷雾的自然完整对局暴露了重复失败：电脑只按规划时看到的守军数量征兵，忽略同一目标上次交战前已公开出现的增援，连续进攻超过 1,200 轮仍不结束。修正仅限策略，不改点数、战斗、收入或结转公式。

- 忽略公开战报中的实际伤亡和增援，反复发送同样不足的兵力。
- 读取敌方私有计划／金币，或将隐藏的战报快照当作已知兵力。
- 用久远战报无限抬高估计；未受当前可见人口限制，征兵超出驻军上限。
- 对中立地区虚构征兵能力；改变规则或强制赢家来结束完整对局。
