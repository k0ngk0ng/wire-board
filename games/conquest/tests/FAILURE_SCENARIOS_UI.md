# 征服时代前端先行验收场景

本清单和测试先于前端实现建立。完整功能通过真实房间 E2E 验收；镜头的坐标变换使用先行针对性测试，不能以它替代浏览器验证。

## 地图与加载

- 首页误加载世界／欧洲的全部几何数据；封面与运行模块元数据不一致。
- 选择欧洲却创建世界地图；改地图后继续使用旧镜头、选区或兵力草稿。
- 地图代码已下载但路径尚未绘制即提前确认加载；失败没有重试。
- 刷新、观战或重连阻塞已经开始的对局；初始快照重播旧战斗。
- 地图版本不匹配后悄悄显示错误地图；地区 ID 与动态兵力错配。

## 镜头与命中

- 鼠标滚轮必须按修饰键才能缩放；缩放中心偏离鼠标；地图外滚轮被拦截。
- 鼠标／触屏拖动结束误选地区或误提交；移出、取消、失焦后仍保持拖动。
- 双指缩放以错误中心进行；第二根手指覆盖第一根手指；松一指后镜头跳动。
- 镜头跑出地图边界；复位不能还原；超宽屏地图过宽或过扁。
- 小地图仅点击可用，连续拖动定位无效；地图主体与小地图视窗不一致。
- 缩放后地区实际命中与显示不一致；小地区无法使用邻近地区选择或键盘到达。

## 行动与状态

- 观众、非行动玩家、托管玩家仍能发指令；页面按钮与服务器权限不一致。
- 点击目标即直接发兵；拖动途经地区触发进攻。
- 出兵数量为负、零或超过可用兵力；招募超过余额；普通快照丢失草稿。
- 来源被占领后仍可提交旧指令；服务端拒绝后错误消失或UI永久忙碌。
- 改变出兵比例导致来源／目标错位；快速连续提交重复扣兵。
- 同领土增援、敌领土进攻及海路标识混淆；无连接地区伪装成可达。
- 暂停后继续倒计时、电脑仍行动；恢复后重置对局或重播动画。
- 回合推进、提交状态和结算切换造成地图／操作区跳动。

## 可见性与可访问性

- 320px 手机横向溢出；主要操作位于滚动按钮容器内或被提示挤出。
- 兵力数字随整图缩小而不可辨认；所有数字重叠导致无法点击。
- 玩家资源只存在DOM中实际被裁掉；零金币不显示；操作后资源滞后。
- 当前玩家与其他势力难以区分；只有颜色没有邻近名称／无障碍标签。
- 文字与真实背景对比不足；禁用按钮整块低透明度导致不可读。
- 地区不能用键盘选择，焦点不可见；输入数字时快捷键误触进攻。
- 自定义游戏结算横条挤动棋盘；关闭平台结算后普通更新自动重开。

## 证据

`accept_ui.py` 在真实应用服务执行，保存运行参数、HTTP快照、几何位置、原生鼠标／触摸结果和桌面／320px截图到 `.local/conquest/browser/`。每个失败均让脚本返回非零。随机局保存开局快照，服务端规则完整对局另由后端E2E验证。

## 财政显示回归（修复前列出）

- 本人金币负债（包括 -10000 和恰好 -1）被当作敌方隐藏值显示为问号。
- 本人可用金币为负值时，被格式化成未知或零，掩盖无法负担行动的原因。
- 金币为 0 被空值分支隐藏；对手财政的 -1 哨兵被显示成真实负债。
- 观众借用任一席位身份看到私人财政；普通公开兵力仍须保留 -1 表示未知的规则。

本回归先以实际 PlayerSummary 的 React 渲染测试验证本人、他人和观众视图，再修改格式逻辑。镜头与数值纯函数检查不能替代真实浏览器可见性验收。
