# 征服时代地图

世界与欧洲共用一套地区数据结构和规则。世界图有 206 个地区，欧洲及地中海周边图有 75 个地区。地图由 Natural Earth 公有领域地理数据生成；不是原游戏商业地图的提取或描摹，也不声称恢复其原始行政区划。

地理边界使用 1:110m 的概略比例。较大国家按经纬线划为带「东部／西部／北部／南部」等明确地理名称的游戏地区，不将这些划分称为真实省份。世界图不包含南极与无对局意义的偏远南大洋领地。欧洲图包含北非、地中海与近东边缘，以保留海路和多方向扩张。

## 生成与校验

```sh
python3 -B games/conquest/maps/generate.py
python3 -B games/conquest/tests/map_contract_test.py
```

生成使用仓库内固定 SHA-256 的地理源文件，不依赖网络、系统 GIS 或第三方 Python 包。`--check` 比较重新生成后的逐字节结果。来源及许可链接见 `sources.json`。

陆地连接由实际共享的边界线段生成，包括生成的地区分界和飞地边界；接触一个点不足以建立边。海路在生成器的 `SEA` 表中明确列出两端和地理名称，不使用自动「最近地区」补齐。绘制海路时在已指定的两区中选择近岸端点，并验证沿线采样点位于水域。跨越世界左右边界的线路分段显示，避免在整个大陆上画直线。每图必须完全连通，否则生成失败。

区域 ID、路径、标签、邻接和开局位置都来自同一份 JSON。Go 使用本目录的嵌入数据，前端按当前地图动态导入。标签使用主陆块内部离边界较远的位置，不以多边形外部质心代替；小地区的命中和放大由前端完成。

测试在地图实现前编写，失败场景见 `../tests/map-scenarios.md`。验证产物写入 `.local/conquest-maps/validation.json`。该检查覆盖资料、连通性与确定性；完整电脑对局、公平性和实际手机命中由游戏 E2E 继续验收。
