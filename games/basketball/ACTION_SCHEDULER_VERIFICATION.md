# 原版对象动作调度验证

实现前失败场景：

- 固定按 0～12 各执行一次，遗漏依附对象优先执行或人物同一步重访。
- 把链接值 0 当成「依附于对象 0」，或只看高位而忽略原已处理位。
- 父对象执行后没有重新读取链接，错误使用步骤开始时的依附快照。
- 回到根对象搜索时没有再次标记篮球已处理，提前把球混入人物遍历。
- 篮球尾阶段或某个篮筐修改链接后，错误重新开始人物搜索。
- 接受对象动作输出的链接时顺便回填位置或动作，掩盖物理缺失。

证据为固定 `$E130/$E15A` 的 REA 指令档案，以及原 6,000 帧参考场景中 `$D345/$D348` 之间每次 `$E18B` 的实际调用。测试仅验证调度，动作处理后的链接作为显式外部反馈，不把它描述成完整世界物理回放。
