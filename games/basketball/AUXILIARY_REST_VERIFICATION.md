# 辅助对象静置与下落验收

实现前失败场景：

- 动作 0 被当作空操作，遗漏首次清平面速度、设置已进入标志、物理更新。
- 直接复用玩家 X 边界，把纽约辅助对象 X48 错误挤到 X56；辅助对象应使用 X47／480 阈值，越界重置48／479并保留小数。
- 静置首次进入错误清空动画状态，或者 owner>=7 时未将对应对象姿态设为2。
- 空中且 owner<0 且无负附着时，应在物理后转动作12；顺序或 owner 符号判断错误。
- 动作12进入后竖直速度应为1/16像素、重力1/2像素，owner和对象独立关联字段清为-1；错误使用普通人物下落冲量。
- 动作12应在物理前读取已有离地标志决定转回动作0，不能提前一帧按本次落地结果切换。
- 未恢复的携带、抛掷、附着运动或其他场地静默当作静置。

复用 REA 对 `$B029` 的既有分析，并独立批量查询 `$B3C1`、物理及纽约边界辅助函数。原采样保留 6000 帧中对象4/5的全部动作0/12单次调用，并核对完整RAM。
