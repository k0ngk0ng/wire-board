# 真人动作输入验收

实现前失败场景：

- 以已实现动作白名单拒绝Falling、攻击、落地等原本共用输入路径的动作。
- 所有攻击动作应共用原方向计时；低四位2的移动反向刹车与普通双击分派混淆。
- A/B延迟两次输入更新合并，连续按键与A+B顺序造成多次触发或漏触发。
- 空中A/B应在原地面请求基础上增加1；持球A为传球、B为瞄准，放开B触发出手。
- A+B空中首次设置JumpPhase80，重复起跳应按原阶段／角色增强条件拒绝，不能自造无限二段跳。
- 近物搜索必须按对象4..12顺序和原坐标窗口，不使用最近物体；0634写入必须输出给Prep.Contacts.Marks，不能另建持久副本。
- 附着父对象的种类／离地状态、人物携带与持球／持筐请求分组错误；未恢复的辅助物操作不得默默转为普通攻击。
- 输入更新中改变身体位置、速度、得分，或原子失败留下世界／标记命令。

自然验证场景共3360帧：自由移动连续按键1800帧、持球起始1200帧、持球起跳和空中按键360帧。每场先执行未插桩参考，再记录805C..8085单调用；全部场景完整RAM一致。1117个调用全部保留，测试先于实现。
