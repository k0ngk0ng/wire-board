# 疯狂坦克重构浏览器验收

本清单先于浏览器脚本和夹具编写。采用真实生产 HTTP、SQLite、系统时钟、规则模块及浏览器；只允许测试服务器在开局时安排明确标注的初始局面。禁止注入前端对局数据、伪造 `/api/state` 或推进浏览器／服务端时钟。

## 必须失败的场景

1. 冷缓存或前景比背景晚到时，战场呈现可穿越的空白地形；前景加载完成后未重绘。比较地形画布的指定实心区域及其映射到主画布后的实际像素，不以整图色彩数量代替地形验证。
2. 图片请求全部失败时无可辨认地形／坦克；CDN 失败后未回退本地文件。
3. 空格／鼠标／手机触摸按下立即开炮；长短按力道相同；松手或按键重复产生多发；取消、失焦、回合变化后松手误开炮。原版二阶段证据明确后新增：按每车 Range 以项目 30 Hz 计时，从 0 蓄力，充满自动且仅发射一次，之后松手不能二发。
4. 地图点击开炮；拖动后误瞄准／开炮；原生左拖、滚轮锚点缩放、触屏单指／双指、小地图连续拖动不生效；地图外滚轮不能滚动页面。
5. 无先存火毒危险区的可控初始局面中，飞行期间公共玩家栏 HP、地形、坐标、存活或结算提前变化。逐帧记录公开快照、服务端时间、Canvas 绘制坐标和公共栏实测值。
6. 发射前摇的 334 ms 提前显示炮弹；launchAt 已过去 250 ms 仍未由真实主机发布 shot 事件；命中后没有弹坑／伤害；落地中的坦克瞬移；最终 HP、死亡或结算先于服务端落地节点出现；画布轨迹与服务器公开 falls 不一致。
7. 飞行／落地阶段直接 API 或电脑能行动；下一回合没有完整操作时间；中途刷新重新播放弹道或重置期限。
8. 结算关闭后普通快照重新弹出；打开／关闭结果导致棋盘跳动；同一动作阶段公共提示文字切换挤动棋盘。
9. 1280px、超宽屏或 320×844 下地图比例失真、画布过宽、关键公共 HP 被裁切；零 HP 不可见；正文或禁用控件实际对比度不足。
10. 两真人可控射击、真人与电脑混合、托管／手动接管或恢复后无法继续对局。浏览器选择平地、浮空、高落差代表地图；17 图／14 车型完整矩阵由对应服务端验收承担。

11. 回血弹道具点击立即加血、炮弹还在飞就出现绿色回血数字、命中时无真实 heal 事件或公共生命值不更新；回血弹不得制造弹坑。
12. 火／毒地面区域早于 impact 出现、跟随坦克移动、在 server endAt 后仍可见；周期伤害早于对应 status.at 或没有真实公开事件；后续弹坑移除支撑时仍在空中绘制。独立记录已有危险区在下一发飞行期间继续作用，不能将真实周期伤害误判成该炮提前命中。

13. 射手在 334 ms 前摇中被真实地面伤害击毁后仍发炮、追踪不存在的炮弹、发出 shot／explode 事件或在重连后重播；开局安排真实危险区下一 tick，按实时时钟用原生按键释放，禁止修改运行中数据制造死亡。

14. 同一地面危险区在前摇末段造成非致命伤害，受击动画覆盖原版 Fire 第 5 帧；在 launchAt 至 launchAt+67 ms 读取实际 Canvas 的 action/sourceIndex，必须为该方向和坡度的原帧，伤害数字和生命仍按真实 status 事件更新。

## 产物和复跑

`python3 scripts/fortressblue/check-refactor.py --build`（已有相同源码构建可省略 `--build`）。旧 `check-browser.py` 转发到此入口。每次生成独立 `.local/fortressblue/refactor-browser-*`，保存 `report.json`、初始局面及校准射击输入、逐帧 JSON、关键截图、短录像和可重跑命令。临时数据库、浏览器 profile/socket、编译临时文件在验收后删除；保留有证据价值的结果，不覆盖旧 `.local/fortressblue/browser`。

本脚本不声称复刻未经原版运行证明的精确伤害、delay、弹种或蓄力常数。参考边界见 `docs/research/fortressblue-refactor/reference.md`。
