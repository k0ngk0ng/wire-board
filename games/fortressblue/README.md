# 疯狂坦克（fortressblue）

2／4／6／8 人的回合制坦克炮战，使用《Fortress 2 BLUE》的 17 张地图与 14 种坦克素材，支持可破坏地形、双武器、蓄力射击、电脑玩家、托管、观战和断线恢复。当前重构依据官方公开画面、客户端配置和 REA 原生分析修正操作与演出；尚未确认的原版物理、Delay 和精确时钟不标为已还原。

## 规则与操作

- 前一半席位为红队，后一半为蓝队；当前采用固定红蓝交错次序，跳过阵亡坦克。原版 Delay 排序公式尚未取得，不用虚构等待值代替。
- 开局有 20 秒选坦克；全部选定或超时后，在各队一侧的外部顶面选择安全出生点，再进入对局。出生点检查真实移动碰撞体、支撑、可移动方向和有效射界，避免旧坐标将坦克放进低层洞穴。每回合默认 60 秒，房间可设置 15～60 秒。移动消耗移动力，开火后等待发射、飞行、命中和落地结束，再开始下一回合。
- 普通弹和特殊弹是两种武器模式，新局均不限制发数。每车最小／最大角度取自客户端 `character.txt`；炮角相对车身计算，实际发射方向叠加当前坡度，角度盘随车身变化；界面力度为 0～100。旧存档的有限特殊弹按旧库存兼容。
- 按住空格或「按住蓄力」按钮从 0 蓄力，松开发射；达到满力自动且只发射一次。蓄力上限使用每车 `Range` 更新计数，换算采用项目 30 Hz 时钟，原版精确更新频率仍未知。上一发力度保留为标记。失焦、隐藏页面、取消手势、交接控制权或回合变化会取消未发射的蓄力。
- PC 使用 ←／→ 或 A／D 连续移动，↑／↓ 或 W／S 调角度，Q／E 切换弹种，Escape 取消蓄力。点击战场只调整瞄准；鼠标左拖平移，滚轮以指针为锚点缩放。手机使用方向按钮、角度控件和按住蓄力按钮；地图支持单指平移、双指缩放。小地图支持连续拖动定位，复位按钮恢复自动跟随。
- 每名玩家开局获得两件不同道具；四槽底栏显示当前库存，使用道具不结束回合。回血按最大生命百分比计算，能量补充弹在下一发命中后为落点附近双方坦克回血。完整道具表见 [CONTRACT.md](CONTRACT.md)。
- 炮弹与坦克使用同一份可见地形碰撞位图；悬空地块同样挡弹。命中才产生伤害和弹坑，失去支撑后按服务端落地时间结算坠落。火／毒留在落点地面并持续作用，离开区域后不再受该区域伤害。
- 8 分钟后进入决胜阶段，12 分钟按双方存活坦克总生命判定；双方同时全灭或限时生命相等为平台显式和局。这些时限、伤害及友伤规则属于本项目规则，不能据此宣称与原版全部一致。

## 画面与时间轴

战场使用近景镜头、角度盘、生命／力度／移动力仪表、弹种按钮及道具槽。不开启落点或完整弹道预览。坦克动画与炮弹按原始锚点及地图一致的世界比例绘制，辨识度通过镜头取景调整；保持公共玩家栏、回合提示和统一结算浮层。

坦克图集 v3 包含原生动作和坡度变体。发射请求先播放准备动作，项目校准的 334 ms 后才出膛；飞行、伤害、弹坑、落地和死亡使用服务端时间。原版只确认每两次更新推进动画及 Fire 第 5 帧出膛，334 ms 不是原版实测值。准备出膛期间若射手死亡，服务端取消尚未发出的炮弹并记录 `cancelledAt`；已经出膛的炮弹继续飞行。刷新或恢复继续当前时间轴，不从头重播已发生动作。音频统一通过 `BoardProps.audio`。

## 实现与证据

- `server/`：规则、碰撞、弹道、阶段时钟、地面效果及电脑策略。
- `maps/`、`data/`：地图碰撞、原始角色属性、道具说明和动画元数据。
- `web/`：Canvas 战场、原生动画、蓄力输入、镜头及操作底栏。
- `tests/`：模块完整对局、HTTP／SQLite、恢复、时间轴及交互验收。
- `assets/`：来源、SHA-256、v2 媒体与 v3 动画图集；封面保持本项目原创 SVG。

原版证据见[官方画面参考](../../docs/research/fortressblue-refactor/reference.md)、[REA 原生分析](../../docs/research/fortressblue-refactor/native-findings.md)和[原生动画图集](assets/README-v3.md)。[阶段接口](../../docs/research/fortressblue-refactor/implementation-contract.md)记录服务端时间轴；[CONTRACT.md](CONTRACT.md)描述当前实际协议及失败场景。历史[素材获取记录](../../docs/fortressblue-original-acquisition.md)保留获取过程，旧的玩法／精确复刻表述不覆盖本契约。

原版服务端 Delay、全部炮弹的精确重力／风力／伤害公式、原版更新频率、特定房间武器配额和回血弹精确半径仍未确认。当前固定回合顺序、物理常数、时间换算和地面效果数值均为明确的重构选择。

## 本地检查

仅运行疯狂坦克及本次影响到的公共检查，不扩大为全部游戏矩阵：

```sh
. scripts/env.sh
go test -count=1 ./games/fortressblue/...
go test -race -count=1 ./games/fortressblue/...
npm --prefix web run build
python3 -B scripts/check_game_boundaries.py
python3 -B scripts/fortressblue/verify-assets.py --dist
python3 -B scripts/fortressblue/check-refactor.py
```

本轮最终结果见[重构验收报告](../../docs/research/fortressblue-refactor/verification.md)。浏览器验收范围及复跑方式见 [BROWSER_REFACTOR_SCENARIOS.md](tests/BROWSER_REFACTOR_SCENARIOS.md)。脚本输出独立的 `.local/fortressblue/refactor-browser-*`，保留报告、截图、录像和逐帧记录。需要从原包复核时运行 `verify-original-source.py` 或 `verify-animation-assets.py`；这些源素材检查依赖已取得的本地客户端，不是干净检出的必需依赖。

原素材版权归原权利方，来源、转换与逐文件哈希见 `assets/sources.json`、`assets/manifest.json` 和 `assets/manifest-v3.json`。发布范围沿用会话授权和仓库素材约定。游戏默认上架，管理员可显式下架。


电脑难度可选简单、普通、困难，新房间默认普通；托管与电脑席位使用同一难度。困难保留此前策略，降低难度只降低瞄准精度，不改变坦克属性。原进行中存档保持困难。

比赛中直升机间歇送来随机补给。木箱落地后，两队坦克都可以靠近拾取；库存最多 4 格，满格时箱子留在地面，使用道具腾出位置后可再拾取。补给只加入库存，须按正常道具操作使用。小地图金色标记显示补给位置。

各车二号弹现在有独立外观和效果：包括散射、下降后锁定、地雷、波动光束、离子炮、移动限制和萨满同队治疗。不同弹体分别飞行和命中，不在第一枚落地时提前结算整组。地雷对敌方隐藏，但不因同队就免于触发；萨满电脑会治疗受伤友军，全员满血时使用普通弹。
