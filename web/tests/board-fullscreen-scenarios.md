# 公共全屏与棋盘布局验收

先列失败场景，再修改全屏和棋盘布局。验收仅使用实际 Board 组件、真实 DOM／原生事件和既有本地验收局面的匿名化静态视图，不执行游戏规则或完整对局。

- 非 CS 游戏仍被公共 sticky 顶栏与外围 padding 挤小，退出操作占整行；重要回合状态或保存入口被直接删除。
- 退出浮层覆盖右上按钮或已标记的关键 HUD；通过给所有游戏统一加大 padding 规避问题，反而缩小棋盘。
- 五子棋／围棋的固定视区高度、国际象棋／中国象棋的 620 px 列上限、军棋的 480／800 px 列与固定高度，在全屏仍限制棋盘；窄屏长操作面板把棋盘挤出屏幕。
- 棋盘没有按剩余宽高放大，出现无必要的大空白；为填满空间破坏方形、9:10 或军棋原图比例。
- 五子棋在小屏全屏仍强制 480 px 初始细节宽度，无法查看整盘；缩放与选点混同，概览误落子。
- 确认、认输、和棋、围棋停一手／数子、军棋布阵等必要操作不可达；聊天遮挡、无法编辑、退出后草稿丢失。
- native 与 page 回退尺寸不一致，旋转、Duo、Pad 或退出时残留滚动锁／inert，ESC 不再传给游戏，原 Board DOM 被重建或选择丢失。
- 浮层碰撞计算接受非整数几何或越界，不保留安全边缘，在完全无空位时静默声称已避让。

重放：`node --test web/tests/fullscreen-overlay.test.mjs`；`node --test web/tests/board-fullscreen-browser.test.mjs`。布局产物位于 `.local/room-tools-followup/fullscreen/`，不冒充实体手机或完整棋局验收。
