# 游戏内触控浮层验收

用户明确要求 FC、MD 及其他独立控制器区域在手机上尝试移入游戏区，使用半透明控件，并让主要控件尽量贴近底部安全边缘。当前实际外置消费者为魂斗罗、热血篮球、幽游白书和坦克大战；仙剑、当前赛车模式和迈阿密热线的主要触控已位于游戏区内。

预先失败场景：

- 仍为控制器保留独立一行，横屏全屏画面因此缩小；改变画面宽高比或在大画面中拉伸源像素。
- FC 上排 Turbo B／Turbo A、下排 B／A 或 MD 六键缺失，方向键、辅助键小于 44 px；配置界面或 PC 的原手柄样式被手机规则覆盖。
- 控件落在游戏区外，被其他控件、体力条、聊天或全屏工具栏覆盖；竖屏没有安全操作区域。
- 底板不透明，或通过降低整个控制器透明度使文字无法辨认；半透明背景与文字必须分别定义。
- 原生方向与攻击不能同时按下，松开一指释放了其他手指；换键、禁用、失焦和配置切换仍保留旧输入。
- 跨页面复用浏览器时继承了旧触点，测试把上一场未清理的原生输入误判为新页面故障。每组先取消遗留触点，单指结束传入该次实际结束的触点，所有释放断言仍在清理前执行。
- 坦克大战的队伍、装甲或方形战场被控制器挤出视区；触控浮层不能改变规则和输入接口。
- 误触、无效操作或短暂输入失败在游戏中弹出错误横幅、红字或错误弹窗；无法继续加载时只保留重试入口，账号和房间表单校验保持原作用域。
- PC 主指针为 fine 时仍显示 FC／MD 手柄或独立触屏区，普通与全屏都为控制器预留空行；窄 PC 窗口被误当成手机。
- 手机、Pad 与 Duo 的 coarse 主指针被桌面隐藏样式误伤；在切为 fine 隐藏控件后仍保留旧触点，重新切回触屏时误继续移动或攻击。
- 控制器设置页的 FC／MD 配置图被游玩模式的隐藏样式覆盖；键盘与实体手柄映射被触屏显示条件禁用。

复跑入口为 `node web/tests/controller-overlay-browser.mjs`，使用真实 FC／MD 控制器、坦克触控组件和各游戏样式，在 320 px 竖屏与手机横屏验证原生多指并保存截图。结果分别写入 `.local/<game-id>/controller-overlay/`。该入口验证界面和触点，不冒充完整规则对局或实体手机；幽游白书另保留 `games/yuyuhakusho/tests/md-touch-browser.mjs` 的完整六键组合验收。
