# 平台空间短音效失败场景

先登记场景、编写接口测试并保留失败记录，再实现平台能力。范围为 `GameAudioPort.spatial`、`spatialListener`、`stopSpatial`，以及公共音频生命周期；游戏继续使用平台音频，不自行建立播放器。

| 场景 | 预期 |
| --- | --- |
| 声源位于听者左右、听者旋转或移动 | 原生 StereoPanner 声像和三维距离衰减随之变化；不重播、不重建源 |
| 播放路径 | AudioBufferSource 经 Gain、StereoPanner 和 MediaStreamDestination 进入平台原生 HTMLAudioElement；不连接 AudioContext.destination |
| 同一 key 与 playbackID 重复、音效已经结束或显式停止 | 不重复播放；新事件可以复用已解码缓冲 |
| 静音、主音量为零、页面隐藏、暂停、离桌、换房或媒体失败 | 立即取消短声与待解码工作；取消静音或恢复后不补播旧事件 |
| 旧解码或原生 play 延迟完成 | 不能复活已经取消的声音或影响新房间 |
| 同时大量短声、持续产生不同事件或来源 | 活跃声音、解码缓存、身份历史均有明确上限 |
| 来源失败、无效音频、超大资源、坐标非有限、无效距离或空标识 | 返回失败并清理；无效请求不创建输出设备 |
| 资源加载过慢 | 超过 250 ms 的短声不延迟补播 |
| 浏览器不提供所需空间音频能力或播放被拒绝 | 返回失败，不尝试直连物理输出；新用户操作只解锁后续新事件 |
| 主音量变化 | 调整原生媒体音量，不重启短声或改变各声源相对衰减 |

空间坐标沿用 GoldSrc：x/y 为水平面、z 为高度；yaw 使用弧度，0 朝 +x，π/2 朝 +y。正声像为右侧。距离单位与位置一致，默认最大距离为 2400。音量、声像与衰减仅用于呈现。

复跑：`node --test web/tests/audio-spatial.test.mjs`。此测试通过假的浏览器原生节点验证公共接口、实际连接图、声像参数和取消行为，不能作为实体扬声器或手机音频实测。

产物位于 `.local/cs16/verification/audio/`。
