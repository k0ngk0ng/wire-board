# 通用结算与房间工具验收

先登记失败场景，再编写测试和实现。验收使用完整前端、真实 HTTP／SQLite／WebSocket 服务和现有游戏模块；只验证公共交互，不运行游戏规则矩阵。

| 范围 | 失败场景 |
| --- | --- |
| 一键创建 | 选择游戏后仍出现设置页或要求输入名称；默认名称未使用创建者昵称；重复点击创建多个房间；创建失败后不能重试；未上架游戏可创建；窄屏选游戏或进房间横向溢出 |
| 房间人数 | 房主无法增减人数；固定人数游戏出现非法人数；人数小于已入座人数仍保存；非房主或开局后修改成功；过期版本覆盖新设置；失败时部分保存；刷新后丢失；真人准备未清除或电脑准备被清除；地图、双人及五六人规则与人数不匹配；由准备界面管理规则的游戏未同步角色和队伍数组 |
| 房间密码 | 一键创建后无法设置、替换或移除密码；未修改密码却被清空；密码明文进入快照或操作日志；非房主可修改；修改失败影响原设置 |
| 结果展示 | 结束后未自动展示；点击遮罩或按 Escape 误关；仍有含义不清的关闭按钮；收起后无法重新查看；普通状态刷新重开；新一局结束不再展示；重新加载丢失结果 |
| 返回房间 | 按钮名称过长或使用特定游戏类型的术语；非房主或观战者能重置房间；房主交接后权限未更新；返回时房间号、名称、密码、规则或有效席位丢失；自动开始下一局 |
| 离开房间 | 一次点击直接退出；默认焦点落在确认离开；取消或点击确认框外仍退出；最后一位真人离开时未说明房间关闭；多名玩家时错误提示关闭；确认期间状态更新导致操作旧房间 |
| 图标工具 | 整组房间操作仍有文字按钮，包括对局日志、邀请、结束、离开／观战、保存／读档／重新开始；无可访问名称；悬停提示延迟过长或被裁切；键盘无法识别用途；手机点击目标过小或触摸无效；等待房间仍出现全屏；托管状态和名称不随实际状态切换；操作失效 |
| 布局与全屏 | 320 px 横向溢出；结果或按钮被遮挡；文字对比不足；全屏结果位于游戏区域外；切换全屏重置对局 |
| 静态规范 | 新增代码含注释、目录或文件命名不合规、标识符使用下划线、动态执行字符串；lint 只测正例，未拒绝违规输入 |
| 发布检查 | 完整前端浏览器验收未安装项目声明的 Go 版本或未恢复共享编译资源；CI 的 Chromium 沙箱限制导致浏览器启动失败；失败日志未包含浏览器错误或截图报告未归档；lint 入口变更错误触发游戏规则矩阵；隔离发布目录过长导致浏览器 socket 无法启动 |

测试入口：`node --test web/tests/room-flow-browser.test.mjs`。报告和截图保存在 `.local/room-flow/verification/`，浏览器 profile、临时服务和缓存均限制在工作区内。报告标明桌面鼠标和 Chromium 触摸模拟的范围。

静态检查范围为 `web/scripts/room-ui-lint.mjs` 登记的公共结算、离开确认、图标按钮及本次测试文件，不能代表全仓库 lint。
