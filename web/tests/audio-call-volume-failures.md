# 单次平台音量失败场景

先登记失败场景，再编写测试和实现。范围为平台 `GameAudioPort.play` 与 `music` 的可选 `volume`，不新增播放器。

| 场景 | 预期 |
| --- | --- |
| 未传单次音量 | 沿用原有主音量，旧调用行为不变 |
| 音效、音乐同时使用不同音量 | 各自与平台主音量相乘，互不覆盖 |
| 队列进入下一段、源失败回退或暂停后继续 | 保留本次请求音量；新请求未传值时恢复默认比例 |
| 同一音乐来源与播放标识更新音量 | 只调整原生媒体音量，不重播、不跳转播放位置 |
| 旧异步请求晚于新请求返回 | 不覆盖新请求音量，也不能恢复已取消声音 |
| 全局静音、零主音量或离桌清理 | 停止并清空待播声音；取消静音不补播 |
| 单次音量为零 | 允许静音媒体继续时间轴，后续同标识增益更新不重播 |
| 单次音量超出范围 | 有限值限制在 0～1；非有限值拒绝且不改变已有播放 |

验证命令：`node --test web/tests/platform-audio-call-volume.test.mjs`。本次验证记录位于 `.local/pokepath/verification/audio-call-volume-*.log`。
