# 登录页验收场景

实现前冻结以下失败场景：主视觉地址未登记或未使用公共 OSS 命名空间；图片缺失导致布局坍塌；登录字段或请求改变；邀请码注册缺失；确认密码不一致仍提交；邀请房间提示丢失；忙碌状态可重复提交；错误不可访问；更新日志入口消失；320 px 下横向溢出、输入框或按钮小于 44 px；桌面图文区域与参考失配；页面依赖外部字体服务。

先运行 `node --test web/tests/auth-page.test.mjs` 验证组件和资源登记。再以实际登录组件执行桌面与 320 px 浏览器操作，保留登录、注册、校验、忙碌、错误、邀请状态的结果及截图。运行时图片须完成本地 CDN 回读，原稿保存在 `.local/_common/login/source/`。
