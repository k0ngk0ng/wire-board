# 对局行动作用域开发前失败场景

本清单先于异步行动作用域实现建立。作用域包含账号、服务器实例、房间、席位身份、对局标识、设置代次、游戏 epoch 与控制身份，不使用帧号或普通房间版本作为身份。

- 旧房间的延迟拒绝覆盖新房间全屏，或旧错误已经显示后仍残留在新房间。
- 离开、结束、再来一局和离开观战意图发出后，尚未收到服务器状态期间继续发送旧输入。
- 离开操作失败后无法恢复当前控制，或者恢复后让意图前的旧 Promise 再次有效。
- 同房间 epoch、服务器实例、对局或席位改变后接受旧失败；离开后回到相同 ID 时误接受旧 token。
- 用每个帧或版本更新使当前业务错误失效，掩盖同房真实 400 错误。
- 把旧失败变成成功，破坏控制器的松开／重同步；把所有 400 错误标记成暂态错误。
- 清除旧作用域错误时删除新的登录错误、网络错误或其他未归属该作用域的消息，即使两条文案相同。
- WS 游戏包更新 epoch 晚于 Promise 失败回调才更新作用域，或者依据过期渲染闭包发出新房间的错误。
- 作用域保存无限请求、错误或历史记录；卸载后仍显示旧行动错误。
