# 公共新增源码 lint 开发前失败场景

本检查只覆盖 `web/scripts/platform-source-lint.json` 登记的新公共文件与既有文件新增行，不代表全仓库或全部公共前端通过。入口不导入任何游戏代码，不运行游戏规则或素材恢复。

- 新增空间音频、默认人数与检查器本身缺少命名、无注释、语法和禁用写法检查；新增源文件缺失时被静默跳过。
- 共享音频直接连到 AudioContext 的物理设备目标，或使用下标、别名绕过原生媒体通道约束。
- 非平台音频实现自行创建播放器；公共源码依赖某个游戏的实现；使用动态执行或 TypeScript `any`。
- 注释样式的字符串、URL、测试中的物理目标反向断言被误报。
- 既有 `audio.ts`、`game-api/module.ts` 和 `host.tsx` 的旧注释导致失败，或新增行中的注释与错误命名未被检查。
- 原生媒体通道允许浮点空间表现计算，默认人数等业务助手却使用小数边界或非确定性随机数。
- 检查器或测试把临时产物写到系统默认目录、其他游戏目录或工作区外。
- 只修改公共 lint 脚本时未启动公共前端检查，或者因此触发所有游戏的检查。

复跑：`node --test web/tests/platform-source-lint.test.mjs`。测试产物位于 `.local/cs16/verification/lint/platform-source.json`。
