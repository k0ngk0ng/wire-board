# 页面图片直接使用 CDN

实现前列出的失败场景：封面或登录主视觉仍输出站内相对路径；带入 AssetsContext 导致 CDN 地址被再次拼接；直接地址与已验证资源清单的摘要或游戏归属不符；切换 CDN 配置后地址没有更新；正式构建缺少 CDN 配置时退回站内跳转；图片请求仍经过应用服务器；本地开发没有发布配置时无法读取本地素材；重复上传已发布图片。

组件检查覆盖全部 32 款封面、旧版房间入口、运行模块加载后的封面以及登录主视觉。浏览器验收显式启用 CDN，拒绝所有站内图片路径，要求 33 张图片直接使用已验证的 CDN 内容地址并完整解码；保留原始 src、实际资源请求和应用服务器图片请求数。此浏览器检查仅在本地显式执行，普通 CI 不下载 CDN 图片。
