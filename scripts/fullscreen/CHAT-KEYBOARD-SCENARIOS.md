# 全屏聊天软键盘视区失败场景

实现前记录。

- iPad 软键盘缩小可见视区并向下平移时，不能把全屏根节点高度再次当成可见视区裁剪，导致面板被压成一条线。
- 输入框、发送、关闭按钮始终在可见视区内且可命中；面板保持可输入高度，消息区域滚动，不能把编辑区挤没。
- 弹出、收起、重复切换、横竖屏和暂态零尺寸后重新测量；收起键盘恢复正常面板高度，不保留压缩后的错误尺寸。
- 自动聚焦不滚动游戏或页面；视区调整不重建输入框、不丢草稿／选区、不重复发送、不改变未读状态。
- 原生与网页全屏回退、正常页面、拖动后的聊天位置和退出全屏都可恢复。

E2E 使用真实 Chat／GameFullscreen 组件和原生点击／输入。输入传输是本地可控接收端；VisualViewport 尺寸、偏移与页面全屏根节点瞬时收缩由测试夹具模拟。该记录不代表实体 iPad 或 Safari 键盘验收。
