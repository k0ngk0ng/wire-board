# 浏览器运行层先行验收

- 标准新局从 `NewSession` 建立，保留原始生命／续关；进入 Intro 后由原生 Start 输入进入第一关，不读 ROM 执行或录制后态。
- 原生键盘按键通过 `/api/controllers` 的 `classic-2` 配置与公共 Turbo 采样，实际改变服务端位置并创建弹丸；输入框、失焦和页面隐藏释放输入。
- 320 px 下使用公共 FCController，原生鼠标／多指触摸操作方向、B／A；键盘与触摸不互相清空。
- 原生 Go 服务端始终权威；相同已接受输入由 Go/Wasm 重放，比较 Go 规范化状态摘要。浏览器不能上传结果／状态覆盖服务器。
- epoch 错误、跳帧、非法按键与未知字段拒绝且不改变状态；重复帧不重复推进；正式对局结局只在 FlushTerminal 完成后公开。
- 代码、当前关卡、Intro 与已请求 CHR 页校验成功并完成首次绘制后才就绪；不能固定延时假进度或预下载八关／全部音乐。
- Canvas 使用现有纯背景／OAM 渲染器，只消费 Session 呈现；保存 Intro、第一关、桌面、320 px 截图及真实输入、资源请求、native/Wasm 摘要结果。
- 音频复用 BoardProps.audio 和现有 ContraAudioAdapter；开发夹具可实例化公共 GameAudio 宿主，但游戏运行层不创建播放器或新的控制器设置。
- 这是一款未注册游戏的开发入口，验收范围是标准新局、Intro 与首关移动／射击，不宣称八关、联机或正式发布验收完成。
