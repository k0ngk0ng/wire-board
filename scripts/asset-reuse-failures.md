# 资源复用的先行失败清单

在实现前验证以下场景：未变资源换地址或重复 PUT；同批相同内容重复上传；只改一份内容导致其他文件换地址；改名后不能复用；同名但内容不同误复用；大小、SHA-256、MIME 或 Content-Encoding 不匹配仍复用；原地址已损坏时覆盖或绕过；历史引用被删除；清单路径或 URL 注入私密路径、查询参数、站外地址；清单引用与本地文件不一致仍剥离；JS/CSS/HTML 的资源引用与最终清单不同；音频跳转丢失 Range；运行时清单跳到旧内容；素材写入工作区外。

检查通过后保留逐文件 URL 映射、复用／新增对象数和传输字节数。相同资源集合再次发布须产生零新增对象和零上传字节；旧版本对象不删除。生产基线来自已部署的清单并绑定已成功的本地 CDN 回读状态；Actions 仅读取发布元数据并核验 OSS，不进行 CDN 资源回读。
