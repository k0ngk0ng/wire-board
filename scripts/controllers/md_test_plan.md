# MD 控制器验收范围

本清单和验收入口先于本次控制器实现。用户要求新增 MD 六键型号、保留 FC 默认布局使用的键盘位置并增加 O/L，同时移除没有游戏使用的 SFC 型号。

默认：方向 W/S/A/D；Mode=F，Start=空格；B=J、A=K、C=L；X=U、Y=I、Z=O。MD 的 X/Y/Z 为普通键；FC 的 U/I 仍为连发 B/A。

失败场景：型号目录仍出现 SFC；MD 缺键或默认映射错误；型号和用户配置串用；保存后默认值被污染；删除型号仍接受写入；键位冲突／缺键／过期写入未拒绝；数据库重启后设置丢失；触屏多指覆盖、方向滑动或斜向丢失；失焦、隐藏、禁用、配置改变、卸载未松手；设置弹窗触发游戏；游玩模式显示键盘键位；320px 溢出、重叠命中区、低对比度；MD 按键被误当 FC 连发；共享交互修改使 FC 回归失败。

验收分两层：真实 HTTP／SQLite 覆盖型号、持久化和用户隔离；真实 React Settings 与共享手柄组件通过原生鼠标、键盘、多点触摸验证，保留 PC、320px、设置／游玩截图和几何／计算样式结果。组件夹具不冒称《魔强统一战》游戏已经接入或完整可玩。
