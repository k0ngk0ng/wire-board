# CI 付费下载失败场景

本清单先于实现编写。验收只连接本机 HTTP／HTTPS 服务，禁止消耗线上 OSS／CDN 流量。

## 资源恢复

1. 普通 CI 缓存为空、过期、缺少一个对象或对象损坏时，自动回退到 OSS／CDN 下载。
2. 普通 CI 接受非零下载预算，或旧 `hydrate --oss` 入口绕过缓存门禁。
3. 手动准备缓存未提供预算、预算不足、超过硬上限或预算不是非负整数时，先下载后报错。
4. 一个对象被多个逻辑路径引用时重复下载；下载失败后无上限重试；响应超过登记大小仍继续读取。
5. 手动准备后的缓存未验证 SHA-256、大小和 MIME；后续恢复信任缓存文件名而不重新校验。
6. 路径穿越、符号链接、未知游戏、注册表中的冲突身份或错误编码进入缓存和工作区。
7. 前端构建恢复游戏测试夹具、研究和验收录像；服务器打包恢复公开图片、音频或其他游戏测试资料。
8. 游戏任务恢复其他游戏的测试夹具；共享任务恢复全部游戏的研究资料。
9. 缓存键绑定应用 SHA 或构建日期；无关游戏资源变化导致当前游戏缓存失效。
10. 私有桶的密钥进入缓存、产物或日志；普通恢复步骤仍得到 OSS 密钥。
11. PAL 服务端发行输入或 Fortress 公开资源遗漏，导致构建改为隐式 CDN 回源。
12. 未创建缓存、临时和报告目录；失败后没有记录计划量、实际读取量、缓存命中和缺失对象。

## 发布

1. 重复发布、重命名和批次别名复用仍产生对象 GET 或重复 PUT。
2. 只改变一个文件仍完整读取历史对象和整个外部资源注册表。
3. 已有对象的 ETag、大小、MIME、编码或 SHA-256 元数据不符时仍复用或覆盖。
4. 没有本地正文、可信历史记录或摘要元数据的外部对象被直接当成已验证。
5. 新对象 PUT 未禁止覆盖、未发送 Content-MD5 或摘要元数据；并发 409 导致 GET 回读。
6. 伪造或冲突的历史记录使未验证对象跳过检查；历史外部记录未纳入可信复用清单。
7. 报告只记录上传量，不记录 GET、HEAD、复用对象和下载字节；部分失败被标记为成功。
8. 为节省费用取消本地 CDN 回读、源码与运行时绑定、服务器包边界或版本发布门禁。

## 自动约束

1. 主工作流、扩展验收或研究工作流重新加入直接恢复或静默付费回源。
2. 缓存缺失使用 `continue-on-error`，或手动缓存入口可以由 push、定时或工作流调用触发。
3. 资源恢复和发布工具改动没有执行流量 E2E 与 lint；命名、目录和禁止代码注释只写在文档。
4. lint 不验证自身正负例，或仅用文本中存在某个关键词证明实际没有付费下载。

复跑入口：`python3 -B scripts/ci/resources_e2e_test.py`、`python3 -B scripts/ci/cdn_concurrency_e2e_test.py`、`python3 -B scripts/ci/traffic_lint.py --self-test`。结果保存在 `.local/ci-traffic/`。
