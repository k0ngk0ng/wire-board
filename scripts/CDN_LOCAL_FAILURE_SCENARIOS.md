# CDN 本地回读先行失败场景

- GitHub Actions 的发布资源步骤仍从 CDN 下载或做 Range 校验，受跨区域网络影响；即使仅上传也标记为 CDN 已验证。
- 本地运行误用另一次构建、其他提交或重新构建的资源，回读结果不能对应正式 Linux 产物。
- 缺失、失败、旧构建编号或其他提交的本地回读状态仍放行版本发布。
- 上传失败、资源清单或编译入口改变后仍生成成功记录或剥离不匹配资源。
- 将回读搬到本地后丢失 SHA-256、大小、MIME、CORS、音频 Range 或服务器包边界检查。

Actions 产出资源候选与服务器包；本地从同一次构建下载资源并回读验证，通过后写入绑定提交和构建编号的发布状态。tag 发布必须检查该状态。隔离测试只用临时目录与 mock，不访问真实 CDN；真实发布保留完整本地回读报告。
