# 许愿正文编辑失败场景

实现前定义，验收通过真实 HTTP、SQLite 和浏览器进行。

- 未登录、普通玩家、被停用的管理员不能编辑；不存在的许愿返回 404。
- 正文去除首尾空白后须为 2～10000 个 Unicode 字符；缺少正文、版本、非法版本、未知字段不能保存。
- 任意处理状态均能编辑；作者、创建时间、参考图、处理状态、审核备注、审核人与时间、已有问答不变。
- 内容版本独立递增；陈旧版本返回 409，不能覆盖新正文。相同正文不增加版本或重复写审计。
- 正文和编辑审计在同一事务提交；记录编辑管理员、时间和目标。
- 玩家列表、管理列表及代理增量读取能看到新正文；编辑后紧接状态转换不能被 since 游标漏掉。
- 旧数据库升级与重复启动后正文、版本、编辑信息、原问答均保留。
- 详情内可编辑、保存、取消；轮询不重置草稿，错误不清空草稿；保存后摘要与正文立即刷新。
- 320px 和桌面下编辑区及按钮可见、无横向溢出，保留可重跑脚本和截图。

本次编辑范围为正文；参考图与问答保持原记录。
