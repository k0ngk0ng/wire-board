# 兵线争锋 · DotA 桌游

支持 2、4、6 人，分别组成 1v1、2v2、3v3。每人控制一位英雄；8 位经典英雄、17 件装备。所有模式必须摧毁敌方遗迹，没有击杀或限轮比分胜利。

## 开局与规划

普通房间入座、添加电脑、准备后，由房主点击开始。游戏内随机均分近卫/天灾，房主可以调整。所有玩家确认后，双方交替选择不重复的英雄，才进入战场。调整队伍会撤销旧确认。

每轮所有人暗选一张行动牌及目标；自己和队友可以看已锁定的计划，对手与观战者只能看到锁定状态。全员锁定之前可以撤回。揭牌后，所有行动及结果公开。

先移动，再结算魔免、沉默、防护和治疗，再按公开的先手队伍交替结算伤害。每轮先手队伍换边，队内起始席位也轮换。先被击倒的英雄不能执行尚未发动的伤害；一张牌的范围伤害与反伤一起结算。

各路比较推进值，净优势 1–2 推进一格，至少 3 推进两格。兵线到达端点即攻城：先打塔，塔已毁才打遗迹，同次攻城不穿透塔。第 1–12 轮攻城伤害 1，第 13–20 轮伤害 2，以后伤害 3。两边同轮拆毁遗迹时，本轮先手队伍获胜。

完整纸面规则和英雄、装备数值见 [规则表](research/dota1/RULES.md)。界面的行动牌、英雄检查面板和装备商店也提供效果说明。

## 操作与恢复

- 每阶段 120 秒；共同规划期间，其他人锁牌不延长时间。选英雄换人后获得新的 120 秒。
- 超时未操作的玩家自动托管，电脑接管同一席位和队伍。回来可以取消托管，没有永久淘汰或超时踢出。
- 托管与电脑使用相同的合法行动规则、公开局面和队友已锁定计划，不读取敌方计划。
- 分队确认、选人、未揭开的行动、时限和战场均保存在数据库中，刷新或重启可恢复。
- 获胜队伍全员共同获胜；纯真人完整对局胜方每人 +20，负方每人 −10。含电脑席位或房主中止的对局不计积分；真人托管仍保留其身份与战绩。
- 牌桌聊天仍是公开聊天，观战者可发言并标注“观战”。不要在公开聊天中发送秘密计划。
- 手机可切换“战场与玩家 / 我的行动牌”；玩家信息、战报、装备、日志和玩法速查均可展开。

## 素材与实现

素材是经典 Warcraft III / DotA 图标，不是 DOTA2。配置 `ASSETS_BASE_URL` 后从其下 `dota/v1/` 加载；CDN 失败时回退到随程序提供的本地副本。无损 WebP 约 246 KiB，未叠加改变图标颜色的遮罩。

Go 实现位于 `internal/game/dota*.go`，前端在 `web/src/dota.tsx` 与 `dota.css`。服务器对每位访问者过滤视图，同时提交使用独立阶段序号防止旧轮次重放。提交、揭牌、结算、存档和积分写入沿用已有事务边界。

180 个 Python 参考局面逐一核对 Go 的玩家资源、伤害结果、防御塔、遗迹、兵线、击杀和胜方；另测三种人数电脑完整对局、非法操作、保密、阶段确认、HTTP 同阶段旧版本提交、未揭牌时重启、超时托管、取消托管、团队积分和历史记录。

研究阶段的 3,000 局结果是规则可行性证据，不代表最终平衡或真人体验已经确定。初版保留已验证规则，后续调整通过明确规则版本和回归用例管理。
