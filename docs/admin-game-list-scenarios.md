# 后台游戏卡片与列表内排序验收

实现前确定的失败场景：

- 超过六款游戏后编号退回默认橘红色；搜索或排序后配色再次变化。
- 卡片未复用创建房间的封面，图片缺失、变形或长名称在 320 px 手机造成溢出。
- 基础配置仍平铺在卡片上；打开配置后失去游戏身份，保存失败无反馈，关闭后焦点没有返回入口。
- 排序仍打开弹窗或需要二次保存；拖动封面、触屏手柄和键盘方向键不能直接保存。
- 搜索和分类后排序影响不可见游戏；空列表或单个结果发送无意义请求。
- 普通点击配置、上下架或封面引发误拖；触屏取消、拖回原位置仍发送请求。
- 保存中重复排序，后台自动刷新覆盖拖动意图；其他管理员修改顺序后被旧页面覆盖。
- 保存失败后列表和编号没有恢复；重开后台、创建房间或大厅顺序没有同步。

使用真实 HTTP、SQLite 和后台 React 页面验收；封面直接使用当前创建房间的资源。覆盖桌面拖动、320 px 触屏、键盘、持久保存、失败回滚、并发冲突、搜索、分类、配置弹窗和图片解码。重放：配置工作区内的 Go 缓存与临时目录后，运行 `WIRE_BOARD_GAME_CONFIG_BROWSER=1 go test ./internal/server -run '^TestAdminGameListBrowserE2E$' -count=1 -timeout=5m`。截图和结果保存在 `.local/admin-game-config/list/`。
