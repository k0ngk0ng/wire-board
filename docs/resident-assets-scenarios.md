# 对局资源驻留失败场景

实现前登记。适用所有游戏的图片、音频、字体、运行时及静态数据；游戏状态、操作和实时消息继续使用原有网络接口。

- 同一资源并发预取或在正文仍写入时再次请求，产生重复下载；离开不能取消其他标签页仍在使用的共享下载。
- 开局只预取或校验字节，却没有保存正文，首次播放或绘图再次下载。
- 加载页提前确认，原生媒体只达到可播放状态而完整资源仍未下载。
- 连点、重建播放器、解码失败、画面恢复、缓存参数变化或重新初始化触发再次下载。
- Range、媒体 seek、跨域图片、CSS 图片及字体绕过普通 fetch 缓存。
- 已成功保存的资源丢失、损坏或读取失败后，自动回源补救。
- 一局结束后的重开丢失本地正文；相同资源重复下载。
- Service Worker 被系统停止后忘记对局状态，重新允许网络取图和取音频。
- 旧加载过程的迟到释放、确认或失败覆盖当前对局；两个标签页互相解除限制。
- 新资源服务取得页面控制后，错误拦截尚未接入驻留加载的旧标签页；兼容旧窗口时，又错误放行已接入游戏的工作线程回源。
- 初次加载失败、字节数错误、配额不足或存储不可用仍被标记为就绪。
- 外部资源因为同一游戏存在少量本地运行时文件而被整组排除；幽游白书和热血篮球的音频未进入预加载清单。
- 资源扩展名筛选漏掉动态字体、索引贴图、调色板或新的二进制格式；游戏目录内已发布正文均须进入声明范围，不能靠当前场景偶然触发下载补齐。
- 只为保证网络零请求而丢失必要资源；须补全当前对局全部必要素材，不能把缺失贴图推迟到游玩时首次下载。
- 只测普通 fetch，却没有验证真实图片、原生音频与音频 Range 播放。
- 克隆后未消费的 Response 在内存积压整份音轨；并发读取须复用下载及已保存正文，不长期保留重复正文。
- 为保存资源而长期保留全部已解码图片或完整音乐 PCM；正文保存在浏览器持久缓存，解码缓存继续有界。
- 离开或切换对局时，旧下载继续占用网络；取消不能中断当前新对局。
- 新版本、地图或角色集合变化使用错误的旧资源；未变的内容地址继续复用。
- 资源驻留实现把客户端资源正文重新装入正式服务器或容器。

加载阶段完成完整资源准备并保存正文；就绪后图片和音频请求只读取本地正文。已成功资源的读取、播放或解码失败不能触发 CDN 下载。缺失明确失败，不以自动回源掩盖。元数据与实时状态接口不受影响。统一入口承载约束，各游戏只声明本局必需资源。

同源工作线程引导只允许引用已发布清单中的 JavaScript，不携带工作线程正文；缺失、非法来源、错误 MIME、非 GET/HEAD 和媒体别名入口须明确拒绝。正式服务器仍不保存客户端资源正文。

- 专属资源计划须保留同局后续剧情、卡牌及阶段所需素材，同时排除未使用的历史包、其他场地音乐和其他版本核心；声明缺失时阻止就绪。独立游戏工作线程也必须复用本地正文，并拒绝未准备资源的网络下载。

## 重复执行

- 公共浏览器：`node web/tests/resident-assets-browser.mjs <Playwright 模块> <WebKit 可执行文件>`；Chromium 使用 `BROWSER_ENGINE=chromium` 并传入对应可执行文件。报告、请求计数和截图写入 `.local/yuyuhakusho/resident-assets/`。
- 真实房间：使用 `games/yuyuhakusho/tests/recovery-server.mjs <已准备素材目录>` 启动隔离 Go 房间；`--basketball --observe-resources` 用于篮球，`--terminal --observe-resources` 用于真实终局重开。
- 幽游白书：`node games/yuyuhakusho/tests/resident-gameplay-browser.mjs <房间地址> <Playwright 模块> <WebKit 可执行文件>`。音源正文保持原发布版本，以独立资源服务器的请求计数验证，额外记录规则恢复和音频输出。`resourcePolicyPassed` 与 `gameplayHealthy` 分别报告，不能用资源策略通过代表全部规则健康。
- 篮球：`node games/basketball/tests/resident-gameplay-browser.mjs <房间地址> <Playwright 模块> <WebKit 可执行文件>`。结果保存在 `.local/basketball/verification/resident-assets/`。
- 重开：`node web/tests/resident-rematch-browser.mjs <终局房间地址> <Playwright 模块> <WebKit 可执行文件>`，验证真实新对局身份、相同配置、零新增下载、本地正文丢失及恢复、退出全屏无操作屏蔽残留。

浏览器模拟与 iPhone 真机验收分别记录。资源策略通过不代表未覆盖的规则分支、整局稳定性或真机性能已经通过；发现规则错误时保留具体帧、原因和隔离房间状态。
