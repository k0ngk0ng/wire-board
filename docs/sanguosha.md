# 三国杀身份局与基础国战

支持4–8人身份局和独立基础国战。身份局以经典25将为默认，可独立加入风、火、林、山与八位经典神将，全部启用共65将；标准将可切换至界限突破版本（21名修订将替换对应经典将）。牌堆可选标准108张（含EX）或标准＋军争160张。身份仍为主公、忠臣、反贼、内奸，五人以上主公体力上限加一。扩展版本依据与验证见 [扩展实施清单](sanguosha-expansions.md)。

基础国战采用独立60将和108张国战牌，同势力双将、暗将/亮将、野心家和势力胜负均独立处理。详见 [国战规则与实现](sanguosha-hegemony-notes.md)，不与身份局的武将版本和牌堆混用。

规则数据位于 `internal/game/sanguosha_data.go`，每一张实体牌具有固定 ID、花色和点数。卡面文字以应用内显示的经典规则为准。角色技能、牌型、出牌成本、距离、响应与胜负均由 Go 服务端验证。

## 军争与开局配置

房主可在创建房间或等待开局时选择模式；身份局另选标准／军争牌堆、标准将版本和扩展包。修改设置后真人玩家需要重新准备，开局后配置锁定，房间快照和历史记录保存所用规则。未保存配置的旧房间仍使用标准牌堆，原有 108 个实体牌 ID 保持不变，军争 ID 为 109–160，国战独立使用1001–1108。

军争新增 52 张实体牌，包括火杀、雷杀、酒、铁索连环、火攻、兵粮寸断、朱雀羽扇、古锭刀、藤甲、白银狮子和骅骝，以及新增的桃、闪与无懈可击。

- 属性杀与普通杀共用次数，并能作为龙胆、决斗等要求的杀；朱雀羽扇只能转换使用的普通杀，不转换普通响应中的杀。
- 连环传导保留原伤害数值和属性，逐个处理目标的防具，不重复计算酒、裸衣或古锭刀的加成。青釭剑忽略防具不随连环传导。伤害、濒死、技能和后续传导均可序列化恢复。
- 酒的主动使用每回合限一次，效果随下一张杀消耗或回合结束清除。濒死时可以连续用酒自救，不可用酒救其他人。
- 铁索可作用于自己；重铸直接弃牌并摸牌，不触发集智或无懈。多目标按座次结算，无懈只抵消对应目标的效果。
- 火攻只公开目标所选的展示牌，其他手牌保持私密。目标超时自动展示；使用者超时放弃弃牌，不自动花费手牌。
- 兵粮按距离与判定区重复牌校验，不为梅花跳过摸牌；白银狮子限制伤害，离开装备区后回复体力。

## 响应与保存

结算队列和待响应提示全部序列化到现有 SQLite 房间快照。不存在依赖浏览器存活的技能回调。技能可产生新的响应、判定、伤害、濒死和死亡；这些过程结束后继续原来的结算。

- 主动思考时间 120 秒；回合外响应 20 秒；选将 120 秒。
- 其他人响应期间保留主动玩家的剩余时间；出牌不会重置两分钟。
- 无懈可击使用共同响应窗口。所有存活玩家可同时选择放弃或使用无懈；仅放弃不会改变提示编号。成功反制后重新开启一轮响应。
- 请求带提示编号；旧响应不得作用于新提示。房间版本与动作 nonce 继续防止重复操作。
- 超时放弃可选响应；必要的选将、弃牌、牌序和分配自动合法完成。不会通过移除身份角色处理超时。
- 濒死可能需要多张桃；存活到 1 点以上才结束求桃。死亡之后检查阵营胜负，胜方包括已经阵亡的同阵营成员。

`sgView` 从公开信息构造视图。牌堆、对手手牌、未公开身份、其他人的候选武将、观星牌序和遗计牌不能发送给观战者或其他玩家。电脑的决策只利用自己的身份、自己的牌与公开局面，不读取其他隐藏身份来判断敌友。

## 美术

使用 QSanguosha-v2 的经典武将画像与较大尺寸牌图，固定上游提交 `e8768851bd8054db9fd1b63cd6f1feca813590d7`。使用怀旧画像的武将显式映射到 `nos_` 资源。画像不包含技能文本，技能文字单独渲染以保证与规则版本一致。

运行 `python3 scripts/prepare_sanguosha_assets.py <工作目录内的输出目录>` 准备 25 张画像与 32 种牌图。脚本需要 `cwebp`；下载的 PNG 转换后自动移除，输出附带来源清单。上传使用既有 `scripts/upload_assets.py`。资源路径相对于 `ASSETS_BASE_URL` 为 `sanguosha/v1/{generals,cards}/...webp`。服务器地址、存储服务配置与凭据不进入源码。

`--pack military` 可单独生成军争的 11 种新卡图，上传到共享素材根目录下的 `sanguosha/v2/cards/`，标准图继续使用 `v1`。已上传文件的来源及 SHA-256 清单位于 [军争素材清单](sanguosha-military-assets.json)。

扩展画像支持 `--pack wind|fire|thicket|mountain|god|breakthrough`，分别使用 `sanguosha/v3` 至 `v8`；国战使用 `--pack hegemony` 和独立固定来源，输出到 `sanguosha/v9`。各包来源与SHA-256记录在对应的 `sanguosha-*-assets.json` 中。

## 验证

测试包括牌表、角色技能、装备与响应、改判/天妒、双闪、濒死连续求桃、无懈反制与共同响应、并发旧版本放弃、隐藏信息隔离、无效动作回滚、序列化恢复、HTTP 完整牌局、阵营积分与电脑模拟牌局。模拟中每步检查标准 108 张或军争 160 张牌既不重复也不丢失。军争测试另覆盖酒杀＋藤甲＋白银狮子的传导、青釭剑作用范围、火攻隐私和保存恢复、铁索重铸与逐目标无懈、兵粮跳过摸牌、酒的连续自救与次数、羽扇转换、选项权限和开局锁定。
