# 三国杀经典身份局

本实现固定为经典 25 将与 108 张游戏牌（104 张标准牌 + 4 张 EX），不混用界限突破、2013 修订将或军争包。支持 4–8 人。魏 7 将、蜀 7 将、吴 8 将、群 3 将；身份为主公、忠臣、反贼、内奸。五人以上主公体力上限加一。

规则数据位于 `internal/game/sanguosha_data.go`，每一张实体牌具有固定 ID、花色和点数。卡面文字以应用内显示的经典规则为准。角色技能、牌型、出牌成本、距离、响应与胜负均由 Go 服务端验证。

## 响应与保存

结算队列和待响应提示全部序列化到现有 SQLite 房间快照。不存在依赖浏览器存活的技能回调。技能可产生新的响应、判定、伤害、濒死和死亡；这些过程结束后继续原来的结算。

- 主动思考时间 120 秒；回合外响应 20 秒；选将 120 秒。
- 其他人响应期间保留主动玩家的剩余时间；出牌不会重置两分钟。
- 无懈可击使用共同响应窗口。所有存活玩家可同时选择放弃或使用无懈；仅放弃不会改变提示编号。成功反制后重新开启一轮响应。
- 请求带提示编号；旧响应不得作用于新提示。房间版本与动作 nonce 继续防止重复操作。
- 超时放弃可选响应；必要的选将、弃牌、牌序和分配自动合法完成。不会通过移除身份角色处理超时。
- 濒死可能需要多张桃；存活到 1 点以上才结束求桃。死亡之后检查阵营胜负，胜方包括已经阵亡的同阵营成员。

`sgView` 从公开信息构造视图。牌堆、对手手牌、未公开身份、其他人的候选武将、观星牌序和遗计牌不能发送给观战者或其他玩家。电脑的决策只利用自己的身份、自己的牌与公开局面，不读取其他隐藏身份来判断敌友。

## 美术

使用 QSanguosha-v2 的经典武将画像与较大尺寸牌图，固定上游提交 `e8768851bd8054db9fd1b63cd6f1feca813590d7`。使用怀旧画像的武将显式映射到 `nos_` 资源。画像不包含技能文本，技能文字单独渲染以保证与规则版本一致。

运行 `python3 scripts/prepare_sanguosha_assets.py <工作目录内的输出目录>` 准备 25 张画像与 32 种牌图。脚本需要 `cwebp`；下载的 PNG 转换后自动移除，输出附带来源清单。上传使用既有 `scripts/upload_assets.py`。资源路径相对于 `ASSETS_BASE_URL` 为 `sanguosha/v1/{generals,cards}/...webp`。服务器地址、存储服务配置与凭据不进入源码。

## 验证

测试包括牌表、角色技能、装备与响应、改判/天妒、双闪、濒死连续求桃、无懈反制与共同响应、并发旧版本放弃、隐藏信息隔离、无效动作回滚、序列化恢复、HTTP 完整牌局、阵营积分与电脑模拟牌局。模拟中每步检查所有 108 张牌既不重复也不丢失。
