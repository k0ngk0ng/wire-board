# 宝石回合布局与退出入口

2026-10-17。

- 顶部移除直接退出登录按钮；点击自己的头像或姓名进入玩家页面后，可在页面上方退出。查看其他玩家时不显示退出入口，关闭玩家页面不改变登录状态。
- 宝石取币操作区及底部跳过按钮始终保留原有布局高度。不能操作时仅隐藏视觉内容，同时设置 `inert`、隐藏读屏内容并禁用按钮，不能误点或通过键盘提交。
- 公共回合标题不因较长昵称换行而增高；保留完整文本供辅助技术读取，视觉上超出宽度时省略。

先编写 `scripts/accept_splendor_layout_logout.py`，通过真实建房、两位玩家轮流取币及浏览器逐帧采样复现。修复前手机宝石池高度变化 28px，整张牌桌变化 58px；320px 的长昵称还使回合提示增加 19.5px。证据在 `.local/bank-layout-3b99a67d/result.json` 和 `.local/bank-layout-9f3384af/result.json`。

修复后 `.local/bank-layout-5e8613ba/result.json` 通过：1440、851、850、390、320px 下，每种宽度连续四次正常取币，逐帧测得牌桌高度／位置、宝石池高度、市场与手牌区位置变化均为 0px。另实际验证自己／对手玩家页、关闭资料不退出、手机点击退出后会话失效。脚本与截图可复跑，未用修改游戏快照代替操作。

公共回合栏的现有浏览器布局检查 `scripts/accept_turn_layout.py` 同时通过，覆盖公共组件在 13 个独立游戏样式、9 种宽度和 6 种状态下的 702 个组合；未执行其他游戏的规则或整局验收。宝石 15 项和公共前端 65 项检查、生产构建通过。

复跑需独立本地服务，管理员为 `LayoutAdmin`、测试密码 `layout-local-password`、邀请码 `layout-accept-code`，执行 `python3 -B scripts/accept_splendor_layout_logout.py`。这些只用于临时本地数据库；脚本仅接受本机地址，运行后保留结果和截图、清理独立浏览器配置。
