## 轮流放港口

从当前先手开始按座位顺序循环，每人放一个随机抽出的港口。港口须在陆地与海洋／外框之间的边上，不可与其他港口共用端点，即彼此至少隔开一条边。只能放当前公开的港口，不能指定尚未抽出的港口种类。

`NewCatanNewWorld` 使用独立阶段 `catan_world_ports`。洗好的完整港口栈与当前位置保存到服务端存档；对外只返回当前港口、已放数量、总数和剩余数，玩家及观战均看不到未来顺序。只有当前操作人收到合法海岸提示。每次动作后下一位获得完整120秒；超时只放一个港口，托管沿用合法位置选择。全部放完后返回原先手、第0步起始村庄，再获得完整120秒。港口阶段不发资源／助手、不放建筑、不推进配对行动。

## 对局规则

每人顺序放第一组村庄与道路／船只，再逆序放第二组。两座起始村庄可同岛或不同岛，记录各自的家乡岛；只从第二座村庄领取资源。每位玩家首次在自己的非家乡岛建村额外得1分，每岛一次，别人已定居不影响自己的奖励。

自己的行动阶段达到12分立即获胜，包括五／六人配对玩家的行动段。其余船只／海盗／金矿、最长路线、最大骑士军队及发展卡规则沿用航海家。Helpers可组合，起始助手仍在第二组建设完成后领取。

## 开局前共同确认地图

等待房间可以预先生成地图。房主可交换两块完整地形／数字，或修改单块地形及数字；其他玩家只读查看。编辑先保留本机草稿，点击“应用地图并重新准备”才提交。地图实际变化后，所有真人取消准备，电脑保持准备；相同地图不取消准备。草稿未应用时，房主不能准备、开始或切换扩展设置。非法编辑保留草稿及错误提示，不改变服务端地图或已有准备状态。

服务端只接收官方框形内按行排列的地形和数字，不接受坐标、岛屿身份、棋子或港口栈。开局使用这张已确认地图，重算连通岛屿，随后进入正常的轮流放港口阶段，不重新抽取地形。版本检查拒绝过期编辑；等待状态重启保留地图和准备状态；开局后禁止编辑。切换五至六人扩充会重新生成相应42／63格地图并要求重新准备。

自选组件可与默认配方不同，但不能超出基础版及相应航海家扩展的实物库存。库存已对照固定来源的2025版组件页核对：

|---|---|---|
| 五种普通地形 | 各5 | 各7 |
| 沙漠、海洋、金矿 | 3、19、2 | 5、26、4 |
| 数字2／12 | 各2 | 各3 |
| 数字3／4／5／6／8／9／10／11 | 各3 | 各5 |

三／四人的28枚数字来自基础18枚与航海家10枚。五／六人航海家明确使用基础18枚加基础扩充28枚，共46枚，并把航海家10枚放回盒中；不能套用基础五／六人单独游玩时的数字库存。这里列的是自选上限，不要求每张地图用完全部组件。

验证同时检查海洋／沙漠无数字、生产地块有合法数字、金矿无红号及6／8不相邻。为避免任意合法放置顺序使开局无位置可放，当前实现保守要求海岸边至少为`3×港口数−2`、陆地交点至少为`8×玩家数−3`。这两项是实现的支持边界，不是官方额外规则；不满足时明确拒绝，不暗改地图或增加组件。仍使用官方固定外框，不支持任意坐标或扩大棋盘。

正式战绩会从实际游戏状态记录航海家剧本，并显示对应中文名称。
