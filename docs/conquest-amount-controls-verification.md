# 征服时代人数与资源提示验收

本页记录 v1.33.3 的界面改进；后续整数行动、随机出生和逐步播放见[回合流程验收](conquest-round-flow-verification.md)。

本轮仅修改征服时代前端，不改战斗、经济、地图或电脑规则。保留地图内图标操作，补充人数调整、人口提示、行动点计数和皇冠绘制。

## 操作

- 征兵默认选当前合法上限的一半，派兵默认选剩余可移动兵力的一半，奇数向上取整。支持鼠标／触屏滑块、键盘方向键和精确人数输入；「一半」可恢复动态半数。
- 征兵选择人数后确认，进攻选择人数后点相邻领地。打开、调整、取消人数选择都不会下单；长按征兵也不会绕过人数选择。筑堡保留长按建城镇。
- 手动人数在普通快照中保留，切换领地、操作或回合后恢复默认；每次点击独立记录数量，按服务端回执顺序下单。默认连续进攻仍是剩余兵力的一半；海费不足不擅自减少所选人数。
- 选中己方领地显示预计剩余人口和当前可征人数；人口、金币、驻军容量或行动点不足时显示对应原因，可同时显示多个原因。不能征兵时仍可打开面板查看，确认按钮不可用。
- 计划按钮下面显示已用／总行动点，例如 `0/3.2`、`1/3.2`；征兵、派兵各消耗 1 点，筑堡消耗 0.5 点，免费税率计划不消耗。撤销会恢复点数，新轮总额度按服务端结转结果更新。
- 全屏时地图与底部操作使用窗口可用空间，退出后恢复普通页面尺寸；超宽屏保留合理地图比例。全屏切换不重挂棋盘，不清除领地或人数选择；对局结束后仍保持全屏尺寸。
- 地图与君主按钮共用金色皇冠，包含底座、冠齿、圆珠与宝石；保持兵力和选地操作可辨认。

## 验证

先记录失败场景并运行失败测试，再实现。人数计算与资源短缺检查纳入征服时代前端测试；真实房间使用 agent-browser，原生 CDP 输入验证鼠标／触屏滑块和连续点击，实际订单来自正常服务端接口。

针对性入口覆盖 1440px PC、320px 手机视口和平台全屏：默认半数、范围端点、方向键、精确人数、空值与零值、无意外下单、滑块不拖地图、普通快照保留选择、连续排队、请求拒绝后重试、撤销与刷新、人口更新、金币和行动点不足、免费税率、分数点数、新轮结转。截图检查最终计算颜色与文字边界，皇冠检查大小及独立渐变标识。

本轮征服时代前端检查通过 59 项。人数与资源入口通过 28 项，包含 14 条原生输入；全屏入口通过 27 项，覆盖四图的 2048×1127、320×780 和中国地图 2560×1080 超宽屏。相同的 2048×1127 窗口中，游戏区从 1160×777 扩展到 2032×1075，地图从 1158×660 扩展到 2030×970。

普通四图回归通过 913 项、197 条原生输入与 98 组逐帧测量，运行在最后的全屏样式扩展前。最终变更仅追加全屏条件下的样式；移除该段可重建回归记录中的 CSS 摘要，其余运行代码摘要均一致。最终人数与全屏验收绑定当前完整源码，增量范围记录在交付目录 `verification.json`。

手机验收使用 Chromium 窄屏与原生触摸事件，不作为实体手机或 WebKit 验收结论。四张地图的完整交互回归沿用既有入口；不因前端操作改动重跑服务端完整对局矩阵。
