# 界限突破标准将规则与实现

继续使用 `Mogara/QSanguosha-v2` 固定提交 `e8768851bd8054db9fd1b63cd6f1feca813590d7`。依据 `src/package/standard-generals.cpp`、`standard-skillcards.cpp`、`lang/zh_CN/Package/StandardGeneralPackage.lua`，与 `nostalgia.cpp` 的怀旧标准将对照。这是该提交的旧版界限突破规则，不混用后续移动版/OL改版。界限突破已接入本地开局选项，随整批扩展完成验收后发布；当前未发布。

## 武将版本与候选池

现有25名经典标准将中，21名有该来源的修订版；甄姬、诸葛亮、孙权、孙尚香在该来源没有对应怀旧替代，沿用现有版本。使用独立 `jie_` 武将 ID、独立修订技能 ID，不能修改老快照里标准将的含义。

开局选项提供标准将版本切换（经典/界限突破），界版替换上述21名经典候选，四名未改将继续保留。因此候选池仍是25名标准系将，不会让同一个人物的经典和界版同时进候选或同时登场。该设置与军争、风火林山、神将独立，开局后冻结。化身使用当前房间已启用的完整候选池。

## 引擎接入

- 非锁定技能暂时失效与手牌禁用分别持久化，回合结束或当前玩家死亡后恢复。不能借技能转化、蛊惑或装备牌响应绕过手牌限制；禁用“使用/打出”不等于禁止弃牌、赠送、拼点。按固定来源的技能频率建立显式元数据，不能从中文文案推断锁定状态。
- 跟踪实际阶段（尤其摸牌阶段及进入前的跳过），清俭与遗计取回不能只依赖前端phase字符串。跳过摸牌与涉猎替代摸牌是不同事件：裸衣跳过不触发遗计取回/七星交换；涉猎仍在摸牌阶段。
- 统一手牌获得入口，让摸牌、获得装备/判定牌、赠送、五谷、拼点获得、遗计/星交换、行殇、原子缔盟都能按正确批次触发清俭。手牌交换、七星/集智交换不可制造假的空手联营。
- 奇才保护需要统一“别人能否弃置某张牌”检查：过河、寒冰剑、猛进、挑衅、刚烈、除疠等都要过滤，只有受保护装备时不能打开无合法动作的提示。顺手/反馈/归心获得不受限制，自弃、神愤要求本人弃牌不受限制。
- 奋威记录整张锦囊的原始目标及无效目标，逐目标结算和无懈不能丢失；谦逊判断整张牌是否唯一目标，不能把全体锦囊的逐人事件误当唯一目标。
- 涯角要记录实际“使用/打出”牌类别以及是否全部来自手牌，改判/弃置/装备失去不能误触发。无懈与龙魂/蛊惑等虚拟牌须按实际类别与支付位置处理。
- 孙策魂姿获得的英姿与神司马懿极略引用的集智需显式核定关联版本，不能随着候选包开关暗中改变同一快照技能。极略已按此来源的新集智单独实现；界版集智可提取共享结算核心。
- 所有新私有牌堆只向对应拥有者暴露ID，其他人只见数量。阵亡清理、失去技能后的到期归还、保存/恢复、观战与电脑策略都要覆盖。

## 验收范围

逐将规则与非法动作原子拒绝；21修订将与现有65将的混合电脑对局；受控拼点及隐私；多层濒死、判定、手牌获得与死亡续接；新版/经典候选互斥；旧快照不变；前端桌面/390px手机操作；原画像21张、OSS摘要验证及临时文件清理。已完成下述规则、浏览器与素材验证。

## 关联技能版本与兼容

新建游戏写入 `rulesVersion: 1`。孙策魂姿获得 `jie_yingzi`，与固定来源一致；旧快照没有版本号时仍获得经典 `yingzi`，已经保存的技能 ID 不改变含义。极略和界集智共用新版亮牌/交换结算；经典集智继续直接摸牌。英姿的固定手牌上限是基础值，按同提交 `player.cpp::getMaxCards` 继续叠加血裔、绝境等额外上限。
