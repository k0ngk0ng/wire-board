# 全屏与声音控制验收

全屏按钮只在开局并完成加载后显示，位于游戏区右上角；等待房间没有此入口。原生全屏的目标是游戏区元素，排除平台菜单、房间标题和上方玩家栏，保留游戏组件、必要倒计时、操作面板和游戏弹窗。支持原生全屏的浏览器使用原生接口；不支持或拒绝原生请求时，使用网页铺满模式。ESC 和退出按钮恢复普通页面，切换房间及异步请求晚到时清理全屏状态。

疯狂坦克在桌面全屏中使用约 2:1 的画面比例，并扩大水平视野。1920 × 1080 验收中，画布从 894 × 503 扩大到 1594 × 797，水平世界视野从 800 增至 900；退出后恢复。进入全屏将焦点交给游戏，避免空格触发全屏按钮。

右上角使用一个喇叭按钮，音量、静音和试听集中在弹出面板中。背景音乐不再固定为 15% 音量，新浏览器默认 50%；设置在浏览器保存并同步同源标签页。调节音量不重启当前音乐，连续音效保留相对音量。静音或音量归零停止播放并清空队列，恢复音量不补播已取消的音效，试听不能取消静音。全程沿用平台原生媒体通道。

## 本地验证

| 范围 | 结果 |
| --- | --- |
| 25 款游戏 | 等待房间无入口；实际游戏元素全屏、ESC、按钮退出、320px 触摸；真实开局的桌面与手机画面、控件、动画图层及组件保留 |
| 疯狂坦克 | 宽屏尺寸恢复；全屏内原生键盘调角、换弹、蓄力发射；泡泡堂另验证键盘放水泡及角色资料弹窗 |
| 斗地主、掼蛋、升级 | 320px 原生触摸全屏切换，顶部操作与倒计时文字不重叠，计时文字计算对比度至少 4.5:1 |
| 泡泡堂声音 | 原生媒体播放中调整音量；音乐时间连续，试听与音乐共存；静音、零音量、恢复、刷新、跨标签页同步 |
| 声音面板 | 原生鼠标与键盘调节；320px 原生触摸静音；游戏全屏排除声音等平台入口，退出后恢复声音面板；计算样式对比度检查 |
| 公共前端测试 | 144 项通过，其中包含新增音量及偏好场景 |
| 受影响游戏前端／素材检查 | 疯狂坦克、泡泡堂、璀璨宝石、车票之旅、卡坦岛通过；未运行服务端规则矩阵 |
| 构建与边界 | TypeScript、Vite、游戏依赖边界和按需加载构建检查通过 |

浏览器验证使用 Chromium。手机项为窄屏与原生触摸事件仿真，未声称通过实体 iPhone 验收。游戏检查覆盖全屏交互、真实开局和控件保留，不等同于所有特殊阶段、规则组合及完整对局验收；本次没有修改服务端规则。

## 复跑

```sh
npm --prefix web run build
python3 -B scripts/fullscreen/check-browser.py --out .local/fullscreen/<新目录>
python3 -B scripts/sound/check-browser.py --out .local/sound/<新目录>
node --experimental-strip-types --test web/tests/*.test.mjs
node web/scripts/test.mjs fortressblue
python3 -B scripts/check_game_boundaries.py
node scripts/game-loading/check-build.mjs
```

最终本地产物位于 `.local/fullscreen/game-area-ship/` 和 `.local/sound/game-area-ship/`，包含 JSON、源码／构建摘要、控件清单和截图。脚本清理自身的数据库、浏览器 profile 和临时文件；调试失败目录在交付前清理。发布仍须等待 main 同一提交验证成功，由版本 tag 复用该构建，不重新编译应用或重复规则矩阵。
