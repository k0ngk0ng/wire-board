# 璀璨宝石与卡坦岛扩展实施记录

目标是完整接入已讨论的扩展，包含规则、真实数据、素材、可操作界面、电脑/托管、超时、观战隐私、保存恢复和发布验收。阶段性实现不代表整批目标完成；仅添加选项、卡图或规则说明不算可玩。

## 范围

- [ ] 璀璨宝石城市、贸易站、要塞、东方四模块，固定规则版本，并支持该版本允许的组合。
- [ ] 卡坦航海家的官方剧本：船只与路线、海盗、金矿、探索及各剧本胜负条件。
- [ ] 卡坦城市与骑士：商品、城市建设、三类进步牌、骑士、城墙、大都会、蛮族入侵及结算。
- [ ] 卡坦商人与蛮族：渔夫、河流、商队、蛮族进攻、运输任务及其变体（含双人）。
- [ ] 卡坦探险家与海盗：探索、海上移动、装载/卸载、定居、海盗巢穴、鱼群、香料及完整任务组合。
- [ ] 基础卡坦及四大扩展对应的五至六人规则、地图、资源与回合流程。
- [ ] 官方支持的扩展/剧本组合，按组合规则逐项验收。航海家与探险家海盗不允许组合。
- [ ] 卡坦 Helpers 助手全部角色、使用/归还/交换与兼容规则。

用户已确认本批包含主要扩展与Helpers。宝石对决、漫威、儿童版等独立游戏另做，不在本批范围。
- [ ] 创建/等待房间配置、准备重置、开局冻结、存档与历史规则标记；旧房间默认基础版。
- [ ] 扩展电脑/托管、必要操作超时、非法动作原子拒绝、观战与隐藏信息隔离。
- [ ] 原版素材与颜色、扩展动画与日志、桌面/手机布局、现有素材服务上传与逐项加载验收。
- [ ] 模块定向测试、组合交互、完整模拟局、重启恢复、HTTP权限、桌面/手机浏览器验收。
- [ ] 完整检查通过后由GitHub构建镜像发布，服务器在线备份、短时切换、版本与健康核验及旧镜像清理。

## 规则依据

宝石新版官方产品为 [The Silk Road](https://store.asmodee.com/products/splendor-the-silk-road-expansion)（城市、贸易站）和 [The Sun Never Sets](https://store.asmodee.com/products/splendor-the-sun-never-sets-expansion)（东方、要塞）。旧《Cities of Splendor》也包含四模块，实施前须核对新版规则书与数据，不混用同名模块的不同版本。

卡坦优先采用官网2025年新版基础与四大扩展规则，以及对应五至六人和组合规则。官方入口：[核心系列](https://www.catan.com/explore-catan/catan-core-family-games)、[航海家](https://www.catan.com/seafarers)、[城市与骑士](https://www.catan.com/cities-knights)、[商人与蛮族](https://www.catan.com/traders-barbarians)、[探险家与海盗](https://www.catan.com/explorers-pirates)。具体下载地址、摘要及版本决策随核对记录。

## 初始代码审计

现有宝石采用普通单色发展卡、贵族与15分触发终局，特殊卡效果、城市目标和额外动作需要显式持久化。卡坦地图目前为固定19块陆地，边只有道路所有者；扩展需要支持可变地图、海陆边界、船只与额外棋子，以及不同剧本的资源和回合规则。规则选项应沿用现有房间配置的权限与冻结机制，不能仅修改前端人数或选项。

当前线上版本不包含本批扩展。此文为持续验收清单，最终完成以真实运行和逐项证据为准。

## 实施进展（尚未发布）

已接入宝石新版贸易站与要塞的可持久化规则流程、房间设置及界面。包含每回合至多获得一个贸易站、按发展卡张数判断条件、黄金逐色增值、私有盲预留二选一、购牌前后效果与延迟补牌、要塞占据/移动/移除、征服额外购买、电脑/托管与移出清理。扩展非法请求在游戏层原子拒绝。

定向测试已覆盖上述规则及恢复/隐私，并运行贸易站、要塞和组合电脑完整局；基础宝石相关回归通过。HTTP测试覆盖房主权限、准备重置、开局冻结、历史记录与旧房间兼容。前端构建与game/server的go vet通过；浏览器两人托管局已正常结算。1440px桌面与390px手机验证了额外取宝石、要塞放置、征服购牌、面板收起及刷新恢复；手机无横向溢出，候选牌单独滚动，确认按钮保留在面板内。城市/东方加入后仍需做完整组合验收。

五种贸易站原图取自固定哈希的新版规则书，并通过 `scripts/prepare_splendor_expansion_assets.py` 重现提取。PDF中图片对象顺序与正文顺序不同，已通过拼图逐项核对。公开宣传图存在旧版能力图案，不能直接当作新版规则卡使用。素材已上传既有素材服务，五张均验证为有效WebP。

城市14个面、东方30张牌的当前版本数据仍需完整核对。已发现第三方旧城市CSV有15条且与新版样例颜色不符，未纳入游戏数据。新版城市为公共目标、不领取移走，胜利仅比较满足城市条件的玩家；东方双宝石卡仍只算一张卡；这些规则需在后续模块中实现。

Helpers 已接入官方12位双面角色版本（2022版权、官网2023 PDF），默认按人数选用2N位助手，也可选展示全部备用助手。包含起始分配、翻面/交换、当回合使用限制、12种能力、掷骰后的他人响应、私有发展卡与对手手牌选择、地图道路迁移、电脑/托管与超时自动选择。助手响应共用独立120秒，连续选择不刷新时间；期间暂停原玩家回合，完成后恢复剩余时间。

Helpers 房间配置支持房主权限、准备重置、开局冻结与历史记录。定向测试覆盖全部能力、非法动作原子回滚、资源守恒和完整电脑局；HTTP测试覆盖私有信息、跨座位响应、重启恢复、超时胜利归档，以及助手超时后多人同时弃牌的版本衔接。原版12位人物图已从固定哈希官方规则书提取并上传，CDN逐图验证为有效WebP，可由 `scripts/prepare_catan_helper_assets.py` 重现。

1440px桌面和390px手机已验证助手使用、翻面/交换、私有发展卡选择、地图末端道路迁移、浮层收起和刷新恢复，无横向溢出。手机助手区域使用整行，候选卡可独立滚动。基础卡坦回归与game/server的go vet、前端构建通过；整批扩展的最终组合与发布验收仍待完成。

Helpers 官方文档明确支持基础版、航海家及其5–6人扩充，并写明与新版双人配对回合的衔接。目前接入基础3–4人及基础版五至六人配对回合，不能直接假定它兼容所有大扩展。卡坦四大扩展、对应五至六人及组合尚未完成。


基础五至六人扩充已接入30陆块、80交点、109条边、11港口、每种24资源与34张发展卡；采用2025新版两枚标记的配对回合。第一位随机，第二位为其左侧第三位；两段行动各有120秒，可分别使用一张发展卡并获胜，第二位不掷骰、不自由交易。新发展卡在下次自己的行动阶段解锁；Helpers在同一完整配对回合的领取/使用限制保持一致。玩家离场时跳过已离场座位，保留扩大地图和库存。

测试覆盖组件数量、起始建设/助手分配、标记轮换、回合数、两段行动的卡牌限制、交易权限、即时获胜、离场衔接、保存恢复和五/六人完整电脑局及资源守恒。HTTP验证了人数边界、开局冻结、扩充选项与第二段行动的独立计时。真实六人桌已在1440px桌面和390px手机检查，30地块与六色棋子正常加载、无横向溢出；手机建造按钮改为名称/费用分行，避免竖排挤压。

五至六人开局目前采用可变地形及官方示意的逆时针螺旋（跳过两个沙漠），数字牌采用既有扩充的A–Zc顺序。发布前仍需取得当前2025版数字牌正反对应的独立证据，核对字母与数字是否沿用旧版；不得将组件数量测试当作这项数据核验。固定新手布局也尚未作为单独房间选项提供。四大扩充及其组合仍未完成，整批没有发布。

东方与城市的规则引擎已接入，但两个选项仍未开放：新版完整30张东方卡、14个城市面及原图尚待核实。现有代码支持六个独立牌堆、黄金卡提供虚拟黄金、复制具体卡牌（含双奖励）、跨级免费连锁、按优先顺序弃置复制卡购牌、延迟原位补牌与持久化选择。免费取牌不会重复触发贸易站或要塞购牌奖励；弃牌扣除卡牌奖励与分数，但保留已获贵族和贸易站。城市替代贵族及15分终局，只在符合城市条件的存活玩家之间比较分数和卡牌数。

新增定向测试覆盖非法支付的原子拒绝、复制/连锁恢复、要塞阻挡免费取牌、六牌堆盲预留隐私与离场归还、城市同色条件不能重复使用、双奖励仍只算一张、贸易声望先于城市终局、多人平局与触发者离场。24场合成卡牌模拟局覆盖2–4人及东方与贸易站/要塞/城市的8种组合，每步核对120张卡唯一性、筹码守恒、永久奖励和分数，并定期序列化恢复；均正常结束。这些是规则引擎证据，不作为真实卡表、界面或完整组合发布验收的替代。宝石/机器人及相关HTTP回归、game/server静态检查通过。

补查官方东方产品页的实拍图，已确认新版二级复制连锁卡样例为1分、蓝4/黑3/红1；图片只展示部分卡牌，不能据此推断缺失的完整牌表。下载的重复展示图和临时拼图已清理，仅保留两张有新增信息的研究图及来源哈希。

航海家基础路线规则已接入（未开放）：船只支付木材/羊毛、独立15艘库存、海陆位置限制、道路与船只仅通过己方建筑连通、混合最长路线、开放末端旧船每行动阶段移动一次、移动后重新检查连通、海盗封锁进出、海盗移至海洋/外框及仅从邻接船主偷牌。骑士可选择海盗，道路建设可混建道路/船只，配对回合两位玩家各自重置移动限制。合法位置、船只移动目标、库存与机器人已共用规则；末端道路助手不会误移动船只。

增加轴向坐标剧本地图生成，保留地块共享边信息并兼容旧存档的动态邻接查找。官方2025《航海家》规则书第5页“驶向新海岸”四人固定地图已录入：42地块（14海、2金矿、五种资源各5、1沙漠）、27数字、9港口，陆地区域为19/5/2/2四座岛。已将生成的地图与原书逐项图形对照，核对地形/数字/港口位置；初始海盗在外框、强盗在主岛沙漠。主岛限定起始建设、各玩家独立获得首次小岛定居2分、14分胜利已实现及测试。

航海家定向测试覆盖路线交接、对手建筑阻断、关闭航线不因对手插建而可移动、海盗、购船成本、库存上限、道路建设组合、移动原子拒绝/存档恢复、配对行动、机器人行动与公开提示、固定地图组件/拓扑、起始区域和登陆计分。基础卡坦、Helpers、五至六人及相关HTTP/机器人回归和game/server静态检查通过。此阶段尚缺金矿资源选择及计时、其余人数与剧本地图/规则、房间选项/界面/素材/浏览器验收，未将该地图作为可玩选项开放，也未运行宣称完整规则的官方剧本模拟局。核对用临时地图导出和页面渲染已清理，保留固定哈希原始规则书。
