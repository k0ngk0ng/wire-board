# 公共交互修复与创建房间流程验收

本次修复公共回合提示、动画唤醒和结算显示，并将创建房间调整为统一的两步流程；不修改游戏规则、计分算法或电脑策略。

## 原因与修复

- 回合动画暂时移除倒计时后，提示栏失去撑高内容。本机围棋实测桌面高度在 39px 与 32.5px 之间切换，320px 窄屏公共提示栏在 79px 与 41px 之间切换。现保留倒计时布局位置，隐藏时同时从读屏内容中排除，不显示无效时间。
- 动画截止时间包含小数，浏览器计时器可能提前触发。原来的单次唤醒发生在截止时间前时，动画仍锁定操作，且相同截止时间不会再次注册唤醒，直到约 15 秒后的网络轮询才恢复。本地连续落子曾记录约 13.8 秒的停顿。现在向上取整等待时间，并在提前触发时继续等待剩余时间；取消或替换动画会清理最新计时器。
- 结算原来插在玩家栏与棋盘之间。现在使用统一结果浮层，关闭后保留「查看结果」按钮；按对局结果 ID 管理显示周期，普通快照更新不重开，再开一局后下一次结算正常显示。顶部按钮减少时保留原有高度，窗口尺寸变化时重新适配。Escape 关闭浮层时阻止浏览器的停止加载默认行为，避免中断后续请求。

提示栏共用组件覆盖 13 款独立游戏；公共动画唤醒由中国象棋、国际象棋、军棋、围棋和斯诺克使用。结果浮层位于平台入口，沿用全部游戏的原结算内容、积分与房主再开一局权限。

## 两步创建房间

第一步只显示游戏封面目录，支持分类和搜索；点击游戏才进入第二步，显示所选封面简介、房间名称、并排的座位／密码以及该游戏的规则选项。第一步不会默认展开某一游戏的表单，搜索回车和键盘选择游戏不会创建房间。

返回选择游戏时保留筛选状态和公共草稿；再次选择同一游戏保留其规则，选择其他游戏使用对应默认规则。关闭弹窗后清空草稿；已选游戏被下架时退回目录，不继续提交。新旧游戏复用同一弹窗，原有游戏专属规则选择器与提交参数保留。隐藏步骤从键盘焦点循环中排除。

## 重复验收

```sh
. scripts/env.sh
node --experimental-strip-types --test web/tests/*.test.mjs
python3 -B scripts/accept_turn_layout.py
python3 -B scripts/accept_turn_layout_http.py
python3 -B scripts/accept_draw_result.py
python3 -B scripts/accept_create_flow.py
python3 -B scripts/accept_game_filters.py
```

`accept_turn_layout.py` 在浏览器中渲染正式公共组件及实际游戏样式，覆盖 13 款游戏、9 种宽度和 6 种状态，共 702 个组合。检查提示栏高度、棋盘参照位置、倒计时可见性与窄屏溢出。临时入口只用于验收，结束后删除，不进入发布包。

`accept_turn_layout_http.py` 使用真实围棋 HTTP 会话和浏览器，依次在 1440、851、850、390、320px 宽度连续落子，逐帧记录提示栏高度、棋盘位置与动画耗时。另验证真实胜利结算、桌面／手机浮层、关闭与重开、普通轮询后保持关闭、再开一局及文字对比度。`accept_draw_result.py` 验证和局浮层、双方 0 积分、刷新和个人历史；包含 Escape 关闭浮层后的资料请求。

`accept_create_flow.py` 用实际应用和临时数据库验证全部 19 款游戏，在 1280px／320px 下共创建 38 个房间，核对游戏、人数、名称、密码保护及围棋非默认选项。另验证返回草稿、键盘选择、取消清空、上下架变化、图片可见性和新摘要区的计算对比度。目录验收另加入 30 款临时游戏，验证长列表与分类／搜索，临时模块不会进入发布包。
