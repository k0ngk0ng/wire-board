# 管理后台

玩家可在自己的「玩家页面 → 修改密码」中自助改密，入口与会话处理见[玩家修改密码](account-password.md)。管理员替他人重置密码仍使用下文的管理操作。

管理员登录后，点击顶部「管理后台」，也可以收藏 `/?admin=1`。普通账号不能进入，全部管理 API 都在服务端检查权限。

## 永久管理员

生产环境推荐在服务器私有 `.env` 中设置 `ADMIN_EXISTING_USERNAME` 为指定的**已有账号**，重建容器后生效。不会新建账号，也不改变原密码、ID、好友或战绩；昵称不存在时启动失败，不会悄悄创建或提升其他用户。

只有一个永久管理员，角色保存在数据库中。移除启动配置、重启、升级、退出登录都不会使其降权。后台禁止任何人停用、降权、强制退出或重置该账号。更换配置中的昵称也不能接管永久身份。

全新站点也可使用 `ADMIN_USERNAME` 与 `ADMIN_PASSWORD` 创建专用账号，密码须 16–72 字节；不能与 `ADMIN_EXISTING_USERNAME` 同时使用。若昵称已被普通账号占用，不会自动提权。此模式下修改服务器配置中的密码会在重启时轮换密码并撤销旧会话。配置凭据不能提交到 Git。

永久管理员可授予或撤销其他用户的普通管理员权限。普通管理员只能管理普通玩家，不能管理自己、其他管理员或永久管理员。后台没有删除账号功能，以免破坏历史记录和牌桌引用。

## 游戏、用户和牌桌

后台菜单依次为「用户管理」「游戏管理」「牌桌管理」「许愿管理」「操作记录」。点击顶部统计卡片可进入对应列表；在线人数、进行中牌桌和等待开局牌桌会自动应用对应筛选。

### 游戏顺序

进入「游戏管理」，点击「游戏排序」，在独立浮层中拖动游戏封面，再点击「保存顺序」。手机拖动封面右下角的手柄；键盘聚焦手柄后使用方向键。排序同时用于后台、创建房间的游戏卡片和大厅游戏筛选；上架状态保持不变。

分类或搜索后排序，只调整可见游戏所在的位置，其他游戏不变。后台定时刷新不会丢掉尚未保存的顺序；点击「取消排序」可恢复服务器当前顺序。其他管理员已修改顺序时，保存会提示冲突，不覆盖对方的修改。

顺序持久保存在独立的 `game_order` 表，并与操作记录一起提交。重启和升级保留已保存顺序，新注册游戏追加到末尾。

### 管理操作

- **上架 / 下架：** 新注册游戏默认上架；管理员的显式上/下架变更实时生效并持久保存。下架后大厅卡片、游戏筛选、创建选项及该游戏的公共房间列表隐藏；服务端拒绝创建、加入、观战、新开局和再开一局。等待中的牌桌关闭；已经开始的对局和已加入的观战仍可继续，历史战绩保留。管理员可在牌桌管理中单独结束它们。所有游戏同时下架时，大厅显示准备中。
- **停用 / 恢复：** 停用立即撤销所有登录会话，拒绝再次登录。正在比赛的席位转为电脑托管；等待牌桌中的席位移除，必要时转移房主，没有真人则关闭牌桌。恢复后可用原密码重新登录。
- **强制退出 / 重置密码：** 撤销用户的全部会话，包括实时连接，进行中的席位转为电脑托管。重置密码须 12–72 字节，以 bcrypt 保存，管理员自行将新密码私下交给用户；响应和日志不包含密码。
- **结束牌桌：** 可以关闭等待或进行中的牌桌；中止的比赛不计胜负和积分。后台只展示公共席位信息，不展示手牌、隐藏身份或未揭开的计划。
- **许愿管理：** 「许愿管理」按待审核、已通过、正在实现、已实现、已驳回筛选玩家提交的新游戏想法、参考图和 AI 追问记录。AI 制作代理可以直接处理待审核许愿，需求含糊时最多追问 2 次；管理员仍可通过、驳回或推进状态，并附最多 500 字备注。玩家会在「我的许愿」中看到结果并回答追问。代理只能推进状态，不能自行审批。审核、追问和操作记录都会持久保存，展示提交者、时间和参考图地址，但不会展示任何登录凭据。
- **操作记录：** 记录管理员、操作、目标、时间和请求 IP，可翻阅历史。管理写入与日志在同一事务中完成，保存失败不会仅改变内存中的状态。

## 在线情况

后台每 5 秒自动刷新，各列表页右上角另有独立「刷新」按钮。手动刷新时按钮显示等待状态，请求完成后恢复可用。最近 60 秒内有已认证的状态请求或成功 WebSocket 心跳的用户算在线；多个标签页按一个用户统计，另显示连接数。可按昵称搜索或仅查看在线用户，查看大厅、等待开局、对局、托管、观战状态和最近登录/活跃时间。关闭网页后的状态最多约一分钟更新。服务重启后，在线状态依据新连接重新计算，历史活跃时间保留。

在「用户管理」中可查看注册 IP、最近登录 IP，点击每个用户的「查看动态」可翻阅注册、逐次登录、退出、牌桌、好友和许愿操作的时间、对象及 IP。动态和 IP 仅对管理员开放，重启后保留；不记录密码、聊天正文、手牌或高频游戏输入。反向代理配置见[部署说明](deployment.md#nginx已有-https-站点)。

上线已有数据库时，旧账号没有可追溯的注册时间、历史 IP 和访问记录，这些字段显示为「暂无记录」。新记录从本次升级后开始保存，不补造历史数据。

玩家点击右上角「战绩 · 好友」头像入口，可在玩家页面前部查看好友与申请；PC 页面会随可用宽度展开。

## 验证

`go test ./internal/server -run '^TestAdmin'` 覆盖已有账号提权及重启保留、永久身份保护、权限边界、撤销会话、在线去重、六款游戏下架的服务端限制、进行中对局保留、无积分中止、持久化及事务失败回滚。`go test ./internal/server -run 'TestAccessActivity|TestClientIP'` 验证 IP、代理信任边界、动态权限、分页与重启保留；`python3 -B scripts/platform-admin/run-acceptance.py` 生成真实浏览器验收记录与截图。发布按影响范围执行必需检查，并核验 GitHub 构建和镜像。
