# 八位经典神将规则核对

依据固定提交 `e8768851bd8054db9fd1b63cd6f1feca813590d7` 的 `src/package/god.cpp`、`lang/zh_CN/Package/GodPackage.lua` 及 `src/server/room.cpp` / `gamerule.cpp`。不混入移动版或后续改版。神将包已完成本地规则、界面、电脑、隐私与素材验收，随整批扩展发布。

- 神将选将后选择魏/蜀/吴/群势力，保存为基础势力；化身神将时另行选择势力，失去化身后恢复本人的基础势力。神将仍按经典身份局胜负。
- 神关羽（5）：武神是强制过滤红桃手牌为普通杀，不能再按原牌使用；红桃杀无距离限制，不增加出杀次数。须同时更新本人牌面和处理区牌面，离开其手牌/处理区后恢复原牌。武魂在实际伤害扣血前给其他来源等量梦魇；自己死亡且本局尚未结束时选择存活梦魇最多且非零的一人判定，不是桃或桃园结义则直接死亡，不能求桃。并列由已死亡的本人选择，需要允许此特定死亡响应；不能泛化为阵亡玩家仍可出牌。判定后清除梦魇，嵌套死亡完整结算。
- 神吕蒙（3）：涉猎替代摸牌，公开亮5张，每花色必须取得一张，其余自然置入弃牌堆。攻心每出牌阶段一次，仅使用者可看另一人的全手牌，可放弃，或选其一张有效红桃弃置/放回牌堆顶；不能向其他人或观战者公开整手牌。
- 神周瑜（4）：琴音统计整个弃牌阶段真正弃置的自己的牌，至少2张后可令全场各回血1或失去体力1，逐人完整结算濒死。业炎整局一次，小业炎对1–3名不同角色各1火伤；大业炎弃四花色手牌各一张、失去3体力，再分配总计3点火伤到1人或2人（3，或2+1），先完成自损濒死，来源死亡后仍结算已支付效果。目标可含自己。
- 神诸葛亮（3）：七星起手4+7=11张，选7张秘密置为星，剩4手牌。摸牌阶段结束可等量交换手牌与星；跳过摸牌阶段不交换。结束阶段可用1星对1人狂风，再用N星对N名不同角色大雾。星的实体牌仅本人可见，其他人仅见数量；标记及目标公开。狂风在受伤预处理加1火伤，大雾防止所有非雷电伤害（不防失去体力），先于天香和护甲；转移/连环的每个接收者分别处理，不能在同一人的响应恢复时重复加成。效果在施术者下次进入回合开始阶段或死亡时清除；失去七星清除星牌。固定源码在武将背面直接跳过回合时不进入回合开始阶段。
- 神曹操（3）：归心每点伤害可选择一次，依次从每名其他存活角色手牌/装备/判定区取得1张，然后翻面；中途死亡停止剩余获得，支持连续伤害多次翻面、失去装备触发和保存恢复。飞影他人到自己距离+1。
- 神吕布（5）：开局2暴怒，造成与受到伤害后各按点数获得。无谋使用非延时锦囊（含无懈）须弃1暴怒或失去1体力，在锦囊继续前完成濒死。无前可多次，每次2暴怒指定他人；自己本回合获无双且目标整个防具失效，到回合结束/来源死亡清除，不能误删原有无双。神愤每出牌阶段一次付6暴怒，按三批顺序让全体其他人受到1伤害→弃全部装备→弃4手牌（不足全弃），最后自己翻面；不是对每人连续完成三项再处理下一个。
- 神赵云（2）：旧版绝境正常摸牌数加已损失体力，手牌上限+2。龙魂用max(1,HP)张同花色手牌或装备：红桃桃、方片火杀、黑桃无懈、梅花闪；每次按支付时体力校验，包含装备损失、响应、濒死和连环联动。
- 神司马懿（4）：忍戒受到伤害后按点数加忍；弃牌阶段真正弃置自己的牌按张数加忍。拜印准备阶段忍>=4，减1上限并获极略。极略分别扣忍发动鬼才、放逐、集智、制衡、完杀；制衡与完杀各每出牌阶段一次，完杀仅本回合，原本拥有的技能不能被临时技能清理误删。连破记录任何人的本回合内击杀，回合结束可插入自己的额外回合，下一回合开始清零记录；复用放权的持久化续接与120秒计时。

源码顺序核对：`Room::killPlayer` 先处理 `GameOverJudge`，未结束再触发 `Death`、清理遗牌与奖励。故已因本次死亡结束的比赛不继续武魂，尚未结束的武魂直接死亡可进一步触发胜负。`Room::damage` 为预处理→来源加成→受伤替代/防具→扣血前标记→伤害及受伤后技能。

实现重点：私有星/攻心牌和公开展示分离；武神有效牌型与原始实体牌；可持久化的临时技能/护甲失效/星效果；无谋与大业炎的中断恢复；琴音/忍戒/固政共享准确弃牌原因；极略明确采用该提交中实际引用的标准技能版本，与现有怀旧黄月英、司马懿分别实现。


极略的版本差异已核定：固定源码引用标准 `Jizhi`，任何锦囊（含延时）亮出顶牌，非基本直接获得，基本牌可用一张手牌置顶交换；不是怀旧黄月英的非延时锦囊摸1。`Guicai` 在神司马懿有手牌时询问极略，支付1忍后可用手牌或装备换判。放逐按本次伤害触发一次，目标摸当前损失体力数再翻面；制衡弃手牌或装备再摸等量，不额外奖励全部手牌。技能说明和独立测试均体现这些版本差异。


死亡续接核对：`standard-cards.cpp` 的顺手牵羊、过河拆桥在使用者阵亡后直接结束，不询问阵亡角色；借刀的持械者仍可响应杀，但失败时不把武器交给已经阵亡的使用者。新增无谋致死后的专门回归测试。武魂直接死亡引发另一个武魂时，梦魇在嵌套死亡结算后清除；只开放阵亡者自己的 `wuhun_target`，其他动作仍拒绝。
