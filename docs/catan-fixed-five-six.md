# 卡坦岛五至六人固定新手布局

来源为固定清单中的 `catan-base-5-6-2025` 第2页，结合基础规则第4页的固定开局说明。PDF SHA-256：`7b7285e178689585ca39c2c72f78ce20a78c02608c40dd3be2cd9f97c8d95ea1`。已渲染完整页和局部港口图，将实际页面逐格对照地形、数字、建筑、道路和港口朝向。

## 已实现

`NewCatanFixedFiveSix` 是内部构造入口，限定启用五至六人扩充且实际5或6人。地图为30块陆地，行长3/4/5/6/5/4/3；地形、数字和11个港口按官方图固定，不使用随机地形或打乱港口。每色两座村庄、两条道路，起始资源取自官方图黑框标出的第二座村庄，各三张。资源库存为每种24张，发展卡34张，沿用2025配对回合及10分条件。

颜色独立随机分配，六色均可能分配给任意真人或电脑；先手仍独立随机。五人局剩余颜色的两座村庄照图放置，不放道路。中立村庄以 `owner=-1, level=1` 保存，不创建虚假的第六名玩家，不获得资源、不参与分数或偷取，也不能升级；距离规则、道路连接和最长道路仍将其视为阻挡建筑。普通空点同样owner=-1但level=0，不能据owner单独判断是否空置。

`baseSetup` 保存固定规则身份、每座位颜色和中立颜色，六人无中立时为-1。前端玩家栏、道路、建筑和原版素材共用颜色映射，中立村庄有专门的无障碍名称；不读取不存在的玩家。基础旧存档及海盗群岛颜色映射保持原逻辑。玩法速查显示固定布局和五人中立规则。

开局直接进入随机先手的掷骰阶段，已预放的村庄不再让玩家重复建设；Helpers启用时按先手相对座位发初始助手，第一次行动即可使用。强盗初始放上方沙漠：规则只要求沙漠，两个沙漠都不生产；这是确定性默认位置，并非声称规则书指定上方一块。固定图与随机图使用不同初始化流程，未改随机图的数字序列。

## 房间配置与正式流程

房间用独立的 `catanBaseConfiguration` 保存 `layout/rules`，实际游戏用 `baseSetup` 冻结规则、布局和随机颜色。`NewCatanConfigured` 按实际开局人数构造，五至六人可选固定新手或随机布局，三至四人暂时仍只有既有随机布局。固定布局直接进入掷骰，随机布局保留两轮起始建设。两类地图均在实际存档记录身份；无配置的旧房间不添加新字段。

配置目录只发送给已内部预置配置的等待房间；公开创建严格拒绝该字段，普通房间的配置命令也不能启用它。只有房主可改，修改后取消真人准备并保留电脑准备；同布局不重置。非法/缺失/过期/非房主请求不改变房间。关掉五六人扩充会转回支持的随机布局及基础规则版本，重新启用后仍保留随机选择；不会悄悄切回固定地图。布局与航海家配置/新世界草稿互斥，损坏或混合的等待配置也拒绝开局。

设置面板与玩法速查在等待阶段显示布局说明，客人只读。正式开局后停止发送选择目录，布局不可再改；战绩读取实际游戏字段并显示“固定新手布局”或“随机布局”，不会把基础地图标为航海家，也不受残留房间草稿影响。再开一局保留布局、真人重新准备，随后重新生成本局颜色和先手。

验证覆盖配置权限、未开放入口、原子拒绝、准备、人数切换、等待持久化/服务重启、六人容量下实际五人固定开局及120秒、混合配置拒绝和历史身份。配置HTTP定向race通过（4.022秒）。四场5/6人×普通/Helpers完整HTTP局只预置等待配置，随后正式准备/开始，不在开局后替换状态；均经过初始存档、配对第二行动阶段和待回应阶段服务重启后继续至胜利。首轮469–618步、28–37次托管、1–6次超时，共10.73秒，隐私、结算战绩和结算后禁止新观战均通过。
