# 林包实现核对

规则依据固定提交 `e8768851bd8054db9fd1b63cd6f1feca813590d7` 的 `src/package/thicket.cpp`，无怀旧替代版本。实现与验证记录见 `sanguosha-expansions.md`。

- 曹丕（魏3）：行殇在非终局死亡结算期间可获得死者手牌与装备，不含判定与不屈牌；放逐按本次伤害一次发动，目标摸曹丕当前损失体力数的牌并翻面；颂威由其他魏角色黑色判定后自行决定是否让主公摸一张。
- 徐晃（魏4）：黑色基本牌或装备牌可作兵粮寸断；包括装备区。兵粮距离增加1，支付坐骑后的距离仍须合法。
- 孟获（蜀4）：祸首免疫南蛮；其他人使用南蛮时记录孟获为伤害来源，后续孟获阵亡则无来源。再起代替摸牌，亮出损失体力数的牌，红桃回复，其余获得，不是判定。
- 祝融（蜀4，女性）：巨象免疫南蛮，其他人使用南蛮结算后若实体牌仍在处理区则获得（不抢夺已被奸雄取走的牌；怀旧蛊惑实体牌也支持）。烈刃仅自己的杀直接造成伤害后，与存活且有手牌目标拼点，赢后获得其手牌或装备一张；不含转移/连环伤害和判定牌。
- 孙坚（吴4）：准备阶段受伤时，可令另一角色摸X弃1或摸1弃X；弃牌可含装备，不足则全弃。
- 鲁肃（吴3）：好施摸牌+2，摸后手牌>5则必须交出一半（向下取整）给其他手牌最少角色之一；缔盟每阶段一次，支付两名其他角色的手牌数差后，原子交换两人的手牌。不能暴露手牌ID给使用者/旁观者。
- 董卓（群8）：酒池用黑桃手牌作酒；肉林与女性互相使用杀要求两闪（不与无双叠成四闪）；崩坏结束阶段若有别人HP更低，强制选择失去1HP或1上限；上限到0直接死亡。暴虐由其他群角色造成伤害后决定，判定者为造成伤害者，黑桃使主公回复1。
- 贾诩（群3）：完杀在自己的回合限制救桃为自己与濒死者；乱武整局一次，按座次要求其他人对最近距离目标使用杀或失去1HP，逐个完成求桃/伤害后再轮下人；帷幕禁止成为黑色锦囊目标，含延时与群体牌，经典蛊惑声明的例外按固定规则处理。

关键联动重点：死亡遗牌持久化与阵营结算；祸首与刚烈/反馈/奸雄/击杀奖惩；巨象与蛊惑；烈刃与拼点隐私；好施和缔盟的空手联营；完杀与涅槃/不屈/酒/蛊惑；肉林与八阵；颂威/暴虐与鬼道/红颜；乱武与主公技、转化杀、装备、最近距离变化。
