# 征服时代验收记录

## 范围与来源

征服时代为独立模块，使用世界和欧洲两张地图。开放 2～8 席、三档电脑难度、公开地图与战争迷雾；支持真人／电脑混合、托管、观战、暂停保存和恢复。规则实现参考已核对的旧版桌面执行行为，iOS 同版精确一致性未被证明。详见[规则证据](research/conquest/legacy-rules.md)及[游戏说明](../games/conquest/README.md)。

本次规则、地图、界面及平台修改均在独立 `feat/conquest` worktree 完成。测试场景和契约先于实现编写；独立审阅发现的问题先复现，再修复。

## 完整对局与服务端

- 84 场模块完整对局覆盖 `2 地图 × 7 人数 × 3 难度 × 2 迷雾设置`，无缺失、重复或额外组合；全部使用正常开局资源和生产电脑策略自然结束，无注入资源、强制赢家或用投降代替收尾。5～48 轮，共 71,969 个行动／计时步骤。
- 每局保存初始状态、上下文时钟、完整动作和计时回放、终局、源码与地图 SHA-256。84 份压缩回放均完整，摘要与验收时的源码一致。证据索引：`.local/conquest/rules/release-matrix/index.json`。
- 14 场真实 HTTP 完整对局覆盖两张地图全部 2～8 席。真实账户提交生产策略，通过平台鉴权、版本校验、幂等和 SQLite 事务；从初始快照逐条重放，所有提交后的快照摘要一致。该矩阵减少了平台电脑的等待间隔，不能用它证明实际调度速度。
- 实际平台电脑席位与真人托管另完成一局自然对局，使用宿主正常调度。记录：`.local/conquest/http/TestConquestAutoPlayMixedCompleteHTTP/`。
- HTTP 边界覆盖公开注册、未授权／观众拒绝、独立玩家同时规划、私有计划、重复 nonce、撤回／撤销、过期指令、重启、暂停／恢复、托管接管和全员加载屏障；定向规则与 HTTP 竞态检查通过。

## 公共平台

显式暂停保存 30 天，普通房间仍为 24 小时。暂停停止普通电脑、后台选步及系统推进；实时帧中进入暂停会阻止剩余电脑操作，暂停／恢复必须先持久化再广播。后台迟到结果不再生效。验证覆盖 SQLite 失败回滚、幂等、重启和到期关闭文案。

独立操作期限的模块可声明 `ReclaimOnCancel`。征服时代启用后，非全局最早但已经过期的玩家取消托管，也能恢复自己的窗口，不延长其他玩家期限。原有模块默认保持原调用方式。验证记录分别位于 `.local/module-pause/` 和 `.local/module-reclaim-cancel/`。

公共平台按既有 scope 运行 HTTP、存档与竞态检查；未将其他游戏的完整对局或规则矩阵纳入本次改动范围。全项目编译、`go vet`、格式与游戏边界检查通过。

## 浏览器与素材

最终浏览器验收通过 63 项，保留 22 条原生输入记录，覆盖两张地图、桌面／320px、8 席、迷雾、观战、托管接管、私有计划、暂停恢复、实际占领、两次结算关闭／重开及再来一局。真正行军结算的逐帧检查覆盖 `planning → resolving → planning`，地图和操作区几何变化小于 1px；零金币在 PC／320px 分别连续 14／13 帧真实可见。采样文字最低对比度 4.87:1。静音、重连事件游标和各地图只加载自身代码块均已核对。

最终报告为 `.local/conquest/browser/result.json`，`source-binding.json` 记录源码、构建入口和报告摘要。截图：[世界桌面](screenshots/conquest-world-desktop.png)、[欧洲桌面](screenshots/conquest-europe-desktop.png)、[手机选区](screenshots/conquest-mobile.png)。

地图来自 Natural Earth 公有领域数据，世界 206 个地区／48 条海路，欧洲 75 个地区／17 条海路。离线重建、边界、邻接、连通、海路和起始位置验证通过。地图是独立制作的地理分区，不是复制原版商业素材。

3 段原创 WAV 已验证解码、时长、音量、平滑起止与重复生成一致性，并发布到不可变 `conquest/v1/audio/` 目录。OSS 与 CDN 回读均核对 SHA-256、字节数和 MIME；[发布回执](../games/conquest/assets/published.json)绑定当前素材清单。音效通过平台播放与静音通道，不创建独立播放器。

## 复跑与发布约束

完整命令见[游戏验收复跑](../games/conquest/README.md#验收复跑)。本地浏览器使用真实 Chromium 与原生鼠标／触摸输入、桌面及 320px 移动视口；不将移动视口模拟标为手机真机。

最终 main 检查按增量范围选择征服时代及公共平台。只有同一提交的 `Test and Linux amd64 binary` 成功且有效产物存在，才能打版本 tag 发布。tag 作业必须以该 tag 为 ref，复用已验证二进制，不重新编译游戏或再次运行完整矩阵。
