# 三国杀响应筛选与验证

无懈可击窗口只等待当前确实能响应的玩家，不再要求所有存活玩家逐个放弃。没有可用响应时直接继续结算；成功反制后，重新检查剩余手牌、技能状态和响应资格。

筛选使用规则合法性，不使用机器人的出牌倾向。原生无懈、国无懈、看破、龙魂、蛊惑等合法响应均保留；技能失效、手牌禁用、花色或数量不足时，不会仅因「拥有技能」而弹出空提示。查询响应资格不会明置国战武将、触发奖励或向其他玩家公开手牌。

杀／决斗响应、求桃、护驾／激将协助、火攻弃牌，以及部分改判和装备响应，也会跳过没有可用选项的环节。八卦阵、八阵、可转化的牌、无需牌的技能和蛊惑质疑仍保留选择。只打出无双所需两张牌中的第一张后，会再次检查第二张的响应能力。

响应权限、玩家视图、机器人和超时接管使用相同的无懈资格判断。无牌玩家和观众没有响应按钮，无法提交放弃操作，也不会因其他人的响应超时而被托管。仍然有效的多人响应沿用同一提示编号和截止时间。

服务重启时会继续处理旧存档中无人可响应的窗口，并恢复剩余回合时间。已超过闲置期限的房间交由闲置关闭流程处理，不借升级推进牌局或结算积分。

## 验证结果

- 三国杀完整规则测试：159 个顶层用例通过，含子用例共 395 个通过事件；覆盖标准、军争、各武将包、国战和 3v3。
- 服务端相关验收带 `-race`：13 个顶层用例通过，含子用例共 18 个通过事件；包含多人响应、超时、断线恢复、旧空窗口恢复及闲置房间处理。
- 真实浏览器：9 个检查点通过。四个独立会话分别验证出牌者、持有无懈者、没有无懈的玩家和观众；持有者刷新后仍能选择，放弃后所有会话立即继续。桌面与手机检查无 JavaScript 错误、手牌泄露或横向溢出。
- 前端 265 项测试、TypeScript／Vite 生产构建、`go vet ./...`、Go 构建及游戏依赖边界检查通过。

现有测试中专门验证人工响应顺序的场景，已提供真实可用的牌；原先要求手动放弃空响应的步骤，已改为验证自动继续。未删除这些规则用例。

## 重复执行与产物

从仓库根目录执行，浏览器验收需要已安装 `agent-browser`：

```sh
. scripts/env.sh
mkdir -p .local/sanguosha-responses
go test -json -count=1 -timeout=5m ./games/sanguosha/server \
  > .local/sanguosha-responses/engine-all.jsonl
go test -json -race -count=1 -timeout=5m \
  -run 'Test(Sanguosha|TimeoutAutoplay.*Sanguosha|AutoPlaySanguosha)' ./internal/server \
  > .local/sanguosha-responses/http-race.jsonl
python3 -B scripts/accept_sanguosha_responses.py
```

`.local/sanguosha-responses/http-acceptance.json` 保存 HTTP 场景轨迹；`browser/result.json` 保存浏览器断言结果，同目录保存各会话截图、页面快照和运行日志。浏览器夹具仅在显式启用的测试中启动，不增加生产接口。
