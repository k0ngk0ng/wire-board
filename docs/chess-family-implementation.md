- 最终公共平台检查已通过（含 `-race`）：`.local/ci/shared/result-0.json`。专项汇总、当前源文件摘要和实际通过事件见 `.local/chess-family/async-bot/result.json`；公共检查运行中的全部新增异步用例通过。`go vet ./...`、模块边界和 11 项检查范围测试通过。没有运行无关游戏的规则或完整对局矩阵。

复现专项：

```sh
. scripts/env.sh
go test -race ./internal/gameapi ./internal/server \
  -run '^(TestBotSearchRegistration|TestModuleAsyncBot.*|TestModuleIdleBotSchedulingHTTP|TestModuleRegistrationAndLifecycleE2E|TestModuleBotAndTimeoutE2E)$' \
```

每个新增 HTTP 用例会在 `.local/chess-family/async-bot/` 保存自己的 JSON。专项和完整公共检查都必须通过，不能用旧的失败日志或单个通过项代替最终验证。

## 后续实施次序

1. 公共异步调度与显式和棋契约已通过当前验收。真人和棋双方积分保持不变，保留和棋历史。
2. 五子棋是该接口的第一个真实使用者，已完成本地实现和验收；它不作为整个目标的替代。
3. 分别实施国际象棋、中国象棋、军棋两种模式、围棋，不把不同棋的规则写进公共平台。
4. 每款游戏完成自己的完整电脑对局、混合席位、手动接管、重启恢复、PC 原生输入与 320px 手机验收，并准备和发布素材。
5. 对照上表逐项审计实际实现和产物，全部满足才完成目标和发版。增强引擎是调研候选；不能用它们替代无额外服务依赖的基本电脑。

验证范围遵循当前 `AGENTS.md`：公共平台和模块契约始终验证；某游戏的规则、完整对局和竞态只在该游戏规则／测试／夹具实际变化时执行。图片／前端改动检查对应游戏与必要的公共界面，不扩大到无关游戏。
