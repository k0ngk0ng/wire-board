# 独立国战基础模式

身份局继续采用既有 QSanguosha-v2 固定版本。国战改以独立项目 [Mogara/QSanguosha-For-Hegemony 2.0.0](https://github.com/Mogara/QSanguosha-For-Hegemony/tree/c787f870ac8f30084800c08782c89ba4ca32b039) 为依据，固定提交 `c787f870ac8f30084800c08782c89ba4ca32b039`。旧 QSanguosha-v2 中的 Basara/EnableHegemony 是较早的暗将模式，不能拿来替代这一规则集。

本阶段完整范围是该版本的基础国战：四势力各15将，共60将；108张标准国战牌；不混入该项目的君临天下等后续包。身份局的军争、风火林山、神将、界限突破仍为独立选项，不把这些身份将自动塞进双将候选池。

## 规则与实现

- 独立持久化模式状态与 `heg_` 武将 ID；每席七名私有候选，候选不重复，从中依次选择主将、副将，要求同势力且不同卡。主将与副将体力值相加除以二、向下取整；无主公加血。随机先手，起手四张。
- 公共姓名、势力、性别、有效技能只从已明置武将构建。主将明置后按主将性别，否则按已明置副将；全暗置时没有公开性别，不能被离间、结姻当作男性。本人可以查看两将和自己的候选/手牌；观战者不获得这些信息。
- 19对珠联璧合关系。按固定版本：首亮可摸二；双将明置且珠联璧合可摸二或回复一；双将总阴阳鱼为奇数时双亮可摸一。奖励是当时的选择，不是后续版本中可随时使用的奖励标记。放弃后也消耗该次奖励。终局和死亡强制亮将不奖励。
- 已亮同势力人数（含阵亡）超过开局人数一半后，新亮者成为野心家；每个野心家独立。未亮将不算公开队友。阵亡亮出两将；同势力阵亡队友随本势力共同获胜。若剩余暗将可能变成野心家，不能自动亮将强行结算。
- 未亮杀手不获击杀奖励；杀敌摸“死者加其仍存活公开同势力人数”张牌，野心家为一张；杀同势力则弃全部手牌和装备。
- 完整108张实体牌，卡ID为1001–1108，原有1–160的身份局卡ID不变。修正公开有效牌面过滤对连续ID的假设，支持国战红颜等牌面转换和保存恢复。
- 以逸待劳冻结使用时的公开同势力目标，逐目标无懈、摸二，所有摸牌完成后再逐人弃二；被无懈的目标不弃牌。中途恢复保留哪些目标已生效。
- 知己知彼可查看手牌、暗置主将或暗置副将；信息只给使用者，查看武将不会亮将或改变势力。武将情报可保存在使用者的私有状态里；重铸摸一，不触发集智。
- 远交近攻要求使用者和目标均已亮将且不同势力；目标摸一、使用者摸三。吴六剑仅增加其他已明置队友的范围、不叠加；三尖两刃刀仅针对杀的直接伤害，弃手牌后伤害受伤者距离一的第三人，不能伤原目标、自己或由传导再触发。
- 国无懈可选单人/势力；反制其他无懈时只能单张反制。首张国无懈的范围随反制链保留，最终生效时按当前公开势力取消同一锦囊的后续目标，已处理目标不会回滚。
- 国战仁德给三张才回复；制衡至多体力上限张、每阶段一次；离间生成可无懈的决斗；奋迅为本回合单向固定距离一；雄异只惠及公开队友且判定最少势力；度势每阶段四次转以逸待劳；集智排除牌型改变的转化，保留同牌型单张虚拟复制。

- 洛神黑牌在判定序列结束后批量获得；与天妒的先拿/暂留、途中停止、保存恢复和死亡清理均不重复或遗失实体牌。
- 骁果、淑慎、神智、短兵、名士、礼让、双刃、死谏、随势、狂斧、倾城与国战断肠已接入规则及定向测试。礼让只分配本次真实弃牌，不取响应/使用牌或旧弃牌；双刃拼点未赢跳过出牌，赢后可攻击对手的公开盟友且不计普通杀次数；断肠由阵亡本人选择主/副将，只废一槽且不公开对方暗将。
- 准备阶段可亮主将、副将或两将；合法主动/转化技能才亮对应槽。马术、奇才、咆哮、短兵只在具体出牌需要其距离/次数/额外目标时亮将，公开范围查询不触发。祸水在拥有者的实际回合内禁止其他角色新亮将，已明置技能仍可使用；非法动作原子回滚亮将与奖励。
- 共用可选触发和新国战响应接入隐藏技能资格检查。没有发动时保持暗置；其他玩家/观战者只能看到通用等待提示，不能从技能提示种类获知暗将。亮将奖励在支付已提交的费用后、后续事件或二次选牌提示前处理；待恢复提示仅存服务端，恢复后更换响应ID。
- 空城、谦逊、帷幕按国战在使用牌后取消目标，不沿用身份局禁止选中的规则；首亮摸牌使空城手牌不再为空，也不撤销已经发动的本次取消。隐藏无双、享乐、完杀、名士、随势、狂骨和判定结束改判后的红颜可选择亮将；明置后对应锁定技执行。八阵响应可亮将，受青釭剑/已有防具限制。
- 祸首在南蛮选定目标时声明本张牌的伤害来源；随后仅为免疫南蛮而亮将不会追溯改换来源。巨象可在免疫时放弃亮将，再在本张实体南蛮进入弃牌堆时选择亮将获得；奖励导致弃牌堆重洗也保持实体牌守恒。

- 固政先返还当前角色弃置的一张手牌，再独立选择是否获得其余弃牌；第二步可放弃或超时放弃。首亮奖励与返还牌的获得触发先处理，奖励导致弃牌重洗后不能重复获得旧牌。返还资格遵循该版本中文说明的“弃置手牌”，不扩大到其弃置的装备。
- 英姿＋好施可叠加摸五，再按全部手牌执行好施分配；突袭替代正常摸牌，不同时触发裸衣。共用技能按国战的暗将资格、公开性别/势力与锁定技时机处理，身份局原版行为保留。

## 界面与运行

创建房间或开局前可选择“基础国战”；该模式固定60将和108张国战牌，不能混入身份局牌堆、武将包或界限突破。修改选项会重置准备状态，开局后冻结。七名候选仅本人可见，先选主将再选同势力副将，确认前可交换；所有玩家均有120秒选将，必要超时选择合法组合。

主副将分别展示，暗将对别人显示统一背面。本人可以展开两将技能、珠联璧合/半阴阳鱼奖励状态与知己知彼的私有情报。新锦囊、技能、亮将与奖励均有相应操作按钮；国无懈可选单人或势力范围。候选和主副将布局适配桌面与手机，桌面中间公开牌宽112px、手机76px，牌名和点数同步放大，超出时仅牌区横向滚动。

电脑与托管使用同一规则校验和势力策略，包含队友救助、国无懈范围/反制、隐藏转化、新主动技能与新提示，只读取自己的暗将和手牌、对方已公开信息。可选响应超时放弃，必要选牌与分配自动合法完成。结算事件和待响应状态全部持久化；重启可以继续选将、亮将奖励、秘密情报与技能链。

国战画像和专用牌取自同一固定上游版本：60张画像、1张暗将背面、6种专用牌图，共67张WebP。通过 `scripts/prepare_sanguosha_assets.py --pack hegemony` 生成，资源使用相对路径 `sanguosha/v9/`。来源、大小与摘要见 [素材清单](sanguosha-hegemony-assets.json)，上传后逐张下载核对SHA-256。地址和凭据只保存在部署配置中。

## 验证

- 核对60将与固定版本中文技能说明、专用规则的源实现；版本差异使用独立技能ID或国战分支。身份局与国战使用各自的胜负、候选和实体牌表。
- 定向测试覆盖双将候选隔离、非法动作原子拒绝、暗置技能/锁定技、技能丢失、首亮奖励及牌堆重洗、双将摸牌、死亡奖惩、野心家、共同胜利、私有查看，以及专用锦囊/装备的反制和中途恢复。
- 八局四人及四局八人的轮换整局覆盖全部60将，电脑与超时混合驱动，定期核验108张实体牌守恒并保存恢复。另有队友策略、隐藏信息不影响决策、HTTP完整对局与阵营积分只结算一次的测试。整局模拟验证流程可完成，不代表穷尽所有双将组合和技能顺序。
- HTTP验证选项权限、准备重置、开局冻结、4/8人选将计时、观战禁止操作与秘密隔离，以及服务重启后继续选将。
- 浏览器验证1440px桌面与390px手机的候选、主副将交换/确认、图片加载、以逸待劳弃牌、首亮与半阴阳鱼奖励、知己知彼、礼让、狂斧、国无懈、倾城和固政获得/放弃；无页面横向溢出或JavaScript错误。中间公开牌实测宽度112/76px。

本版本范围为基础国战，不包含君临天下等后续国战包或3v3模式。
