# 连点音效回归

## 实现前失败场景

- 连点时创建、重载和销毁大量原生播放器，较短间隔内的播放反复被后续操作中止。
- 多个短音效共用一个播放器时，后来的声音中断前一个声音；组合按钮不能使声音丢失或阻塞游戏。
- 使用缓存混音后，必须实际解码原有 FLAC/WAV、输出非零 PCM，并由原生媒体流持续播放；不能用静音或丢弃所有事件伪装流畅。
- 重复事件、历史校正和恢复不能补播旧音效；过期下载、解码和播放结果不能恢复已经停止的声音。
- 短音效与空间音效的同名通道互不替换，移动空间监听器不得改变居中短音效的音量和声像。
- 静音、离开、页面隐藏和暂停须立即取消短音效；恢复只接受新事件，音乐维持现有暂停和恢复行为。
- 解码失败、媒体拒绝、缓存和并发上限沿用平台短音效的有界处理，不能影响规则运算或触控。

## 播放契约

`GameAudioPort.transient` 用于最长 5 秒、无需续播的短音效。按通道替换，以 playbackID 去重；平台复用一个原生媒体输出及有界解码缓存。暂停取消短音效，恢复不补播；需要暂停后继续原位置的声音仍使用有限播放器或音乐接口。空间音效和居中短音效共享解码缓存，但独立管理通道、声像及停止操作。

## 重放入口

`TRANSIENT_REFERENCE_SHA=2f7ed8dd355a928ec81ad9d3a2897c414f3a9dc8 node web/tests/transient-audio-browser.mjs <工作区内的 Playwright 模块> <浏览器可执行文件>`。默认使用 WebKit，设置 `BROWSER_ENGINE=chromium` 可运行 Chromium 对照。Playwright 版本为 1.65.1，WebKit 构建为 2388。入口冻结旧游戏适配器，对比当前适配器的相同原始音效；使用原生触控，记录媒体播放结果、解码次数、实际启动音效、输出采样和原生媒体流时钟。报告与截图保存在 `.local/yuyuhakusho/effect-mixer/`，属于桌面浏览器验证。
