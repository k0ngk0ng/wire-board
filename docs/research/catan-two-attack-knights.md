# 双人蛮族进攻＋城市与骑士：引擎阶段

2026-10-09。本阶段接通双人组合内部引擎，尚未开放服务器建房和网页操作。F10、F12 均未完成，总进度保持 **10/12**。自然引擎对局不等于 HTTP 或真人网页验收。

## 规则来源及组合裁决

已核对官方 [双人＋城市骑士规则](https://www.catan.com/sites/default/files/2025-07/CATAN%20for%202%20w%20CnK.pdf)与[蛮族进攻＋城市骑士规则](https://www.catan.com/sites/default/files/2025-07/Barbarian%20Attack%20w%20CnK.pdf)。另搜索官网三者同开的中立骑士说明，未找到专门条文。按用户授权，以下冲突采用明确标识的本站补充规则。

- 两家中立势力各使用城市骑士棋子，替代普通双人蛮族的一名共享骑士。普通双人蛮族仍使用原规则标记，不改变原存档含义。
- 中立骑士在城堡空边免费招募；当前玩家代两家中立势力完成回合末移动、城堡离开和被驱逐后的退让。中立骑士始终不激活、不升级三级、不参战、不获得俘虏。
- 蛮族城市骑士的损失补偿优先：真人骑士损失或降级领取 3 金币，不再叠加普通双人蛮族的筹码损失补偿。
- 真人村庄与中立村庄分别触发登陆，筹码仍可移动一个蛮族。建设、船面事件、金币、俘虏与 13 分目标使用蛮族城市骑士规则。

以下行为直接沿用官方双人城市骑士规则：两次完整生产；普通骰子总数不同，事件牌保留连续两张相同点数；招募后额外招募一家中立骑士、不能招募时改建道路；一级升二级后对应中立升级；贸易筹码有限；移除自己的道路骑士按等级兑换筹码；叛变可选中立势力但须移除最低等级，替代骑士不再触发中立招募。

## 本阶段实现

- 新增独立版本标记 `catan-for-two-attack-knights-site-v1`；多人公开入口继续拒绝双人组合，等待后续联机和界面验收。
- 接通双人两次生产、事件牌接续、招募／升级中立回应、锻造连续两次中立升级、有限筹码、建筑登陆、强制交易和蛮族移动。
- 道路骑士移动计划支持中立棋子，退让由当前真人代办；叛变中立最低等级约束、私有选择和超时托管一致。
- 新增道路骑士筹码兑换位置投影；修复带中立道路骑士时公开库存投影使用负下标的问题。
- 移动蛮族征服商人所在地时移除商人。普通双人蛮族、普通双人城市骑士、三至六人组合保持独立规则。
- 事件牌抽取在记录第二个点数后、正式开始生产前属于过渡状态：校验上一稳定状态，完成第一轮时恢复第二轮生产阶段，避免错误拒绝合法抽牌。

## 验证与剩余

自然引擎完整局覆盖事件牌开／关两种配置，并定期 JSON 恢复、校验以及生成本人、对手、观战投影。专项覆盖招募与升级、有限库存与兑换不足、不能招募时改建道路、中立不参战、驱逐／退让权限、叛变最低等级／私选／托管、损坏存档、锻造连续回应、连续相同事件牌点数和公开入口保持关闭。

本阶段没有运行双人组合 HTTP 完整局或网页验收。还需接通建房／等待切换、双人中立骑士颜色与地图选择、道路骑士兑换界面、叛变中立目标、规则提示、战绩标记，验证回应时钟、恢复和基础隔离，再进行手机／桌面操作检查。三至六人退让及叛变的专项 HTTP 路径仍保留为待办。

本阶段最终验证：双人组合完整局及专项 `go test -race` 通过（60.812 秒）；包含普通双人蛮族、普通双人骑士和多人道路骑士计划／叛变的回归竞态检查通过（99.720 秒）。新增边界、完整公开投影及两次事件牌的最终普通测试通过；服务器既有多人组合计划时钟／回基础和公开配置定向回归通过（1.681 秒），`go vet ./internal/game` 与 `git diff --check` 通过。服务器回归验证的是既有入口，不计为双人组合 HTTP 验收。
