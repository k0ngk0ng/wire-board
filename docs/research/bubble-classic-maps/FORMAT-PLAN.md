# 原始经典地图提取：实现前边界

来源固定为保留的 2002 客户端 Fx.idx / Fx.idd / CA.exe；原始资源编号不等同后续国服地图编号。

提取前列出的失败场景：索引重复名、越界、重叠；对象名长度越界／编码错误；对象表负偏移或体边界错误；地图尺寸／出生点越界或重复；地图扩展段被误当格子；地面／对象引用不存在；尾部额外数据未完整消费；未知 TileInfo 字段被当成已证实规则；动画帧引用越界；精灵 RLE 长度、操作码、尺寸、帧边界错误；解码后像素数量错误；源文件摘要变化；输出不确定性；源文件编号冒充其他版本的地图名。

先对全部资源做只读盘点，再实现显式边界检查的提取器。非零扩展与未知规则保留原始字段及偏移，不静默截断。解析必须消费成员全部字节，提取可重跑核验摘要。静态反编译不声称运行原作。
