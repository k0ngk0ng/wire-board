# 战场前端接入：实现前失败场景

- v3 仍画旧四套 avatar；隐藏角色、蓝队或死亡姿态使用了错误资源；v2 存档被换成新角色。
- 已乘坐仍画步行角色；掉骑后仍画坐骑；坐骑图失败后人物或坐骑不可见；道具落地图显示成通用文字圆片。
- 经典地图没有实际图像绘制；换图旧异步请求覆盖新图；每个快照重复下载；已毁／已推原生箱子又从静态矩阵复活。
- 300 ms 推箱只有目标格瞬移、重复画目标箱、减少动态效果改变规则、刷新后重播旧动作；以客户端动画决定推箱结果。
- 可推箱 4 被本地预测当成可走；飞碟穿墙或穿泡；对传送带、方向门自创预测；矿车无视服务端 speedMs。
- 主角校正被推到障碍里；坐骑／困泡／运输重连状态变化仍沿旧速度预测。

针对性验证先写：实际 Canvas drawImage 调用与资源身份、动态箱体插值和去重、v2/v3 角色及坐骑切换、图片失败回退、v3 预测碰撞／飞碟／特殊地形权威显示。原生触摸、实际像素布局和多客户端完整对局交由主任务浏览器 E2E 保存截图与诊断数据验收。
