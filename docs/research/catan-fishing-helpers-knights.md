# 渔夫＋城市与骑士＋Helpers

本阶段接通三至六人的独立渔夫骑士助手，以及新海岸、四岛／六岛、迷雾、穿越沙漠、遗忘部落、布匹、奇迹、新世界八张捕鱼海图。可同时选择事件牌、友善强盗和港口霸主。属于 F12 的部分工作，总进度仍为 **10/12**，本批未推送、未部署。

## 规则依据与组合

沿用[骑士助手规则依据与本站适配](catan-helpers-knights.md)、[渔夫助手规则](catan-fishing-helpers.md)和[捕鱼海图骑士规则](catan-fishing-sea-knights.md)。助手与骑士的适配仍为本站规则，不宣称为官方组合。

对局同时保存 `fishing.helpers = wire-board-fishing-helpers-v1` 和 `citiesKnights.helpers.rules = wire-board-helpers-knights-v1`；建房说明、玩法上下文和战绩保留两个标记。

- 鱼筹码与普通资源、商品分别计算，不计入 7 点弃牌上限，也不能代替助手所需的普通资源。
- 生产回应按换鱼、金矿、引水渠、希尔达、助手翻面／更换的顺序完成，再回到原回合。希尔达资格取自实际普通资源与商品生产；鱼收入、引水渠补偿不取消资格。
- 支付 7 条鱼只能按渔夫骑士规则领取一张进步牌，不能叠加迪亚拉的三选一；不会消耗助手的可用状态。迪亚拉另行支付羊毛、粮食、矿石，选择牌堆后私选一张。
- 卡娅、迪古尔只领取普通资源，不领取商品。湖泊／金矿可任选普通资源；无沙漠时沿用渔夫助手的强盗退场规则。普通资源银行为空时，迪古尔仍可驱逐强盗但不领奖，即使商品银行尚有库存。
- 托罗夫按普通资源与商品总数、个人城墙上限判断；鱼不影响免弃或补偿。

## 「发明」双数字修复

六人穿越沙漠自然联机对局暴露出旧校验问题：使用「发明」交换双数字地块的主数字后，地图校验仍要求开局数字，导致后续操作（包括结束回合）被拒绝。

现在可选择地块上的具体数字圆片，主数字与额外数字均遵循不能交换 2、6、8、12 的限制。带额外数字的捕鱼地图记录公开交换过程；恢复时逆向核对交换并验证原始地图配方，不放宽湖泊、地形或额外数字位置的校验。主数字和额外数字命中同一点数时，仍沿用每块地一次生产的既有规则。

旧客户端省略数字槽位时仍选择主数字。普通城市骑士继续使用原操作，探索者继续使用其专用数字交换校验；没有交换记录的旧合法存档继续有效。电脑也能选择额外数字。
