# 赛车极速与踏板调整

目标：将道路实际极速从 310 世界单位／秒（约 112 km/h）提高到 900（324 km/h），保持速度表的单位换算；桌面和手机踏板由左至右为手刹、刹车、油门。

实现前失败场景：只改仪表读数而真实速度不变；只提高上限但阻力使其不可达；预测仍限速 310 导致回弹；路外也能保持公路极速；高速转向／碰撞产生非法位置或跳检查点；电脑弯前不减速或无法完赛；自动挡过早到顶挡；按键音效／镜头过早饱和；按钮仅 CSS 换序而键盘顺序不一致；手机长按选中文字、双指制动失效、松手仍持续操作。

先增加针对性物理、预测、挡位检查与浏览器踏板布局／原生多指操作验收，再修改实现。规则变化运行赛车自己的完整 75 组对局、HTTP／恢复／竞态检查；浏览器保留桌面与 320px 的位置、截图和操作记录。其他游戏不新增规则验收。

追加要求：电脑提高直道速度，保持弯前制动和自然完赛；真人取消自动加速，松油门后惯性滑行，仅触摸方向盘不能加速。平台所有游戏进入对局后自动定位到主要游戏区，等待初始布局稳定；用户已开始操作时取消定位，快照、倒计时和手动返回玩家栏不得触发重定位。删除泡泡堂的重复开局滚动，避免与平台竞争；疯狂坦克保留选车结束后的条件定位，不在选择浮层打开时滚动平台。

实际视区验收发现俄罗斯方块在 844px 高度下即使滚动到游戏顶部，按键底部仍超出视区。先加入实际按钮边界断言，再按视区高度限制本人棋盘宽度，保持 1:2 比例和最小可读宽度，不隐藏 HUD 或公共玩家栏。
