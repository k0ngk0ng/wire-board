# F10 原生双人探索者与城市骑士

核对日期：2026-10-08。此阶段接通五种探索者剧本的双人城市骑士组合，属于 F10 的一部分，总进度仍为 **9/12**，未发布。普通双人航海家及其余嵌套组合尚未完成。

## 依据与本站补充规则

已阅读官网 2025《Explorers & Pirates Combining with Cities & Knights》完整两页，以及探索者基础／任务规则的双人段落。原始 URL 和哈希见 `docs/board-expansion-rule-sources.json#catan-pirates-knights-2025`、既有探索者来源记录。

官方组合规定：首轮放城市、次轮放港口，起始岛用一块田地替换森林，目标分数比原剧本增加 5；蛮族只计算真正城市，不计算港口；船员不参与防守，骑士不能装船或参与任务。探索者原生双人使用两家中立建筑作为静态障碍，不套普通双人卡坦的贸易筹码和双生产。

上述组合材料未专门交代双人中立城市。按已有授权采用 **本站补充规则**：真人各放城市与港口；两家中立势力仍各放村庄与港口，不建城市／骑士，不生产，不参与蛮族结算。真人每回合一次生产，不额外建设中立道路或发放双人贸易筹码。本阶段核对了缓存官方材料，没有宣称完成额外互联网穷尽检索。

补充规则独立标记为 `wire-board-explorer-two-knights-v1`，保存于地图 `twoKnights`，显示在配置、规则说明、开局日志和战绩 `explorer_two_knights`。旧原生双人、三至六人骑士组合不携带此标记，普通城市骑士构造器仍不接受直接降低为两人。

## 实现

- 初航、巢穴、鱼群、香料、完整三任务均支持两人，可叠加已接通的 Helpers、渔夫（有湖／无湖）、事件生产牌；分别为 13／17／20／20／22 分。
- 起始放置保留两家中立村庄／港口，真实玩家放城市／港口。修复电脑规划中立位置时用负数所有者作数组下标的问题。
- 地图、开局、货物库存和聚合状态校验拒绝中立城市及缺失／未知版本。创建、等待房间开关、实际开局人数、准备重置、重开、恢复与历史接通。
- 前端两座位下可以选择骑士，并保留 2–6 座位选项；双人剧本说明跟随真实目标分数。浏览器验收发现的“开始游戏”按钮仍要求三人问题已修正。

## 验证

- 60 种配置（五剧本 × 三种渔夫设置 × Helpers 开关 × 事件开关）完成真实起始建设、后续回合和逐步保存恢复。检查中立建筑、单生产、起始分数与八种资源／商品库存。
- 定向检查蛮族防守平局、两名真人失城后生产、中立建筑不参与结算、损坏中立城市／规则标记拒绝及基础隔离。相关引擎回归通过（36.882 秒），包含旧三至六人起始、地图恢复、骑士行动及聚合流程。
- 五场自然完整 HTTP 对局，每剧本一场，覆盖 Helpers、渔夫／湖泊、事件；通过公开建房、加入、准备、开始直至结算，含阶段重启、持续超时托管与主动托管／恢复手动、隐藏信息和战绩检查（19.270 秒）。此项沿用本阶段先前运行结果，未为记录重复执行。
- 公开配置回归通过（1.687 秒）：非房主／非法选项原子拒绝、实际两人开局、关闭骑士回到原生固定初航。旧测试“实际两人不能开始”已随新支持范围移除；实际人数验证由新增双人配置用例覆盖。
- 前端 202 项测试、前端／Go 构建、`go vet`、相关服务器竞态检查通过（8.125 秒）。生产构建仍有既有单包大小提示。
- 浏览器真实创建两座位初航＋城市骑士＋渔夫／湖泊＋Helpers＋事件，添加电脑、准备并开始；手动确认交点 4 的起始城市，再启用托管完成中立与真人开局、推进至正常回合，恢复手动操作成功。核对 320／390／1440 像素配置、规则浮层和游戏界面，无页面横向溢出、破图或脚本错误，截图已查看。完整结算由上述 HTTP 对局验证，浏览器检查不代表真人手动玩完一局。
