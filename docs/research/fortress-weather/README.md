# 疯狂坦克原版天气核查

**有天气和环境事件，而且不只是风力。** 本次保留的官方网页客户端可确认降雪、浓雾、局部龙卷风及陨石事件。降雪、雾和龙卷风都有实际规则影响，不能只画一层背景特效。没有足够证据证明另有独立的雷雨／闪电天气系统。

本结论绑定保留的 Fortress Blue 网页客户端，不等同于历年全部客户端或 Steam 版的完整机制。未运行原版游戏；代码结论来自原始 WASM 的静态解码。Steam 官方视频中出现旋风的独立公开观察可复查既有 `docs/research/fortressblue-refactor/reference.md`，这里不将其当作概率和规则公式的证据。

## 已确认的要素

| 要素 | 出现条件的已知范围 | 实际影响 | 尚未确定 |
| --- | --- | --- | --- |
| 普通风力 | 客户端接收有符号风值，并保存为独立状态 | 进入炮弹横向速度更新；雪花也随风偏移 | 原版服务端选风概率、随回合变化公式 |
| 降雪 | 网络状态可启用；使用官方道具 `701402` 也会设置同一状态 | 显示雪花；阻止新火焰、毒气对象创建，清除已存在的火焰与毒气 | 自然出现概率、各模式开关、精确持续行动数配置 |
| 浓雾 | 网络状态可启用；官方道具 `701404` 也会设置同一状态 | 坦克绘制按阵营、雾和照明状态分支，影响敌人可见性；不是统一降低全屏透明度 | 所有观战与照明例外的完整矩阵、自然触发概率 |
| 龙卷风 | 网络事件创建／移动；官方「旋风弹」可在落点生成 | 炮弹进入旋风横向区域后改变运动状态和速度，边缘路径会反转横向速度；穿风类弹有例外 | 服务端发生频率、移动选点、完整持续回合规则 |
| 陨石事件 | 特定事件类型与非零网络参数进入 `EMeteor` 创建分支 | 使用弹体碰撞、地形破坏和范围伤害路径；命中还能创建火焰 | 哪些房间／模式开放、触发轮次和概率；不能直接称为「雷雨」 |

### 「Rain」实际对应下雪

源码内部标识是 `ERain`、`SetRain`，资源名为 `rain.i16`，但不能据此把玩法命名为下雨：

- 官方中文门户道具 `701402` 名称是「人工降雪弹」，说明为「可以使得比赛场地内突降大雪，用来阻挡火势的蔓延以及消除毒气气云」。
- 同包 `Asset/item.iif` 的韩文名称为 `눈내리기`，说明 `눈이 내리도록 합니다.`，含义也是使其下雪。
- 原始 `rain.i16` 解码为两张雪花图（11 × 9、9 × 11），不是线状雨滴。证据预览保存在 `.local/fortress-weather/evidence/rain-resource.png`，是原始资源放大图，不是游戏运行截图。
- `f998` 的道具编号 `701402` 分支设置全局对象 `+2932` 指向的值；`ERain` 更新、火焰与毒气判断都读取这个值。

因此当前证据支持**一套内部名为 Rain 的降雪机制**，不支持凭名称额外添加另一套独立下雨系统。

### 官方道具相互作用

| ID | 原版中文名称 | 原始说明关键内容 |
| --- | --- | --- |
| `701402` | 人工降雪弹 | 降雪阻止火势蔓延、消除毒气 |
| `701404` | 起雾弹 | 产生浓雾，把自己隐藏在雾气里 |
| `701405` | 旋风弹 | 在落点产生龙卷风，卷走试图穿过的炮弹 |
| `701406` | 穿风弹 | 正常穿过龙卷风，并获得 50% 威力增加 |
| `701407` | 照明弹 | 让己方看清烟雾中的敌方坦克位置 |

这里的「穿风弹」说明针对龙卷风，不能直接改写成「普通风力完全无效」。烟雾弹 `701306` 是落点附近坦克的持续状态，不能与全局浓雾合并后随意改变作用对象。

## 有界负结果与限制

对该 WASM 的静态数据段字符串、当前天气赋值／分派路径、官方门户道具说明进行了检索，没有建立独立雷雨、雷暴或闪电天气的创建及规则链。电属性炮弹、雷霆坦克或技能名称不是雷电天气的证据。这个结果不表示所有历史版本绝不存在雷电天气。

未获得原版服务端，所以自然天气概率、模式开关、重连同步的全部边界及天气持续配置尚不能宣称完全还原。截图、名字、单个函数均不能填补这些缺口。

## 最小接入建议

优先保留独立的服务端环境状态：普通风、降雪剩余行动数、浓雾剩余行动数、局部旋风实体。先接入证据闭合的道具触发降雪及灭火／消毒，再接雾与照明，最后做旋风弹道；自然随机发生率暂不冒充原版参数。陨石需要独立的触发规则验收，不宜为了「有天气」就加入无来源的随机雷击。

如果本轮只回答用户问题，可以明确说：**原版有降雪、雾和龙卷风，它们会影响场上效果、可见性或炮弹；我们现在只有风，还没完整还原这些环境机制。**
