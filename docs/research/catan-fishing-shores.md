# 渔夫＋驶向新海岸：F07

本地接通三至六人，尚未推送或部署。三四人保留固定／可变海图选项；五六人沿用可变主岛、固定外围岛屿及配对回合。未开启渔夫时仍使用原新海岸开局，不替换地形、不改变强盗起点。

## 依据与配方

[2025 官方组合说明](https://www.catan.com/sites/default/files/2025-07/Fishing%20on%20Catan%20w%20SEA.pdf)第 1 页明确允许新海岸＋渔夫，要求湖泊完全被陆地包围，鱼可驱离海盗和造船，海盗阻断渔场，沿用所选海图胜利条件。原三人新海岸没有沙漠，说明未给出湖泊替换位置。复查 [官方 FAQ](https://www.catan.com/faq/traders-barbarians) 并搜索三人新海岸湖泊／沙漠规则，没有找到对应细则。

按用户对未明确规则的授权，使用版本 `wire-board-fishing-shores-v1`：

- **三人本站补充规则**：主岛内陆位置 ID 16 替换为湖泊，移除原生产数字。固定图为 5 点山地；可变图使用相同几何位置，移除该地实际数字，不另行迁移或增加数字。
- **四人**：主岛沙漠换为湖泊；固定图为 ID 26。可变布局仅接受沙漠位于内陆的生成结果。
- **五六人**：两块主岛沙漠均换为湖泊。生成时限定沙漠在内陆，不在编排数字后交换地形；保留已有 28 枚螺旋数字配置及外围岛屿。第一湖 2／3／11／12 产鱼，第二湖 4／10 产鱼。
- 湖泊必须位于主岛，且有六个陆地邻居。三四人六处渔场、30 枚鱼筹码；五六人八处、44 枚，均包含旧靴。
- **本站开局解释**：采用渔夫的场外强盗起点，海盗沿用海图起点。强盗可进入湖泊；没有沙漠时事件「强盗逃跑」按官方 FAQ 置于场外。
- 保留主岛起始建设、非家乡区域首次定居奖励和 14 分目标。港口霸主及旧靴门槛照常叠加，金矿选择在鱼筹码回应完成后处理。

存档记录 `fishing.map.seaRecipe`，历史记录 `fishing_sea_recipe`；创建／等待提示、开局日志和玩法速查显示本站规则。Helpers 和海图骑士仍按 F08、F09 的完成状态控制，F07 不绕过限制。

## 页面验收

使用普通公开 API 创建三人固定、六人可变房间并加入电脑，浏览器以对应玩家登录；不修改规则状态或给玩家注入资源。检查桌面 1440×1000、手机 320×740／390×844 的单湖和双湖地图、渔场、筹码、资源与规则浮层。无页面横向溢出，六人页面 25 种 SVG 图片从既有 CDN 解码成功，无脚本错误。手机缩放与从自动托管恢复手动操作成功。

六人账号在等待页面检查期间自然超时进入托管，登录后仍显示托管图标和恢复入口，没有静默取消。页面局部验收不计为完整对局。检查发现规则标题把本站配方都写成固定布局，已按实际固定／可变布局修正；数字配置文字在捕鱼时显示跳过湖泊。

专用浏览器全程静音，登录后关闭站内音效，没有播放网络音频。临时浏览器、服务器和文件在验收结束后清理；共享规则研究目录保留。
