# 可见死亡证据与原版借命

本项验证电脑／主动托管通过普通 A 按键尝试原版借命。策略不读取私有 `GameOver` 状态，不修改自己或队友的生命，也不因备用命为 0 或短暂不可见就断言已经淘汰。

可用证据有两类：介绍页中对应席位的「GAME OVER」文字，以及确实见过死亡姿态且公开备用命为 0。后者只建立「可以尝试借命」的策略记忆，不等同于声明隐藏淘汰状态。可辨的活体姿态重新出现或公开备用命增加后清除该记忆；暂停时不尝试。队友公开备用命大于 0 时，策略交替按下／松开 A，最终资格仍由原版规则判断。

全局终局识别限定到原版居中的「GAME OVER」布局。介绍页的单席文字不能把仍存活的队友或整场对局标为结束。该位置回归和正常继续菜单／关卡标题检查已通过；介绍页词组不是普通战斗 HUD 的常驻字段。

标准生命数 E2E 从 `NewSession(42, 2)` 开始，重放保留的合法双人输入。第 13,737 帧，画面显示第二名角色的死亡姿态 10、备用命 0，第一名角色公开备用命为 1；此时才显式启用待验证席位的策略，首个动作仅为 A。第 13,841 帧，原版规则完成借命：队友备用命减少 1，原淘汰席位进入复活流程。全过程没有补命或规则状态注入。

[验证清单](evidence/bot-standard-borrow-verification.json) 绑定完整按键、触发画面、公开观察、前后 Session 和摘要。独立重放不调用策略，完整 13,841 帧末态及下一帧状态一致。记录位于 `evidence/standard-borrow/`；较大的 JSON 已压缩保存。它证明本次引擎流程，不代替完整八关、浏览器托管入口或最终构建验收。

策略边界的先红后绿记录为 `bot-visible-borrow-{red,green}.jsonl`、`bot-visible-death-borrow-{behavior-red,green}.jsonl`。`bot-visible-death-borrow-red.jsonl` 是同期规则接口尚未实现时的编译失败，不能当作行为失败证据。最初要求队友至少有 2 条备用命的搜索没有找到合适场景，该搜索失败也不当作策略失败证据。
