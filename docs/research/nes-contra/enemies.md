# 日版第一关敌人与出生链

本项使用固定日版 ROM、REA 和原版执行记录恢复敌人规则。Go 代码使用命名的敌人状态、固定精度坐标、图形请求和事件，不执行 ROM 或模拟 CPU。当前范围是第一关及已验证的公共辅助过程；其他关的完整敌人 AI 与自然八关通关仍未验收。

本文保留第一关交付时的范围和证据。后续八关敌人接入、公共接口及当前验收边界见 [八关敌人说明](enemies-all-stages.md)。

## 原版入口与状态

| 日版位置 | 作用 |
| --- | --- |
| 固定 `$E54F` | 清除双方 `OnEnemy`，按槽 15 到 0 运行实体，再按原版门槛检查玩家接触和玩家弹命中 |
| 固定 `$E58A` | 依据实体类型和当前 routine 分派；公共类型表 `$E5D9`，第一关专属表 `$E5F9` |
| bank 4/5 `$A97B` | 固定屏幕出生脚本，wrapper 为 `$FA22` |
| bank 4/5 `$AA85` | 随机跑兵的计时、地形搜索与生成，wrapper 为 `$FA32` |
| 固定 `$EDAD` | 初始化实体属性；`$ED34` 从最高空槽开始找，随机跑兵另用 `$ED30` 限定槽 6 到 0 |
| 固定 `$E10A`／`$E276` | 已准入的玩家接触／玩家弹命中，不能替代外层门槛 |
| 固定 `$C3D1` | 背景图块变更请求；以当前队列字节游标决定是否接收 |

`EnemySystem` 保存 16 个独立实体；空槽保留原版未清理的字段。常规敌弹与道具也使用这个实体池。`Enemy` 中的四个 `Data` 字节是各类型自己的状态载荷，例如朝向、跳跃阶段或射击计数，并非通用 RAM。

第一关固定出生脚本已恢复 13 屏、19 个类型属性。普通出生组每次调用只消费一组；组内多次出生即使因无空槽失败也继续推进脚本。触发位置最低位为 1 的强制实体可替换最高编号敌弹槽；没有敌弹时按原版使用槽 0。

## 已实现的规则接口

- `SpawnScreen`、`Initialize`：屏幕脚本及初始化。
- `StepBullet`：敌弹初始化、运动、变体、爆炸及移除。
- `StepRunner`：跑兵等待、临边转向、原版随机跳跃、射击、受击、落水及消失。
- `StepPickup`、`StepCapsule`、`StepWeaponBox`：室外掉落道具、飞行补给及枪盒。道具取得由碰撞阶段处理。
- `StepBridge`：爆桥的图形接收、碰撞删除、次级爆炸、自身爆炸和下一段推进。
- `StepSniper`、`StepTurret`、`StepRedTurret`、`StepBossCannon`、`StepBossDoor`：见 [射击与 Boss 说明](enemies-shooters.md)。
- `CollidePlayers`、`CollideProjectiles`、`ArcadeScores`：见 [碰撞说明](enemies-collision.md)。原版局内分数与平台通关积分分开。
- `GraphicsQueue`、`RequestSupertile`：见 [图形请求说明](enemies-terrain.md)。实体不假设请求总会成功。
- `Tick`：第一关完整倒序敌人阶段，读取实时槽位及即时碰撞后的玩家状态，合并原版顺序的声音与进度信号。

枪盒的 HP 变化必须在对应图块请求被接受后发生。被毁枪盒先请求背景替换，再发出声音、创建另一个爆炸实体，并把自己的槽转成道具。飞行补给的第三阶段跳转至同一个 `$82D4` 转换尾部，不需要擦除背景。完整阶段验收实际触发了这条此前未自然覆盖的路径，已加入独立原版 fixture 修复。

爆桥不在请求提交前删除碰撞。两半图形请求成功后才按返回的 nametable 地址清理四个碰撞格；随后按原版次序生成三个次级爆炸及自身爆炸。源超图块索引不随图形请求自动改写，图形、碰撞和超图块缓存仍分别由它们的原版规则维护。

跑兵死亡冲量为日版实际字节 `$FC80`，即 `−896/256 = −3.5`，不是部分美版参考注释中的 `−4.5`。原版函数受控调用已经验证该差异；实现采用实际字节含义。

## 随机跑兵与确定性接口

`SpawnSoldiers` 使用三段状态机：设定间隔、寻找地板、尝试出生。它读取共享 `RandomState.Value`，不在生成器内部制造另一个随机源。用户允许随机序列的时序适配；原版计时运算、地形扫描、概率条件、边缘保护和生成属性仍保留。

`SoldierGenerator` 的 `Generated` 是原版当前屏计数。普通出生增加它；三体连生分支不增加它。首次第一关计数小于 30 时使用 `$FC` 作为出生横坐标；其他情况按原版左右位置表选择。边缘保护读取玩家 `GameOver`，不能用 `State != 1` 代替。

三体连生使用原版 `$06` 工作值选择临边转向标记。`SpawnVariantSeed` 是这个兼容输入，`NextVariantSeed` 是执行后的值，不能置零或换成新的随机数。1900 次自然生成器入口已追踪最后一次写入的 PC、bank、帧和数值；1163 次受控原版调用覆盖非零／回绕值、三个体的顺序、容量、八关间隔表及边界条件。

已确认的生产者包括：共享元精灵指针低字节（bank 4/5 `$92D9`）、敌人瞄准的 12／24 方向整圈常数（`$F3DD`）、敌弹的请求速度及成功后的钳制值（`$F225/$F269`）、碰撞格更新循环完成值 `$FF`，以及固定区 `$CF09` 的工作结果。记录器报告的 PC 位于写指令之后。场景绘制、框架尾部与敌人阶段需要把这些具名语义结果按实际顺序交给 World，不能引入一个通用 RAM 解释器。

Hangar 的一个原版属性选择会越过声明的 28 字节属性表，读取相邻屏幕指针的四个字节。导出的第 7 组兼容数据绑定日版 ROM 原位置，未将其替换为自创的普通兵行为。此表边界属于受控验证范围，不代表该关完整 AI 已验收。

## 验证范围

| 范围 | 原版观测／验证 |
| --- | --- |
| 固定出生与初始化 | 1200 次自然出生调用、28 次初始化，全 16 槽一致 |
| 普通敌弹 | 924 次自然调用；63 次变体、计时、溢出、滚动及碰撞受控调用 |
| 跑兵 | 1123 次自然移动／跳跃／落水调用；81 次受击与爆炸边界；射击与转换另有独立验证 |
| 飞行补给 | 257 次自然飞行、1 次自然被毁转道具 |
| 枪盒与道具 | 868 次自然枪盒调用、121 次自然道具飞行，覆盖纯按键取得 M 的路线 |
| 爆桥 | 161 次自然调用，队列、碰撞、全槽和声音一致 |
| 公共爆炸 | 43 次原版受控调用，含实际声音请求 |
| 随机跑兵 | 1900 次自然、1163 次受控调用，生成器状态及全槽一致 |

这些数字包含嵌套过程和重用场景，不能相加当成不同完整对局数量。图形与敌人状态的比较只覆盖实际 CPU 图形缓冲 `$0700..$07BF`；其后的 palette、比分和 PRG bookkeeping 分别处理，不把 `$07EC` 的 bank 恢复记录当成游戏规则状态。

[完整 REA 索引](evidence/enemies-index.json)保留 9 组原始证据、输入身份、函数地址与限制。[实现记录](evidence/enemies-implementation-verification.json)绑定当前文件摘要及各项范围。碰撞、射击、图形请求和整阶段的详细 red／green、自然／受控及重复录制结果在各自说明中列出。

第一关完整敌人阶段通过 5,396 次原版调用，含实时倒序槽位、碰撞后的目标更新、Boss 音频重置、图形请求及 `$06` 的实际交接。独立入口与整阶段检查合并后，**31 项限定 race 检查通过**，命令、文件名单和摘要见 [子系统验收](evidence/enemies-subsystem-verification.json)。并行开发期间使用明确文件名单编译测试助手，不运行其他游戏或尚未完成的呈现测试；主任务后续仍须运行整个魂斗罗及在线对局验收。

可重复运行：

```sh
python3 -B scripts/contra/enemies_verify.py
```

静态分析可以从 `enemies_prepare.py` 生成的各个 spec 重新执行 `enemies_rea.mjs`，全程使用工作区内的独立会话。原版自然出生录制器 `enemies_capture.py`、绘图交互录制器 `enemies_capture_drawing.py` 及生成器录制器 `enemies_capture_generators.py` 均接受新的运行名称／标签；已保留 fixture 的再次录制只比较结果，不覆盖原始 oracle。

[重复录制与清理记录](evidence/enemies-replay-and-cleanup.json)确认四对主记录的完整 RAM、调用和地图字节一致。本轮清理约 165 MiB 自身缓存、重复捕获和未采用的分析候选，保留仍用于 World 集成的主记录；用户 ROM、其他游戏及并行任务目录未删除。

本轮没有注册游戏、修改平台发布状态、上传 ROM 或公开资源。自然射击轨迹抵达第一关 screen 10 后全灭；Boss 采用明确的受控起点和连续原版轨迹验证。完整世界的连续联调、自然 Boss 战、其他七关和真人／电脑完整对局仍由总任务继续验收。
