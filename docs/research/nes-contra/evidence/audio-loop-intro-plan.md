# Intro `$14` 循环扩展的实现前检查

输入限定父级已经完成两次原版录制的 `$14`，`kind=loop-effect`，slot 4／pulse1 和 slot 1／pulse2。仅增加两条候选，保留既有 7 曲的 PCM 与参数。

失败场景：把 112 tick 控制周期直接视为 APU 相位周期；错用三轨模板补出不存在的 triangle；不同声部选择不同周期；缩短尾部或改前奏来隐藏接缝；为通过 Intro 降低 RMS／跳变门槛；把旧平台 SHA 的浏览器结果复用于新 `audio.ts`；新增效果时覆盖旧音乐或错误提升听感／发布状态；硬链接的重复生成物造成假一致。

沿用原验证器的全部数值条件，先对未加工 `$14` 两条 stem 测量，再搜索两轨共同切点。周期与主体不变，尾部最多 1,411 样本升余弦衔接。生成后独立进程重做并比较 SHA；首次未找到候选即报告失败，不放宽标准。浏览器按每组真实声部数检查，覆盖 23 条轨各两次原生边界，以及每组前缀、暂停／恢复、停止。只有稳定 `audio.ts` SHA 对应的实际浏览器结果才能提升 `loopReady`；`listeningAccepted`、`acceptedForRelease` 继续为 false。
