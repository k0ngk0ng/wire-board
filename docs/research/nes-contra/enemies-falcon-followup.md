# 实际首关 Boss 击杀后的销毁标记

主任务的连续 World 对照在首关大门实际被玩家击毁后发现了入口校验缺口：原版批量销毁会给其他敌人的 `Attributes` 设置 bit 7，炮台仍须继续执行自己的毁坏图块和爆炸阶段。原实现把这个合法高位当成无效属性而拒绝执行。

本项沿用主任务的原版按键轨迹，只保留既有的初始备用生命数设为 30 的介入。没有设置 Boss HP、死亡状态或结果。独立观察器记录了击杀前后 42 个完整敌人阶段、193 次实体调用；前 6,030 个模拟器帧的完整 RAM 与主任务原始运行一致。

新增原版对照先在模拟器 frame 7385 的 slot 11 炮台上失败，再修正 `StepBossCannon` 的校验。炮台的低位方向与高位销毁标记均保留。原绘图过程在进入前只按 bit 0 决定是否减 8，返回时按整个属性非零决定是否加 8；这使被大门销毁的左炮台从 X=177 移到 185。独立规则保留这项已观测行为，没有把两个条件擅自统一。

同类审查还发现狙击兵入口过早校验属性。三个独立受控原版阶段通过正常玩家接触取得 F 道具，然后由原版转移后槽狙击兵到 routine 5、设置属性 `$80/$81/$82`。狙击兵先跌落，再进入 routine 7 的共享爆炸；因此仅 routine 1..4 需要验证三项活跃属性表。跌落绘制仍使用原始属性值，不能先掩掉 bit 7 改变原版画面。

现有第一关完整阶段对照加入这 45 个场景后，共 5,441 个阶段通过。炮台、狙击兵、相关射击与碰撞、八关初态分发合计 **12 项正常包 race 检查通过**，运行中源码没有变化。这是 70 项子系统基线之后对改动范围的补充检查，没有重复执行无关关卡矩阵。
