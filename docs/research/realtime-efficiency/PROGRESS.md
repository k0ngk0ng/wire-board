# 实时效率优化进度

本轮目标仍在进行中。以下是已经落地并验证的阶段，不代表全部优化完成。此前疯狂坦克重构改动仍在同一工作树，未回滚、未发布。

## 已实现

- `/api/ws?stream=1` 提供完整初始状态、精简 `game` 推送和可靠 `input/ack`。输入复用 HTTP 命令的权限和规则校验；普通输入使用有界内存去重，确认表示服务器已处理，`durable` 明确区分持久化。原通知 WebSocket 与 HTTP 保留兼容。
- 高频消息不再携带大厅、游戏目录、聊天和平台配置；每个用户仍通过自己的 `Module.View` 投影。50 ms 推送窗口合并待发快照，网络写入不持有平台锁。
- 公共前端直接应用游戏消息，不再由每条通知触发 `/api/state`。带房间、开局版本及单调房间版本检查，过期完整状态不能把玩家带回旧房间。
- 实时模块不再获得平台操作期限／自动超时托管；手动托管及电脑玩家保留。旧存档中明确标为超时接管的真人席位恢复手动控制；启动时清理手动席位的旧方向／开火，手动托管不变。
- 连续输入不能推迟已预约系统帧，修复真人频繁操作导致电脑决策饥饿。
- 三款连续运动游戏允许有界的流式输入窗口（最多 8），HTTP 回退仍为单请求；俄罗斯方块与街霸方块允许其既有两批输入窗口并行发送。

- 普通移动和物理帧只在内存中推进，每秒保存有变化的房间；开局、结算、托管、关闭及游戏关键阶段保持事务保存。正常关闭保存待持久化状态，检查点失败记录最后成功版本并重试。五款实时游戏提供 `CheckpointKey` 阶段标识。
- 新实例标识允许客户端接受崩溃恢复后的较低版本；拒绝旧实例输入，迟到的旧请求不能覆盖新启动状态，棋盘控制在实例变化时重建。

## 当前证据

产物目录 `.local/realtime-efficiency/`：

- `transport-legacy.json`：约 2 秒，21 次完整状态 GET，紧凑应用 JSON 115,788 字节。
- `transport-stream.json`：同一房间／三个受控席位／100 ms 帧，约 2 秒，20 个游戏帧、0 次状态 GET，JSON 13,132 字节。约减少 89%；不含 HTTP／TCP／TLS 开销，不代表最大承载能力。
- `stream-green.txt`：新通道、输入幂等与重启、权限、取消超时接管及旧存档迁移 race 检查通过。
- `input-clock-red.txt`／`input-clock-green.txt`：先复现连续 48 次输入但 0 次系统帧／电脑输入，再验证保留到期节点。
- `stream-privacy.txt`：未登录／跨源拒绝，不同席位和观众投影隔离，大厅不收到实时战场更新。
- `frontend-all.txt`：五款游戏与新传输辅助检查共 79 项通过；构建通过。
- `browser-rt9ef696/report.json`：五款游戏直接推送、无重复状态 GET、手动托管／取消、桌面和 320px 截图。根任务检查了泡泡堂手机和街霸方块桌面截图。
- `browser-rt2a6e25/report.json`：泡泡堂真实空闲 65 秒，没有自动托管，收到 650 个帧且没有状态 GET。
- `browser-rtt300-a/report.json`：测试网络通道双向各 150 ms 延迟，确认延迟 302～305 ms；松手早于第一条 ACK 约 60 ms，0 次游戏动作 HTTP POST、0 次状态 GET。
- `internal/nettest` 的真实 TCP／WebSocket 测试验证测试延迟保持消息顺序与并行传输，不会每个包重复串行等待 RTT。该工具只供本地测试，生产未导入。

本次内存检查点阶段新增：

- `checkpoint-green.txt`、`instance-green.txt`：普通输入／物理帧零逐步写入、有界 nonce 去重、检查点保存与重试、无变化不写、托管立即保存、关键输入批次失败回滚、系统帧及关闭恢复。
- `sigkill-checkpoint.json`：真实子进程接收未持久化移动后被 SIGKILL；恢复最后检查点，未保存移动回退，旧按键清除，实例标识变化。
- `instance-client-green.txt`：9 项传输辅助测试通过，包括新实例版本回退与旧实例帧拒绝。
- `checkpoint-front.txt`：五款游戏及公共流式输入辅助测试 81 项通过；`checkpoint-build.txt` 前端构建通过。

本次新增的多房间与数据库测量、50／150／300 ms 浏览器验收、泡泡堂八真人／多标签页／重连、公共平台及五款游戏对应检查均已完成。完整指标和复跑命令见 [CHECKPOINT-RESULTS.md](CHECKPOINT-RESULTS.md)。
