## 共同规则

| 情况 | 规则及实现 |
| --- | --- |
| 开局 | 先村庄后城市；第二轮只领取每个相邻地块一张普通起始资源。保留航海家地图和新世界已确认地图的港口前置流程。 |
| 获胜 | 航海家剧本的目标加2分；本阶段新海岸/沙漠16分、四岛或六岛15分、迷雾/新世界14分。不能统一采用独立城市骑士的13分。 |
| 海盗 | 与强盗一起在首次蛮族进攻前休眠；首次进攻结束后，按实际剧本的起始位置入场。 |
| 蛮族 | 所有岛屿同时受攻击，统计全部城市和活跃骑士；先完成劫掠，再按降级后的建筑进行同次资源、商品及金矿生产。 |
| 金矿 | 只产生普通资源，城市领取两张。数量、库存、自动选择只计算前五种卡；银行仅剩商品时跳过，不生成无解回应。领取金矿后不再误发引水渠补偿。 |
| 商人 | 不可放在金矿，也不可放在海洋或未知迷雾。 |
| 骑士 | 可以沿己方连续道路和船只移动，包括纯海洋交点；对手棋子仍阻挡经过，驱逐/退让保留既有资格限制。 |
| 驱逐 | 相邻骑士可明确选择驱逐强盗或海盗。目标类型随阶段持久化，不能在下一步改成移动不相邻的另一种棋子。 |
| 道路建设 | 可以免费建两条道路、两艘船或混合，仍保留逐步完成/探索/库存等规则。 |
| 征税 | 只移动强盗，不能借此移动海盗。 |
| 外交 | 开放道路或船只均可移除；己方只可重放同类棋子，不能船换道路。FAQ65允许外交搬移海盗旁的开放船，普通移船仍受海盗封锁。新位置仍须合法连接，重放的船按本行动新放置记录。 |
| 骑士连接 | 移船/外交不能切断骑士与己方建筑的最后连接；检查跨道路/船只的整个己方网络，不能只检查同类边的开放末端。既有异常旧档也不能再拆去孤立骑士的最后一段路线。 |
| 计时 | 金矿结束后若进入另一人的引水渠，该人获得独立120秒；全部回应完成恢复原行动剩余时间。外交重放船延续同一机制。 |

## 本阶段支持与后续

内部构造器 `NewCatanCitiesKnightsSeafarers` 接入新海岸、四岛/六岛、迷雾、沙漠、新世界、卡坦奇迹和卡坦布匹，3–6人；通过原航海家构造器保留地图版本和布局。六岛的存档ID是`six_islands`，房间配方ID仍为`islands`，内部掷骰须同时识别。

遗忘部落、海盗群岛的额外组件和特殊终局需要各自组合规则，仍显式拒绝，不能简单套用“加2分”。卡坦奇迹和布匹已按下述组合规则内部接入；布匹公共库存耗尽仍是发布阻断项，内部构造器可运行不代表已完成验收。Helpers与城市骑士尚无本项目已核实的兼容规则，也不启用。以上仍在完整组合目标的后续核对范围，未缩减原定范围。

## 卡坦奇迹＋城市骑士（2026-10-05）

### 规则推导与边界

依据同一固定2025版《Cities & Knights》第12页的组合条款“Winning the Game: Increase the number of VPs needed to win a Seafarers scenario by 2 VPs”，以及同版《Seafarers》第18页的两条独立获胜条件：完成奇迹，或者10分且已建等级高于其他玩家。本组合把分数条件改为12分，保留4级直接获胜及必须独自领先的要求；没有把等级、领取条件（如城堡6分）或每级费用也加2。这是两条规则合并适用，不宣称存在另一本独立“奇迹组合”规则书。

第18页明确“Return the pirate to the box. It is not used in this scenario.”，因此本组合仍不使用海盗。先手在沙漠中选择强盗未来起点，保存到`RobberStart`，强盗当前位置保持-1；首次蛮族进攻后才入场。不因选择起点提前启用偷牌。开局顺序村庄、逆序城市，禁建标记、主岛限制、普通起始资源与三/四人固定/可变、五/六人固定地图均保留。

## 布匹＋城市骑士：开局与结束接续基础（2026-10-05）

本阶段只修复、验证可明确合并的基础规则，不开放组合构造器或房间选项。

规则依据是已固定的2025《Seafarers》第14–15页（三轮建设、仅第三座发起始资源、14分或5村落耗尽），《Cities & Knights》的第二座起始建筑改为城市及第12页航海家组合条款（海盗与强盗首次进攻前休眠，获胜分数加2）。合并得到顺序村庄、逆序城市、顺序村庄，第三座发普通资源；目标16分，保留5村落耗尽的回合末结束与布匹平分规则。这是两本规则的合并适用，没有找到单独的布匹组合补充规则。

- 修复起始阶段判断：只有第二轮建设放城市，不能把第三轮也当成城市。三至六人固定图及三/四人可变图共六组测试核对座次、每步存档恢复、两村庄一城市、只有第三座发资源且不发商品，以及路线超时完成一个建设组。
- 可变地图选择强盗起点只更新预定起点，不提前启用强盗。手动拒绝越权，自动选择读取预定位置；首次蛮族进攻按保存的位置放入两种棋子。入场后仍需先建立贸易才可移动海盗。
- 三/六人分别手动、自动完成回合末进步牌弃置，实际从保存恢复状态接续，确认随后立即检查五村落耗尽，不跳到下一玩家或配对行动。保留布匹与54张进步牌库存；验证14/15分不足、16分达标。
- 公共库存边界现在有明确的筹码核算反例：四名贸易者各领取首次连接和生产奖励，一个村落共发8枚，其中3枚来自公共库存。三个村落耗尽后公共剩1枚，第四村落可有1枚且四人已连接，下一次需要公共3枚。此时只有3村落耗尽，每名玩家持有7枚布匹，不能用耗尽终局或布匹分数排除此状态。测试使用4/6人官方地图的局部库存夹具，保持50/70枚守恒；**不是从开局走出的完整合法航线对局**。
- 公共库存不足仍拒绝生产；这是临时防透支保护，不是已核实的正式规则。测试明确保留组合入口限制，不能把它视为剧本验收完成。不得默默增发、少发或按座次分配。

## 布匹＋城市骑士：骑士与贸易交互（2026-10-05）

依据2025《Cities & Knights》第9页的“knights interact with routes as if they were a building”、招募/移动终点必须为空交点，以及《Seafarers》第14页数字圆片代表村落、第15页允许船线从村落继续延伸/分叉。组合实现将中立村落视为已占用的终点，而不赋予它对手建筑的阻断作用：骑士不能招募、移动、退让或通过叛变放在村落上，可以沿己方连续路线经过村落。这是规则合并推导，并非声称官方有单独的布匹骑士问答。

新贸易连线现在被敌方骑士阻断，不论激活状态；己方骑士不阻断，也不能代替己方建筑作为贸易起点。已建立的贸易关系保留，仍按村落数字生产，连接奖励不重复领取。骑士移走、阴谋驱逐、叛变移除/重放或平台超时离场收回骑士后，重新检查存活玩家的船线并立即更新布匹与分数。退让或叛变放置尚未完成时不依据临时空位发奖，整个动作完成后使用最终位置。非当前玩家因此达16分仍等自己的行动才能获胜。
