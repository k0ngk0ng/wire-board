# 航海家＋城市与骑士：共同规则与实施边界

核对日期：2026-10-05。本阶段只接入内部规则引擎及响应接口，未提供公开房间选项，也未发布。

## 官方依据

- [2025 Cities & Knights 规则书](https://www.catan.com/sites/default/files/2025-03/CN3087%20CATAN%E2%80%93Cities%26Knights_%20Rulebook.pdf)，第12页“COMBINING WITH CATAN – SEAFARERS EXPANSION”。固定PDF的来源和SHA256见 `../board-expansion-rule-sources.json`。
- [官方 Cities & Knights FAQ](https://www.catan.com/faq/cities-knights)，问题64–66、88–94。2026-10-05读取的 Diplomat 段落文本SHA256为 `b313ebf1afe9b48b5139e9d8c3aa6b70bd9189fa1c546c5a6d94e9fc987ee30e`，这是提取文本而非原始HTML的哈希。临时读取文本在记录后清理。

第12页说明该组合可以使用航海家地图，推荐驶向新海岸和穿越沙漠；四岛、迷雾等探索地图会显著增加蛮族的影响，并非一律禁止。

## 共同规则

| 情况 | 规则及实现 |
| --- | --- |
| 开局 | 先村庄后城市；第二轮只领取每个相邻地块一张普通起始资源。保留航海家地图和新世界已确认地图的港口前置流程。 |
| 获胜 | 航海家剧本的目标加2分；本阶段新海岸/沙漠16分、四岛或六岛15分、迷雾/新世界14分。不能统一采用独立城市骑士的13分。 |
| 海盗 | 与强盗一起在首次蛮族进攻前休眠；首次进攻结束后，按实际剧本的起始位置入场。 |
| 蛮族 | 所有岛屿同时受攻击，统计全部城市和活跃骑士；先完成劫掠，再按降级后的建筑进行同次资源、商品及金矿生产。 |
| 金矿 | 只产生普通资源，城市领取两张。数量、库存、自动选择只计算前五种卡；银行仅剩商品时跳过，不生成无解回应。领取金矿后不再误发引水渠补偿。 |
| 商人 | 不可放在金矿，也不可放在海洋或未知迷雾。 |
| 骑士 | 可以沿己方连续道路和船只移动，包括纯海洋交点；对手棋子仍阻挡经过，驱逐/退让保留既有资格限制。 |
| 驱逐 | 相邻骑士可明确选择驱逐强盗或海盗。目标类型随阶段持久化，不能在下一步改成移动不相邻的另一种棋子。 |
| 道路建设 | 可以免费建两条道路、两艘船或混合，仍保留逐步完成/探索/库存等规则。 |
| 征税 | 只移动强盗，不能借此移动海盗。 |
| 外交 | 开放道路或船只均可移除；己方只可重放同类棋子，不能船换道路。FAQ65允许外交搬移海盗旁的开放船，普通移船仍受海盗封锁。新位置仍须合法连接，重放的船按本行动新放置记录。 |
| 骑士连接 | 移船/外交不能切断骑士与己方建筑的最后连接；检查跨道路/船只的整个己方网络，不能只检查同类边的开放末端。既有异常旧档也不能再拆去孤立骑士的最后一段路线。 |
| 计时 | 金矿结束后若进入另一人的引水渠，该人获得独立120秒；全部回应完成恢复原行动剩余时间。外交重放船延续同一机制。 |

## 本阶段支持与后续

内部构造器 `NewCatanCitiesKnightsSeafarers` 接入新海岸、四岛/六岛、迷雾、沙漠和新世界，3–6人；通过原航海家构造器保留地图版本和布局。六岛的存档ID是`six_islands`，房间配方ID仍为`islands`，内部掷骰须同时识别。

遗忘部落、布匹、海盗群岛、奇迹的额外组件和特殊终局需要各自组合规则，仍显式拒绝，不能简单套用“加2分”。Helpers与城市骑士尚无本项目已核实的兼容规则，也不启用。以上仍在完整组合目标的后续核对范围，未缩减原定范围。

## 验证证据

- 20组默认配方的3–6人初始建设、普通起始资源、两类休眠棋子、实际剧本目标、保存恢复通过。
- 金矿两张/一张、八种库存中只选五种、商品独存、普通资源耗尽、金矿后引水渠；蛮族劫掠先于金矿生产、全岛防御；骑士海路移动/驱逐/退让；指定海盗目标保存恢复；外交原型/海盗特例/骑士连接/原子拒绝；免费两船和商人/征税地形边界通过。
- 十场3人/6人完整电脑局从各剧本构造器起始状态到正常胜利，312–945步、5–12次蛮族进攻；每步核对卡与棋子库存、定期完整保存恢复。20组开局加该轮定向和完整局合计45.458秒。不是正式等待配置入口或浏览器完整对局的证据。
- 金矿→引水渠和外交重放船，各手动/托管/超时三条真实HTTP路径均实际重启，检查原子拒绝、手牌隐私、独立回应期限和原行动时间恢复（2.391秒）；骑士驱逐海盗另实际重启，拒绝改动强盗，恢复普通行动和原倒计时（0.915秒）。前六条HTTP并发检查通过（20.178秒）。

配置、战绩的双扩展标识、组合专用界面与说明、地图/卡牌动画交互、手机/桌面和完整HTTP/浏览器对局仍需后续接入及验收。特殊剧本和其他主要扩展也仍在原定目标内。
