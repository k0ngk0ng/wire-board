## 共同规则

| 情况 | 规则及实现 |
| --- | --- |
| 开局 | 先村庄后城市；第二轮只领取每个相邻地块一张普通起始资源。保留航海家地图和新世界已确认地图的港口前置流程。 |
| 获胜 | 航海家剧本的目标加2分；本阶段新海岸/沙漠16分、四岛或六岛15分、迷雾/新世界14分。不能统一采用独立城市骑士的13分。 |
| 海盗 | 与强盗一起在首次蛮族进攻前休眠；首次进攻结束后，按实际剧本的起始位置入场。 |
| 蛮族 | 所有岛屿同时受攻击，统计全部城市和活跃骑士；先完成劫掠，再按降级后的建筑进行同次资源、商品及金矿生产。 |
| 金矿 | 只产生普通资源，城市领取两张。数量、库存、自动选择只计算前五种卡；银行仅剩商品时跳过，不生成无解回应。领取金矿后不再误发引水渠补偿。 |
| 商人 | 不可放在金矿，也不可放在海洋或未知迷雾。 |
| 骑士 | 可以沿己方连续道路和船只移动，包括纯海洋交点；对手棋子仍阻挡经过，驱逐/退让保留既有资格限制。 |
| 驱逐 | 相邻骑士可明确选择驱逐强盗或海盗。目标类型随阶段持久化，不能在下一步改成移动不相邻的另一种棋子。 |
| 道路建设 | 可以免费建两条道路、两艘船或混合，仍保留逐步完成/探索/库存等规则。 |
| 征税 | 只移动强盗，不能借此移动海盗。 |
| 外交 | 开放道路或船只均可移除；己方只可重放同类棋子，不能船换道路。FAQ65允许外交搬移海盗旁的开放船，普通移船仍受海盗封锁。新位置仍须合法连接，重放的船按本行动新放置记录。 |
| 骑士连接 | 移船/外交不能切断骑士与己方建筑的最后连接；检查跨道路/船只的整个己方网络，不能只检查同类边的开放末端。既有异常旧档也不能再拆去孤立骑士的最后一段路线。 |
| 计时 | 金矿结束后若进入另一人的引水渠，该人获得独立120秒；全部回应完成恢复原行动剩余时间。外交重放船延续同一机制。 |

## 本阶段支持与后续

内部构造器 `NewCatanCitiesKnightsSeafarers` 接入新海岸、四岛/六岛、迷雾、沙漠和新世界，3–6人；通过原航海家构造器保留地图版本和布局。六岛的存档ID是`six_islands`，房间配方ID仍为`islands`，内部掷骰须同时识别。

遗忘部落、布匹、海盗群岛、奇迹的额外组件和特殊终局需要各自组合规则，仍显式拒绝，不能简单套用“加2分”。Helpers与城市骑士尚无本项目已核实的兼容规则，也不启用。以上仍在完整组合目标的后续核对范围，未缩减原定范围。

## 房间、战绩与界面阶段（2026-10-05）

内部已同时配置两项扩展的房间可选择五个共同规则剧本，列表显示加2分后的目标。HTTP仍只能修改已配置字段，公开创建、普通房间和单项扩展房间都不能自行开启另一项。特殊剧本和Helpers继续拒绝。人数扩充同时更新两套规则，重置真人准备；新世界可编辑或重抽地图，同配置不重抽，正式开局使用确认地图。

战绩新增`catanExpansionRules`，分别保存航海家和城市骑士版本；原`catanRules`在组合中保留航海家地图规则，独立城市骑士仍保留其版本。布局、实际剧本及两项扩展标识全部取自游戏状态，不受后续房间草稿影响。旧档和历史不需要迁移。

等待页、规则速查、地图与结算使用实际14/15/16分；保留固定/可变/确认地图及各剧本探索奖励说明。金矿选择和可领数量只计算五种普通资源；新增骑士驱逐海盗按钮、服务器保存的目标类型恢复/禁用切换。外交船只待选显示船只、合法船位和同类重放；道路建设与外交说明按组合显示。
