# Helpers＋城市与骑士

本阶段完成三至六人的独立城市与骑士及九种航海家地图。支持事件牌、友善强盗、港口霸主和五六人配对回合。这是 F12 的一部分，F12 尚未关闭，总进度仍为 **10/12**。本批未推送、未部署。

## 来源与本站适配

Helpers 官方规则明确列出基础版、航海家和五六人扩充，未给出城市与骑士的配方。参考 [Helpers 官方规则](https://www.catan.com/sites/default/files/2023-02/Helpers_Rules.pdf)及本地规则来源清单 `catan-helpers`。补充检索未找到可核验的官方组合说明，不能据此称其为官方禁止。

按用户授权采用本站规则 `wire-board-helpers-knights-v1`，写入对局状态与战绩 `helpers_knights`，在建房、玩法速查和助手说明中显示。基础 Helpers 和探索者专用 Helpers 保留各自规则。

## 交互与验证

- 迪亚拉支付后选择进步牌颜色，候选牌只发给本人；对手和观战者收不到牌面或进步牌堆内容。
- 格雷戈尔先选归还的骑士，再点地图位置，确认框显示骑士交点及费用；服务端按选定骑士移除后的地图计算合法位置，查询不修改棋盘。
- 卡拉只列出本人私有进步牌；资源选择不显示商品。
- 80 种初始化配置、11 场自然完整引擎对局、十二位助手关键交互及原 Helpers／城市骑士回归通过。
- 4 场自然完整 HTTP 对局通过：三人独立骰子、六人独立事件、三人部落事件、五人布匹骰子。均完成助手回应、过程中重启恢复及历史标记校验。
- 三人／六人的九图切换、权限、准备重置、重开、关闭助手隔离通过。私有选择、错误操作人、倒计时暂停／恢复、超时托管通过。
- 定向 race、`go vet ./...`、前端 212 项测试和生产构建通过。另修正旧航海骑士测试中仍将已开放的双人初航列为非法配置的过期断言，改为一人非法配置。
- 浏览器检查 320／390／1440 像素宽度：进步牌私选、骑士升城与确认、更换进步牌、等待房间开启骑士／Helpers 和五六人切换。未见横向溢出，浏览器无脚本错误。浏览器保持静音，站内音效关闭。
