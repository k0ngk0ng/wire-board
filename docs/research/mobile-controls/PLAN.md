# 手机屏幕按键验收

实现前失败清单：

- 长按方向、开火、蓄力、旋转、刹车等按钮时选中正文、箭头或子元素说明。
- 从按钮空隙、方向盘说明开始滑动，扩展到相邻文字的选区；iOS 长按出现文字操作菜单。
- 只给 button 禁选，遗漏方向盘和方向键容器；只写无前缀属性，旧版 WebKit 未保护。
- 长按、双指移动加放泡／开火、滑出按钮后松手、touchcancel 后丢失停止事件或误发操作。
- 全页面禁止选择，导致聊天、规则正文和输入框不能复制、编辑；覆盖现有 touch-action 使页面不能正常滚动。
- 按钮变成不能聚焦或键盘不能操作；禁用状态、按钮内 small/span 仍能选字。

范围：平台统一按钮；泡泡堂、坦克大战、赛车、俄罗斯方块、街霸方块、疯狂坦克的连续／屏幕控制区。其他游戏的普通按钮通过同一公共样式覆盖，不运行无关游戏的规则矩阵。

验收先运行未修改实现的真实浏览器脚本，记录实际长按选区、事件与计算样式；再修复。使用真实生产注册表、HTTP、SQLite、服务器时钟与 CDP 原生触屏。保留 320px、390px、桌面截图和 JSON，区分 Chromium 实际行为与 WebKit 声明检查，不将手机仿真声称为实体 iPhone 测试。
