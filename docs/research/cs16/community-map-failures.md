# 冰雪世界与血战回廊接入失败场景

先固定原图和来源，再实现转换。入口为 `python3 -B scripts/cs16/test_community_maps.py`；所有研究、临时文件和结果限定在 `.local/cs16/`。

- 同名地图版本不一致、来源分支未固定、下载后字节数／SHA-256／Git blob 不符、把重绘地图当原图。
- 多仓清单的 URL 与声明仓库、固定 ref、源路径不一致；重复输出路径、目录逃逸、符号链接、重定向或隐式网络回源。
- 仅凭 `cs_` 前缀误判血战回廊为人质模式；凭 `fy_` 前缀删掉实际中央购买区。
- 任一队少于五个真实出生点；忽略原出生朝向、出生高度或原地图边界。
- 冰雪世界缺少原 24 个 armoury 实体；缺省 item 被误判；item 枚举映射错位；数量和原位置丢失；把原高处实体 origin 当最终落地高度。
- 血战回廊凭空增加地面武器、炸弹区、人质、装备或禁止购买规则。
- NAV 版本／魔数／BSP 大小不匹配，计数越界、截断、非法引用或尾部未消费；第三方导航未经原 hull 核验就当成可通行事实。
- 外部 WAD 贴图或雪天天空缺失，改用占位颜色；新增 WAD 使旧图纹理选择发生变化。
- 只增加目录却未加入真实 render/rules/preview/sky、服务端规则数据、资源恢复与六图运行时身份。
- 转换新地图时重建旧四图或模型、音频，导致未变资源摘要和 URL 变化。
- 增量执行重复插入资源／地图，清单顺序不稳定；公开规则与 `data.MapsJSON` 不一致。

原图静态事实来自固定第三方归档，REA 包清点只验证成员身份与完整性，不证明原版运行行为或地图作者签名。
