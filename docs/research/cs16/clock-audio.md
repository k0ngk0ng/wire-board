# 回合时钟与 C4 声音对照

手机回合时间移至游戏区顶部安全边缘。C4 安装后隐藏时钟，保留安装和拆弹操作进度；不再把回合时钟替换为炸弹爆炸倒计时。按用户明确要求，C4 嘀声作为全房间非空间提示播放。全局声音是本平台定制，与所选原版样本的空间衰减不同。

## 固定原版样本的静态证据

客户端为既有第三方归档中的 `cstrike/cl_dlls/client.dll`，1,090,224 字节，SHA-256 为 `2dad31c59dabbddfaae5c9df0577899fda5f3f68bce6b492ef3d280faf34e5e7`。服务端为同一固定归档中的 Linux `cs.so`，SHA-256 为 `608904a0357af349466c7b34e69f224268090e3b553b5d46bf13b180001c9d8c`。归档来源及发行方身份限制沿用 `assets.md`；本轮没有运行原版游戏。

使用现有 Apple LLVM `objdump` 读取所选字节。REA 原生分析 provider 的既有可用性限制未变，没有安装 provider 或修改其配置。下表属于普通工具静态证据，不冒称 REA 反编译或原版运行记录。PE 中保留的邻近导出名不是这些内部函数的名称；内部用途由消息字符串、注册回调和调用链确定。

| 范围 | 静态位置与结果 |
| --- | --- |
| 回合时间消息 | `RoundTime` 字符串在 `0x19e8a14`，注册回调为 `0x194aee0`。回调读取短整数时长，写入计时状态。绘制路径从剩余秒数除以 60 得到分、秒，不是一个独立的 C4 截止时刻显示。 |
| 安装后隐藏 | `BombDrop` 注册回调 `0x194cd90` 转入 `0x194fa90`。安装标记为 1 时，`0x194fada` 清除 `gHUD + 0x476d` 的字节；`ShowTimer` 的实际处理函数 `0x194fb40` 将同一字节设为 1。 |
| 绘制门槛 | 时钟绘制函数 `0x194afa0` 在 `0x194aff1` 调用 `0x194cb30`；该辅助函数在上述字节为 0 时返回隐藏，绘制路径直接跳过。因此安装 C4 后隐藏时钟有原客户端字节依据。 |
| 原 C4 声音 | `CGrenade::C4Think` 位于 `0xdfdd0`。`0xdfea8` 使用双精度常量 1.4 更新下一次嘀声，`0xdfefc` 的重定位明确指向 `EMIT_SOUND_DYN`。五个分支引用 `c4_beep1` 至 `c4_beep5`，衰减值分别为 1.5、1.0、0.8、0.5、0.2，音量为 1，声道为 2。它是实体声源，不是全房间等响提示。 |

原客户端消息挂钩、隐藏字节、时钟绘制分支、ELF 重定位、常量和五档分支记录于 `.local/cs16/research/timer-clock/`。固定 ReGameDLL 参考提交 `1f16a7f25c14225931f8df1abc51f68d18ded839` 的 `wpn_shared/wpn_c4.cpp:193–205` 也说明 `BombDrop` 会令客户端隐藏时钟；可选的 `show_bomb_timer` 扩展会再次发送计时消息，不能把该扩展当作原版默认行为。

参考 `ggrenade.cpp:1307–1314`、`1403–1478` 说明首嘀在安装后 0.5 秒，之后每 1.4 秒发声，并逐步切换原样本和衰减。原版浮点时钟和 Think 采样与平台 100 FPS 定点投影存在边界差异；本轮没有声称逐帧等价。

## 最小公开声音元数据

服务端负责计算 `bombCue`，客户端不读取爆炸截止时间，也不需要爆点坐标或拆弹者信息来播放声音。字段是一个整数：`serial * 8 + stage`，序号从 1 开始，低 3 位为样本档位 1 至 5；未到首嘀或 C4 已停止时为 0 或省略。身份复用现有对局代次和回合号。

平台现有 45 秒引信按 100 FPS 计算：安装后第 50 帧首嘀，每 140 帧增加一次序号。档位在该次声音的发生帧计算，不能在两次嘀声之间因档位变化重复发声。分界沿既有整数语义为 1100、2090、2981、3782 帧。首码为 9，末段第 32 声的第 5 档为 261。这些元数据不包含爆炸截止时间、隐藏位置、敌方拆弹者或拆弹截止时间。

客户端使用平台 `audio.effect` 的独立 `cs16:c4-beep` 通道和原有五个音源，不占用枪声空间通道或回合播报通道。重复码、同序号的档位变化和过期序号不重播；跨越多个声音序号时仅重建基线。首次接入、恢复、取消静音或返回前台后，先以新的投影建基线，再播放后续新声。静音、暂停、后台、拆除或爆炸会停止当前通道，旧声音不自动恢复。

## 验证与范围

先行失败场景见 `games/cs16/tests/clock-audio-failures.md`。旧界面的真实 DOM RED 记录了 PC 安装后仍显示时钟；新实现的最终结果位于 `.local/cs16/verification/clock-audio/green-final/result.json`，包含源码摘要、截图、原音频资源 SHA-256、HTTP／Range 请求、平台通道调用和原生 HTMLMedia `playing`／`pause` 等记录。

验证覆盖 320 × 568、890 × 626、626 × 890、820 × 1180、1180 × 820 的普通、原生全屏和网页全屏，共 15 种布局；另检查 PC 安装后隐藏时钟。时钟与其他 HUD、全屏工具栏无重叠，安装和拆弹进度保留。五个原始 C4 音源均有原生媒体播放记录；重复投影、静音、恢复和真实标签页前后台切换没有补播旧声。

复跑入口：`CS16_CLOCK_REPORT=current node games/cs16/tests/clock-audio-browser.mjs`。夹具使用实际 CS Board、公共全屏与平台媒体实现，控制传入投影，并替换 GPU 绘制和运动加载。它不代表完整规则对局、原版运行听音、实体手机、Safari 或正式 GPU 性能验收。模块检查入口为 `games/cs16/tests/web-clock-audio.test.mjs`，并沿用观察、HUD 和反馈检查。
