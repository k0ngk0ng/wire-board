# 原始资源转换失败场景

以下场景在实现转换器前冻结，检查入口为 `python3 -B scripts/cs16/test_build_assets.py`。全部产物、缓存和临时文件限定在 `.local/cs16/`。

- BSP 不是 30 版、头部或 lump 截断、负偏移、越界、记录长度不对齐、无效平面／节点／边／纹理引用。
- BSP 实体缺少出生点、爆破区或人质／营救区；brush 模型号越界；brush 平移丢失；站立和蹲下 hull 混用。
- 地图自带纹理缺失、WAD 不存在、WAD 压缩格式不支持、外部纹理查找失败；名称 NUL 后脏字节被误作名称。
- 索引贴图调色板截断；透明贴图索引 255 不透明；纹理重复、动画与天空面被误作普通不透明墙。
- face 反面三角形绕序错误；纹理坐标未保留重复；光照块大小／偏移越界；atlas 重叠或贴图路径未进入清单。
- TGA 方向、BGR 通道或 RLE 解码错误；天空六面不完整。
- 第三方 PWF 版本、地图名、节点数、固定记录大小或连接越界；未对实际地图 hull 校验可通行性。
- 音频转换有损、采样率／位深／声道／采样帧数变化、还原 PCM 不一致；原始声音键与发布文件不匹配。
- 绝对路径、`..`、符号链接、输出目录逃逸，或者把任何媒体载荷写入 Git 源目录。
- 四图不完整、24 枪械模型缺失、8 个玩家模型缺失、预览不能对应实际原图。
- 重复执行结果不稳定、字节数或 SHA-256 不匹配、manifest 未列出所有间接贴图依赖。

研究来源为固定摘要的第三方公开归档；转换成功证明解析和自洽性，不证明发行方身份或原版运行行为。
