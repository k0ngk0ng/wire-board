# 失败重试的已通过游戏复用

实现前的失败场景：

- 已有成功祖先时跳过部分复用，修复一个失败游戏却再次运行所有此前通过的游戏。
- 把未改动、未选择的游戏误当作待运行游戏，扩大检查范围。
- 修复或待合入的游戏实际输入已变化，却仍沿用之前的通过结果。
- 篡改所需游戏集合、源提交或复用集合，使未通过的检查被跳过。
- 公共检查失败、任务同名不明确、游戏命令变化或较新失败被旧成功掩盖。
- 手动全量或显式指定游戏被自动复用吞掉。
- 复用检查后未重新构建当前提交的前端与服务器包。

用真实临时 Git 提交、模拟 GitHub 作业返回及实际计划器验证。保留原有严格失败行为；只缩小输入没有变化且已有成功证据的游戏任务。
