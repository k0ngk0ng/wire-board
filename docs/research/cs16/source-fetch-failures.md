# CS 1.6 原始样本恢复失败场景

本入口只在本地显式执行，不由普通 CI、构建或游戏运行自动调用。先登记失败场景并保留失败测试记录，再实现恢复器。

| 场景 | 预期 |
| --- | --- |
| 已有原样文件大小与摘要正确 | 直接复用，不发出网络请求 |
| 冷恢复、局部缺失或本地普通文件损坏 | 只获取固定清单中需要的来源，逐文件校验大小、SHA-256 和可用的 Git blob SHA-1 后原子落盘 |
| HTTP 失败、重定向、提前结束、过长正文或摘要不符 | 失败并保留已有目标，清理临时文件，不发布伪成功记录 |
| 清单出现绝对路径、父目录、空分段、反斜线、重复或大小写冲突 | 在开始下载前拒绝 |
| 输出目录、目标、清单或临时目录包含符号链接 | 拒绝，不跟随链接写入 |
| 来源主机、提交或资源路径偏离登记来源 | 拒绝；命令不接受任意 URL 或外部输出目录 |
| 离线 `--check` 时文件缺失或损坏 | 明确失败，不回源、不修复 |
| 可选参考源码 ZIP 包含路径逃逸、符号链接或重复成员 | 解包前拒绝；解包输出仅在 `.local/cs16/research/regamedll-reference/` |
| 可选源码 ZIP 大小或摘要不符 | 不解包，保留已恢复源码 |
| 中断或多文件部分失败 | 不生成完整成功结果；下次重新执行时复用已经验证的文件 |

元数据固定在 `games/cs16/assets/original-sources.json`、`navigation-sources.json` 和 `reference-source.json`，仅包含路径、固定来源、摘要和来源限制，不包含媒体载荷。原始样本输出至 `.local/cs16/research/original/`，导航输出至 `research/navigation/`，临时文件只放 `.local/cs16/tmp/`。

显式恢复原始素材与导航：`python3 -B scripts/cs16/fetch_sources.py`。增加 `--reference` 同时恢复固定版本的开源参考源码；增加 `--check` 只检查已有文件，完全不访问网络。正确的缓存不会重复下载。

复跑：`python3 -B scripts/cs16/test_fetch_sources.py`。测试使用位于游戏临时目录内的受控文件和本地 HTTP 服务，覆盖真实下载、错误响应、原子替换与完整离线清单验证；不会调用公网来模拟故障。验收产物位于 `.local/cs16/verification/source-fetch/`。
