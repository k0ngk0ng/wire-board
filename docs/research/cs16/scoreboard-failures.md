# Tab 计分板验收失败场景

实现前登记，范围限定为 CS 计分板和 CS 游戏区内的 Tab 行为。

- 计分板使用卡片、斜杠合并数据或额外操作说明，丢失原版阵营分组、击杀、死亡、延迟字段和阵营总分。
- 阵亡玩家、本人高亮、长名字或十名玩家显示错误；按未提供的私有库存推断敌方 C4、拆弹器等状态。
- 按住 Tab 未显示、键盘 repeat 反复切换、松开未关闭，或抢走当前游戏焦点。
- 死亡和观战时无法查看；菜单开启、切换标签页、窗口失焦或退出全屏后旧按键仍保持显示。
- 允许只读计分板后，暂停、托管或失去控制权期间按下的移动／射击键在恢复控制时自动生效。
- 原生全屏或网页全屏中 Tab／Shift+Tab 跳到网页按钮；取消默认行为时吞掉游戏计分板事件。
- CS 全屏内聊天、文本框或可编辑内容中的 Tab／Shift+Tab 仍然跳转网页焦点、意外打开计分板或改动文字草稿；普通页面编辑器的原生 Tab 被错误屏蔽。
- 手机「更多」中的战绩入口无法打开、不能关闭，或小屏内容横向溢出、无法滚动。
- 验收只注入脚本事件，没有可信键盘、触摸事件及可重复复跑的报告和截图。
