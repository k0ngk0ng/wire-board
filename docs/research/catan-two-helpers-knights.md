# 双人城市骑士＋Helpers

本阶段接通独立双人城市骑士与八种普通双人航海家地图的 Helpers，可叠加捕鱼、事件牌、友善强盗和港口霸主。地图为新海岸、四岛、迷雾、穿越沙漠、遗忘部落、布匹、奇迹、新世界。属于 F10 的部分工作，总进度仍为 **10/12**；F10、F12 均未关闭，本批未推送、未部署。

## 规则与范围

双人生产、中立势力及城市骑士规则依据见[双人组合跟踪](catan-two-combinations.md)。Helpers 官方未发布双人骑士专用配方，沿用[双人助手](catan-two-helpers.md)与[骑士助手](catan-helpers-knights.md)已明确标记的本站适配；捕鱼叠加参见[捕鱼骑士助手](catan-fishing-helpers-knights.md)。没有将本站规则标为官方规则。

- 对局同时保存 `two.helpers = wire-board-two-helpers-v1` 与 `citiesKnights.helpers.rules = wire-board-helpers-knights-v1`；捕鱼开启时还保存 `fishing.helpers`，战绩保留对应版本。
- 两位玩家持有助手，中立势力没有助手、资源手牌或鱼。每回合两次生产共用一次助手机会；跳过可选的希尔达补偿不消耗助手，因此第二次生产仍可使用。使用后翻面保留也不能在同回合再次使用。
- 引水渠与希尔达分别补偿；完成第一次生产全部回应及助手翻面／交换后才进行第二次生产。鱼筹码不取消任何一种补偿资格。
- 格雷戈尔只能归还己方实体骑士，不能牺牲中立骑士。归还骑士不发贸易筹码；如果此次建设的是村庄，村庄本身仍按双人规则领取可用贸易筹码。捕鱼局不使用贸易筹码。助手翻面／交换后接续中立村庄建设；升城不触发中立建设。
- 迪亚拉的私选候选牌计入进步牌总库存，选定前不进入手牌或牌堆，也不发给其他玩家与观战者。卡拉更换私有进步牌、资源助手不操作商品等规则沿用骑士助手。
- 普通骑士双人贸易筹码仍有限量；捕鱼仍替代全部贸易筹码，不因开启 Helpers 改变。基础双人、多人基础及关闭助手的旧合法存档保持原操作。

- 36 种初始化配置：独立与八图，捕鱼开关、全部备用助手开关，均同开事件／友善／港口，完成开局、行动与保存恢复。
- 18 场自然完整引擎对局通过，覆盖上述九种地图的捕鱼开关；不同地图交替使用骰子／事件牌。
- 22 场自然完整 HTTP 对局通过：独立骑士与捕鱼骑士各 3 场，八图的捕鱼开关共 16 场。运行中覆盖手动操作、持续托管、超时自动托管、各回应阶段重启、旧请求重放、隐藏信息、库存与战绩。
- 18 种公开配置验证正常创建、准备／开始、房主权限、助手开关、重开、恢复、关闭助手以及回基础。未开放的河流、商队、蛮族、运输组合继续拒绝。
- 八条定向双生产路径覆盖本人／对手希尔达、跳过／使用、捕鱼开关；验证引水渠先回应、助手使用次数和第二次生产接续。
- 格雷戈尔建村／升城及捕鱼开关四条路径验证拒绝中立骑士、移除己方骑士、在腾出的交点建村、筹码奖励、中立建设接续及保存恢复。
- 定向检查私选进步牌库存与隐私、错误操作人、缺失规则标记拒绝、旧无助手存档；原双人助手、双人骑士、捕鱼骑士和多人骑士助手相关回归通过。

自然完整对局使用测试客户端和电脑决策。以上结果只证明已列明配置，不替代最终版本的整合与真人整局验收。
