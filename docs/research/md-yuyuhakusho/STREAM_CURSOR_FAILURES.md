# 逐连接增量输入的先行失败范围

本清单先于本 worktree 的 `StreamView` API、连接游标和本作增量投影实现。Main 的现有源文件只读参考，不整文件移植，也不改规则、呈现或控制器。

- API 缺失或允许非即时模块／无恢复接口模块注册逐连接投影；未采用回调的模块被改变行为。
- 投影仍持有平台锁，慢计算、Socket 写入或一个慢连接阻塞其他玩家、权威时钟或 HTTP；回调取得 room 原始 Data、Actors 或其他共享引用。
- 快照与消息信封来自不同 room version；不同 room、viewer 或 epoch 共用游标；新连接／重连继承旧连接游标。
- 未成功写入的消息提前推进连接游标；连接积压形成无限队列，落出恢复窗却继续猜测缺失帧。
- 所有连接持续重发完整 120 帧输入环；空闲／相同帧消息继续携带旧输入；少量冗余无上限。
- 无效、非规范、未来、旧 epoch 或落出 120 环的游标没有明确 `resync`；恰好处于窗口左边界的有效游标被错误拒绝；64 位帧被舍入或溢出。
- 增量裁剪修改持久历史或普通 View；`/sync` opaque checkpoint、资源身份、公共玩家字段或鉴权发生变化。
- 常规 WS 泄漏 world、HUD refs、缓存、存档、素材；仅断言 payload 小，却没有验证客户端逐步规则和呈现摘要与服务器相同。

验收先冻结：新增输入只带最多 6 帧已发冗余；相同帧返回规范空窗口；密集双人增量 View 不超过 2048 字节；真实 WS 快端输入 ACK 不超过 500 ms（本机验收界限，不是公网延迟承诺）。保留真实 HTTP／WS、慢端并存、重连、逐帧重演和消息字节记录；不重跑未改动的 32 场 AI 规则矩阵。
