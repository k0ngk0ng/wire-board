# 独立 PCM 算术与原生事件模型的先行失败场景

本清单先于新采样器、事件观察桥、离线验证器和 `audio/pcm` helper。原分派仲裁、有限目录、时基、世界和旧 producer 保持不变。

- 把编码样本当成线性 PCM；高／低 nibble 顺序、零 nibble、`8` 的 `-128`、8-bit 累加回绕或初始 `80` 错误。
- 将单 DAC 与双槽视为同一输出路径；双槽中非活动声部的中性值、查表前相加和 DAC 8-bit 限幅发生顺序错误。
- 把双槽查表当作平均或 16-bit WAV 相加；在滤波、量化之后补一个固定增益，掩盖原算法差异。
- 只对照从相同数学公式产生的期望；未保留原固件母表或真实原程序解码结果。
- 观察桥替换函数后未委托原读写、改变参数或返回值；恢复后丢失 wrapper／递归调用 wrapper；截断事件或记录溢出却宣称全量。
- 只比较 RAM／视频而不比较 PCM；host pointer、内核回调位置或原始 CPU cycle 被误当作跨平台、真实硬件采样时刻。
- Z80 ROM bank 读的 core 平均等待、VDP DMA 等待及对 M68K 的经验偷周期被混作样本编码本身；忽略总线握手、预取和初始两槽模式状态。
- 对比滤波后 WAV，任意移位或修改增益制造通过；将 DAC 数值匹配误称 YM2612 模型、滤波器、重采样或扬声器输出全部匹配。
- 从真实事件中借用生产 PC／原时刻回放表，或把 Z80 指令、固件、寄存器／RAM VM 带入独立 Go 运行时。
- 短片段算术正确被误称完整播放寿命、bank 事件时基或任意成对抢占已恢复；结束、切换、暂停和 duck 未单列边界。

本阶段先证明 16 项 delta 与 512 项限幅母表，再采真实 DAC、编码读、累加结果和 bank 读事件。生产 helper 只实现直接 typed 算术；cadence、prefetch、握手、过滤及 resampler 不在未经证明时加入 API。
