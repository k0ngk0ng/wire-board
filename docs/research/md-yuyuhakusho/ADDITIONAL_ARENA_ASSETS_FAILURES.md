# 其余七场地素材：实现前失败范围

本批只恢复原场地偏移 `2/4/6/8/a/c/e` 的紧凑 indexed A／B 背景。场地名称尚未核实。原 ROM、原版内核、RAM／VRAM 和视频只用于开发取证，不进入运行素材。

## 先行验证

先保存本清单和 `scripts/yuyuhakusho/verify_additional_arena_assets.py`，运行缺资源的真实失败，再编写提取器、导出紧凑素材。验证器独立解析 ROM 清单及压缩流，检查每个单元的属性和 32 bytes 图块；像素验证使用合法原版输入的完整基线和每行实际显示状态。观察器必须保持全部原 RAM／视频摘要。

## 失败场景

- 缺少七场之一，错误场地 ID、callback、资源清单、ROM 摘要或压缩源摘要；将默认场地素材改名使用，或把任意清单放行。
- 压缩流截断、越过编码边界、反向引用早于输出、输出超过 VRAM；token count、解压长度或解压摘要错误。
- 漏掉公共 `27db80→0000`、`27dcb4→1800`，ID2 的 `28bde8→a000`，或 IDa 的 `297056→ba00`；依地址间距猜图块范围。
- 将 `c100/e100` 开始的地图机械补零，未核对加载后的前 `0x100` bytes；额外图块未与实际 loaded VRAM 核对。
- 只保留当前可见区域，漏掉完整 64×32 A／B 平面，或将未引用图块／整 VRAM 隐藏在素材中。
- 图块高／低 nibble、翻转、palette、优先级或局部图块索引错误；未去重、超范围索引、重复／未引用图块、无效 flags。
- 初始色盘与对应场地资源不符，混入默认色盘；将初始 palette 当作整局固定色盘。
- 将帧末 VRAM／VDP 状态直接对应同帧视频，忽略 `f+1`；漏掉绘制入口、空白行、背景色更新、窗口和 HUD。
- 将默认的可见行、窗口范围、滚动 profile 套给其他场地；把逐行滚动当单相机偏移。
- 把精灵遮住的原像素当背景本色，扩大遮罩来消除差异，或比较零个有效像素；只比较自解码图片而未比较原视频。
- 忽略 ID4 色盘循环、IDa 的子对象、跨帧／有效行内图块或平面更新；从单帧通过宣称全时段静态。
- 观察器改变游戏状态、漏记资源加载／扫描行、恢复 checkpoint 时不恢复 refresh cycles，或 original／hook 输入身份不匹配。
- 两次导出同输入产生不同 JSON／gzip，或运行资源夹带 ROM、RAM、VRAM、视频、CPU／VM 或内核代码。
- 场地 `a` 的 `21258` 子对象遗漏 `297056` 的 48 个顺序图块；擅自去重破坏局部起点 `0/16/32`，将硬件地址放入运行包，或未按每个自然样本核对额外上传范围。

## 验收边界

静态绑定和 ROM 解压通过不证明完整画面通过。七场须分别报告实际 sample frame、blank／draw 行、寄存器、色盘、地图／图块变化和原视频比较像素数。动态范围不符合静态 schema1 的场地必须明确报告并提供必要 typed 素材证据，不允许静默固定为首帧。
