# FM／PSG 芯片层先行失败边界

范围为固定参考配置的 YM2612 离散模型及集成 PSG：有序端口输入、独立 typed 芯片状态、原生芯片输出和连续重采样。世界声音调度、PCM 固件时钟及扬声器录音不在本项证明范围。原模拟器仅作为研究 oracle，生产不得执行原核心、CPU、ROM、任意 RAM 或原 PC 时间表。

生产实现之前先建立下列独立原生对照，再编写失败的 Go API／轨迹检查。需要单独保存真实 red、完整输出来源及命令，不能在实现后补写声称先行的测试。

| 输入或边界 | 可能失败 |
| --- | --- |
| 六个通道、八种算法、八档反馈 | 路由、反馈两步历史、延迟节点或载波量化错误 |
| 频率高字节锁存、跨 bank 地址／数据端口 | 将共享锁存错误拆成每通道；错误依据 data port 选择 bank |
| 每个操作器的 DT／MUL／TL／KS／AR／DR／SR／SL／RR | 符号、定点舍入、零倍频、率索引、限幅或写入生效时点错误 |
| 同时刻连续写、零长度生成、写后 key-on | 丢顺序，提前刷新 keyscale，或误把可派生缓存永久双存 |
| 普通包络、最大速率、计数器 4095→1 | Attack 被阻止边界、SL0、保持 Sustain 状态或 12-bit 计数回环错误 |
| 全八种 SSG 包络、运行中改形、key-off | 反向、保持、相位复位、迟一步输出或 Release 转换错误 |
| 全八档 LFO 时钟、AM／PM 深度 | 错误的三角方向、频率分段、有效位、detune 溢出和三音模式 |
| 三音模式、Timer A／B、CSM | 频率操作器映射、重载、status 清除、CSM 抑制与下一采样释放错误 |
| 第六通道 DAC 使能、符号和声像 | 冻结相位、持续包络、离散 ladder 偏移或 mute 语义错误 |
| 分批输入、snapshot／restore | 状态别名、缓存丢失、恢复改变轨迹或重复输出 |
| 非法状态、端口、长度、时间回退／溢出 | 部分提交、无界分配或跨域状态被接收 |
| PSG latch、divider0、noise、增益变更 | 边沿顺序、分频器相位和未提交增益变化错误；由独立 PSG 子项覆盖 |
| 帧末和超帧 lookahead | 误丢 oscillator／envelope 副作用，或将原 raw 时间 clamp 到帧尾 |
| Native／Wasm | 浮点建表差异、int 宽度差异或输出字节不一致 |

数值方程和芯片行为可以重建。参考 PSG 源码明确有 NonCommercial 条件，不能把其源码复制或直译到生产；chip 语义、数值事实、研究调用和实现来源须明确区分。所有研究缓存、输出和临时文件只写本 worktree。
