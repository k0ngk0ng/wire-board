# PSG 子层先行失败场景

本范围只恢复固定 MD 参考配置的集成式 PSG 寄存器、分频与振幅边沿。运行时不执行 ROM、CPU 或原生内核，也不包含音序播放器、主时钟调度或 HQ 重采样器。

实现前列出以下失败场景。先取得缺失包／接口的真实编译失败，再编写生产实现；原生对照的完整状态、音频缓冲和 PCM 用于验证观察器及边沿，不能用自己的实现生成期望值。

| 场景 | 必须验证的失败 |
| --- | --- |
| 原生配置 | 不得把分立式零频率和噪声反馈规则误用于 MD 集成式芯片；确认 HQ、150% 和双声道 |
| 初态 | latch 初值、静音振幅、15 位反馈位置、计数器与负极性不能猜测 |
| 寄存器锁存 | 低四位与后续六位更新、三音调、四衰减、噪声控制及无 latch 数据均按原输入顺序 |
| 零分频 | 集成式 0 与 1 同周期；1023 与高位掩码边界正确 |
| 音量流水线 | 改写振幅后不提前发声，待内部同步时钟再提交差值；相同周期多写不得丢失或重复 |
| 频率修改 | 保留当前计数器相位；只修改下一次累加的周期 |
| 噪声 | 周期／白噪声、8 种控制、正沿移位、LSFR 重置、tone 2 联动及完整白噪声周期 |
| 边界 | 写在 tick、tick 前后、视频帧尾和超前输入；推进条件严格小于目标时间 |
| 观察无扰动 | 批量原生推进与逐 240 周期观察的全部 typed 状态、完整 blip 缓冲与 PCM 完全相等 |
| 完整恢复 | 半周期／待提交音量差／噪声移位中途保存恢复，后续边沿和状态完全一致 |
| 原子拒绝 | 倒序输入、未知 profile、非法初态、时间溢出、超过有界批次不得提交部分状态或边沿 |
| 资源 | 时间与队列有明确上限，合法最短周期不能分配无界边沿 |
| 平台一致 | native 和 Wasm 使用同一原生夹具，逐条比较全部边沿与每个检查点 |

原生 `psg.c` 具有非商业许可条件。它只作为本地研究的行为与状态 oracle，不复制或翻译其实现到生产；生产采用独立 typed 事件方程。数值振幅按 2 dB 衰减公式量化，参考专用配置与硬件差异分别记录。
