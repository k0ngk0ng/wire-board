# 总线时基直接观察的先行失败场景

本清单先于本轮观察器和模型。既有声音 phase 证据有完整请求与消费偏序，但没有逐次 Z80 bank 访问和 68000 被延长的关联，因此不能把残差可分解为 70／77 当作直接观察。

- 只记录 bank 读取入口，漏记 DMA 将 Z80 等到 dma_endCycles 后的实际延长；用读取前相位错误计算 70／77。
- 混用绝对 master 时间与当前参考视频帧的 Z80.cycles 相位；896040 不能被 7 整除。
- 把 ROM bank 与 7Fxx 的 VDP 访问混为一类，或丢失写访问、相同值写入、每次访问的原顺序。
- wrapper 改变原 handler、RAM、视频、PCM、样本数或声音字段；事件溢出、丢帧或未恢复 handler。
- 不能在同一原序号上连接 bank 访问、语义块、IRQ 和声音写入，反而按来自不同进程的时间戳猜测归属。
- arena 含 IRQ／自身硬件访问时仍强行应用纯 row-loop 成本；给全部块加同一个拟合成本。
- 把给定原事件的逐次算术对照宣称为自主 PCM cadence、独立世界调度或真实硬件时序已完成。
- 生产层保存原 PC 时间表、全寄存器或 RAM 镜像，或以通用 CPU／字节码 VM 运行原程序。
- 在生产代码后补写针对性单元测试，或修改旧冻结模型以隐藏已有 6710 个反例。

先冻结检查器，再对既有不含总线事件的 compact trace 运行：应明确失败。新增被动采集必须逐步匹配现有未观察控制组，并用同一检查器连接实际总线事件与自然语义块。
