# 场地 4／c／e：实现前失败场景

本范围只恢复原 `A060.word` 偶数偏移 `4/c/e` 对应的 `20cb2/212f8/21412`，以及场地 4 的 `20dca` 色盘子规则。依据为固定 SHA 的日版 ROM 和 [已保存的 Ghidra 指令](static/arena-assets-scenes.txt)。静态记录不是执行证据；合法菜单自然输入与未挂钩原版控制由统一采集提供。当前没有新增独立规则实现，也没有声称三场地已验收。

## 状态和输入

- 将 ID 当成连续序号，或将场地 4 的初始化、色盘、表格和滚动公式套用默认场地。
- 把 `F550` 按非零暂停：实际仅负 byte 跳过；或忽略 `F55A` 任意非零均跳过。
- 只阻止初始化，仍在暂停／慢连接门内调用相机、写色盘、填行或执行反馈。
- 非零 stage 被错误拒绝，或误作另一阶段；原三个主入口仅区分零与非零。
- 创建第二份 mode、速度、相位、计时器、行表或反馈 owner，导致保存恢复后分叉。临时视图必须立即合回 `World.Objects/Palette/Cells/Stream`；`6000..6400` 仍由 `Stream` 唯一持有。
- `F572` 被读取为 byte 或另一计数器；实际是 `Clock.PanOffset` 的 word。其非零值应冻结相关累积器／色盘，同时仍运行相机、行写入与公共反馈。
- 丢弃 c／e 初始化对 `F6DF` 的清零，或把它混入 `F6E7` 滚动模式。已追到它是 VDP 寄存器 7 的背色索引低 byte：`4aa` 初始化影子命令高 byte，`438/5d8/60a` 将 `F6DE.word` 提交控制端口，详见[消费者静态](static/arenas-4-c-e-consumers.txt)。
- 相机采样未消费、消费两次、用了本轮而非上轮结果；把 word 累加、无符号除法、算术右移、带符号截断或 word 溢出改为宽整数运算。
- 只测试干净初态，掩盖本应保留的字、word 的低半字及未写行被错误清零。

## 场地 4

- 初始化遗漏 `F6E7=3`、`+20/+22=0`、stage 加二，或错误清除其他字段。
- 初始化填充区错位、少一组、越界：`RowsA[80:112]`、`RowsA[176:240]`、`RowsB[120:168]` 应为 `01a0`。
- 当前 Y 减 shake 后未按 word 回绕；垂直两字不相同；两个源指针未分别从回绕后的 `2*dy-1800/1600` 符号扩展。
- 表行选择未使用 `X&63`，把 X 直接索引、符号扩展错误，或只恢复自然出现的少数行。
- `2a000+row*256+30` 表片段长度错误；`+40` 填充值不是该片段的第 8 个 word。
- `RowsA[112:176]` 填充值错误；`RowsB[8:120]` 的 112 word 反向顺序错误；`RowsB[168:248]` 的 80 word 正向片段错误。
- 把初始化区当作每次写入，导致非零 stage 下旧行丢失；或把不重叠的行合成一个全覆盖区。
- `20dca` 在 `F501 != 0` 或 `F572 != 0` 时仍写入；将 `F501` 错读为 `F500` 或只检查某一 bit。
- 在独立 `20dca` 子规则中添加原入口不存在的 Pause／Slow 门。它们由外层主 callback 检查，子规则只检查 `F501/F572`。
- 计时器不是先按 word 减一再检查符号；漏掉 `0000→ffff`、`ffff→fffe` 更新，以及 `8000→7fff` 不更新。
- 更新时未将计时器设为 5；`(+20+4)&000c` 的 word 回绕或四态循环错误。
- `20e00` 指针表次序错误。四组三色分别为 `04ae/024a/0006`、`024a/04ae/024a`、`0006/024a/04ae`、`024a/0006/024a`。
- 三色写入位置错为当前色盘或整盘；实际仅 `Primary[9:12]`（`E092..E097`），其他色字及色盘寄存器应保留。

## 场地 c

- 初始化未清 `+1c/+1e` 和 `+10/+14` 的全部 long；把相位误合到默认场地 `+20/+22`。
- 垂直 B 错用 A；实际 B 是 `asr.w(dy,1)+0010`。B 源是 `asr.w(2*dy,1)&fffe-15e0`，不能在 word 溢出前约简。
- Pan 为零时 `+10 += 00010000`、`+14 -= 00030000`、`+1c += 0010` 的 long／word 回绕错误；Pan 非零仍更新。
- 横向基值未按 `-(X-0360)+0060` 的 word 顺序计算，未写回 `+08`。
- 波形取样把偶数 byte 偏移当作 word 索引；忽略 `&07fe`、有符号 byte 扩展、算术右移三位、每组相位加 `0020`。
- 80 组重复二 word 写入 `RowsA[80:240]` 的边界或重复数错误。
- B 的两个漂移应读取 long 的高 word；错用低 word、浮点、另一个速度或默认累积器。
- `F589.bit0` 交换次序错误，漏掉任意高位脏 bit；28 组四 long 共 224 word 的交替模式或 `RowsB[16:240]` 边界错误。

## 场地 e

- 初始化仅清 `+08` 的高 word，低半字残留；或在非零 stage 错清长期累积器。
- Pan 为零时 `+08 += 00008000`，高 word 每两次变化一次；负值、低半字进位和 long 回绕错误。
- 将现有默认场地 56-word 尾表用作此处 64-word 表，静默补零或重复最后八个 word。
- 表地址计算未保留 `ext.l(X-02e0)` 后左移八位及加 `0050` 的顺序；`+10` 持有的原表地址丢失或由第二 owner 重算覆盖。
- `+0c` 保存表首 word；`+14` 保存其算术右移一位；`+18` 是 `2*-(X-0360)-0060`，任一字段与别场共用时错误别名。
- A 的 `80:144` 累积器填充、`144:184` 表首填充、`184:248` 原表拷贝边界错误；B 的 `16:200` 半值填充和 `200:240` 横向值填充边界错误。

## 反馈、取证和回放

- c／e 共用默认垂直／源指针公式，忽略各自 B 的半速公式；反馈又重复实现一次相机或漂移。
- `21690` 的源读应跨 HUD／A／B 当前行视图，并按 word 加 Pan；错误只读本场刚写的区间，错误补零，或错误允许不足 224 行的源。
- 忽略反馈源指针的有符号 word 结果与 `6000/6200` 目标，创建与 `Stream` 不一致的持久 `PanA/PanB`。
- 将全 RAM 差异仅按大范围白名单过滤；未知写必须失败，并保留精确地址和前后值。
- 自然调用遭 IRQ／声音穿插时，将 `24` 位与完整 PC 别名混为一类；未逐个 RTE 关闭 IRQ，或不记录 `219xx` 声音路径和 `37c56/37cac` 外部清除。
- 用原版函数外的中断／声音结果修改场地预期；或把未知外部写当作无关噪声屏蔽。
- 观察器改变固定输入任一帧的完整 64 KiB RAM、视频或尺寸；未用统一提供的 3,602 帧原版控制逐帧核对。
- 私有用例未显式声明脏初态、调用入口、输入注入和停机点；恢复未包含 `refresh_cycles=True`，或返回地址未匹配实际栈。
- 连续用例每帧重新解码原 CPU before，从而掩盖独立规则的状态漂移；必须仅从单一初态向前推进，外部输入逐条声明。
- 测试缺实现时因为夹具／环境／别人的 symbol 先失败，未证明本组 own symbol 的真实 red；实现先于冻结测试或失败产物。
- 只在原生通过就宣称浏览器可用；夹具、typed 表、采集器、ROM／core／输入／控制 SHA 未绑定，或结果无法重复执行。

验收顺序：完整失败清单 → 合法菜单自然记录及逐帧控制等价 → 私有脏初态／单初态连续原 CPU 记录 → 冻结测试与 own-symbol red → 独立实现 → 精确状态与全 RAM 审计 → 原生竞态和 Node/Wasm 结果。最终规则不携 ROM、内核或 CPU 虚拟机。
