# 原生无损音乐分片承载的失败场景

本范围是研究载体，不修改平台或游戏。输入是已验收 `82` 的连续原 PCM 片段，输出不是新的循环音乐资产，也不代表独立 DSP 已完成。

- MIME 能力声明可用，但真实 FLAC／fMP4 初始化、解码或持续追加失败。
- 编码或封装改变采样率、声道、样本值、样本数量、前导延迟；有损 AAC／Opus 被误称无损。
- fMP4 包的 PTS／DTS、片段基准或持续长度存在缝隙、重叠、倒退；只验证整文件能播放，未验证分片重组。
- 浏览器只播首片段，后续追加发生在停止之后；时间轴有 `waiting/stalled/error` 或多个不连续缓冲区。
- 通过重新创建 audio 元素、切换 src、`ended→seek→play` 或交叉淡化掩盖分段间断。
- native captureStream 在首边界结束，后续录音没有覆盖；Opus 录音的 48 kHz 输出被误作原 44.1 kHz PCM。
- 用播放时钟或 `playing` 事件替代解码样本等价证明；本轮容器往返 PCM 与浏览器时间轴分别报告，不作扬声器逐样本证明。
- 游戏另建 `AudioContext`／播放器；本轮研究 harness 不能作为绕过 `BoardProps.audio` 的正式接入。
- 只在一个桌面 Chromium 测试后宣称 Safari／手机通用，或把 12 秒载体片段误称无限 BGM 已完成。

验收先冻结连续 PCM、片段时间戳、实际播放和至少两个边界的断言。只有这些独立证据均通过，才说明此载体在所测浏览器可行。
