# 独立精灵呈现：实现前验证范围

目标是在已确认的角色索引素材和精灵组合格式上，建立可由独立世界与浏览器调用的呈现层，并补齐当前酎子对象、通用特效和附着特效使用的图形资源。模拟器只用于原版取证；生产接口不执行原指令，也不保留整幅 RAM、DMA 命令或 SAT 图像。

可能失败的场景：将角色目录误作全部世界精灵；依赖旧图块槽的帧被补成透明；使用各人物私有映射而遗漏全局槽覆盖；每帧无条件重传导致缓存／跳过图块语义错误；裁切后仍改变缓存或槽；片段调色板覆盖／翻转／定点缩放／word 回绕错误；按提交顺序代替原层链顺序；精灵上限只在开始检查而丢失末片行为；把透明索引零和黑色混淆；只比较几何或重新编码的自洽性而没有原 CPU／原视频；以截图作为正式素材；只恢复静态人物却声称特效和全部世界可呈现；测试后补或写出 worktree。

先保留原 CPU 精灵提交和自然像素输入，列清素材来源及未确认的静态公共槽，再编写独立呈现测试并实际观察缺实现失败，最后实现。所有缓冲编码只留在测试适配器；运行接口使用图块、赋值、片段、颜色和具名缓存。比较范围、预览、来源摘要与复跑命令在验证完成后补充，不提前声称平台渲染或完整世界已验收。

## 资源目录与绑定

`world-sprites.json.gz` 合并已验证的 1,133 个父角色图形键和 367 个额外非零图形键，共 1,500 键、34,520 个去重 4bpp 图块。额外范围如下；表内存在不等于正常玩法均可到达。

| 图形集合 | 图块库身份 | 非零键数 | 用途与边界 |
| --- | --- | ---: | --- |
| `D8F1A` | `240000` | 60 | 酎弹体、蓄力／释放附件的共享图形 |
| `D9E4A` | `246F80` | 35 | 通用动态特效；参数 70 为零哨兵，不解析 |
| `DA16A` | `24B620` | 10 | 自然 `9C80` 覆盖层实际使用的图形 |
| `DA1DA` | `24B9E0` | 107 | 结果、姓名与计数文字；参数 214 为零哨兵 |
| `DAA4A` | `25D260` | 9 | 开战字块；参数 18 为零哨兵 |
| `27F618` | 预载依赖 | 146 | 公共特效、数字和影子，实际回调使用 `SkipTiles` |

每表以已确认相对 word 表与显式片段终止位建立范围，零项排除。最大项仍受声明上界约束，不把后邻字节当作额外图形。`27F618` 的传输描述符不是合法的未知库素材来源；目录将其标为 `PreloadedOnly`，不从 ROM 0 或任意旧图块库复制程序字节。默认公共槽 `C0..1FF` 从原版场景 0 的实际预载状态提取为独立索引图块，只作为初始化依赖；其他场景及动态 UI 仍由世界资源层提供。

生产目录只含索引图块、语义传输身份、片段及调色板尾段；原图形 payload、原 CPU 缓冲和原 VRAM 仅在受摘要约束的研究 oracle 中。客户端可离线加载目录，正式发布需按平台资源分包／CDN 规范处理，不能嵌入服务器镜像。本轮不发布资源。

## 可复用呈现层

[presentation](../../../games/yuyuhakusho/presentation/README.md) 为独立包，没有修改旧 `verify-sprites` 命令。`ComposeActor` 先按原范围裁切／禁用，再依据四缓存、`SkipTiles` 和当前帧应用全局槽赋值；后写覆盖前写，未赋值槽保留。错误返回保持输入与库不变。缓存命中时不会因为重画而重传，Actor 的资源库身份只有发生实际上传时才参与绑定校验。

片段保留中心缩放、整体与局部翻转、颜色覆盖、word 相加回绕及来源高 nibble。后者虽然不参与图块大小，却在原完整精灵缓冲中保留，因此由 `SourceXor` 明确携带，测试没有把它屏蔽。完成列表按 `Layer&FC` 升序连接，组内保持提交顺序；静态可达指令见 [world-sprites-order.txt](static/world-sprites-order.txt)。原循环允许写出终止的第 81 项，但正常 H40 列表解析在索引 80 前停止，呈现层保留组合输出并在光栅层停止后续层组。

`TileSlots` 仅存 2,048 个当前图块 ID 及存在位，不是原 VRAM。`FrameState.Parts/Transfers` 是当前帧的短窗口，跨帧保留槽映射和每对象缓存即可。调用者还需按规则的初始化／清槽前缀同步缓存；不能把所有存活对象都绘制，也不能每帧重新安装默认预载槽。

`RasterizeSprites` 输出普通 H40 精灵层的 RGB565、透明度、优先级和来源对象，`RGBA()` 可供图片或浏览器使用。索引零透明，非零黑色仍不透明；尺寸 8～32 像素，图块按列排列，正常坐标按 9-bit 环绕。高／低优先级留给独立背景合成；逐行溢出、硬件 X=0 掩码、影亮模式及完整背景融合不在本包中模拟。

## 原 CPU 与自然呈现对照

旧 9,218 个父角色完整 CPU 提交与新增 3,020 个世界提交均通过新语义呈现包，再由测试适配器编码回完整 256-byte 对象、3,072-byte DMA 队列、4,096-byte 精灵缓冲、256-byte 层链及游标／标志；没有缓冲字段屏蔽。新增调用覆盖全部 367 键的四朝向、普通／`D8` 深度及裁切、缓存、跳传、字节计数回绕和 80 上限边界。零长度传输身份仍保留为事件，但不声称模拟故意不一致私有缓存触发的原硬件零长度 DMA 拷贝。

528 次原版色盘完整调用也由 `ApplyPalette` 重放，128-byte 结果完全一致。它只替换一槽的颜色 6～15，保留公共前六色及其他槽；不会将酎色盘猜作所有角色颜色。

另外捕获两套原输入下 83 个自然呈现帧，覆盖开战、交战、子对象／特效及结果／淡出。固定输入扩展到 5,500 帧后松开控制的原基线、特殊动作输入的 3,600 帧基线，全部 RAM／视频逐帧不变。只读 PC wrapper 观察 `125A` 初始化完成后的当前槽上下文及真实 `1580` 绘制请求，每次仍只执行原函数一次。

呈现测试从每个被测帧的前置图块上下文开始，独立执行该帧全部缓存、赋值、层排序，再与下一次实际上传的槽和最终链逐项比较。重复绘制同一对象时缓存由 Go 的上次输出延续，不取期望缓存。83 帧共 355,914 个不透明高优先级精灵像素与原视频零差异，包含父角色、`9100/9200/9300` 子槽、多种池特效及覆盖层。低优先级像素只参与精灵相互遮挡和链验证，没有冒充完整背景融合。

自然默认场景在初始化后保留两个屏外哨兵，`F57A=1`、`F578=2`，不能把预算初始计数改成 0 或 1。首次错误假设已经由捕获失败暴露，随后按实际字段采样。淡入／淡出还需使用对应上传时点的色盘：oracle 同时保留原帧结束和下一次上传后的色盘／寄存器，不把旧色盘覆盖为“已验证正确”。

测试先于实现，真实缺 `Catalog/Actor/ComposeActor` 失败已保留；硬件列表边界回归也先保存失败，再实现停止规则。自然帧是单帧呈现回放，跨帧世界和其他资源上传由外层提供，不是整个世界或连续独立对局。原生竞态、Wasm、源码／夹具摘要及明确边界见 [world-sprites-validation.json](../../../games/yuyuhakusho/data/world-sprites-validation.json)。

## 复跑与预览

```sh
mkdir -p .local/md-yuyuhakusho/tmp
PYTHONDONTWRITEBYTECODE=1 python3 scripts/yuyuhakusho/extract_world_sprites.py \
  --out .local/md-yuyuhakusho/world-sprites-replay
GOCACHE="$PWD/.local/go-cache" GOMODCACHE="$PWD/.local/go-mod" \
GOTMPDIR="$PWD/.local/md-yuyuhakusho/tmp" \
go test -race -count=1 -json ./games/yuyuhakusho/presentation
GOOS=js GOARCH=wasm GOCACHE="$PWD/.local/go-cache" GOMODCACHE="$PWD/.local/go-mod" \
GOTMPDIR="$PWD/.local/md-yuyuhakusho/tmp" \
go test -count=1 -json -exec "$(go env GOROOT)/lib/wasm/go_js_wasm_exec" \
  ./games/yuyuhakusho/presentation
```

独立透明精灵预览在 `.local/md-yuyuhakusho/world-presentation-preview/2181-independent-sprites.png`，原视频为 `2182-original.png`，已人工查看。透明预览包含会被原背景高层遮挡的低优先级精灵，不能将它当作最终合成画面。本轮未接入浏览器页面、全场地、全姿态像素或完整世界循环。
