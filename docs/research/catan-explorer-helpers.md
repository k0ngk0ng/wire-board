## 依据与适配边界

[官方 Helpers 规则](https://www.catan.com/sites/default/files/2023-02/Helpers_Rules.pdf)第 1 页写明适用于基础、航海家及其五六人扩充；规则文件的大小和 SHA-256 已记录在 `board-expansion-rule-sources.json`。本次重新核对规则正文和[官方产品页](https://www.catan.com/helpers)、产品页实际链接的 [Helpers FAQ](https://www.catan.com/faq/helpers-catan)、[探索者产品页](https://www.catan.com/explorers-pirates)。没有找到探索者的专门适配条款；FAQ 主要讨论旧版助手的时机和翻换。最初猜测的 `/faq/helpers` 返回 404，未作为依据。Google 查询 `Catan Helpers Explorers Pirates combination Diara Gregor` 没有返回可用的补充规则正文。

不把缺少适配说明说成官方禁止。按用户授权，对探索者缺少的发展卡、强盗和已打出骑士卡制定明确的本站规则，保存版本为 `wire-board-explorer-helpers-v1`。原基础与航海家助手规则不变；关闭 Helpers 时，不添加该组件。

| 格雷戈尔 | **本站替代能力**：归还港口内或停靠己方港口船上的一名人员，木砖各 1 建村，或粮食 1、矿石 2 升级港口／城市。初航没有船员，使用移民；其他任务使用船员。不能撤回巢穴、农场或远海船上的人员。 |

助手池仍按人数使用前 N 名起始助手与随机 N 名展示助手，或启用全部 12 名。按随机先手的相对座位分配起始助手，开局放置完成后才可使用。太阳面使用后可翻月面或交换，月面使用后必须交换；新获得及本回合已用助手不能立即再用。五六人的两个配对行动段分别沿用已有回合序号，第二位不重新生产或触发生产助手。双人使用探索者原生轮序，不引入普通双人贸易筹码。

## 控制器与保存

- 新组件保存在探索者聚合内；严格核对版本、助手总数、唯一归属、使用回合和回应类型。低层开局、海盗、香料事务保留只读组合元数据，不能在复制时遗失 Helpers 标记。
- 七点计算先排除可用的托罗夫持有者，再完成助手回应，之后恢复其他人的弃牌及海盗流程。非七点按鱼筹码替换→希尔达→引水渠→建设接续，原生产所得单独保存，不被助手奖励覆盖。
- 助手回应不改主回合归属；通过 `CatanPendingActor` 指定真正回应者。非法玩家、过期回合、错误费用、重复使用和未启用的助手操作原子拒绝。
- 建设费用由持有助手的控制器决定，不能由客户端传入免费标记。道路、船和建筑仍使用原合法位置与库存检查；不临时注入资源绕过支付。
- 探索者使用独立视图：规则版本、当前助手、可用状态和行动参数显式输出。瑞安的普通资源只发给使用者；观战者和其他玩家得不到查看结果，商品保持隐藏。
- 离场归还助手到展示区，其他玩家继续。Helpers 不开启时，保留原探索者开局、费用、生产、胜利与保存行为。

## 验证证据

- **90 种配置**：五剧本，普通二至六人／骑士三至六人，随机展示／全部助手各一组；全部叠加事件生产牌，全部助手组还叠加有湖渔夫。完成起始放置及四段自然回合，每次操作保存恢复。
- **4 场自然完整引擎局，62.499 秒通过**：双人初航；五人巢穴＋渔夫＋事件；三人初航骑士＋渔夫＋事件；六人完整三任务＋骑士＋渔夫。没有注入资源或分数缩短这些完整局。
- 90 种配置、主动能力、七点／生产回应、瑞安隐私、离场及损坏保存检查，定向 race **287.133 秒通过**。主动能力同时检查公开操作数据编码后仍可正确提交。普通与骑士的七点大小手牌、资源与商品合计、希尔达接受／放弃及引水渠后续均验证。
- 10 种主动助手的电脑决策在交换隐藏地图、巢穴数字、对手资源组成后保持一致，且不修改实时状态；定向 race **8.066 秒通过**。
- 没有原木时实际用替代资源修路／造船、拒绝零费用，以及船员回收与城市优惠，定向 race **2.935 秒通过**。
- 原 Helpers、探索者付费建设／药剂、原初航、开局、海盗与香料相关定向回归 **1.210 秒通过**；既有公开配置、原 Helpers 联机流程与基础隔离回归 **159.097 秒通过**。这些服务器回归不是新增探索者 Helpers 的 HTTP 验收。
- game/server 静态检查、Go 构建及差异检查通过。本阶段没有前端改动、浏览器操作或音频播放，未声称完成 UI、图片或真人整局验收。

## 公开入口与界面验收

- 建房、等待房、重开使用统一的探索者 Helpers 选项，随机备用池或全部助手均可选择。初航和四个任务剧本之间保留设置；按实际入座人数分配助手。探索者五六人仍由实际人数决定，不混入基础版 `fiveSix` 标记。切回普通双人清除探索者助手配置；未开放的其他组合仍拒绝。
- 新游戏在加入事件牌前初始化助手；战绩记录 `explorer_helpers` 版本及实际 Helpers 选项。已开局时不能变更设置，观战者不能操作。
- 专用助手面板展示探索者能力。英格维／迪亚拉在地图选建设位置，再选具体支付；格雷戈尔显示要归还的人员及所在港口／船，霍格尼先选原道路再选新位置。确认记录包含助手标记、资源、人员和具体船只，不能与普通建设或过期选择混同。
- 阿斯拉保留可选第二位对手，斯蒂娜可一次换取多种、多张资源。瑞安的普通资源只展示给使用者；其余替代能力和助手翻换使用服务器提供的有效选项。回应浮层可收起看地图；手机助手区横跨整行。
- 助手回应暂停建设预算。同一玩家从领奖到翻换共享一个回应窗口；进入其他玩家或下一种强制回应时按既有规则开始回应计时，完整结束后恢复原预算。超时自动托管持续有效，保存重启不重置。

本阶段验证：

1. 公开配置及生产回应定向 race **7.875 秒通过**；二／三／六席、五剧本切换、渔夫和骑士开关、房主权限、同值设置、就绪重置、实际两人开局、重开与关闭 Helpers 均覆盖。
2. 希尔达领取→翻换→引水渠的 HTTP 验证覆盖非主回合玩家回应、非法玩家、同窗计时、保存重启、请求重放及持续超时托管。另有托罗夫七点免弃→其他人弃牌→建设的定向 race **4.071 秒通过**，原建设预算均保留。
3. **3 场自然完整 HTTP 对局，33.14 秒通过**：双人初航＋事件；五人巢穴＋渔夫＋湖泊＋事件；三人完整任务＋骑士＋渔夫＋湖泊。分别经历 25／45／59 次助手回应，全部自然结束、恢复及战绩记录通过，没有注入资源或分数缩短这些整局。
4. 既有探索者公开配置定向回归 **3.805 秒通过**；原 Helpers 联机、基础隔离和新增跨剧本切换回归 **1.691 秒通过**。前端 **189 项测试通过**，包括支付／人员选择身份、私有回应与过期选择；前端构建、Go 构建、game/server 静态检查及差异检查通过。
5. 浏览器实际验收桌面 1440×1000、手机 390×844／320×740。通过 UI 完成助手替代支付造船、两步道路迁移、人员优惠建村、多笔二比一、翻面及浮层收起；人员实际返回供应、游戏恢复建设。手机创建六席完整任务＋Helpers＋渔夫／湖泊＋骑士＋事件成功，等待房可切换 Helpers／渔夫／事件。320／390 视口无页面横向溢出，已显示的助手图片从既有 CDN 解码成功，无页面脚本错误。

浏览器能力场景使用明确的本地中局夹具，只用于验证操作和布局；不算自然整局。首次配置测试误用了不存在的命令名，修正为真实命令后通过。页面首次检查发现造船文案误把默认卡号当作归还人员，以及手机助手区占半栏，均修复后复验。图片使用既有素材，没有播放互联网音频；专用浏览器以静音参数启动并关闭站内音效。

F05 完成后仍剩 F06–F12 七组，范围不变。宝石与铁路的剩余整体验收按总台账执行；本阶段未推送或部署。临时测试服务器、浏览器、截图、日志、专用配置和构建产物已清理，保留共享研究目录。
