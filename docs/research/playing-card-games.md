# 升级、掼蛋、斗地主：玩法、分类与素材调研

调研日期：2026-10-13。本文记录已确认的产品决定、核实过的来源和建议规则；用于后续实施评审。

## 已确认的决定

- 新增三款独立游戏：**升级、掼蛋、斗地主**。
- **升级采用上海规则**，可选一副牌（40 分）或两副牌（80 分），**默认两副牌**。40／80 指抓分方的上台门槛，不是这副牌的总分。
- **掼蛋采用江苏规则**；本次已核验的规则文本为《江苏省掼蛋竞赛简易规则（2017版）》。
- **斗地主首版同时支持三人经典版和四人上海版**。四人版是一个地主对三个农民，不是对家搭档。地区与人数模式分别保存，不能只增加一个席位而沿用三人判定。
- 参与者的手牌始终位于自己屏幕下方，不能按房主或服务端第 0 席固定视角。
- **默认牌面采用传统英式方向**。本次对比中的 Byron Knoll 牌组为默认候选；其余风格作为可切换皮肤。
- 游戏仍在同一仓库独立维护，新增游戏默认下架，由后台决定上架。

## 大厅建议增加分类

建议这次一起加。仓库目前有 8 个游戏模块，新加三款后为 11 个；大厅已有名称搜索、分批展示和按游戏筛选房间的下拉框，但 `GameModule` 没有分类字段。

建议先使用一个主分类，加少量补充标签：

| 主分类 | 游戏 | 补充标签示例 |
| --- | --- | --- |
| 扑克牌 | 升级、掼蛋、斗地主 | 搭档、吃墩、跑牌 |
| 策略桌游 | 璀璨宝石、铁路环游、卡坦岛、卡卡颂、强手棋 | 经营、拼图、地图 |
| 卡牌对战 | 三国杀、兵线争锋 | 身份、阵营、同时规划 |
| 即时策略 | 星垒 | 合作、塔防 |

兵线争锋目前是同时暗选行动牌的回合制游戏，不因题材接近 MOBA 就归入即时游戏。人数另有独立字段，不混作分类。主分类用于找游戏，标签描述合作方式等交叉属性。

界面使用**带标签的分类下拉框**，与名称搜索组合，不新增一排不断增长的游戏 tab。大厅目录、创建弹窗和后台复用同一份分类元数据；房间列表继续保留具体游戏下拉框。切换分类时清除不属于该分类的具体游戏选择，重置分批展示数量，提供无匹配结果提示。

分类只过滤已经允许当前用户查看的游戏，不能绕过上架设置。前期可由各游戏 `web/module.tsx` 提供静态 `category`／`tags`，使用现有 `availableGames` 控制可见性，不必先新增分类数据库。创建弹窗仍用统一封面卡片和现有房间字段。

## 升级

### 可以确定的骨架

已确认采用上海规则。资料 [R1]、[R2] 分别描述双副拖拉机和单副四十分；[R2] 另外明确链接到上海版的专门资料 [R7]。这些资料用于确定预设，不把任意一份通用说明直接冠名为全上海唯一规则。

四人固定搭档。5 为 5 分，10、K 各为 10 分，因此单副共有 100 分，双副共有 200 分。抓分方达到 40／80 分后上台；底牌加倍可能使最终抓分高于原牌堆总分。

流程为：洗牌／抓牌 → 亮主、反主窗口 → 庄家取底和扣底 → 庄家首引 → 逐墩跟牌 → 抠底及分数结算 → 更新庄家、双方级数 → 下一副或整局结束。

主花色和级牌要同时显示。例如打 7、梅花主，所有 7 和大小王属于主牌；非主花色的 7 不能再作为原花色跟牌。副级牌之间的同强度、先出优先，以及相同牌型的先后顺序需明确处理。

单副牌没有重复的同花同点实体牌，因此不能照搬双副的对子和拖拉机。[R7] 的上海历史玩法还记录了“四同点数领出”和无分牌申请重发；是否纳入线上上海预设要明确，不能因它与其它地区玩法相似就直接排除，也不能把它当斗地主炸弹处理。

### 上海规则的计分参考

用户明确采用上海规则后，撤回上一版“单副统一每 20 分一档”的建议。单副与双副分别定义，不把双副计分简单折半。

| 40–75 | 抓分方上台，本方级数不变 |
| 80–95 | 抓分方上台，本方升 1 级 |
| 100 及以上 | 抓分方上台，本方升 2 级 |

## 掼蛋

### 规则来源与建议基线

地区已确认采用江苏规则，以已读到原文的 **《江苏省掼蛋竞赛简易规则（2017 版）》**作为本方案的规则基线 [R3]。原省体育局下载域名本次无法解析，已通过 Internet Archive 取得原始 Word 文件并核对标题、正文与文件校验和。它是明确的 2017 版本，不将其称为当前最新全国规则。

原文明确：

- 两副 108 张，四人对家搭档，每人 27 张，从 2 开始。
- 红心级牌是逢人配，可与普通花色牌组成牌型，不能代替大小王。
- 常规牌型：单张、对子、三同张、三带二、恰好五张顺子、恰好三连对、恰好二连三（钢板）。不要把斗地主的任意长度顺子、三带一或飞机带翅膀搬进来。
- 炸弹按张数优先、同张数按点数比较；同花顺压五张及以下炸弹，六张及以上炸弹压同花顺；四大天王最大。
- 上游与同伴二游升 3 级，三游升 2 级，末游升 1 级。
- A 必打，且同伴获得二游或三游才能过 A。
- 从第二副开始进贡、还贡；贡最大牌但排除红心级牌，回贡牌点不得超过 10；双下的两份贡牌按大小分配，同大按顺时针约定分配。应贡方持有两张大王时抗贡。
- 最后出牌者已走完，且对手都不接时，由对家接风。有人走完后跳过空手席位，不能继续等他操作。

### 需要明确的变化与边界

[R4] 的一个版本把双上升 4 级，并将“还 10 以下”列为变体；它不能与 [R3] 的 3／2／1 和回贡规定混用。本项目首版建议采用 [R3]。

其它差异包括：过 A 要求双上还是允许头三；冲 A 三次失败是否退回 2／K；是否启用不洗牌；同贡先手如何确定；报剩余牌数从 10 张还是 6 张开始。首版建议洗牌、3／2／1、头二或头三过 A，不启用连续失败退级，后者明确标为平台选择。

连续结构按自然牌点判断，A 可在合法结构两端作低或高，但不能穿过边界循环；级牌不打断自然顺序。百搭可能使同一组选牌存在多种合法解释，应让玩家选择“按连对出”或“按钢板出”等含义，服务端校验指定解释，不暗中换成另一个牌型。

落实前还需补齐：还贡时没有满足条件的牌怎么办、级牌在还贡限制中的计算方式、回贡可见范围、已有两位同队玩家走完时如何确定剩余顺位。[R3] 回贡面朝下，默认应仅让交接双方知道其牌面，贡牌则按规则公开。无合法回贡候选时必须有公开的回退条款，不能让对局卡死。

## 斗地主

首版同时支持 **三人经典（54 张）**和 **四人上海（108 张）**。大厅仍是一张“斗地主”游戏卡片，创建时选择人数／规则模式，两者联动校验。模式切换后清除准备状态；房间已坐满四人时不得无提示切成三人并移除玩家。

### 三人经典

三人版采用一副牌的经典叫分方案。可参考 [R5] 的通行玩法及题署“国家体育总局棋牌运动管理中心，2016 年 2 月”的《竞技二打一扑克竞赛规则》原文镜像 [R6]。借鉴其牌型与叫分规则，不把休闲房间宣传为已完整实现其复式竞赛制度。

每人 17 张，底牌 3 张。按顺序叫 1／2／3 分或不叫，叫 3 分可结束叫牌，最高叫分者成为地主并取得底牌；首版建议底牌公开。无人叫分重新发牌，不能偷偷指定一个不愿叫的玩家为地主。

地主先出。同型同张数才能正常压制，炸弹与火箭例外。连续两家不出后，最后出牌者重新领出；先前过牌不妨碍后续轮到时再跟。地主先出完则地主赢，任一农民先出完则两位农民共同获胜。

首版牌型包括单张、对子、三张、三带一、三带对、顺子、连对、飞机及带翅膀、四带二、炸弹和火箭。顺子至少五张，连对至少三对，飞机至少两组；2 和大小王不能进入连续主体。A2345 不按掼蛋的低顺子规则处理。

[R6] 明确给出 `333444 + 55` 作为飞机带单例子，因此“两个翅膀恰好成一对”不能一概判错；但它对双王、炸弹和与飞机连续的三张等带牌有限制。四带二两张单牌能否为一对、同点四张能否充当两对、带双王的限制，必须在选定预设中逐项固定。[R5] 的部分约定与常见线上版本不同，不应仅凭“经典”二字省略这些条款。

三人版地区／产品差异还包括：叫分与抢地主、是否加倍／再加倍、明牌、癞子和炸弹倍数上限。首版建议不含癞子和明牌，保留炸弹、王炸、春天／反春；加倍功能可作为房间选项。开启每位农民分别加倍时，按双方分别算分，不能用一个全局倍数代替所有人的倍数。

计分建议使用牌局积分：未启用个人加倍时，两位农民各 ±S，地主 ∓2S，所有人得分和为 0；S 由底分、叫分和已启用倍数规则计算。每副及时结算，整场可按创建时约定的副数累计积分排名。

### 四人上海

基本结构由 [R5] 的上海／江浙四人版记载与运营方 [R8] 交叉核对：两副含王 108 张，每人先发 25 张，8 张底牌归地主，地主共 33 张；一个地主对三个农民，任一农民出完即三位农民共同胜利。建议底牌公开。

四人模式需要独立牌型和结算参数，不能直接把三人规则的座位数改成 4：

| 项目 | 四人规则依据／方案 |
| --- | --- |
| 三带牌 | 三带对子；[R5]、[R8] 均不支持三带一 |
| 飞机带牌 | 可不带，或带相同组数的对子；不带单翅膀 |
| 四带二 | [R5] 明确不支持；[R8] 的可用牌型表也未列出 |
| 对王 | 两张大王或两张小王可组成对子；大小王混合不能作为普通对子 |
| 多张炸弹 | 4–8 张同点数；先比张数，再比点数，不能按三人版统一当四张炸弹 |
| 四王与八张炸弹 | **用户已确认：四王为王炸，最大，可压八张炸弹**。采用 [R5] 这一约定，不采用 [R8] 的八炸压四王例外 |
| 单顺 | [R5] 的四人差异列表未禁用三人单顺，[R8] 的牌型表却没有列单顺；必须核准上海预设是否允许，不按沉默推断 |
| 炸弹计分 | [R5] 四／五张炸弹不翻倍，六张及以上每次翻倍，四王也翻倍；[R8] 未给出同样的炸弹倍率细表。牌型强弱和计分倍率分别保存，不能从牌型名推算倍率 |
| 全不叫 | 重发；[R8] 连续三次无人叫分解散游戏，这属于运营方规定，不能自动当成上海全部玩法；本平台需明确上限后的处理 |
| 过牌 | 连续三家不出才重新领出，不能沿用三人版的两次不出 |
| 基础计分 | 未启用个人加倍时，三位农民各 ±S，地主 ∓3S；总分仍为 0 |
| 春天与加倍 | 地主赢且三位农民均未出牌才计春天；反春、个人加倍及倍率上限须在上海规则集里单独固定 |

[R8] 是游戏茶苑的四人斗地主说明，本身没有将其标为全上海统一规则；其冲突内容用于提出需要确认的细则，不替代用户指定的上海方向。三人版、四人上海版各自保存规则版本，并给出开局摘要。四人模式的 `winners` 必须正确返回三位农民，机器人协作与统计也要按三个农民处理。

## 统一牌桌与视角

四人牌桌以本家为底部、对面玩家为顶部，上家在左、下家在右；三人牌桌自己在下方，其余两位在左右。升级和掼蛋的对面玩家是搭档，四人斗地主的阵营按地主／农民身份判定，对面玩家不一定是队友。只转换显示坐标，不改变服务端席位编号、搭档关系和出牌顺序。换座、重连、任何一席开局都要得到同样的本家视角。

```text
                 对面玩家（四人局）
                   出牌区

  上家／对手       本圈牌面       下家／对手

          状态、倒计时、选牌解释与操作
                我的手牌
```

- 自己的牌明示，其他人只展示牌背和剩余数量；搭档也不例外。隐藏信息从服务端就不下发，不靠 CSS 遮住。
- 观战默认只看公开牌面；切换观察方位不应获得那位玩家的私有手牌。
- 手牌、出牌、不出、提示、取消选择置于同一操作区。按钮不遮住手牌角标，也不与手机底部安全区域冲突。
- 升级取底时可有 18／33 张，掼蛋正常 27 张、贡还中可能临时更多，斗地主地主在三人版为 20 张，四人上海版为 33 张。分别验证，不能只用 5 张样例牌验收。
- 手机采用分排、分组或展开查看，优先保证数字和花色可读，不能把 27／33 张硬缩到单行。滑动选牌和页面滚动要区分，松手选中后再点“出牌”，不因误拖直接打出。
- 升级常显主花色、级牌、庄家和抓分；掼蛋常显级牌、配牌、搭档顺位；斗地主常显地主身份、叫分、倍数及剩牌数。
- 公共玩家栏、创建弹窗、等待房间继续沿用平台框架，游戏 CSS 不隐藏公共信息。牌桌内部可复用一个只处理相对座位和摆放的轻量 UI。
- 收牌、发牌、出牌、吃墩、进贡及炸弹等反馈由服务端事件驱动；命中点击区与实际牌面一致，刷新不重播历史动作。

### 换肤设计

提供“牌面主题”和“牌背”选择，先落实传统英式默认，其他候选经质量修整后再开放。每位用户可选择自己看到的皮肤，不要求整桌统一；偏好在三款扑克牌游戏间共用。

皮肤只改变 `cardKey → 图片资源` 映射，不改变牌 ID、花色、点数、出牌顺序和服务端判定。两副牌中的两张相同牌仍有不同实体 ID。主牌、级牌、逢人配标记由游戏状态叠加，不绘死在素材中。切换前预加载必要资源，失败时保留当前可用主题；不因换肤清空选牌或重播动画。

### OSS 发布

素材按独立主题版本发布，例如 `poker/skins/english/v1/`、`poker/skins/large-index/v1/`、`poker/audio/paper/v1/`，挂到现有 `assetsBase` 下。不要覆盖已发布路径。

每包保存：作者、原始页面和下载地址、版本或提交、适用许可证、原文件及成品 SHA-256、修改说明、完整的 54 张映射、牌背列表、尺寸和 MIME。LGPL 素材同时提供许可与相应可编辑源文件。SVG 先检查外部引用、脚本和字体依赖；可固定字体与尺寸导出高清 WebP／PNG，OGG 按平台兼容要求转换成适合原生媒体播放的格式。

上传后回读 OSS/CDN，核对字节、MIME、解码与缓存；默认主题加载失败有本地基础牌面回退。三款游戏的首页封面仍各自绘制手绘式 SVG，沿用现有规范，不直接拿商业游戏截图或素材包宣传图作封面。

## 代码边界与实施顺序

建议目录为 `games/shengji/`、`games/guandan/`、`games/doudizhu/`，各自包含规则、配置、机器人、存档、视图、UI 和验收。互相不导入业务实现。

允许共享的内容只保留：普通扑克牌展示、选牌手势、相对座位布局、皮肤清单与偏好，以及现有平台音效服务。**不要抽象一个同时决定三款游戏牌型的通用规则引擎**。升级对子要求同花同点，掼蛋有级牌和百搭，斗地主顺子又不能含 2，耦合会妨碍并行维护。

先固定分类元数据、牌面资源契约与私有视图；用斗地主先完成三人经典与四人上海两种模式的开房到结算闭环，验证公共牌桌和人数切换。随后升级和掼蛋可按各自目录独立推进。规则配置在开局时规范化并保存规则版本，对局途中和部署升级时不得静默改变。

## 实现前的验收清单

1. 同一真实牌局从全部 3／4 席登录，自己均在下方，身份、搭档、出牌顺序和公开区域正确；观战切换方位不泄露手牌。
2. 单副 54、双副 108 张实体牌守恒；升级取底／扣底、掼蛋贡还、地主拿底后无重复、丢牌或错误跨副 ID。
3. 升级覆盖单副／双副所有计分边界、零分、超总分抠底、主副级牌、同强度先出、缺门、强制结构跟牌、合法甩与失败甩、换庄和过 A。
4. 掼蛋覆盖多种百搭解释、不能代王、5／6 张炸弹与同花顺关系、双贡同点、合持两大王抗贡、隐私回贡、无候选回贡、接风、头末不算过 A。
5. 斗地主覆盖三人／四人人数规则联动、54／108 张守恒、20／33 张地主手牌、全不叫重发、叫满分结束、两次／三次不出重开；四人禁用三带一、单翅膀和四带二的规则检查；同色王对、四王／八炸的选定关系、不同炸弹倍率、春天／反春、个人加倍计分及任一农民胜两人／三人全队。
6. 每款完整真实对局和真人＋机器人流程可完成。机器人只使用其合法视图，不能因在服务端运行就偷看对手牌。
7. 手机 320／390px、PC，多张选牌、33 张取底手牌、皮肤切换、失败回退、不同主题的 54 张对应、大小王和实际点击范围；保留截图与源码校验和。
8. 发牌、出牌、贡牌、吃墩的事件顺序，断线重连不重播，音效静音不漏播，动画不提前改变服务端结果。
9. 分类与搜索叠加、很多游戏、长名称、空结果、下架游戏不可创建；三款新增游戏发布后仍默认下架。
