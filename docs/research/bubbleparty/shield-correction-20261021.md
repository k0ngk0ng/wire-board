# 护盾道具纠正

用户指出地上“盾”没有图片。当前 renderer 只映射速度、水泡容量和射程，shield 落入文字回退；服务器将 shield 随机加入木箱掉落池并永久保留到抵挡一次，这是此前实现加入的简化，不是已核验的原版基本道具。

来源：已保存的官方道具资料，文章 122326，名称「盾牌」，描述「可在2秒钟之内抵挡敌人的水柱，对战游戏中一局可使用2个」。见 reference-findings.md。不能用该资料证明当前随机掉落、被动一次性盾是原版行为。

实现前失败清单：经典规则的新掉落仍出现自定义 shield；误删已保存地上道具／玩家持有盾；旧规则 0 掉落或抵挡机制被改变；基础三种道具掉落缺失；图片加载失败后基本道具不可辨认；为了补图继续将不符原版规则的道具当作基础玩法宣传。

改动范围：经典规则后续木箱掉落仅包含速度、水泡容量、射程；保留已保存 shield 的拾取／抵挡与旧规则 0 行为，避免改变进行中存档的既有资源。遗留盾用明确的盾形绘制回退，不再显示一个“盾”字。不会新增未经运行核验的主动道具系统。
