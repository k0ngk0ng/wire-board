# 坦克方向素材复核

实现前失败场景清单：

- 横向图被错误镜像，炮管朝向与输入方向相反；上下方向也可能误用镜像。
- 车型基址跨入相邻车型，或把向下帧当向上帧。
- 履带两帧错位，8×16 OAM 左右半片交换、裁切或 CHR bank 错误。
- 上下两队的三色映射、透明像素与轮廓不一致。
- 前端采用顺时针方向序号，而原 ROM 是上、左、下、右，误直接复用序号。
- 图集修正后 URL 沿用 v1，被 CDN 缓存旧内容；或覆盖已发布不可变对象。
- CDN 失败后本地回退仍加载旧图；音频被无关版本切换破坏。

先保留原 ROM 原生渲染的 OAM/CHR 取样并写逐像素验收，再修改生成器。覆盖五车型、四方向、两履带帧和双方颜色。前端检查帧名、源矩形、绘制位置和矢量回退方向。原 ROM 与商业媒体仅保存在 `.local`／已有忽略的本地回退目录。
