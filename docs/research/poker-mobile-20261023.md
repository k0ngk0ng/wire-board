# 扑克牌桌手机布局与炸弹策略修正

## 需求与范围

按用户截图修正斗地主、掼蛋、升级的手机界面。以实际浏览器可视高度为边界，手牌与主要按钮固定在视窗下部，紧凑倒计时放在桌面右上角。PC 保留既有框架。平台、房间、玩家详情折叠后仍可打开，聊天移到顶部，避免覆盖出牌按钮。提示排序按用户最新要求不修改。

公开出牌根据宽高叠放换行，不使用内部横向滚动条，长牌组可点击放大。全局布局保持稳定，出牌动画在手机上仅淡入，避免移动到邻接手牌区域。规则已补入 `AGENTS.md`。

斗地主和掼蛋电脑不再因存在合法炸弹就必须跟牌：中盘无明确目标时可以让过；直接出完、阻止公开剩余一两张的对手、或炸后有一手短组合可收尾时才使用炸弹。必须炸时，选择足够压住的较小完整炸弹；先手仅剩炸弹时也不会因为保护分数而把完整炸弹拆成单张。这些是局面启发式，不保证必胜，不读取对手私牌。

## 失败场景与验证

实现前覆盖：出牌区裁切或横向溢出；出牌和不出导致界面跳动；视窗底部按钮出屏；长牌组无法打开；折叠后静音/房间/玩家操作不可达；中盘连炸、高点单牌消耗炸弹、错过必要拦截、用大炸代替足够的小炸、先手拆掉完整炸弹。对应单元场景先失败再修复，复杂界面与协议由真实浏览器/HTTP 验收。

- 三款扑克及升级两种副数：37 个浏览器检查点，32 份手机几何记录，覆盖 320×568、320×640、390×720 和 PC 1280×960。牌桌、操作区与倒计时均在视窗内，页面无额外纵向溢出。
- 102 次逐帧状态切换和 18 项鼠标/触屏/角标验证通过；各席位最长牌组全部保留，无内部滚动，点击可放大。
- 斗地主、掼蛋规则与竞态检查，以及独立的完整对局/真实 HTTP 验收通过。
- 完整掼蛋对局结束时阻断新增 JS/CSS，结算显示、关闭、重新查看和再开一局通过。

## 复验

在仓库根目录加载 `scripts/env.sh` 后，依次运行：

```sh
python3 -B scripts/poker/check-layout.py
python3 -B scripts/accept_poker.py
python3 -B scripts/game-loading/check-results.py
go test -race ./games/doudizhu/server ./games/guandan/server
go test ./games/doudizhu/tests ./games/guandan/tests
```

浏览器使用 Chromium 原生鼠标/触摸输入。可视区域模拟不等同于在用户真机 Safari 上执行；小屏极长牌组会缩小，需要更大牌面时点击放大。
