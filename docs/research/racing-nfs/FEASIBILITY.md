# 老极品飞车参考复刻可行性

本文保留初期可行性分析的时点结论。后续已完成五车、四条赛道及昼夜资源转换，实际内容与限制见 [游戏说明](../../../games/racing/README.md)、[资源核验](../../../games/racing/assets/source/nfs4/verification.json) 和 [后端验收](BACKEND-VALIDATION.md)。原版实机画面及原版物理测量仍未取得。


2026-11-11 调研。范围是几款经典车辆、接近原版的赛道和操控手感；赛道数量根据转换效果与最终资源体积决定。本轮只做调研，没有修改游戏实现。

结论：可行。建议使用 Three.js 呈现真正的三维车模、起伏道路和追车镜头，优先以 PC 版《极品飞车 4：孤注一掷》作为操控研究对象；三代可作为备选。保留平台的联机、房间和比赛框架，更新驾驶核心、赛道几何与表现。不能把换车模或调几个速度参数视为完成复刻。

当前实现中可以解释异常手感的原因：

- [physics.go](../../../games/racing/server/physics.go) 第 32～63 行直接用输入修改车头角度，用指数阻尼控制侧滑和刹车，没有车型质量、轴距、轮胎力和偏航惯量。满刹车的速度半衰期约为 0.116 秒，这是公式推导，不是实机测量。
- 同文件第 48～67 行在车辆中心出路时，将速度上限由 900 直接截到 110。按现有 HUD 换算，对应约 324 km/h 与 39.6 km/h；实际触发降幅取决于当时车速。
- [README.md](../../../games/racing/README.md) 明确说明六款车性能和碰撞尺寸相同，挡位由速度派生。车型目前主要是外观选择。
- [state.go](../../../games/racing/server/state.go) 的赛道是二维中心线和全局路宽；[chase-renderer.ts](../../../games/racing/web/chase-renderer.ts) 将车放在固定高度，只显示偏航；[chase-camera.ts](../../../games/racing/web/chase-camera.ts) 将镜头位置直接绑定车头。道路起伏、车身姿态和镜头惯性均需补齐。

上述是源码观察及其推论，本轮未启动现有页面进行主观驾驶对照。

技术方案：Three.js 负责渲染；车辆、路面、桥梁和隧道使用真实三维几何。驾驶使用独立的固定步长运动模型，处理前后轴抓地、转向建立与回正、制动力、传动和滑移，镜头与车身姿态提供连续反馈。是否采用完整刚体引擎，需结合原版算法、碰撞要求和预测成本再决定，当前不预先绑定 Bullet、Rapier 或其他引擎。

联机继续本地立即响应、服务器权威校正。当前服务端与客户端分别有一份运动计算；更新时必须保证一致，或采用可共享的运动核心，避免客户端看似正常而被服务器持续拉回。只将 Three.js 或物理库接入浏览器不足以解决这项要求。

资源按车型与赛道拆包，公共材质、声音与环境对象去重，加入房间只加载所选资源。候选赛道先检查道路、场景、碰撞和路线完整度，再测量压缩后的传输体积、解码内存、GPU 占用和实机帧率。路线与环境足够接近、体积合理时继续增加赛道；不能只凭磁盘大小或复用同一路线换贴图决定数量。原版夜间、天气文件是否能共享几何，需要逐项检查。

建议先用试玩中的车辆资源与 France 赛道跑通导出和驾驶对照，再决定最终车型及扩展赛道。试玩文件名目前只确认两套车辆资源，多款主流车型和更多赛道仍需要相应参考资源。网页最终资源可使用转换后的授权素材或据此重建的自制素材；取得试玩不代表取得公开再分发原模型、纹理和声音的许可。

开始实现前应先固定对照条件并编写可重复执行的验证流程：

1. 记录参考版本、车型、自动挡、驾驶辅助、路面和输入方式，分别测量直线加速、松油滑行、制动距离、定速转弯、转向回正、手刹与失控恢复。保存输入序列、采样数据和录像。
2. 先完成一辆车与一条赛道，验证道路高程、墙体、路肩、检查点和相机；将原版曲线与网页曲线放在相同单位下比较，不能用完成比赛替代手感验收。
3. 扩展不同车型、电脑完整比赛、真人与电脑混合、托管接管和恢复；覆盖键盘、手柄和触屏。
4. 按项目实时规范验证事件到首次可见响应、正常网络、快慢连接并存及重连，保留浏览器录像、性能记录和可重复执行的 E2E 结果。
5. 报告首屏、单车型、单赛道与全部资源的实际压缩体积，并分别检查运行内存与 GPU 性能，再确定新增赛道数量。

初步可行性调研未执行原版安装程序或游戏测试。随后按要求解包并尝试运行试玩，具体进展、实际体积和当前限制见 [运行记录](RUNTIME.md)。初步调研已删除失败的三代下载残片；既有未提交文件未改动。
