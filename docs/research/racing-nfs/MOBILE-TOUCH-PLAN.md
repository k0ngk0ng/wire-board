# 手机双拇指操作

用户明确要求移除方向盘。本轮参考 GRID Autosport 官方移动版说明中的 Arrow Touch Pro：左右箭头同放左侧，右侧保留手动油门。Asphalt 8 官方说明也提供独立的操作方案自定义入口。参考依据是官方文档，未声称已实机试玩这些游戏。

- GRID 官方说明：https://www.feralinteractive.com/en/support/ios/gridautosport/#faqs/ios_control_methods
- Asphalt 8 官方说明：https://gameloft.helpshift.com/hc/en/24-asphalt-8/faq/1828-how-do-i-customize-controls-i-want-to-choose-my-own-control-scheme/

当前 88px 轮盘按横向绝对坐标计算转向，约 2.6px 为中立区半宽，10px 的落点偏差就产生约 27% 转向量。新布局采用左下两个独立方向键、右下刹车和油门，手刹作为次要小按钮置于右下边缘。初次触摸以按钮语义决定方向，不依赖拇指落点；转向继续复用现有速度限制和转向建立／回正模型。

## 实现前失败清单与验收

1. 方向盘仍存在；方向键／踏板小于 56×64px；主操作相互覆盖，或离开画布与可见视口。
2. 按键边缘落点改变方向，手指跨左右键仍保持旧方向，滑出／取消／失焦后方向滞留。
3. 左右同时按下不能归零，释放一个来源会清除另一个来源，键盘或手柄输入被触屏覆盖。
4. 转向与油门无法由两个手指同时操作，刹车优先失效，手刹和辅助按钮覆盖主控件。
5. 按住后失焦，恢复焦点的 repeat 重新施加旧输入。
6. 320px 竖屏、横屏和公共全屏布局裁切，旋转后旧触摸继续生效，桌面出现触控面板。
7. 只证明 ACK 或 DOM 状态，未验证实际车辆变化；原生触摸到车辆像素响应沿用 P95≤80ms，正常及 150ms TCP 延迟分别测量。

先运行真实认证房间 E2E 形成失败证据，再修改产品。保留原生触摸、权威输入、像素和布局截图；浏览器仿真不等同于实体手机的人体工学实测。
