# 极品飞车网页版交付记录

本轮在平台现有 `racing` 游戏中实现独立的 Three.js／WebGL 2 驾驶场景，保留统一房间、玩家栏、控制器设置、托管和全屏入口。

## 内容与体积

提供 Porsche 911 Turbo、Ferrari 550 Maranello、Lamborghini Diablo SV、McLaren F1 GTR、Chevrolet Corvette 五款车型，以及 France、Coastal、UK、Park 四条独立路线。每条路线支持白天、夜间；每辆车包含原始外观和驾驶舱。

v3 清单包含 65 个文件，合计 54,631,266 字节（52.1 MiB），未计清单自身和赛车程序。按当前赛道、时段及本场车型加载，避免首场下载全部资源；GLB 使用无损 gzip 传输。该总量不等于单场网络传输量，实际 CDN 回读记录随发布保存。

原始几何和纹理未为验收简化。27 个原车发动机循环转为无损 FLAC；喇叭为项目自制双音，FLAC 与来源记录合计 2,283 字节，未标作原版 H 音效。资源逐项摘要、原始像素／PCM 核验及转换方法见 [资源记录](../../../games/racing/assets/source/nfs4/README.md)。

## 画面与控制

桌面取消底部操作面板，仪表在游戏内显示；手机仅保留游戏画面内的必要触控。完整键位说明置于「玩法速查」，可通过平台「控制器设置」改键。

| 键位 | 功能 |
| --- | --- |
| W／↑、S／↓、A／D／←／→ | 油门、制动／停稳后倒车、转向 |
| 空格、R | 手刹、行驶中复位（2 秒起步保护） |
| C | 循环近追车、远追车、引擎盖、原车驾驶舱 |
| 按住 B、按住 H | 后视、鸣笛；松开立即释放 |
| F3、F5、F7 | 最大绘距、仪表、真实后视镜 |
| F11／F12、M | 游戏视区大小、赛道地图 |

标准 Gamepad 通过平台映射输出相同逻辑输入，保留模拟扳机和摇杆。视角与显示操作可在托管、观战时使用；驾驶及鸣笛仍受手动席位权限限制。浏览器 Gamepad API 仿真不等于实体手柄兼容实测。

## 核验与限制

- 当前赛车前端 86 项检查、TypeScript／Vite 构建通过；CDN 发布工具 31 项检查通过。
- 后端已覆盖 60 场新版组合、75 场旧版组合及五车型基线自然完赛；最后喇叭期限修复后重跑其余全部检查。具体边界与产物摘要见 [后端验收](BACKEND-VALIDATION.md)。
- 六车六喇叭和完整事件环的消息最大 7,036 字节，低于预先冻结的 8 KiB 上限。
- 已保存的旧控制器配置通过真实 HTTP／SQLite 演进与共享控制器回归；新增动作保留旧映射和修订号，GET 不写数据库，见 [兼容记录](CONTROLLER-COMPATIBILITY.md)。
- 已校验的小型 FLAC 通过 CSP 允许的 data URL 交给平台原生媒体循环，不扩大全局 CSP。
- 原版 Wine 程序已关闭。未取得原版可验证赛道截图、加速／制动／转向测量，当前驾驶是依据原始参数独立重建，不声称与原版物理完全等价。

浏览器 14 项门槛按同一前端构建和赛车源码聚合通过。四项六车移动性能约 60 FPS，帧间隔 P95 为 18.2～18.5 ms；正常／150 ms 真实 TCP 延迟下各 8 次原生输入到车辆像素变化，P95 为 62.87／51.61 ms。六车真实计时自然完赛为 191.72 秒，无复位。键盘、公开改键、Gamepad API 仿真、多指触控、托管／观战和公共全屏均有重复执行记录。门槛映射、证据摘要、测试工具修正与限制见 [浏览器验收](BROWSER-VALIDATION.md)。

发布和生产更新必须另有当前提交的 CI、精确构建产物、本地 CDN 回读、正式 tag／Release 和现网核验，不能用本地验收替代。
