# 视图、地图入口与光束约定

## 空列表

公开视图中协议必需的空列表编码为 `[]`。带 `omitempty` 的可选列表在空时仍允许省略。存档中的 `nil` 切片保持原样，投影不修改存档、随机数或规则时钟。

检查范围覆盖 `View` 的所有列表字段及其嵌套列表，包括队伍、仓库、道具、塔、敌人、弹道、事件、路径、草稿候选、编队成员、目标模式、状态、命中记录和攻击配置。补齐空列表时只浅拷贝需要修改的分支，`ProjectTransient` 不新增整个世界的 JSON 往返或深克隆。

回归通过真实 `saveTeam → loadTeam`、在途弹道、攻击模式和快照恢复验证；每个有效场景比较投影前后的完整存档字节。

## 幻之岛

地图由关闭变为打开时提交权威 `mapOpen` 动作。尚未发现幻之岛时，每次打开抽取一次随机数，小于 `0.01` 则本次可见；再次打开会重新决定本次机会。投影和切换地图列表布局不抽随机。

`View.progression.secretMaps[30]` 是当前的可见性，包含本次机会与永久发现。内部 `ProgressionState.secretMaps[30]` 仅表示永久发现；内部 `mirageVisible` 保存共享的本次机会。实际进入路线 30 后才永久发现，之后打开地图不再消耗随机数。动作共用平台的席位鉴权、控制代次和 `clientInputID` 幂等。

原版路线 30 的 `unlock` 为 `0`，不增加 2400 星限制。其他秘密路线继续使用各自的发现条件。参考 `MapScene.js:438`、`MapScene.js:452` 和 `routeData.js:3117`。

## 光束

`Projectile.beamWidth` 是碰撞与绘图使用的实际全宽，`rayLength`、`targetX`、`targetY` 是实际线段长度与端点。`profile.beamWidthScale` 为倍率，大地膜为 2 倍。

| 光束 | 基础全宽 | 长度 | 寿命 | 逐敌冷却 |
| --- | --- | --- | --- | --- |
| 日光束、魂心反应炉、铁蹄光线 | 24 | 2000 | 260 ms | 140 ms |
| 破坏光线 | 50 | 2000 | 260 ms | 140 ms |
| 冰冻光束、电光 | 20 | 2000 | 260 ms | 140 ms |
| 电磁炮、流星光束 | 8 | 2000 | 260 ms | 140 ms |
| 幻象光线 | 20 | 当前射程，沿目标方向及其三个正交方向 | 260 ms | 140 ms |
| 蒸汽爆炸 | 15 | 2000 | 220 ms | 140 ms |
| 水炮 | 18 | `max(range,100)` | 4000 ms | 390 ms |
| 暗影之光 | 14 | `max(range,100)` | 4000 ms | 390 ms |
| 信号光束 | 5 | 仅附着目标 | 至死亡或脱离 | 250 ms |
| 低温炮 | 3 | 仅附着目标 | 至死亡或脱离 | 500 ms |

光束每 50 ms 扫描，第一次命中同样等待逐敌冷却。20 ms 固定步下，普通光束首次命中为 140 ms，水炮／暗影之光为 440 ms。到期先移除，不补最后一次扫描。

碰撞使用点到有限线段的距离，包含两端圆形端帽；容差为 `beamWidth / 2 + max(enemyWidth,enemyHeight) / 4`。水炮／暗影之光跟随目标移动，目标死亡后保持最后方向至原寿命结束。信号光束／低温炮每塔至多一条，仅伤害附着目标，距离达到射程加 20 时解除；其投射物 `profile.beamDurationMs` 用 `-1` 表示无固定寿命。

原版参数及碰撞对照见 `Tower.js:5508–5691` 和 `Tower.js:7676–7899`。可重复执行的隔离原版对照、字段审计、真实战斗结果与性能记录保存在 `.local/pokepath/native-verification/`。
