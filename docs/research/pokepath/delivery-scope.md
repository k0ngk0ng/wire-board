# 可玩版本交付范围

2026-11-18 用户将优先级调整为尽快游玩，允许停止非必要精修。当前交付保留独立重写、1～4 人共享合作、核心战斗、成长、电脑、触屏、存档与断线恢复。逐像素菜单调整、全技能组合矩阵和连续画面的逐帧一致性作为后续改进，不再阻挡本次可玩版本发布。

发布检查修改前列出以下失败场景：

- CI 默认收集全部研究对照测试，但干净检出没有本地原版程序和浏览器，导致正常交付无法构建。
- 为避开研究工具而同时遗漏独立架构、资源、输入、规则摘要和浏览器预测检查。
- 父级 Node 测试环境传入子进程，导致子测试被当成递归运行并跳过；必须核验实际执行数量。
- 同时运行 Wasm 性能预算套件，或在本机轨迹生成前消费轨迹，导致资源争用或读取旧数据。
- 新游戏没有安装前端检查依赖，或只修改新游戏却改变其他游戏的检查范围。
- 本地对照通过被错误标记为生产上线，或省略同次构建的 CDN 回读与服务器健康检查。

CI 使用游戏专属入口，串行运行可在干净检出重放的交付检查，原版浏览器和像素对照保留本地执行命令与既有证据。线上发布继续遵循通用部署规范。
