# 图鉴、收录和终身统计对照

图鉴读取同一房间的权威统计。敌人按资料中的稳定键记录击败、逃脱和伤害，伙伴按拥有记录的 ID 保留最高伤害、累计伤害、部署、活动时长、击败、完成波次和首领波次。头像、出战位置、进化或筛选不会修改计数。

伤害统计使用单次命中的结算伤害与命中前生命加护甲容量的较小值。护盾不扩大统计上限。事件记录独立于战斗同步日志；保存恢复、换图和波末清理保留累计统计。普通状态伤害、天气和共享伤害按实际目标分别登记。Nox 图鉴和雷霆硬盘控制详情中的额外统计行，持有前不会显示这些行。伙伴排名按每项指标独立计算，保留原版并列顺序。`FinalScene.update` 会在结算时为仍部署的伙伴增加挑战统计：挑战路线按已启用规则数计算，普通路线按原版初始值增加 7。

塔和敌人的排序各保留自己的位置。13 个塔选项、18 个敌人选项按原版顺序循环。塔可按当前语言名称、能力名称或自定义别名搜索，敌人可按名称或资料键搜索。未收录敌人继续可查看属性，但用轮廓和 `???` 标记；原版排除的两个内部敌人不出现在列表。未知图腾的回答使用图鉴输入框并向房间提交带问答阶段的操作。

参考浏览器只加载研究目录中的图鉴绘制和输入方法，产品侧用独立 React 组件与校验后的素材。48 个固定状态覆盖排序、搜索、属性、插图、动画、秘密和道具解锁；另有 320 px 的真实触控提交。报告位于 `.local/pokepath/verification/dex-render/result.json`。详细像素检查保留整幅差异：`behaviorPassed` 标明行为验收，`exactPixelCases` 只计零差异的画面；`passed` 仍要求全部像素一致。键盘焦点、字形边缘及个别动画帧的残差不被遮罩。
