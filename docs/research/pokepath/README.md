# PokéPath TD 原版对照

本次目标为用户提供的 <https://pokepathtd.org/> 所加载的 PokéPath TD v1.7.3。页面实际以 iframe 加载 <https://pokepath-game.pages.dev/>；游戏由原生 ESM、Canvas、DOM 和本地存档组成。网页抓取与静态分析没有发现战斗后端，不能据此推断任何未抓取版本的实现。

## 证据

REA 静态观察编号为 `ev_3f1f93b25cb6caeddde6e44feab209b54e75c89dc8e633a8b3477fa57324b0c2`，页面目标发现编号为 `ev_960b2320df2de06de5d2ed8d9e9368cfe39e9978e70dd55b77ccdd4a6785f79f`。前者分析了浏览器实际加载的 62 个脚本，解析失败为 0；另一个仅由已注释导入引用的旧成就模块由源码导入器保留，共 63 个模块。摘要、模块地址与限制保存在 [evidence.json](evidence.json)。这些证据证明观察到的代码与资源，不等于所有能力均已运行验收。

纯数据模块计数为 47 个地图、4007 个波次、517 个宝可梦形态、257 个收集编号、347 个敌人、254 个能力、85 个敌人被动、197 个道具定义、39 个成就、11 种天气、62 种弹道和 41 首音乐。普通地图 40 个，各含 100 波；另有 7 个单波特殊地图。逐文件来源、摘要、MIME 与图片尺寸见 [资源清单](../../../games/pokepath/assets/manifest.json)。

## 接入约束

原版有 10 种语言，中文索引为 8。升级由金币消费驱动，没有独立经验值机制。原版 `saveData` 不保留塔位、在途敌人、弹道、冷却及延迟规则事件，不能直接替代完整平台存档。连射与羽毛舞通过延迟回调创建弹道；棋子激活同样依赖延迟事件。素材尺寸影响中心点和碰撞，不能在无界面运行中统一返回占位尺寸。

原版界面也包含规则副作用，例如秘密奖励、地图与道具发放。研究时须把这些行为列为独立规则事实，不能只查看战斗类。用户已明确要求自行重写：产品使用独立 Go 规则与原生 React／Canvas 界面，原版源码只作研究对照，不嵌入网页或运行原版程序。早期原版运行器方案及其测试记录已移出产品目录，不能作为独立实现的验收证据。

用户已明确选择 1～4 人合作守图，共享队伍、金币与波次。多人接入保留同一个原版世界，通过平台席位鉴权、操作代次、事务及存档机制协调。
