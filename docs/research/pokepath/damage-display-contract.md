# 本波伤害显示约定

原版 `Area` 保存独立的本波分母，不能通过当前队伍或全部持有伙伴重新求和。伙伴已离开队伍时，它本波造成的伤害仍留在全局分母中。

| 投影字段 | 原版字段 | 口径 |
| --- | --- | --- |
| `View.totalDamage` | `Area.totalTrueDamageDealt` | 本波有伙伴归属的实际伤害 |
| `View.totalOverdamage` | `Area.totalDamageDealt` | 本波有伙伴归属、结算抵抗后但未按剩余生命截断的伤害 |
| `Pokemon.damage` | `Pokemon.trueDamageDealt` | 该伙伴当前显示周期的实际伤害 |
| `Pokemon.overdamage` | `Pokemon.damageDealt` | 该伙伴当前显示周期的未截断伤害 |

四项均为数值，初始为 `0`，随完整快照保存。伤害统计只由权威结算递增，图表不能从浮字、命中特效或当前敌人生命差额反算。现有伙伴字段没有其他规则消费者，因此直接采用原版显示周期，不增加重复的显示字段。

## 重置边界

| 操作 | 伙伴计数 | 全局分母 |
| --- | --- | --- |
| 开始新波 | 清当前队伍 | 清零 |
| 切换路线 | 清当前队伍 | 清零 |
| 收回塔，伙伴仍在队伍 | 保留 | 保留 |
| 加入或移出队伍 | 清对应伙伴 | 保留 |
| 载入编队 | 清发生移出或加入的伙伴 | 保留 |
| 百变怪变更 DNA | 清该伙伴 | 保留 |
| 保存、恢复、查看详情 | 保留 | 保留 |

个人显示清零时，同步清空它的回血伤害门槛累计；整队每波限一次的物品使用标记仍按开波重置。

## 原版核对

- `Area.js:428`、`Area.js:466`：载入路线与开波清空两个全局计数。
- `UI.js:2284`：开波清空当前队伍的两个显示计数。
- `Team.js:32`、`Team.js:58`：加入、移出队伍清空对应伙伴的两个计数。
- `Pokemon.js:433`：DNA 变更同时清空两个显示计数。
- `Enemy.js:1711`：每次真实结算同时累计伙伴和全局的实际／未截断伤害。
- `Enemy.js:1831`：共享伤害保留来源能力与持物，递归进入伤害及回血结算。
- `Enemy.js:1987`：熔岩风暴死亡爆炸以空能力进入同一伤害及回血结算。
