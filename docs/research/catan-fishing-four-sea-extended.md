# 渔夫＋四海图五六人：F06

本地实现，尚未推送或部署。适用六岛、穿越沙漠、遗忘的部落、卡坦布匹的五六人固定地图；公开配置仍使用 `islands`，扩大六岛存档及战绩使用 `six_islands`。三四人原有配方和可变布局范围保持不变。

## 规则依据与本站配方

核对 [2025 官方渔夫＋航海家组合说明](https://www.catan.com/sites/default/files/2025-07/Fishing%20on%20Catan%20w%20SEA.pdf)、2021 德文对应说明、2025 航海家五六人地图和商人与蛮族五六人第 5 页。原文地址和摘要校验值保留在 [来源清单](../board-expansion-rule-sources.json)。官方说明要求湖泊被陆地包围，四岛和布匹不放湖泊，部落渔场只在主岛。五六人增加 5、9 点渔场和 14 枚鱼筹码，合计八处渔场、44 枚筹码（含旧靴）。

组合说明仅列出三四人湖泊替换，没有给出这四张扩大海图的完整配方。复查 [官方 FAQ](https://www.catan.com/faq/traders-barbarians) 并尝试英德文搜索，没有找到对应细则。按用户授权采用以下**本站补充规则**，版本为 `wire-board-fishing-sea-5-6-v1`；不声称这些湖泊和渔场位置来自官方图示。

| 海图 | 本站五六人配置 |
| --- | --- |
| 六岛 | 不放湖泊。4／8 和 6／10 分别在两座不同的五格小岛；其余四岛各放一处 5 或 9 点渔场，保证六岛都有捕鱼位置。 |
| 布匹 | 不放湖泊，两座十三格主岛各放四处渔场；默认一侧 4／5／6／9，另一侧 5／8／9／10。第三座起始村庄领取规则、村落贸易、布匹和特殊终局不变。 |
| 穿越沙漠 | 内陆 3 点麦田（地块 ID 37）、4 点森林（32）换为双湖。原 3 点移至 2 点麦田（20），4 点移至 10 点森林（23），形成双点数生产；沙漠带和探索区域不变。八处渔场使用合法海岸。 |
| 遗忘的部落 | 主岛内陆 12 点牧场（28）、2 点麦田（33）换为双湖，移除这两枚生产数字；八处渔场限主岛。后续强盗移动限主岛，事件逃跑保留既有沙漠退路；部落奖励港口不能覆盖渔场。 |

第一块湖在 2／3／11／12 产鱼，第二块在 4／10 产鱼。双湖均有六个陆地邻居，不使用靠海位置。村庄产一枚、城市产两枚；海盗阻断对应渔场，强盗阻断所在湖。原剧本胜利条件保留，旧靴只增加持有者的分数门槛。

固定配方在存档中保存 `fishing.map.seaRecipe`，历史记录保存 `fishing_sea_recipe`。开局日志、等待房提示和玩法速查标明本站配置。可同时开启事件牌、友善强盗和港口霸主；Helpers、海图骑士仍归 F08、F09，不通过 F06 绕过限制。

## 实现与验证

- 4 图 × 2 人数 × 8 次生成，共 64 张地图：八处渔场、44 枚筹码、岛屿分组、双湖位置、双点数、港口与渔场不重叠、反序边参数归一化、JSON 恢复通过。湖泊逐点数／村庄与城市产鱼、强盗与海盗阻断、损坏存档拒绝通过；定向 race **4.628 秒**。
- **8 场自然完整引擎对局，37.842 秒通过**：四图各五六人，六人同时加事件、友善、港口。每 43 步保存恢复，所有对局自然结束，没有注入资源或分数。
- **8 场自然完整 HTTP 对局**：四图各五六人，均加事件、友善、港口。沙漠／部落／布匹六局分别在 **18.32／14.97／16.66 秒**通过；六岛最终两局 **12.79 秒**通过。覆盖鱼筹码保密、资源与发展卡库存、观战、回应超时、持续托管、配对行动、重启、特殊胜利、版本战绩及重复结果幂等。
- 扩大配置验证覆盖七种海图目录、四人切五人、权限、就绪重置、保存重启、实际人数开局、重开和缩回四人。原版／探索者隔离及损坏配方验证 **3.882 秒**通过；原捕鱼相关引擎回归 **26.085 秒**通过。
- **16 场原三四人完整 HTTP 回归，46.80 秒通过**：四岛、沙漠、部落、布匹各三四人两场；原允许的可变布局照常。独立捕鱼、扩大配置和该批整局合计 **48.223 秒**通过。
- 前端 **190 项测试**通过，规则上下文以运行中存档为准，旧房间草稿不会给基础局附加本站配方。前端构建、Go 构建、game/server 静态检查及差异检查通过。

首轮 HTTP 检查沿用“四岛”名称，六岛在开局和历史断言分别暴露旧预期；修正为实际 `six_islands` 后补跑通过，失败批次没有计为通过。浏览器发现布匹侧栏仍写每岛三处渔场，已改为按实际人数显示三／四处；玩法标题区分原固定布局与本站捕鱼配方。

## 页面验收

实际浏览器使用独立本地服务器和普通公开操作：手机创建六席六岛捕鱼房间，添加电脑、开始并点选建村；结束／重开后依次切换沙漠、部落、布匹。四图均查看桌面 1440×1000 与手机 320×740 或 390×844 的地图，双湖、双点数、渔场、资源及布匹库存可见。手机放大地图和规则浮层可用，检测视口无页面横向溢出；部落页面 22 种 SVG 图片从既有 CDN 解码成功，浏览器无脚本错误。

浏览器仅作局部操作和布局验收，不计自然完整局。全程静音浏览器，并通过页面关闭站内音效；未下载或播放网络音频。

修正文案后重建并重启本地服务，通过页面确认「每岛四处渔场」及「固定布局＋本站捕鱼配方」均生效，原房间恢复成功。
