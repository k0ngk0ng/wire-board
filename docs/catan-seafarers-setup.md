# 航海家剧本配置与正式开局

**最新公开状态（2026-10-08，未发布）**：九种航海家剧本现支持三至六人公开创建与等待切换，均可加Helpers；城市骑士支持新海岸、四／六岛、迷雾、沙漠、布匹、奇迹、新世界三至六人；本站事件牌支持前四种三至六人及Helpers。五六人渔夫仍仅迷雾、奇迹、新世界，但可直接开关并保留地图和人数。五六人海图与港口霸主／友善强盗、其他事件组合等仍继续实施；下文的“未开放／内部”是此前阶段状态，最新验证见文末。五六人新海岸的主岛数列明确标注本站配置，不宣称2025实体字母背面已核验。

规则使用 `docs/board-expansion-rule-sources.json` 固定的2025航海家及五至六人扩充版本。`NewCatanSeafarers` 是共用初始化入口，负责人数／布局／规则版本校验、地图及特殊组件、起始阶段与初始分数。它不表示整批扩展已经发布。

## 房间与界面

房间保存独立的 `catanSeafarers` 设置。公开三／四人房间通过 `catanScenario` 选择 `shores`、`islands`、`fog`、`desert`、`tribe`、`cloth`、`pirate_islands`、`wonders`、`new_world`，服务端生成对应的规范化航海设置；公开创建接口仍不直接接收 `catanSeafarers`。九种剧本可加 Helpers，海盗群岛只提供固定布局，新世界使用开局前确认图，其余七种可选固定／可变布局。其他人数和组合仍需内部预置设置。房主权限、版本及nonce检查沿用房间命令，已开始的对局不可改配置。

实际配置变化取消全部真人准备，保留电脑准备；相同配置不重置，也不重抽新世界地图。离开新世界会清除旧草稿；重新选择新世界才生成新图。切换五至六人扩充会选用相应人数的官方默认布局，并重置准备；新世界同步变为42／63格。非法请求在房间副本上拒绝，不影响保存状态。等待状态重启保留配置、地图和准备。

等待房间显示剧本和支持的布局、对应胜利条件及人数说明。非房主只读。未应用的新世界地图草稿会同时禁用剧本、布局、扩充、准备与开始，防止丢失草稿或误用旧地图。公开九种航海剧本共用普通剧本选择器，另显示布局选择；切回基础会清除航海设置并保留 Helpers。切出新世界会清除地图，重新进入才生成新图，同值选择不重抽。公开入口暂不提供五六人或参考事件牌等其他组合。
