# 航海家剧本配置与正式开局

规则使用 `docs/board-expansion-rule-sources.json` 固定的2025航海家及五至六人扩充版本。`NewCatanSeafarers` 是共用初始化入口，负责人数／布局／规则版本校验、地图及特殊组件、起始阶段与初始分数。它不表示整批扩展已经发布。

布局ID为 `fixed`、`variable`、`prepared`。五至六人新海岸的可变布局只随机主岛并使用数字螺旋，不能理解为全部岛屿随机化。新世界必须传入等待阶段的确认地图，缺失时拒绝开局，不临时生成另一张。其他剧本若意外带入新世界地图则拒绝，而不是静默忽略。

选择器中的 `islands` 表示岛屿剧本系列；五至六人的实际状态／战绩仍保存既有 `six_islands` 身份并显示“六岛”。不修改旧存档的剧本ID。`catan-seafarers-2025` 与实际布局保存在游戏状态和战绩中；基础旧局不添加这些字段。

固定奇迹始终先选沙漠；可变奇迹也通过同一状态级入口。可变布匹先选12号强盗起点；固定布匹按印刷位置开始。新世界先轮流放港口；海盗群岛保留预设村庄／船只，开局已有的村庄立即计入分数。布匹三轮起始建设、其他剧本两轮建设及Helpers第二组之后领取均保留，不绕过必需阶段。

## 房间与界面

房间保存独立的 `catanSeafarers` 设置。只有已内部预置该设置的等待房间，才能通过 `catan_seafarers` 命令切换剧本／布局；公开创建接口不接收此字段，普通房间也不会获得选择器目录。房主权限、版本及nonce检查沿用房间命令，已开始的对局不可改配置。

实际配置变化取消全部真人准备，保留电脑准备；相同配置不重置，也不重抽新世界地图。离开新世界会清除旧草稿；重新选择新世界才生成新图。切换五至六人扩充会选用相应人数的官方默认布局，并重置准备；新世界同步变为42／63格。非法请求在房间副本上拒绝，不影响保存状态。等待状态重启保留配置、地图和准备。

已内部预置的等待房间显示剧本和支持的布局、对应胜利条件及人数说明。非房主只读。未应用的新世界地图草稿会同时禁用剧本、布局、扩充、准备与开始，防止丢失草稿或误用旧地图。普通创建／等待房间继续只显示既有配置。

## 验证与未决项

- 100组开局覆盖3–6人、全部官方支持布局与普通／Helpers，通过统一入口运行合法电脑动作直到原先手首次掷骰。检查地图、阶段、全部起始建筑、助手、资源守恒、周期恢复、公开规则身份及观战手牌隐私。
- 25组真实HTTP配置开局覆盖3／6人全部支持布局，用正式准备／开始及生产超时处理完成所有起始步骤，检查每步能继续及首次掷骰获得完整120秒。
- HTTP配置测试覆盖未开放创建／普通房间激活拒绝、房主权限、非法请求原子拒绝、同配置、准备重置、过期版本、人数变化、地图清理、重启、开局冻结和战绩版本／布局。
- 新世界4局、奇迹4局、海盗群岛8局的完整HTTP测试改为只预置等待配置，再走正式开局；不在开局后替换游戏状态。16局在完整规则、手动动作／托管／超时、私人视图及阶段性重启后正常结算（本轮90.503秒）。
- 真实Go服务／WebSocket浏览器在1440×1000桌面、390×844和320×740手机验证：切换海盗群岛后真人取消准备／电脑保持准备；五至六人显示六岛及受限布局；新世界随人数切换63／42格，离开后清理旧地图；有未应用草稿时实际禁用剧本、扩充和准备，撤销后恢复。客人只读、刷新保留设置。两名真人准备后通过正式“开始游戏”进入49格奇迹可变图＋Helpers的 `catan_wonders_start`，没有跳过沙漠选择。页面无横向溢出，浏览器无运行错误。
- 视觉检查修正原有扩展复选框被通用输入框样式撑大的问题：复选框固定18px，标签保留点击空间；桌面和窄屏文字可读。
- 最终卡坦／机器人全量回归通过（game329.957秒、server120.588秒），静态检查、配置HTTP定向race（3.944秒）、前端构建和4项既有动画测试通过。最后补充公开创建拒绝断言后配置HTTP再次通过（0.872秒）；构建仍保留既有大包体提示。临时浏览器、验收服务及测试入口清理，不提交测试截图／配置／数据库。

尚需最终组合验收及公开创建入口。布匹公共库存耗尽的官方处理、五至六人基础数字牌字母映射的独立核验等未决项保持开放；本轮配置检查不能替代这些规则证据。整批主要扩展尚未完成，也没有发布。

## 统一玩法速查

九个剧本系列共用 `CatanRules`，覆盖特殊建设、探索／贸易／海盗／奇迹、目标分数及共同建设费用、发展卡、船只、配对回合、Helpers、计时和隐私。等待房间读取已选剧本；开局后只按实际存档读取，不让旧房间草稿、容量或扩充设置覆盖实际规则。五六人岛屿显示六岛；海盗实际三人局显示移除胜利点卡，等待四人容量则同时说明三／四人的区别。普通基础局不会因残留草稿显示航海家规则。

三项上下文测试覆盖等待配置、实际局优先与旧存档回退，连同四项既有动画测试全部通过。真实Go服务／WebSocket浏览器分别在三四人＋Helpers、五六人无Helpers配置下遍历全部九个选择，确认剧本名称、目标和条件段落；实际开始三人海盗局后再次核对人数和发展卡说明。1440×1000、390×844、320×740无横向溢出，长速查内部滚动，关闭按钮始终可见；Escape关闭后焦点恢复，无浏览器运行错误。验收服务正常退出（测试358.80秒），前端构建通过，仅有既有大包体提示。临时测试入口、服务／浏览器与截图已清理。

速查仅说明已有依据的规则，不能替代布匹公共库存耗尽边界或全部兼容组合的规则验收；未因此开放普通房间或发布。
