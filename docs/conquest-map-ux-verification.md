# 征服时代地图操作优化

本轮保留第一版平面分区、领土配色和轻纹理，保留用户认可的地图内图标按钮；取消立体地形方向。随后按用户要求将新房间默认地图改为世界，并增加美国、中国地图。原有世界／欧洲数据、核心战斗与经济规则、电脑策略保持原有实现；新增地图接入完整规则验收。

## 最终交互

- 新房间默认世界地图，可选世界、欧洲、美国、中国。美国 51 个地区包含 50 州与华盛顿特区，中国 34 个省级玩法区域；阿拉斯加、夏威夷与港澳采用插图／放大布局。既有世界、欧洲地图文件未改，旧房间地图不被默认值覆盖。
- 点己方领地后直接通过图标征兵、进攻、筑堡。常驻数量输入框、目标下拉和每块中立领地的数字矩形移除；兵力文字与实际军队相邻。
- 进攻每次派出剩余可移动兵力的一半；连续点同一目标继续追加剩余的一半，例如 1,000→500→250→125。快速点击依次核对服务端订单，不重复使用旧兵力。海费不足以派出半数时明确提示，不静默改成较少兵力。
- 短按征兵最多增加 1,000，长按一次征满合法数量且仍只使用一次行动点；筑堡长按可直接建城镇，不要求先筑堡。长按不可行不会退化成短按扣费；Shift+Enter 提供键盘等价入口。
- 手机首次进入靠近己方领地；选择后由应用确保行动图标处于实际可视区。普通连续点进攻目标不移动镜头。
- PC 左键可从领地或兵力文字起拖，包括尚未放大的全图状态。pan／zoom／locate 共用视口 25% 的有界平移余量，复位精确居中；小地图显示实际可见交集。
- 手机连续双指、双指改单指、取消手势和后续点击均保留；镜头按帧更新 SVG 变换，结束后才提交 React 状态。视窗外已知军队预先存在，由 SVG 裁切，拖入时无需等待松手才补画。

## 验证与证据

先写失败场景、针对性测试和真实浏览器基线，再实现。旧版从地区文字开始的持续双指放大仅约 1.04 倍，未放大全图的拖动为零位移，均已实际复现。

最终真实房间验收通过 **913 项**，保留 **197 条原生输入记录、98 组逐帧测量**。覆盖四张地图、1440px PC、320／390px 手机视口、未放大全图鼠标拖动、路径／文字起拖、越界松手、双指、取消、缩放后操作、重复半兵、实际筑堡、暂停／托管、重连、结算关闭重开、8 席迷雾和观战。真实创建弹窗确认世界默认值与四图选择；华盛顿特区、夏威夷、阿拉斯加、港澳、台湾、海南均在放大后原生点选，按标签所在实际陆块计算命中尺寸，不用包含远方小岛的总外框冒充可点区域。

世界地图 320px、4 倍 CPU 降速的代表性拖动／双指采样中，p95 帧间隔约 16.7ms，镜头保持连续位置变化；不能用静止画面的帧率替代运动性能。CPU 降速只是补充压力测试，不等于手机真机或 WebKit 验证。

新增地图后，**168 组**自然完整电脑对局覆盖四图 × 2～8 人 × 三档难度 × 两种迷雾设置，全部结束于真实规则终局，完成 4～48 轮、93,419 个动作／计时步骤。另有 **28 场真实 HTTP 完整对局**覆盖四图各人数，并逐步重放核对快照摘要。地图离线重建、来源／许可摘要、全图连通与开局配置检查通过。

额外回归覆盖：已成功派兵撤销后再点；首次真实请求被明确拒绝后重试；150ms 网络延迟下 20ms 连续点击；长按结束后不多发短按；不可负担的建城镇长按／快捷键不误建要塞；未知兵力、本人负债、零值及实际控件对比度。

最终报告、输入、截图及源码绑定在 `.local/conquest-map-ux/browser/`；独立镜头证据在 `.local/conquest-camera/`，独立长按证据在 `.local/conquest-hold/`。`source-binding.json` 记录实际验收源码和报告摘要，早期阶段报告不作为最终完成依据。

四图完整电脑矩阵在 `.local/conquest-regional/release-bots/`，HTTP 记录在 `.local/conquest/http/`。交付归档仅保留最终记录、必要基线、截图与说明；浏览器 profile、构建缓存、上游下载和中间制图环境不作为交付产物。

发布按 main 的匹配提交构建与 tag 复用流程执行；服务器更新使用已授权的既有更新／备份脚本。连接信息只保存在主工作区 `.local/server-access.md`，不写入 AGENTS.md。
