# 三款扑克牌游戏实施与验收

用户目标：完整实现上海升级（一副四十分／两副八十分，默认两副）、江苏掼蛋、斗地主（四人上海欢乐三打一）。四人斗地主四个王称「王炸」，大于所有炸弹，包括八张炸弹。默认传统英式牌面，支持换肤；自己始终在下方。分类、素材来源与 OSS、平台音效、新游戏默认下架均属于交付范围。

## 规则版本冻结

- 当前 `doudizhu-shanghai-huanle-v2`：仅四人、两副牌，每人 25 张，8 张底牌仅地主可见。一档／二档／三档、农民炸弹额度、荒番／明王／头撩／摊打、单／双报到及结算详见 [官网规则核对](research/huanle-sandayi.md)。新局不套用旧版个人加倍、春天或炸弹翻倍。

- 旧存档 `doudizhu-classic-v1`（不再创建）：三人一副牌，17 张＋3 张底牌，地主 20 张；叫分 1／2／3；炸弹四张，双王王炸。普通顺子≥5，连对≥3 对，飞机≥2 组，连续主体不含 2／王。支持三带一、三带对、飞机单／对翅膀、四带两单／两对；两单可组成一对，不可同时携带双王，四张同点不能充当两个对子。飞机翅膀不能包含主体点数、炸弹或与主体连续的三张。
- 旧存档 `doudizhu-shanghai-v1`（不再创建）：四人两副牌，25 张＋8 张底牌，地主 33 张；一个地主对三位农民。三带对子、飞机只带对子或不带，不支持三带一、单翅膀、四带二。允许同色王对。4～8 张同点炸弹按张数再按点数，四王王炸最大。默认允许单顺（R5），可在房间设置关闭；四／五张炸弹不翻倍，六张以上和王炸各翻一次。三次不出重新领出。两种人数各自校验模式，不允许以四人规则三人开局。
- 以上旧版斗地主底牌公开；全不叫重发，不强迫指定地主。个人加倍为可选项，默认关闭。春天／反春、积分和固定副数结算均实施，不以占位结果代替实际打完。
- `guandan-jiangsu-2017-v1`：江苏 2017 基线，27 张、对家搭档、红心级牌百搭但不能代王。头二／头三／头末升 3／2／1，A 必打且头二或头三过 A。五张顺子、三连对、二连三；同花顺介于五张和六张炸弹之间，四王最大；支持 9／10 张百搭炸弹。实现进贡、还贡、双下、合持两大王抗贡、对家接风。还贡按当前牌序≤10 排除级牌和王，无满足条件牌时退回最小非配牌（公开的线上补充条款）；回贡仅交接双方可见。默认不启用失败三次退级。
- `shengji-shanghai-single-v1`：54 张，每人12、底6；上海单副计分 0庄+2、5～35庄+1、40～75上台不升级、80～95攻+1、≥100攻+2；抠底×2。特殊四同领出和无分牌申请重发单独实现与说明，不借用斗地主炸弹判定。
- `shengji-shanghai-double-v1`：108 张，每人25、底8；0庄+3、5～35庄+2、40～75庄+1、80～115上台、此后每40攻+1；同门同点对子、连续对子拖拉机、完整结构跟牌、甩牌与抠底。底分默认按末墩张数×2（R1），房间可切换按最大结构的指数方式。牌型强弱与抠底倍率分开计算，不能混用不同来源。默认无常主2、无勾J；无主仍保留级牌为主。长局从2到过A，提供限定副数休闲局。
- 三款均保存规则版本与规范化配置，部署／重连不改当前规则。所有差异必须出现在等待房间与玩法说明中。

## 修改前列出的失败场景

1. 54／108 张牌重复或遗失；双副两张同图牌共用 ID；界面能提交不属于自己的牌。
2. 服务端把其他手牌、底牌、牌堆、随机种子或回贡牌泄露给其他席位／观众；机器人利用其他玩家手牌。
3. 两种斗地主混牌型、四王小于八炸、4/5 炸错误翻倍、农民人数/得分不正确、连过计数错误、全不叫死循环。
4. 升级误用同点不同花对子、错跟主副／结构、无效甩牌误扣手牌或改变时限、抠底倍数错、单副照搬双副分档、上台/换庄/过A错误。
5. 掼蛋百搭代王、同牌多解释被强改、贡错最大牌、回贡泄露、合持两大王未抗贡、已出完席位仍等待、接风和过A错误。
6. 时限、断线托管、重连、再来一局、重复 nonce、过期窗口、同时抢主/进贡导致多次扣牌或延长他人时限。
7. 玩家视角固定在房主；四人地主对面被错当队友；手机 27／33 张不可辨认或操作被遮挡。
8. 换肤改变牌 ID／选牌、图片错位／缺王、牌背泄露牌值、音效绕过静音、动画重连重播。
9. 分类筛选绕过上下架、长名称／大量游戏挤出 320px 屏幕、创建人数与规则不一致。

- 每款独立 `games/<id>/`，不可互相导入业务规则；共享仅限无规则的纸牌 UI、素材、偏好和平台端口。
- 实现前编写规则边界案例及真实协议验收；保存失败再通过的结果。真实 HTTP 覆盖注册、后台上架、开房、所有席位私有视图、行动、重连和自然结算；明确区分定点夹具与自然整局。
- 升级两副数、当前四人斗地主以及掼蛋均须有自然完整局；旧斗地主两人数保留恢复回归；机器人与提示不得返回非法牌。
- 真实浏览器覆盖全席位视角、320/390px、33 张手牌、实际选牌/出牌/贡还/扣底、切皮肤、动效及平台静音，并保存截图与检查结果。
- 英式牌面、备选皮肤、原创牌背、三款统一风格封面和纸牌音效有来源、许可证、原件和成品 SHA-256；上传 OSS 后回读确认；本地回退可用。
- 大厅/创建/管理分类下拉与搜索组合；所有新游戏仍默认下架。
- main 检查/构建，版本 tag 复用已验证产物发布，按既有授权更新服务器并保留已有上下架设置。

## 已固定的线上细则

- 升级发齐手牌后集中亮主。反主顺序为单张级牌、同花同点级牌对子、同色双王；两种王对同强度，不能同级反主、自反或自保。后续无人亮主翻底定主；双副首副无人亮主重发。单副无分牌重发后，双方按己方级牌抢庄。
- 升级跟牌保留完整结构，无完整结构则优先最长部分拖拉机再跟对子；甩牌含对家可破，不能成立时直接拒绝，手牌、轮次、得分和时限均不变。按用户确认不收回、不罚分；旧配置中的罚分选项归零，不回改历史得分。
- 升级可选最大结构指数抠底：单张 ×2、对子 ×4、两连对 ×8、三连对 ×16，继续按 `2^(连对数+1)` 计算。默认仍为末墩张数 ×2；单副固定 ×2。
- 斗地主单副按阵营共同判胜负，旧局的个人加倍只改变得分金额；多副整场才按累计积分排名。
- 掼蛋的任意手动选牌可向服务器请求私密牌型预览，玩家明确选择百搭解释。预览不出牌、不延长时限、不向其他玩家泄露。
